## 專案標籤

可以為專案加上標籤來分類與管理。

### 與舊版 emoji 徽章的差異

- 各專案的 emoji 徽章（emoji + 背景色）已由標籤系統取代
- 更新時，既有的 emoji 徽章會自動轉換成標籤
- 之後無法再為個別專案設定 emoji 徽章

<Callout type="warning" title="注意事項">
標籤名稱是依 emoji 產生的。原本使用相同 emoji 的專案，即使背景色不同也會整合成同一個標籤。
</Callout>

## 建立標籤

### 方法 1. 從標籤管理建立

<Steps>
  <Step>
    ### 選擇標籤管理
    在工作區中選擇 `標籤管理`。
  </Step>
  <Step>
    ### 建立標籤
    點選建立標籤。
  </Step>
  <Step>
    ### 輸入名稱
    輸入名稱。（例：行銷、緊急、已完成）
  </Step>
  <Step>
    ### 選擇顏色後儲存
    選擇顏色並儲存。
  </Step>
</Steps>

### 方法 2. 直接從專案建立

<Steps>
  <Step>
    ### 點選新增標籤
    點選專案卡片／清單的 `+ 新增標籤`。
  </Step>
  <Step>
    ### 點選建立標籤
    在標籤選擇的浮出視窗中點選建立標籤。
  </Step>
  <Step>
    ### 輸入名稱與顏色後儲存
    輸入名稱與顏色並儲存。
  </Step>
</Steps>

<Callout type="warning" title="注意事項">標籤名稱在同一個工作區內不能重複。</Callout>

## 為專案加上標籤

### 建立專案時加上

- 在建立過程中即可選擇標籤
- 可以用欄位標頭的新增（+）按鈕快速建立
  - 狀態欄：只能在未發布欄建立
  - 標籤欄：建立時會自動套用該標籤

### 事後加上 -（1）逐一加上

點選專案卡片／清單的 `+ 新增標籤` 按鈕

### 事後加上 -（2）為多個專案批次加上

<Steps>
  <Step>
    ### 選擇專案
    按住 `Shift` 選取多個專案。
  </Step>
  <Step>
    ### 點選標籤
    在下方的動作列點選標籤。
  </Step>
  <Step>
    ### 新增或移除標籤
    新增或移除標籤。
  </Step>
</Steps>

## 合併標籤

可以把相似的標籤整理成一個。

<Steps>
  <Step>
    ### 開啟標籤管理
    開啟標籤管理。
  </Step>
  <Step>
    ### 選擇要合併的標籤
    選擇要合併的標籤。（不支援 Shift 多選）
  </Step>
  <Step>
    ### 點選合併
    點選合併。
  </Step>
  <Step>
    ### 完成整合
    會整合成最後選取的那個標籤。
  </Step>
</Steps>

範例：`行銷 / MKT / 行銷團隊 → 行銷`

## 專案篩選

### 依狀態篩選

- 未發布：尚未發布
- 發布中：正在收集回覆
- 問卷結束：已截止的專案

### 依標籤篩選

- 選取多個標籤時：只要包含其中之一就會顯示
- 選取「無標籤」時：只顯示沒有標籤的專案

### 複合篩選

同時選擇狀態 + 標籤時，只會顯示**同時符合兩個條件**的專案。
- 範例：`發布中 + 行銷` → 發布中且帶有行銷標籤的專案

## 檢視模式

### 卡片檢視／清單檢視

| 卡片檢視 | 清單檢視 |
| --- | --- |
| 卡片形式 | 清單形式 |
| 一眼掌握資訊 | 顯示更多專案 |
| 預設設定 | 結構單純 |

### 以群組方式檢視

#### 欄（群組）

- 依狀態
- 依標籤

#### 列（子群組）

- 不分組
- 依狀態
- 依標籤

### 排序依據

- 修改日期
- 建立日期
- 回覆數
  （可切換遞增／遞減）

### 儲存檢視設定

- 依工作區自動儲存
- 重新整理後仍會保留
- 可用重設按鈕還原預設值

## 應用範例

1. 依團隊管理（建立團隊名稱標籤 → 用篩選查看各團隊的專案）
1. 當成看板使用（檢視模式：欄 = 狀態 → 用拖曳變更狀態）
1. 整理已完成的專案（篩選問卷結束 → 多選 → 移至封存）
2. 整理重複標籤（標籤管理 → 合併）

## 主要名詞

| 名詞 | 說明 |
| --- | --- |
| 標籤 | 用來分類專案的標記 |
| 篩選 | 依條件檢視專案 |
| 分組 | 依類別歸類 |
| 批次動作 | 同時對多個專案操作 |
| 封存 | 存放非使用中專案的空間 |
