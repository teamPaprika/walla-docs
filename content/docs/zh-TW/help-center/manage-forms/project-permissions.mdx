在 **Enterprise 方案**團隊中，具備「編輯角色和權限」權限的擁有者、管理者及獲授權角色，可在個別問卷的 **問卷設定 → 專案權限** 中，為不同問卷分別指定各角色的操作權限與查看回覆範圍。

## 專案權限設定步驟導覽

依照下列步驟即可在個別問卷中設定角色的操作權限與查看回覆範圍：

<Steps>
  <Step>
    ### 開啟問卷設定

    在專案編輯畫面右上角點選齒輪（**問卷設定**）圖示。
  </Step>
  <Step>
    ### 展開「專案權限」並選取角色

    在左側選單點選 **專案權限** 即可展開角色清單；選取要設定的角色後，右側會開啟整合顯示 **編輯**、**整合**、**分享**、**回覆** 四個群組的權限設定面板。
  </Step>
  <Step>
    ### 設定角色的操作權限

    針對工作區角色設定中設為 **依專案設定** 的 7 項操作權限，可在此切換開關決定是否僅針對這份問卷開放；已在工作區固定為 **全部允許** 或 **不允許** 的權限，則會以鎖定的唯讀狀態一併顯示。
  </Step>
  <Step>
    ### 在「回覆 → 查看回覆」選擇存取範圍

    在 **回覆** 群組的 **查看回覆** 下拉選單中，為該角色選擇 **不允許**、**所有回應** 或 **符合條件的回應**。
  </Step>
  <Step>
    ### 設定條件規則並點選底部「儲存」

    若選擇 **符合條件的回應**，請設定如「居住地區 等於 首爾」等規則，並點選畫面下方的 **儲存** 按鈕；變更會立即套用，與問卷是否重新發布無關。
  </Step>
</Steps>

## 設定各角色的操作權限

在 **問卷設定** 左側選單中點選 **專案權限** 即可展開角色清單；選取角色後，會開啟整理為 **編輯**、**整合**、**分享**、**回覆** 四個群組的權限畫面。

在工作區 **角色與權限** 中，只要將下列 7 項操作權限設為 **依專案設定**，即可在此畫面中開啟或關閉對應開關。

此畫面中的 7 項操作權限如下：

| 群組 | 權限名稱 | 說明 |
| --- | --- | --- |
| **編輯** | **複製專案** | 可複製此專案。 |
| **編輯** | **編輯專案** | 可編輯此專案並加上標籤。 |
| **編輯** | **管理專案** | 可移動、封存或刪除此專案。 |
| **整合** | **管理自動化** | 可檢視、建立、修改與刪除此專案的自動化流程。 |
| **分享** | **傳送問卷** | 可在此專案中新增、編輯、刪除收件人並傳送問卷。 |
| **回覆** | **刪除回應** | 可刪除此專案的回應。 |
| **回覆** | **下載回應** | 可下載此專案的回應。 |

<Callout type="warn" title="注意事項">
在工作區角色設定中已固定為 **全部允許** 或 **不允許** 的權限，也會一併顯示在此畫面中，但會處於停用的唯讀狀態（依工作區設定顯示為 **允許** 或 **不允許**）。若要改為依專案分別開啟或關閉，請先前往 [工作區設定 → 角色與權限](/zh-TW/docs/help-center/team-workspace/managing-workspaces) 將該權限變更為 **依專案設定**。
</Callout>

## 查看回覆存取範圍

在 **回覆** 群組的 **查看回覆** 項目中，可透過下拉選單為在工作區角色設定中將 **檢視回應** 設為 **依專案設定** 的角色，設定在此問卷中可查看的回應範圍：

- **不允許**：無法查看此問卷的回應。（預設狀態）
- **所有回應**：可查看此問卷的所有回應。
- **符合條件的回應**：僅可查詢符合指定條件規則的回應。

即使該角色擁有此問卷的刪除回應或下載回應權限，實際可刪除與下載的範圍仍會限制在此處允許的回應集合內。調整完操作權限開關與查看回覆規則後，點選畫面下方的 **儲存** 按鈕即可立即套用變更。

關於條件規則的撰寫方式，以及在回覆表、回覆統計與數據分析中的實際運作差異，請參閱 [回應查詢管理](/zh-TW/docs/help-center/security/response-access-control) 指南。
