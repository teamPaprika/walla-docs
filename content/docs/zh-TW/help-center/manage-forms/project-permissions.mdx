在 **Enterprise 方案**團隊中，具備工作區角色管理或專案權限管理權限的擁有者、管理者及獲授權角色，可在個別問卷的 **問卷設定 → 專案權限** 分頁中，為不同問卷分別指定各角色的操作權限與回應存取範圍。

## 專案權限設定步驟導覽

依照下列步驟即可在個別問卷中設定角色權限與回應存取範圍：

<Steps>
  <Step>
    ### 開啟問卷設定

    在專案編輯畫面右上角點選齒輪（**問卷設定**）圖示。
  </Step>
  <Step>
    ### 選擇「專案權限」分頁

    在 **Enterprise 方案**團隊中具備管理權限的成員，會在左側選單看見 **專案權限** 分頁並可點選進入。
  </Step>
  <Step>
    ### 指定「此專案的角色權限」

    針對工作區角色設定中設為 **依照專案設定** 的 7 項操作權限，可在此切換開關決定是否僅針對這份問卷開放。
  </Step>
  <Step>
    ### 選擇各角色的「回應存取」範圍

    在 **回應存取** 區塊中，為每個角色選擇 **不允許**、**所有回應** 或 **符合條件的回應**。
  </Step>
  <Step>
    ### 新增條件規則並儲存

    若選擇條件式查詢，請設定如「居住地區 等於 首爾」等規則並點選 **儲存**；變更會立即套用，與問卷是否重新發布無關。
  </Step>
</Steps>

## 此專案的角色權限

在工作區 **角色與權限** 中，只要將下列 7 項專案層級權限的其中一項以上設為 **依照專案設定**，該角色就會出現在 **此專案的角色權限** 清單中。

此畫面中可開啟的 7 項權限如下：

| 權限名稱 | 說明 |
| --- | --- |
| **複製專案** | 可複製此專案。 |
| **管理專案** | 可移動、封存或刪除此專案。 |
| **編輯專案** | 可編輯此專案並指派標籤。 |
| **管理自動化** | 可檢視、建立、修改與刪除此專案的自動化流程。 |
| **發送問卷** | 可在此專案中登錄、修改、刪除收件人並發送問卷。 |
| **刪除回覆** | 可刪除此專案的回覆。 |
| **下載回覆** | 可下載此專案的回覆。 |

<Callout type="warn" title="注意事項">
在工作區角色設定中已固定為 **允許（所有專案）** 或 **不允許** 的權限，不會顯示於個別專案設定中。若要改為依專案分別控管，請先前往 [工作區設定 → 角色與權限](/zh-TW/docs/help-center/team-workspace/managing-workspaces) 將該權限變更為 **依照專案設定**。
</Callout>

開啟所需角色的開關後，點選 **儲存** 即可立即套用變更。

## 回應存取

在 **回應存取** 區塊中，可針對在工作區角色設定中將 **檢視所有回應** 設為 **依照專案設定** 的角色，設定在此問卷中可查看的回應範圍。

- **不允許**：無法查看此問卷的回應。（預設狀態）
- **所有回應**：可查看此問卷的所有回應。
- **符合條件的回應**：僅可查詢符合指定條件規則的回應。

即使該角色擁有此問卷的刪除回覆或下載回覆權限，實際可刪除與下載的範圍仍會限制在此處允許的回應集合內。

關於條件規則的撰寫方式，以及在回覆表、統計與數據分析中的實際運作差異，請參閱 [回應查詢管理](/zh-TW/docs/help-center/security/response-access-control) 指南。
