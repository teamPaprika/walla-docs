## 限制重複回覆
想避免同一個人對同一份問卷重複作答時，可以使用重複回覆限制功能。
限制方式有兩種，也可以同時開啟。

|方式|判定基準|特性|
|---|---|---|
|瀏覽器重複回覆防止|填答者的瀏覽器|設定簡單，但換瀏覽器或用無痕模式仍可再次作答|
|每位已驗證使用者限一次|已驗證的電子郵件、電話號碼或外部會員 ID|即使換裝置限制仍然有效|

## 設定方式

<Steps>
  <Step>
    ### 前往填答者分頁
    點選編輯畫面右上角的 `⚙️` 圖示開啟問卷設定，然後在左側分頁清單選擇 `填答者`。
  </Step>

  <Step>
    ### 選擇限制方式
    在 `重複回覆` 區塊開啟想要的開關。區塊上方的摘要句可以讓你立即確認目前的設定狀態。

|設定狀態|顯示的摘要句|
|---|---|
|全部未開啟|同一個人可以重複作答|
|開啟 `每位已驗證使用者限一次`|每個已驗證的電子郵件、電話號碼或外部會員 ID 只能作答一次|

### 1. 瀏覽器重複回覆防止

- 已在同一個瀏覽器完成作答的人無法再次作答。
- 完成回覆後問卷頁面不會開啟，並會顯示已提交過回覆的說明訊息。
- 換瀏覽器、換裝置或使用無痕模式時仍可再次作答。

### 2. 每位已驗證使用者限一次

- 以已驗證的電子郵件、電話號碼或外部會員 ID 為基準，只能作答一次。即使換裝置或瀏覽器限制依然有效，能更準確地防止重複。

- 要開啟這個開關，必須有能識別填答者的方式。在沒有驗證方式的狀態下開啟時，系統會一併開啟電子郵件驗證。

- 識別基準會依設定而不同。
	- 在 `填答者` 分頁使用電子郵件驗證時 → 已驗證的電子郵件
	- 在 `填答者` 分頁使用電話號碼驗證時 → 已驗證的電話號碼
	- 在 `嵌入` 分頁使用主機簽章權杖 + 會員識別時 → 權杖中帶的外部會員 ID

<Callout title="請注意">
關閉 `使用者驗證` 時，`每位已驗證使用者限一次` 也會一併關閉。若曾經把驗證設定關掉再開啟，請再次確認重複限制有沒有被解除。
</Callout>

  </Step>
</Steps>
