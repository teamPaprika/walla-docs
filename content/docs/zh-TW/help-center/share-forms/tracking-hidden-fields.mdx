## 新增追蹤項目（隱藏欄位）

<Steps>
  <Step>
    ### 開啟追蹤管理頁面
    在分享頁面點選 `管理` 按鈕。
  </Step>
  <Step>
    ### 輸入追蹤項目
    輸入追蹤名稱（隱藏欄位名稱）後，必須按 Enter 鍵登錄，項目才會建立。
  </Step>
  <Step>
    ### 儲存
    點選 `儲存` 按鈕儲存。
  </Step>
  <Step>
    ### 運用
    登錄好的隱藏欄位會扮演「用來區分來源管道的分類」角色。
    - ① 確認各社群來源 → 把隱藏欄位名稱設為 `SNS`（例：Instagram、YouTube 等）
    - ② 依顧客族群區分 → 把隱藏欄位名稱設為 `customer`
  </Step>
</Steps>
## 建立隱藏欄位 URL

設定好隱藏欄位後，必須自行把該欄位加進問卷連結（URL）中。

<Steps>
  <Step>
    ### 準備基本問卷 URL
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4
    ```
  </Step>
  <Step>
    ### 加上隱藏欄位名稱
    以 `?欄位名=` 的形式加上。
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=
    ```
  </Step>
  <Step>
    ### 填入欄位值
    例：來自 YouTube 時
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=youtube
    ```
  </Step>
  <Step>
    ### 依管道分享連結
    把各條連結分別在不同管道分享，就能在回覆表中確認來源管道（例：YouTube、Instagram 等）。
  </Step>
</Steps>
## 使用多個隱藏欄位

- 要在 URL 中加上多個隱藏欄位時，用「&」取代「?」串接即可。
```
https://walla.my/v/QA9S0imWeo232fSbd4?source=instagram&media=video
```
→ 代表是透過 Instagram 影片廣告進來的。
<Callout type="warning" title="注意事項">
- 登錄追蹤項目時必須按 Enter 才會儲存。
- 建議隱藏欄位名稱只用英文、數字與底線（_）組成。
</Callout>
<Callout title="小技巧">
若需要大量建立隱藏欄位 URL，複製[隱藏欄位連結產生器 Google 試算表範本](https://docs.google.com/spreadsheets/d/14F7iSY6yNiEV78eceveOkPNCTHzaMK5LIEqtYE4bo_I/edit?usp=sharing)來用會很方便。
</Callout>

## 用隱藏欄位建立邏輯條件

可以依隱藏欄位的值，把填答者送到不同題目。以下範例會把從廣告連結進來的填答者另外送到指定題目。

<Steps>
  <Step>
    ### 登錄隱藏欄位
    在追蹤管理頁面登錄隱藏欄位 `utm_source`，然後點選 `儲存`。
  </Step>
  <Step>
    ### 建立連結
    在廣告要用的連結最後加上值。
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads
    ```
  </Step>
  <Step>
    ### 建立邏輯條件
    在邏輯畫面中選擇 `utm_source` 作為基準題目，條件設為 `等於`，比較值設為 `ads`。
  </Step>
  <Step>
    ### 選擇要前往的題目
    選擇從廣告進來的填答者要前往的題目。
  </Step>
</Steps>

- 隱藏欄位的值會以文字比較。連結中沒有值時，該隱藏欄位的比較條件都不會符合，包括 `不等於`。
- 發布前，可以在專案編輯畫面的預覽中確認。預覽會直接沿用編輯畫面網址上附加的值。請在瀏覽器網址列中，於編輯畫面網址的最後加上 `?utm_source=ads`，再開啟預覽。如果網址中已經有 `?`，請改加 `&utm_source=ads`。
- 發布後，請分別開啟加上值的連結與沒有值的連結，確認兩條路徑都正確。
- 詳細方法請參考[設定邏輯中的「用隱藏欄位建立條件」](/zh-TW/docs/help-center/create-forms/setting-up-logic#用隱藏欄位建立條件)。

## 刪除邏輯中使用的隱藏欄位

邏輯條件中使用的隱藏欄位無法刪除。不只是編輯中的邏輯，已發布問卷的邏輯中有使用時也一樣。
刪除這類隱藏欄位並儲存時，會出現 `無法刪除條件正在使用的隱藏欄位。請先修改該條件。`。請依下列步驟先整理條件，再刪除隱藏欄位。

<Steps>
  <Step>
    ### 修改條件
    在邏輯畫面中找到使用該隱藏欄位的條件，將它刪除或改成其他基準題目。
  </Step>
  <Step>
    ### 重新發布
    如果已發布的問卷也有該條件，請用修改後的邏輯重新發布問卷。
  </Step>
  <Step>
    ### 刪除隱藏欄位
    在追蹤管理頁面刪除隱藏欄位，然後點選 `儲存`。
  </Step>
</Steps>
