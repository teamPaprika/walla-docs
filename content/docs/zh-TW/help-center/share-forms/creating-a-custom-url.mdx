## 建立自訂 URL

- 分享連結預設會產生成 `walla.my/a/自訂部分` 的形式。
- 輸入 URL 時必須符合規則。

### 設定方式

<Steps>
  <Step>
    ### 前往連結客製化
    在分享頁面前往 `連結客製化` 區塊。
  </Step>
  <Step>
    ### 輸入自訂 URL 並儲存
    輸入想要的自訂 URL 後儲存。
  </Step>
  <Step>
    ### 選擇檢視方式
    先從基本檢視／分組檢視中選好想要的檢視方式再儲存，該設定不必按發布就會立即生效。
  </Step>
</Steps>

### 自訂 URL 規則

- 可輸入 0 至 30 個字元
- 不可包含斜線（`/`）
- 不可只由一個句點（`.`）或兩個句點（`..`）組成
- 不可使用符合正規表示式 `__.*__` 的字串

## 分享預覽設定

- 在自訂 URL 下方可以設定專案標題、說明與縮圖。
- 只要儲存就會立即生效，不需要另外執行發布。
- 若沒有上傳縮圖，系統會顯示套用專案標題與佈景主題的預設縮圖。
<Callout type="warning" title="注意事項">
若已變更標題或縮圖，但在 LINE、Slack 等通訊軟體中仍看到舊的圖片或文字，那是因為測試過程中該通訊軟體或瀏覽器儲存了快取（先前的資料）。第一次收到該連結的人會正常看到變更後的預覽，不必擔心。
</Callout>
