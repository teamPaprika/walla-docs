## 發送前的準備

要發送問卷，收件對象必須先登錄在工作區的 **名單** 分頁中。名單上傳方式請參考[管理名單](/zh-TW/docs/help-center/team-workspace/workspace-panel)頁面。

## 發送方式

<Steps>
  <Step>
    ### 前往分享頁面
    前往專案編輯畫面上方的 `分享` 分頁，捲動到 `發送問卷` 區塊。
  </Step>
  <Step>
    ### 沒有已登錄名單時 - 點選上傳資料
    若沒有事先登錄名單，或想把專案發送給名單以外的對象，請點選 `上傳資料` 按鈕。有錯誤或不符格式的資料列會被排除後上傳。
  </Step>
  <Step>
    ### 已有登錄名單時 - 點選從名單匯入
    若已經登錄過名單，請點選 `從名單匯入`。

    如果名單中已登錄部門、職稱等額外資訊，可以在匯入視窗的 `面板資訊 → 隱藏欄位映射` 中指定為隱藏欄位。選擇既有的隱藏欄位，或選取 `建立新隱藏欄位` 並輸入名稱，匯入名單時就會一併連結這些資訊。
  </Step>
  <Step>
    ### 撰寫發送內容
    點選發送問卷按鈕後，輸入寄件帳號與要一併寄出的文字內容。
  </Step>
  <Step>
    ### 發送
    發送完成後，可以在每一列的 `狀態`、`發送次數`、`最後發送時間` 欄位確認發送結果。

    系統會為每位名單對象各自產生不同的專屬連結，回覆表中也會以名單登錄的 CUSTOMER Key 記錄。
  </Step>
  <Step>
    ### 收件郵件範例
    透過「發送問卷」寄出的問卷會以電子郵件送達。
  </Step>
</Steps>

## 將傳送對象名單下載為 Excel

你可以將 `傳送問卷` 中已登錄的對象名單與傳送狀況下載為 Excel 檔案（.xlsx）。檔案包含客戶 ID、姓名、電子郵件、電話號碼、傳送狀態、傳送次數、專屬連結、隱藏欄位值與相關時間。

<img src="/images/guides/share-forms/sending-to-panel-excel-download.png" alt="問卷傳送對象名單的下載按鈕與取消遮罩提示" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

1. 在專案的 `分享` 分頁中，前往 `傳送問卷` 區域。
2. 如果個人資料已被遮罩，請點選名單上方的取消遮罩圖示，並輸入原因以顯示資料。依團隊政策，可能需要管理員核准。
3. 點選名單上方的 `下載` 按鈕。
4. 如果出現填寫下載原因或申請核准的提示，請完成流程後再下載檔案。若提示沒有下載權限，請聯絡工作區管理員。

<Callout type="info" title="下載會包含所有傳送對象">
無論名單目前套用的狀態、日期篩選或已選取的列為何，下載的檔案都會包含該問卷的所有傳送對象。如只需要特定對象，請在下載的 Excel 中再次篩選。檔案中的時間以 UTC 為準，與韓國時間比較時請留意 9 小時的時差。
</Callout>

如要下載問卷中已提交的答案，請使用[回覆表的下載回覆功能](/zh-TW/docs/help-center/result-analysis/response-sheet#下載回覆)。

## 篩選未回覆者並向選取對象再次傳送

你可以選擇已收到問卷但尚未回覆的對象，再次傳送參與邀請。

<img src="/images/guides/share-forms/sending-to-panel-filter-resend.png" alt="依狀態與最後傳送時間篩選問卷對象的畫面" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

1. 在 `分享` → `傳送問卷` 中點選 `篩選`。
2. 在狀態中選取 `已傳送` 和 `已開啟`，篩出尚未回覆的傳送對象。如要一併包含首次傳送邀請的對象，請同時選取 `未傳送`。
3. 如有需要，可使用 `最後傳送時間` 的 `選擇日期範圍` 縮小傳送時間範圍。
4. 確認篩選結果後，使用名單左側的核取方塊選取這次要傳送的列。
5. 點選 `傳送問卷`，確認寄件帳號、主旨及訊息後，傳送給選取的對象。傳送後請確認 `傳送次數` 和 `最後傳送時間`。

| 狀態 | 意義 |
| --- | --- |
| 未傳送 | 尚未向此對象傳送問卷。 |
| 已傳送 | 已傳送問卷，且狀態尚未變更為已開啟或已回應。 |
| 已開啟 | 已開啟問卷，但尚未回覆的對象。 |
| 已回應 | 已回覆問卷的對象。如要將其排除在再次傳送之外，請勿選取此狀態。 |

<Callout type="info" title="變更篩選後請重新選取對象">
變更狀態、日期篩選或點選 `重置` 後，原本選取的列會被清除。請先套用篩選，再重新選取要傳送的列。日期篩選依最後傳送時間判斷，而非回覆日期。從未傳送過問卷的對象沒有傳送時間，因此套用日期篩選後不會顯示。
</Callout>
