## 什麼是名單？

名單就是問卷的發送對象清單。你可以在工作區的 **名單** 分頁中以 CSV 或 Excel 檔案上傳名單，並分類成群組來有系統地管理。

| 項目 | 說明 |
| ---- | ------------------- |
| 客戶金鑰 | 用來識別名單對象的專屬金鑰 |
| 姓名 | 名單對象的姓名（預設遮罩） |
| 電子郵件 | 名單對象的電子郵件（預設遮罩） |
| 電話號碼 | 名單對象的電話號碼（預設遮罩） |
| 群組 | 名單對象所屬的群組 |

<Callout type="info" title="個資遮罩">
為保護個人資料，名單對象的姓名、電子郵件與電話號碼預設會做遮罩處理。若要查看實際資訊，必須先解除遮罩。
</Callout>

## 上傳名單

你可以透過 CSV 或 Excel 檔案一次登錄整份名單。

<Steps>
  <Step>
    ### 點選上傳名單按鈕
    在名單分頁中點選 **上傳名單** 按鈕。
  </Step>
  <Step>
    ### 選擇群組
    選擇要上傳到哪個 **群組**。（選填）
  </Step>
  <Step>
    ### 選擇檔案
    點選 **選擇檔案** 按鈕，選取 CSV 或 Excel 檔案。
    姓名、電子郵件或電話號碼有錯誤的資料列會被排除，不會上傳。
  </Step>
  <Step>
    ### 完成上傳
    確認符合格式的資料後，點選 **上傳名單** 按鈕。
  </Step>
</Steps>

<Callout type="warn" title="檔案格式說明">
- 姓名為必填項目，電子郵件或電話號碼至少要填一項。
- 若電話號碼開頭的 0 消失了，請把電話號碼欄的儲存格格式設為文字，或在號碼前加上 `'`。
- 檔案格式不符時，可以在不符合資料分頁確認錯誤項目。
- 需要範本的話，請點選下載範本按鈕。
</Callout>

<Callout type="info" title="目前支援的發送方式">
目前的問卷發送功能僅支援電子郵件發送。
</Callout>

## 管理群組

你可以把名單對象分類成群組，依用途管理。

<Steps>
  <Step>
    ### 點選群組管理按鈕
    在名單分頁中點選 `群組管理` 按鈕。
  </Step>
  <Step>
    ### 查看群組清單
    可以查看既有的群組清單以及各群組的名單人數。
  </Step>
  <Step>
    ### 建立或編輯群組
    點選 `建立群組` 按鈕新增群組，或用群組右側的編輯按鈕變更名稱。
  </Step>
  <Step>
    ### 刪除群組
    選取要刪除的群組後，用 `刪除所選` 按鈕即可刪除。
  </Step>
</Steps>

## 解除遮罩

若要查看名單對象的個人資料（姓名、電子郵件、電話號碼），必須先解除遮罩。

<Steps>
  <Step>
    ### 點選解除遮罩按鈕
    點選名單分頁上方的 `解除遮罩` 按鈕。
  </Step>
  <Step>
    ### 填寫解除原因
    填寫解除遮罩的原因。
  </Step>
  <Step>
    ### 完成解除
    點選 `解除遮罩` 按鈕。
  </Step>
</Steps>

解除遮罩後，搜尋功能也會一併啟用。

<Callout type="warn" title="解除遮罩注意事項">
解除遮罩時，解除原因會記錄在活動紀錄中。請避免不必要地查看個人資料。
</Callout>

### 篩選與顯示設定

- **篩選**：可以只篩選出特定群組的名單對象。
- **顯示**：可以設定名單清單的排序依據與要顯示的項目。
- **排序依據**：建立日期（遞增／遞減）
- **顯示項目**：客戶金鑰、姓名、電子郵件、電話號碼、群組，各項皆可開關
