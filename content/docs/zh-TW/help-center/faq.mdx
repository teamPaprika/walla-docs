## 團隊／工作區

<Accordions>

  <Accordion title="開啟 Walla 後跳到的是註冊畫面，而不是登入畫面。">
    這通常是因為你很久沒登入該帳號，系統為了保護帳號而再次顯示身分確認與服務條款同意的程序。這並不是錯誤或帳號出問題，只要重新登入並完成畫面上的步驟，就能正常使用。該帳號中先前建立的表單與收集到的資料都完整保留，請不用擔心。
  </Accordion>

  <Accordion title="Free 團隊也可以邀請成員嗎？">
    可以，Walla 提供免費方案。在免費方案中也能使用建立表單、收集回覆等核心功能。若需要更多功能，歡迎看看付費方案。
  </Accordion>

  <Accordion title="我把人邀進團隊了，但對方看不到專案。">
    看起來是已經完成團隊邀請，但還沒被加入工作區成員。請點選工作區上方的齒輪圖示，在 [成員管理] 中把該使用者加入工作區。加入完成後，對方就能看到被邀請的工作區。
  </Accordion>

  <Accordion title="我想設定成只有特定成員能查看回覆結果。">
    要限制只有特定成員能查看回覆結果，請調整工作區成員的權限。點選工作區上方的齒輪圖示，在 [角色與權限] 選單中就能依角色設定可使用的功能。

    ※ 這項功能僅在 Enterprise 方案提供。
  </Accordion>

  <Accordion title="我想把團隊的擁有權轉移給其他帳號。">
    原則上目前不支援團隊轉移，標準做法只有一種：由團隊擁有者自行訂閱 Pro 方案並申請「轉移擁有者」後，再向客服申請退款。不過，若因不得已的情況無法聯繫上前任擁有者，我們會依資料保護與安全程序，在確認該申請確實來自同一組織（公司／網域）的正式請求後，才例外協助轉移。詳細事項請洽 [cs@walla.my](mailto:cs@walla.my)。
  </Accordion>

</Accordions>

## 訂閱與付款

<Accordions>

  <Accordion title="Walla 可以免費使用嗎？">
    可以，Walla 免費提供無限建立表單、無限收集回覆，以及查看統計與回覆結果。
  </Accordion>

  <Accordion title="付款後我沒有使用付費功能，可以退款嗎？">
    Walla 除了建立專案之外，還能以分享問卷連結、收集回覆、查看分析、維持既有專案上已套用的付費功能等多種形式使用。尤其因服務性質使然，即使沒有留下明確的操作紀錄，實際上仍可能已在使用，因此我們難以單以「未使用」為標準判定，敬請見諒。
  </Accordion>

  <Accordion title="要怎麼取消訂閱？">
    在「團隊設定 → 團隊管理」頁面點選 `管理方案` 按鈕前往付款資訊頁面，再點選 `取消訂閱` 按鈕即可取消。詳細內容請參考[取消方案](/zh-TW/docs/help-center/getting-started/starting-or-changing-subscription)。
  </Accordion>

  <Accordion title="可以取消訂閱並退款嗎？">
    能否退款會依付款時間點與方案類型而有所不同。月訂閱在付款後超過 24 小時就視為已使用服務，無法退款。年訂閱則在付款後 14 天內取消可全額退款，之後會扣除部分金額後退款。若希望退款請洽 [cs@walla.my](mailto:cs@walla.my)。詳細事項請參考[退款政策](https://home.walla.my/zh-hant/policy/refund-latest)。
  </Accordion>

  <Accordion title="實際扣款金額和定價頁面上寫的不一樣。">
    Walla 使用海外金流服務商，因此訂閱方案或購買禮物卡時，依發卡銀行政策可能會加收海外交易手續費。
  </Accordion>

</Accordions>

## 建立專案

<Accordions>

  <Accordion title="可以在表單中加入圖片嗎？">
    在任何欄位的題目標題或說明輸入框中輸入「斜線（/）」，就能插入圖片。你可以先寫好說明再用「斜線（/）」插入圖片，也可以先插入圖片再拖曳調整位置。[進一步了解斜線（/）指令 →](/zh-TW/docs/help-center/create-forms/editing-field-text)
  </Accordion>

  <Accordion title="可以翻譯「送出回覆」之類的文字嗎？">
    表單的內建文字（必填、送出回覆、錯誤訊息、送出完成訊息等）會依填答者的瀏覽器語言自動翻譯成韓文、英文、日文、簡體中文、越南文、泰文等。
  </Accordion>

  <Accordion title="淘汰欄位和結尾欄位有什麼不同？">
      淘汰欄位是為了在對方不是填答對象時中止問卷而設計的欄位，被導向淘汰欄位的回覆不會被儲存。若你想在送出回覆後顯示說明訊息，建議使用「結尾欄位」，並把淘汰欄位刪除，或用邏輯設定讓它不會接在前一題之後。
  </Accordion>

  <Accordion title="我希望一頁能顯示多個題目。">
    使用基本檢視時，所有題目會顯示在同一頁，填答者用捲動的方式往下作答。在基本檢視中可以在題目之間加上 `分頁`，依你想要的基準切分畫面。分組檢視則可以用欄位群組把多個題目組成同一個畫面。
  </Accordion>

  <Accordion title="我開啟表單後無法前往下一題。">
    這是因為該題的邏輯參照到找不到的欄位，請修改邏輯設定後再試一次。把顯示為「找不到的欄位／選項」的部分修正後發布即可。
  </Accordion>

  <Accordion title="可以依填答者的答案前往不同題目嗎？">
    可以。運用[設定邏輯](/zh-TW/docs/help-center/create-forms/setting-up-logic)功能，就能依填答者的選擇決定要顯示或隱藏特定題目。
  </Accordion>

  <Accordion title="我加了結尾欄位，但只看到預設的結束畫面。">
    只新增結尾欄位卻沒有設定邏輯時，系統會自動顯示預設結束頁面（「回覆已成功送出。」）。若要在送出後導向其他結尾欄位：
1. 在邏輯頁面點選「送出」按鈕。
2. 依條件指定要前往的結尾欄位。

若不需要任何條件、一律導向某個結尾欄位，把預設路徑改成該結尾欄位即可。
  </Accordion>

</Accordions>

## 管理專案
<Accordions>

  <Accordion title="我找不到之前建立的專案。">
      如果不是刪除了專案，那有可能是你登入了不同的帳號／團隊／工作區。請先確認目前所在的帳號、團隊與工作區，是否和當初建立專案時一致。

#### 1. 確認目前登入帳號的方式

點選右上角的個人檔案圖示，即可確認目前登入的帳號。若想改用其他帳號登入，請點選「登出」。

#### 2. 確認目前所在團隊的方式

可以在左上角的團隊清單中確認目前所在的團隊。

#### 3. 確認目前所在工作區的方式

可以在團隊清單下方的工作區清單中確認目前所在的工作區。
  </Accordion>

  <Accordion title="我不小心刪掉表單／回覆了，還能復原嗎？">
      依據我們把個資保護與資料安全放在第一位的政策，已刪除的問卷與回覆資料會立即永久刪除，無法復原。請設定工作區的角色權限，避免誤刪資料。Enterprise 方案以上還能查看刪除時間點、帳號等紀錄。
  </Accordion>

  <Accordion title="可以預約表單的開始／結束時間嗎？">
      可以，你能預約問卷在特定時間自動開始或截止。使用[預約功能](/zh-TW/docs/help-center/manage-forms/scheduling-survey-start-end-times)後，不必每次手動變更，問卷就會依既定行程開啟與結束。
  </Accordion>

</Accordions>

## 整合專案

<Accordions>

  <Accordion title="收到回覆時可以收到通知嗎？">
    可以，你能在「整合」頁面設定 Slack、Discord、Gmail 等通知。也可以自行設定 Webhook，在任何你想要的外部平台接收通知。
  </Accordion>

  <Accordion title="可以把回覆副本寄給填答者嗎？">
    要把回覆副本寄給填答者，請使用 Gmail 自動化。在自動化設定中選擇 Gmail，然後把收件人（To）項目對應到收集填答者電子郵件的欄位。設定完成後，只要填答者在作答時填了電子郵件，系統就會自動把回覆內容寄到該信箱。
  </Accordion>

  <Accordion title="可以在 Google 試算表即時查看回覆嗎？">
    可以，完成 Google 試算表整合後，系統會在你目前登入的 Google 帳號中建立一份新的試算表。之後每收到一筆回覆，該試算表就會自動新增一列。
  </Accordion>

</Accordions>

## 分享專案

<Accordions>

  <Accordion title="分享到 LINE 等社群的 URL，縮圖／標題沒有更新。">
    在 LINE 等平台分享過 URL 之後，即使變更縮圖／標題再分享一次，仍可能顯示舊版的縮圖／標題。這是因為 LINE 等平台為了縮短載入時間，會對該裝置曾傳送過的 URL 儲存快取。若想減少這種情況，請在[這裡](https://developers.kakao.com/tool/debugger/sharing)清除快取。在沒有傳送紀錄的裝置上收到 URL 時，就會正常顯示更新後的縮圖／標題。
  </Accordion>

  <Accordion title="基本檢視和分組檢視有什麼不同？">
    基本檢視是把所有題目顯示在同一頁的檢視方式；分組檢視則是一頁顯示一個題目（一個欄位群組）的檢視方式。
  </Accordion>

  <Accordion title="可以記錄專案的來源管道嗎？">
    設定好追蹤（隱藏欄位）後，在 URL 中加上參數再分享給填答者看看。收到回覆後，就能在回覆表與統計畫面中確認每位填答者是從哪個管道進來的。
  </Accordion>
   <Accordion title="分享專案時可以使用我們自己品牌的縮圖與 URL 嗎？">
    分享專案時可以設定符合品牌的縮圖與 URL。請在「分享」頁面把預覽圖片與連結客製成你想要的樣子並儲存。設定完成後，分享時就會套用該縮圖與 URL。
  </Accordion>
     <Accordion title="我手上已經有一份填答者名單，可以邀請他們填問卷並確認誰送出了嗎？">
    可以。把手上的填答者名單以 CSV 或 XLSX 檔上傳登錄成名單後，就能在各專案中把問卷發送給該名單。發送之後也能一併確認每位名單對象是否已回覆。
  </Accordion>

</Accordions>

## 查看回覆結果
<Accordions>
  <Accordion title="可以下載分析資料嗎？">
    分析資料無法下載，只能在各表單的「分析」分頁中查看。
</Accordion>
  <Accordion title="可以復原已刪除的回覆嗎？">
    提出刪除請求的回覆會立即刪除，且已刪除的回覆絕對無法復原，敬請留意。你可以在「活動紀錄」中確認是哪個帳號與 IP 刪除了回覆。
</Accordion>
  <Accordion title="可以在回覆的 customerKey 中放入事先定義好的值嗎？">
    把已含有事先定義 customerKey 值的填答者名單以 CSV 或 XLSX 檔上傳登錄成名單後，就能在各專案中把問卷發送給該名單。這種情況下，回覆表的 customerKey 就會填入事先定義好的值。
</Accordion>

</Accordions>

## 發送獎勵

<Accordions>

  <Accordion title="要怎麼發送獎勵？">
    首先要在表單中加入電話號碼欄位（建議）來收集填答者的電話號碼。接著購買獎勵，選擇發送對象後發送即可。詳細方式請參考[發送禮物卡](/zh-TW/docs/help-center/reward/sending-gifticons)。
  </Accordion>
   <Accordion title="我在表單中沒有收集填答者的電話號碼，還能發送獎勵嗎？">
    很抱歉，沒有收集電話號碼時就無法發送獎勵。若要發送獎勵，請務必在問卷作答時收集電話號碼等發送所需的資訊。
  </Accordion>
     <Accordion title="Walla 沒有的品牌禮物卡也能發送嗎？">
    可以。請寄信到 cs@walla.my 告訴我們你偏好的品牌或希望的價格帶與數量，我們評估後會協助你在 Walla 獎勵商店中購買。
  </Accordion>
       <Accordion title="可以用我們品牌自有的獎勵（例如自家商城點數）當作獎勵發放嗎？">
    可以，不過這項功能僅在 Custom 方案以上提供，詳細事項請洽 cs@walla.my。
  </Accordion>

</Accordions>
