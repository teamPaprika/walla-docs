---

import { Step, Steps } from 'fumadocs-ui/components/steps';

## 自訂下一步按鈕

- 分組檢視問卷預設一次顯示一題，前往下一題時會出現「下一步」按鈕。
- **想隱藏這個按鈕時**

<Steps>
  <Step>
    ### 前往設定分頁
    前往專案編輯畫面右側的「設定」分頁。
  </Step>
  <Step>
    ### 啟用隱藏按鈕
    在「下一步按鈕」類別中啟用「隱藏按鈕」即可。
  </Step>
</Steps>

- 若想用**其他文字取代「下一步」**，請在「修改按鈕名稱」項目輸入想要的文字。

## 自訂送出回覆按鈕

- 預設文字顯示為「送出回覆」。
- 想更換文字時，點選按鈕後直接輸入想要的文字即可變更。

<Callout title="請注意">
把按鈕文字調整成符合品牌或問卷調性，有助於提升填答率。
</Callout>
