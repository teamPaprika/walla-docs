## 選擇題表格欄位

- 可以自由新增列（Row）與欄（Column）。
  - 點選表格下方的虛線區域可新增列，點選右側的虛線區域可新增欄。
  - 列與欄的標題直接在表格中輸入即可。
- 用列、欄標題旁的六點把手可以調整順序或開啟選單。
  - 拖曳即可變更列與欄的順序。
  - 點選會開啟 `複製列`、`刪除列`（欄則是 `複製欄`、`刪除欄`）選單。
- 在左下角的 `設定選項值` 可以指定各選項的值。（例：把第一個選項設為值 1）
- 透過[文字編輯器](/zh-TW/docs/help-center/create-forms/editing-field-text)可以套用文字顏色、大小、粗細等各種樣式。
- 也可以用[斜線（/）指令](/zh-TW/docs/help-center/create-forms/editing-field-text)輕鬆插入圖片、表格、標題文字等。
- 在右側邊欄的 `題目行為` 中，可設定限制重複欄位、隨機排列及固定列與欄，以及 `在手機上垂直排列`。
  - 限制重複欄位： 啟用 `限制重複欄位` 後，在某一列中選取的欄，就不能在其他列中再次選取。可用於第 1 順位、第 2 順位等排序型問卷。此功能僅適用於一般選擇題表格。
  - 隨機排列列與欄： 分別啟用 `隨機排列列` 和 `隨機排列欄` 後，填答畫面會以隨機順序顯示該方向的項目。也可以同時啟用兩者。
  - 固定列與欄： 啟用隨機排列後，在出現的 `要固定的列` 或 `要固定的欄` 中選取要維持位置的項目。可同時固定多個項目，取消選取即可取消固定。例如，固定最後一欄的「其他」後，即使隨機排列其他欄，「其他」仍會保持在最後的位置。

    <img src="/images/guides/manage-forms/grid-shuffle-pin.png" alt="在題目行為中啟用隨機排列欄，並選擇公車與自用車作為要固定的欄" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

  - 在手機上垂直排列： 啟用後，可在手機上開啟各列，垂直查看選項並作答。桌面版仍會以原本的表格形式顯示。
  - 請在預覽中確認順序、固定位置與手機顯示方式，並發布問卷以套用至填答者。


## 選擇題表格（多選）欄位

- 和基本的選擇題表格一樣可以新增列與欄，並直接在表格中輸入標題。
- 每個選項同樣可以指定選項值。
- 差別在於：一般選擇題表格每一列只能選一欄，多選表格則可以不受限制地選取多欄。
- 在欄選單中開啟 `單獨選擇`，就能把該欄設定成像「皆非」這樣無法與其他欄一起勾選的選項。填答者選擇該欄時，同一列的其他選擇會全部取消。

<Callout title="小技巧">
選擇題表格適合詢問排序或優先順序的問卷；選擇題表格（多選）則適合允許複選的比較、評估型問卷。
</Callout>
