import { Step, Steps } from 'fumadocs-ui/components/steps';

## 建立團隊範本

<Steps>
  <Step>
    ### 前往範本庫
    前往範本庫。
  </Step>
  <Step>
    ### 載入範本
    點選 `載入範本` 按鈕。
  </Step>
  <Step>
    ### 選擇專案
    選擇要當作範本使用的專案。
  </Step>
  <Step>
    ### 設定選項後儲存
    視需要設定是否以複本載入、預覽方向（基本檢視／分組檢視）與範本說明，接著點選 `載入`，就會存成團隊範本。
  </Step>
</Steps>

- 載入為團隊範本後即成為團隊的共同資產，所有團隊成員都能使用。

## 使用團隊範本

<Steps>
  <Step>
    ### 建立新專案
    建立一個新專案。
  </Step>
  <Step>
    ### 選擇使用範本
    選擇 `使用範本`。
  </Step>
  <Step>
    ### 選擇團隊範本
    在範本清單中選擇團隊範本。
  </Step>
  <Step>
    ### 選擇想要的範本
    選擇想要的團隊範本後，點選 `使用範本`。
  </Step>
  <Step>
    ### 完成
    系統會以所選範本為基礎建立新專案。
  </Step>
</Steps>

## 這些情況特別適合使用

- 顧客諮詢、導入諮詢、滿意度調查等經常使用的問卷
- 需要在公司或團隊層級統一格式的問卷
- 需要基準範本，讓新進團隊成員能快速建立問卷時

<Callout title="小技巧">
- 團隊範本屬於團隊資產，建議不要把不必要的專案存成範本。
- 以範本建立的專案會與原始範本各自獨立，修改互不影響。
</Callout>
