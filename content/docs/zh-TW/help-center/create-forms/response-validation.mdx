## 回覆驗證

| 驗證規則 | 說明 |
|---|---|
| 必填 | 一定要作答。 |
| 回覆長度限制 | 可以設定最少／最多字數。 |
| 必須包含的內容 | 未包含特定文字時會顯示錯誤訊息。 |
| 不可包含的內容 | 包含特定文字時會顯示錯誤訊息。 |
| 數字範圍限制 | 可以指定能輸入的最小／最大值。 |
| 設定可選數量 | 可以指定最少、最多可選數，或精確的數量。 |
| 包含選項 | 一定要包含特定選項。 |
| 排除選項 | 絕對不能選擇特定選項。 |
| 各選項回覆數上限 | 限制特定選項在所有回覆中被選擇的次數。可用於先到先得的招募、席次／數量限制等。 |
| 正規表示式（Regex） | 可以自行指定樣式，做更細緻的格式驗證。 |

<Callout title="正規表示式範例">
- 只能輸入英文：`^[A-Za-z]+$`
- 確認 URL 格式：`^(https?:\/\/)?([\w-]+\.)+[\w-]+(\/[\w-./?%&=]*)?$`
- 韓國身分證字號格式（含連字號）：`^\d{6}-\d{7}$`
- 郵遞區號（5 位數字）：`^\d{5}$`
</Callout>

<Callout type="warning" title="收集身分證字號時請注意">
收集實際身分證字號時有法律上的限制，請務必啟用**資料遮罩**與**回覆自動刪除**功能。
</Callout>
