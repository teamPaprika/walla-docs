## 建立專案的方式

<Steps>
  <Step>
    ### 點選建立專案按鈕
    在工作區畫面點選 `建立專案` 按鈕。
  </Step>
  <Step>
    ### 設定專案
    設定專案名稱與標籤。
  </Step>
  <Step>
    ### 完成建立
    點選 `建立專案` 按鈕，新專案就會加入工作區。
  </Step>
</Steps>

<Callout title="請注意">
在同一個工作區內可以建立多個專案，同時管理各種不同的問卷。
</Callout>
