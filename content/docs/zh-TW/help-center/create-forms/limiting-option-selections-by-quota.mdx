import { Step, Steps } from 'fumadocs-ui/components/steps';

## 設定方式

<Steps>
  <Step>
    ### 啟用功能
    選擇該題目，然後啟用「各選項回覆數上限」功能。
  </Step>
  <Step>
    ### 輸入最大回覆數
    點選「設定」按鈕，輸入每個選項的最大回覆數。
  </Step>
  <Step>
    ### 發布
    發布後，所有回覆中該選項被選擇的次數就不會超過你設定的數字。
  </Step>
</Steps>

<Callout type="warning" title="注意事項">
- 刪除或變更選項時，該選項的限制設定會被重設。
- 回覆數限制自問卷發布後才開始生效。
</Callout>

## 套用後的顯示方式

1. **選項已全數額滿時** → 該選項會變成停用狀態，無法選擇。

2. **填答途中選項才額滿時** → 點選 `送出回覆` 按鈕時會顯示「特定題目的提交次數已超過上限。」的錯誤訊息。

<Callout title="請注意">
善用各選項回覆數上限功能，就能在先到先得招募或席次預約等情境中避免重複回覆，公平地收集回覆。
</Callout>
