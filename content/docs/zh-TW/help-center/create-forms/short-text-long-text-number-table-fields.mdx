---
title: 簡答、長答、數字、表格欄位
description: 這是讓填答者自行輸入的問答型欄位。可以依輸入內容的長度或格式選用不同欄位。
---

## 簡答欄位

- 用於收集大約一行的簡短文字回覆。
- 適合姓名、職業、簡短意見等簡短回覆。
- 點選鉛筆圖示可以修改輸入提示文字。
- 可設定的選項
  - 必填
  - 回覆長度限制
  - 必須包含的內容
  - 不可包含的內容
  - 正規表示式

## 長答欄位

- 用於收集多行的長篇文字回覆。
- 適合詳細意見、回饋、敘述型答案等。
- 點選鉛筆圖示可以修改輸入提示文字。
- 可設定的選項
  - 必填
  - 回覆長度限制
  - 必須包含的內容
  - 不可包含的內容
  - 正規表示式

## 數字欄位

- 這是專門輸入數字的欄位。
- 收集數量、年齡、分數等數字回覆時使用。
- 點選鉛筆圖示可以修改輸入提示文字。
- 可設定的選項
  - 必填
  - 數字範圍限制

<Callout type="warning" title="注意事項">
用數字欄位收集電話號碼時，以「0」開頭的號碼（010AAAABBBB）會被判讀成數字，開頭的 0 會自動消失。電話號碼請使用簡答欄位或電話號碼專用欄位。
</Callout>

## 表格欄位

- 這是能以表格形式一次收集多個問答型回覆的欄位。
- 可以用列與欄的結構分項填寫，適合同時比較或評估多個項目。
- 可設定的選項
  - 必填
