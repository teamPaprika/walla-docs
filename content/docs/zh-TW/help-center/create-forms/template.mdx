---

import { Step, Steps } from 'fumadocs-ui/components/steps';

## 載入範本

<Steps>
  <Step>
    ### 點選建立專案按鈕
    在工作區畫面點選 `建立專案` 按鈕。
  </Step>
  <Step>
    ### 選擇使用範本
    選擇 `使用範本`。
  </Step>
  <Step>
    ### 選擇想要的範本
    選擇想要的團隊範本後，點選 `使用範本`。
  </Step>
  <Step>
    ### 完成
    系統會以所選範本為基礎建立新專案。
  </Step>
</Steps>
