## 邏輯的概念

- 邏輯決定「依回覆內容，下一題要接到哪裡」。
- 預設路徑是指所有填答者一定會經過的流程。（這和「必填」是不同的概念。）

## 新增邏輯

<Steps>
  <Step>
    ### 前往邏輯設定畫面
    在專案編輯畫面點選 `邏輯` 按鈕，即可前往邏輯設定畫面。
  </Step>
  <Step>
    ### 理解條件與前往的組成
    邏輯由「條件」與「前往」兩個部分組成。
  </Step>
  <Step>
    ### 條件
    1. **選擇基準題目** – 選擇要以哪一題的回覆為基準。
       - 方格、排序題、表格、自訂欄位題目還要在 `子項目` 中選出要比較的格子。詳細方法請參考[用子項目建立條件](#用子項目建立條件)。
       - 透過連結帶入的隱藏欄位值也可以當作基準。詳細方法請參考[用隱藏欄位建立條件](#用隱藏欄位建立條件)。
    2. **選擇條件** – 選擇條件的種類。條件大致分為文字／數值、選項、數字、日期比較，詳細種類請參考下方的[條件種類詳解](#條件種類詳解)。
    3. **選擇選項／回覆** – 選擇該條件要在哪些回覆時生效。
       - 也可以同時選擇多個回覆。
  </Step>
  <Step>
    ### 新增多個條件
    - 點選 `+ 新增條件` 可以組合多個條件。
    - 組合條件時請從下列兩種擇一。
      - **AND**：前後條件都符合時邏輯才生效
      - **OR**：前後條件其中一個符合，邏輯就生效
  </Step>
  <Step>
    ### 前往
    - 設定完所有條件後，選擇填答者要前往的欄位。
    - 設定完成後，符合該條件的填答者就會直接跳到指定的題目。
  </Step>
</Steps>

## 條件種類詳解

### 文字／數值比較

| 條件 | 意義 | 範例 | 範例答案 |
| ------ | -------------- | ---------------- | ----------------- |
| 等於 | 值完全相同 | 答案等於 `首爾` 時 | 首爾 |
| 不等於 | 值不相同 | 答案不是 `首爾` 時 | 仁川 |
| 開頭符合 | 以特定值開頭 | 答案以 `010` 開頭時 | 010-1234-5678 |
| 結尾符合 | 以特定值結尾 | 答案以 `.com` 結尾時 | example<span>@</span>walla.com |
| 包含文字 | 含有特定文字 | 答案含有 `股份有限公司` 時 | Paprika Data Lab 股份有限公司 |
| 不包含文字 | 不含特定文字 | 答案不含 `蘋果` 時 | 葡萄汁 |

### 選項比較
用於選擇題、多選題這類可以挑選多個項目的題目，判斷填答者選了哪些選項。

| 條件 | 意義 | 範例 |
| -------- | --------------------- | ----------------------- |
| 全部包含 | 指定的項目全部都被選取 | `A`、`B` 都被選取時 |
| 至少包含一個 | 指定的項目中至少選取一個 | 選了 `A` 或 `B` 其中之一時 |
| 全部未選 | 指定的項目一個都沒選 | `A`、`B` 都沒選時 |
| 至少一個未選 | 指定的項目中至少有一個沒選 | `A`、`B` 中至少一個未選時 |


### 數字比較

| 條件 | 意義 | 範例 |
| ----- | ------------ | ------------------------ |
| 大於 | 大於基準值 | 年齡大於 `19` 時 |
| 大於或等於 | 大於或等於基準值 | 年齡為 `19` 或更大時 |
| 小於 | 小於基準值 | 分數小於 `60` 時 |
| 小於或等於 | 小於或等於基準值 | 分數為 `60` 或更小時 |

### 日期比較

| 條件 | 意義 | 範例 |
| -------- | ----------------------- | --------------------- |
| 早於 | 早於基準日期（不含該日） | 早於 `2026-01-01` 時 |
| 早於或等於 | 等於或早於基準日期（含該日） | 在 `2026-01-01` 或更早時 |
| 晚於 | 晚於基準日期（不含該日） | 晚於 `2026-01-01` 時 |
| 晚於或等於 | 等於或晚於基準日期（含該日） | 在 `2026-01-01` 或更晚時 |

## 用子項目建立條件

像單選方格或表格這類一個回覆裡有好幾格的題目，選好基準題目後，還要再往下一層選出要比較的格子。

<Steps>
  <Step>
    ### 選擇基準題目
    選擇基準題目後，如果該題目有細項，正下方會出現 `子項目` 選單。
  </Step>
  <Step>
    ### 選擇子項目
    在 `子項目` 中選擇要比較的列、欄或屬性。如果又出現一個選單，就接著選到最後一個。
  </Step>
  <Step>
    ### 設定條件與比較值
    選擇條件種類並輸入比較值。比較值的輸入框會配合最後選的格子而改變。例如在表格中選了某一格，就輸入文字；在單選方格中選了某一列，就從該列的選項中挑選。
  </Step>
</Steps>

### 各題目的選擇順序

| 題目 | 選擇順序 | 比較值 |
| ------------- | ------------------- | ---------------------- |
| 單選方格 | 列 | 該列選取的 1 個選項 |
| 複選方格 | 列 | 該列選取的選項（可多個） |
| 排序題 | 名次 | 排在該名次的 1 個選項 |
| 表格 | 列 → 欄 | 該格輸入的文字 |
| 自訂欄位 | 屬性 → 必要時選第幾個項目 | 符合該屬性格式的值 |

- 單選方格、複選方格與排序題選好列（排序題是名次）後，就可以直接設定比較值。
- 如果排序題允許填答者自行輸入選項，請在比較值中選 `選擇選項` 或 `自訂`。要和清單中沒有的值比較時，請選 `自訂`，輸入值後按 Enter。
- 子項目顯示 `此回覆無法用於條件` 時，該格不能用於條件，請改選其他子項目。

### 自訂欄位的子項目

- 屬性是固定的時候，從 `子項目` 清單中選擇。
- 出現 `選擇屬性` 與 `輸入鍵` 按鈕的屬性，可以自行輸入鍵。清單中沒有的鍵，請點選 `輸入鍵` 後輸入。
- 回覆是清單形式時，會出現 `第幾個項目` 欄位。第一個項目輸入 1，第二個項目輸入 2。整個回覆都是清單的自訂欄位，一定要填寫最先出現的 `第幾個項目`。
- `第幾個項目（選填）` 欄位留空時會比較整份清單，輸入數字時只比較該項目。

### 輸入比較值

比較值要在符合最後所選格子的選單或輸入框中選擇或輸入。

- **有選項的值** – 從清單中選擇選項。依格子不同，也可以選多個。
- **直接輸入清單值** – 輸入一個值後按 Enter，值會以小標籤（chip）加入。下一個值也用同樣方式加入。
- **數字** – 輸入框一開始是空白的，請輸入要比較的數字。要和 0 比較時也請輸入 `0`。
- **真／假** – 請直接選擇要比較的值 `真` 或 `假`。在清單欄位中，請輸入 `true` 或 `false` 後按 Enter。

### 尚未完成輸入的條件

條件下方出現 `請檢查條件並完成輸入值。` 時，代表還沒輸入完成。請確認下列幾點來完成輸入。

- 輸入框中還有文字時，按 Enter 把它加成標籤。
- 值不符合格式時，文字會留在輸入框中，並出現 `請輸入符合指定類型的值。`。修正值後再按一次 Enter。
- 出現 `第幾個項目` 空白或超出範圍的提示時，請依提示修正數字。

這個狀態下無法發布問卷。嘗試發布時會出現 `發布前請先完成或修正條件輸入。`。

### 修改題目後條件失效時

刪除或修改題目的列、欄、選項後，條件可能出現 `找不到項目` 或 `此值已不在選項中，請選擇其他值。`。這時請重新選擇其他子項目或值。

這類條件若仍保存在問卷中，就無法發布問卷。嘗試發布時會出現 `回覆值條件無效。請檢查問題、子項目和比較值。`。

## 用隱藏欄位建立條件

可以依附加在連結上的隱藏欄位值，把填答者送到不同題目。例如，只讓從廣告連結進來的填答者前往廣告相關的題目。
請先在分享頁面的追蹤中登錄隱藏欄位。登錄方法請參考[追蹤（隱藏欄位）](/zh-TW/docs/help-center/share-forms/tracking-hidden-fields)。

<Steps>
  <Step>
    ### 選擇隱藏欄位
    在基準題目清單中選擇隱藏欄位名稱。
  </Step>
  <Step>
    ### 設定條件與值
    從[文字／數值比較](#文字數值比較)的條件中選擇一個，再以文字輸入要比較的值。
  </Step>
  <Step>
    ### 選擇要前往的題目
    選擇隱藏欄位值符合條件時要顯示的下一個題目。
  </Step>
</Steps>

- 例：用隱藏欄位 `utm_source`、`等於`、`ads` 建立條件後，只有從 `https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads` 連結進來的填答者會前往指定題目。
- 連結中沒有值的隱藏欄位，包含 `不等於` 在內的任何比較條件都不會符合。
- 邏輯條件中使用的隱藏欄位無法刪除。刪除步驟請參考[刪除邏輯中使用的隱藏欄位](/zh-TW/docs/help-center/share-forms/tracking-hidden-fields#刪除邏輯中使用的隱藏欄位)。

## 用節點設定邏輯

<Steps>
  <Step>
    ### 認識節點與連接線
    在邏輯畫面中，每個題目都會顯示成一個節點，節點之間的連接線則呈現流向。`預設路徑` 是所有填答者都會經過的基本流程，而 `邏輯 #1`、`邏輯 #2` 這類帶編號的分支，則代表依條件岔出的路徑。
  </Step>
  <Step>
    ### 設定預設路徑
    點選節點上的 `預設路徑` 標籤，會開啟選擇 `下一個欄位` 的下拉選單。搜尋欄位或從清單挑選，即可指定不符合任何條件的填答者要前往的預設題目。
  </Step>
  <Step>
    ### 在邏輯節點上編輯條件
    點選 `邏輯 #1`、`邏輯 #2` 這類帶編號的分支標籤，條件區塊會就地展開。你可以直接在節點上修改基準題目、條件與選項，或新增 `新條件`。
  </Step>
  <Step>
    ### 點選連接線直接修改
    選好欄位後，不必點節點上的 `邏輯` 或 `預設路徑` 標籤，直接點選節點之間的連接線也能修改該流程。
  </Step>
  <Step>
    ### 拖曳節點建立連線
    把節點下方的連接點拖到另一個題目節點上，就能直接串連兩個題目形成流程。畫出新的連接線後，填答者就會走該路徑。
  </Step>
</Steps>

## 邏輯應用範例

- #### 範例 1. 依個資同意分支
  - 條件：`個資蒐集欄位` =「我同意」
  - 前往：個資蒐集相關題目（電話號碼欄位等）之後的題目
- #### 範例 2. 依年齡做淘汰處理
  - 條件：`年齡題目（選擇題／下拉式選單欄位）`、不等於、「10 多歲」
  - 前往：`淘汰欄位`
- #### 範例 3. 含特定關鍵字時前往指定題目
  - 條件：`簡答／長答欄位`、包含文字、「蘋果」
  - 前往：`蘋果汁銷售付款欄位`

## 其他設定與注意事項

- 邏輯若在中途斷掉，很可能是**淘汰欄位放在中間，或前面題目的邏輯設定有誤**。

- 欄位群組內的題目也能各自設定邏輯；若設定成前往某個題目，畫面會從包含該題目的群組開始顯示。
- 點選 `重設` 按鈕會刪除該題目的所有邏輯。
