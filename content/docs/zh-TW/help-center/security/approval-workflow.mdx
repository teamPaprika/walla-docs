開啟審核後，成員要執行敏感操作就必須先取得管理員審核。從設定到處理，流程如下。

<Steps>
  <Step>
    ### 開啟需要審核的操作

    前往團隊管理 → `安全性` → `需要審核的操作`，開啟各項操作的開關後點選 `儲存變更`。

    | 操作 | 審核的效力 |
    | --- | --- |
    | 邀請團隊成員 | 審核適用於向所請求電子郵件發出的單次邀請 |
    | 下載回應 | 審核授予問卷限時下載權限 |
    | 取消回應遮罩 | 審核授予問卷限時取消遮罩權限 |
    | 刪除問卷 | 審核適用於單次刪除 |

    管理員（admin）以上不需審核即可操作，審核只套用在等級較低的成員。變更設定需要團隊安全性設定權限。
  </Step>
  <Step>
    ### 成員提出申請

    成員嘗試執行需要審核的操作時會開啟申請視窗。填寫事由並選擇要通知的管理員後送出申請。

    - 選定的管理員會收到站內通知與電子郵件。
    - 申請會在 7 天後自動失效。
    - 若同一操作、同一對象已有待處理的申請，新的嘗試會併入既有申請，不會另外建立。
  </Step>
  <Step>
    ### 管理員核准或駁回

    前往團隊管理 → `審核`，在 `待處理` 分頁確認申請人、操作、對象、事由、申請時間與期限，然後點選 `核准` 或 `駁回`。有待處理的申請時，選單會顯示件數。自己送出的申請無法自行審核。
  </Step>
  <Step>
    ### 決定審核期限

    下載回應與取消回應遮罩是以期限方式審核。點選 `核准` 時可以選擇期限，在該期限內成員可以重複執行。

    邀請團隊成員與刪除問卷則是 **單次** 授權。已審核的操作執行一次後，該次審核就視為使用完畢。
  </Step>
  <Step>
    ### 審核完成

    處理結果會以電子郵件通知申請人。核准後即可執行申請的操作，期限型審核在設定的期限內有效，單次授權則在執行一次後結束。

    若被駁回，該操作仍然無法執行。必要時成員可以重新填寫事由再次申請。
  </Step>
</Steps>

<Callout title="參考">
新開啟審核僅限 Enterprise 方案。已開啟的設定不論方案為何都會持續生效，且隨時可以關閉。
</Callout>

## 查看記錄

在 `記錄` 分頁可以看到所有已處理的申請，並依狀態、操作、申請人篩選與排序。

- 狀態分為已核准、已駁回、已使用、已撤回、已取消、已過期。
- 期限型審核會一併顯示有效期限。
- 成員只能看到自己的申請，管理員可以看到團隊所有申請。

## 撤回審核

已經給出的審核可以立即收回，適用於尚未使用的單次審核，以及期限尚未結束的審核。

在 `記錄` 分頁點選該申請的 `撤回` 按鈕並輸入事由。事由會留在稽核記錄中。

撤回後審核立即失效，即使期限未到也無法再執行該操作。只有管理員可以撤回。

<Callout title="參考">
審核的申請與處理內容也會留在[記錄](/zh-TW/docs/help-center/security/activity-logs)中。實際執行的下載或取消遮罩記錄，會連結到當初核可的那筆審核。
</Callout>
