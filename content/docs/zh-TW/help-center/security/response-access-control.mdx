即使是參與同一個問卷專案的成員，有時也需要依負責地區、部門或分數區間，**僅查詢自己負責的回應**。使用 **Enterprise 方案**的回應存取控制（回應查詢管理）功能，就能設定讓負責首爾地區的研究員只看到 `居住地區 = 首爾` 的回應，並隱藏京畿或釜山的回應，依專案精細控管回應查詢範圍。

回應存取控制會透過以下 **2 個步驟** 套用：

1. **工作區角色層級**：在 **工作區設定 → 角色與權限** 中，將目標角色的 **檢視回應** 下拉選單選擇為 **依專案設定**。
2. **專案層級**：在問卷編輯畫面的 **問卷設定 → 專案權限** 中選取目標角色後，於 **回覆 → 查看回覆** 下拉選單中選擇 **不允許**、**所有回應** 或 **符合條件的回應**，並點選下方的 **儲存**。

## 條件篩選運作模擬器

在下方模擬器中切換套用至 **首爾研究員** 角色的規則，即可即時預覽回覆表、回覆統計與數據分析畫面會如何反應設定結果。

## 設定流程總覽

在實際的 Walla 介面中設定工作區角色、於專案權限儲存條件，並由權限受限成員查看結果的完整流程如下：

<Steps>
  <Step>
    ### 在工作區角色中選擇「依專案設定」

    前往 **工作區設定 → 角色與權限**，在目標角色（例如「首爾研究員」）的 **工作區權限** 分頁中，將 **檢視回應** 下拉選單設為 **依專案設定**。
  </Step>
  <Step>
    ### 在「問卷設定 → 專案權限」選擇「符合條件的回應」

    在尚未為專案設定允許範圍前，回應預設為封鎖狀態；展開問卷設定左側選單的 **專案權限** 並選取角色後，即可在 **回覆 → 查看回覆** 下拉選單中選擇 **符合條件的回應**。
  </Step>
  <Step>
    ### 設定條件規則並點選「儲存」立即套用

    新增如「`居住地區 = 首爾`」等條件並點選畫面下方的 **儲存**，規則會立即套用至該角色成員的回覆表、個別回覆、回覆統計與下載功能。
  </Step>
  <Step>
    ### 限縮權限成員的回覆表畫面

    以限縮角色登入的成員進入回覆表時，畫面上方會顯示 **「僅顯示您可存取的回應。」** 提示，且列表中只會顯示符合條件的回應（例如首爾地區回應）。
  </Step>
  <Step>
    ### 數據分析限制說明

    對於回應存取受限的成員，系統不提供造訪與行為分析，並會在上方橫幅引導前往 **回覆統計** 分析可存取的回應。
  </Step>
</Steps>

## 條件規則撰寫方式

選擇 **符合條件的回應** 後，可以組合 **規則** 與 **條件**。

- **條件（AND）**：在同一條規則內新增多個條件時，僅允許**同時滿足所有條件**的回應。*（例如：`居住地區 包含下列任一 [首爾]` **且** `整體滿意度 大於或等於 4`）*
- **規則（OR）**：點選 **新增規則** 加入另一條規則時，只要**滿足任一條規則**的回應即可檢視。
- **支援的欄位類型**：可依 `提交時間`、選擇題／下拉選單／線性刻度等選擇型題目，以及簡答題文字、數字、日期等題目進行篩選。

<Callout type="warn" title="注意事項">
在工作區角色中將 **檢視回應** 切換為 **依專案設定** 後，在尚未為個別問卷儲存規則前，該角色成員將無法檢視任何回應（處於 **不允許** 狀態）。請務必前往各問卷的 **問卷設定 → 專案權限 → 回覆 → 查看回覆** 中選擇 **所有回應** 或 **符合條件的回應**，並點選 **儲存**。
</Callout>

## 結果檢視與管理畫面的運作差異

回應存取受限的角色成員進入專案結果畫面時，各功能的運作方式如下：

| 功能區域 | 運作方式 |
| --- | --- |
| **回覆表** | 畫面上方會顯示 **「僅顯示您可存取的回應。」** 提示，並僅顯示符合條件的回覆列。*（若與搜尋結果或篩選條件重疊的可存取回覆為 0 筆，將顯示「目前篩選條件的回覆中，沒有您可以存取的回覆。」）* |
| **個別回覆・回覆統計** | 僅統計與顯示可存取的回應，不會外洩隱藏回應的數值或原始內容。 |
| **下載回覆・刪除回覆** | 即使擁有下載或刪除權限，也僅能下載或刪除可存取的回應。*（若可下載的回應為 0 筆，則無法執行下載。）* |
| **數據分析（造訪・行為分析）** | 為避免造訪次數、流失率等整體流量指標與允許回應集合分離而造成資訊外洩，系統**不提供造訪與行為分析**。*（上方橫幅會引導改用回覆統計。）* |
| **專案移動至其他工作區** | 將問卷移動到其他工作區時，依原工作區角色設定的**所有回應存取規則都會被刪除**。移動後需在新的工作區重新設定規則。 |

<Callout type="info" title="說明">
儲存回應存取政策後，**無論問卷是否重新發布皆會立即生效**。不過條件欄位是依據已發布的問卷題目選擇，若您新增了題目，請先發布問卷後再於條件規則中選取該欄位。
</Callout>
