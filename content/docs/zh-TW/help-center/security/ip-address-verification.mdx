## 啟用 IP 存取限制

<Steps>
  <Step>
    ### 前往安全性設定
    前往 `團隊管理` → `安全性`。
  </Step>
  <Step>
    ### 開啟 IP 存取限制並新增允許的 IP
    開啟 `IP 存取限制` 並新增允許的 IP 位址或範圍。啟用 IP 存取限制時，必須登記至少一個 IP 位址或範圍。
  </Step>
  <Step>
    ### 確認套用範圍並儲存
    確認下方的套用範圍後點選 `儲存變更` 即可套用。此設定用於限制團隊**網頁控制台及相關 API** 的存取，不會限制受訪者填寫並提交問卷。
  </Step>
</Steps>

## 套用範圍
啟用 IP 存取限制後，您可以選擇要將下方的允許 IP 清單套用至哪些整合範圍。變更會在點選 `儲存變更` 後套用。

- `同時套用至 MCP 整合`：將允許的 IP 清單套用至 MCP 工具呼叫。
- `同時套用至 Open API 與回覆整合`：涵蓋所有 Open API 呼叫（含 API 金鑰與 OAuth Token）、透過整合讀取回覆及附件下載。

首次開啟 IP 存取限制時，這兩項套用範圍預設皆為勾選狀態。

<Callout type="warning" title="整合中斷提醒">
雲端整合使用發出請求之伺服器的公用 IP 位址。套用此限制可能中斷現有整合，請務必一併將整合伺服器的 IP 位址加入允許清單。
</Callout>

## 管理允許的 IP 清單
可以用下列其中一種格式登錄 IP 位址或範圍：

- 個別 IP：`192.168.1.1`
- CIDR 範圍：`192.168.1.0/24`（192.168.1.0 ～ 192.168.1.255）
- 萬用字元：`192.168.*.*`（192.168.0.0 ～ 192.168.255.255）

<Callout type="warning" title="注意事項">
儲存前，請確認允許清單包含您目前使用的 IP 位址。否則，即使是管理員也將無法存取團隊。
</Callout>
