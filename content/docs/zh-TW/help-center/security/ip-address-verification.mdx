## 啟用 IP 位址驗證
- 在專案設定頁面啟用「IP 位址驗證」後，只有已登錄的 IP 位址才能進入問卷。
- 開啟 IP 驗證的狀態下，一定要至少登錄一個 IP 位址。
## 管理允許的 IP 位址／範圍
- 可以用下列其中一種格式登錄 IP 位址或範圍。
  - 個別 IP：`192.168.1.1`
  - CIDR 範圍：`192.168.1.0/24`（192.168.1.0 ～ 192.168.1.255）
  - 萬用字元：`192.168.*.*`（192.168.0.0 ～ 192.168.255.255）
