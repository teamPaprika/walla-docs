在 `團隊管理` → `安全性` 頁面中，您可以設定適用於整個團隊的安全性政策與整合存取控制。變更設定後，必須點選頁面下方的 `儲存變更` 按鈕才會套用。

<Callout title="參考">
大部分團隊安全性設定僅限 **Enterprise** 方案使用。不過，`允許 Open API` 不受方案限制，團隊管理員皆可設定；而已經啟用的 `需要審核的操作` 政策也可以在任何方案中關閉。
</Callout>

## 設定項目說明

### 雙因素驗證（MFA）
要求團隊成員使用雙因素驗證。啟用後，尚未設定雙因素驗證的成員必須完成驗證才能存取團隊。
詳細設定步驟請參閱[兩步驟驗證](/zh-TW/docs/help-center/security/two-factor-authentication)指南。

### 登入工作階段持續時間
要求每位團隊成員將個人登入工作階段持續時間設為不超過團隊設定的上限。預設為 `使用各成員的個人設定`，您也可以指定更短的上限時間。
設定超過團隊上限的成員，必須先在個人設定中縮短時間，才能存取團隊。

### IP 存取限制
僅允許從已登記的 IP 位址或範圍存取網頁控制台及相關 API。您可以管理允許的 IP 清單，並選擇是否同時套用至 MCP 整合與 Open API 與回覆整合。
詳細設定方式請參閱 [IP 存取限制](/zh-TW/docs/help-center/security/ip-address-verification)指南。

### 需要下載原因
要求使用者在下載回應時輸入原因。填寫的原因可在[活動紀錄](/zh-TW/docs/help-center/security/activity-logs)中查看。

### 防止複製已解除遮蔽的資料
限制在回應表中複製或剪下已解除遮蔽的回應值。
資料遮罩的詳細說明請參閱[資料遮罩](/zh-TW/docs/help-center/security/data-masking)指南。

### 封鎖自動化使用
封鎖 Webhook、Zapier、Google Sheets、Gmail 自動化的新使用與執行請求。

### 封鎖外部 AI 使用
啟用後，使用外部 AI 的功能（包括 AI 問卷生成和 Walla AI 聊天）將停用，團隊的回覆資料也不會傳送給外部 LLM 供應商。
詳細說明請參閱[封鎖外部 AI 使用](/zh-TW/docs/help-center/security/blocking-external-ai)指南。

### 允許 MCP（AI 連接器）
關閉後，所有針對此團隊資料的 MCP 工具呼叫都會遭到封鎖，而且此團隊不會顯示在 AI 用戶端的團隊清單中。此設定和 `封鎖外部 AI 使用` 彼此獨立。

開啟 `允許 MCP（AI 連接器）` 時，可以依功能細部控管是否允許：

- `瀏覽表單與工作區`：AI 可以讀取此團隊的工作區與表單結構。
- `讀取回應資料`：AI 可以讀取已遮罩的回應資料。
- `建立與編輯表單`：AI 可以建立表單、編輯問題並發佈。
- `管理自動化`：AI 可以列出、建立及更新自動化。

### 允許 Open API
關閉後，此團隊的所有 Open API 呼叫都會被封鎖（包括使用現有 API 金鑰和 OAuth Token 的呼叫）。關於 API 錯誤回應的詳細說明，請參閱[錯誤代碼](/zh-TW/docs/developer-docs/error-codes)開發者文件。
此設定不受方案限制，團隊管理員皆可變更。

### 需要審核的操作
可要求團隊成員在執行邀請團隊成員、下載回應、取消回應遮罩、刪除問卷等敏感操作前，先取得管理員核准。
完整流程請參閱[審核](/zh-TW/docs/help-center/security/approval-workflow)指南。
