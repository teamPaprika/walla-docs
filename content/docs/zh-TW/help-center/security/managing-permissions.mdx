Walla 的權限架構分為 **團隊權限**、**工作區角色權限** 與 **個別專案權限** 三個層級運作。全團隊的安全性與管理功能由團隊管理頁面控管；問卷建立、編輯、回應檢視與下載等權限，則以工作區和專案為單位控制。

## 各方案的角色權限差異

| 項目 | Free・Pro 方案 | Enterprise 方案 |
| --- | --- | --- |
| **依角色編輯權限** | 管理者與成員擁有相同的工作區權限（固定為 `擁有者`、`管理者`、`成員`） | 可使用 **新增角色**、**未指定** 角色，並依角色細部編輯權限 |
| **邀請預設角色** | 成員 *（邀請時預設套用）* | **未指定** *（邀請連結與邀請視窗的預設值）* |
| **權限套用範圍** | 整個工作區統一開啟／關閉 | 部分專案與回應權限可委派為 **依照專案設定** |
| **回應存取控制** | 不支援 | 支援依角色條件式查詢回應（[回應查詢管理](/zh-TW/docs/help-center/security/response-access-control)） |

<Callout type="info" title="說明">
在 Free・Pro 方案中，管理者與成員擁有相同的工作區權限；**新增角色**、**未指定** 角色以及依角色自訂權限僅提供給 **Enterprise 方案**。
</Callout>

## 團隊權限

適用於整個團隊的成員、帳務、工作區建立與安全性設定權限。可在左側邊欄的 **團隊管理 → 依角色權限** 中管理。

| 權限名稱 | 說明 |
| --- | --- |
| **邀請團隊成員** | 透過電子郵件或邀請連結邀請團隊成員。 |
| **建立工作區** | 在團隊內建立新的工作區。 |
| **移除團隊成員** | 將現有團隊成員移出團隊。 |
| **變更角色** | 變更團隊成員的團隊角色（管理者、成員）。 |
| **團隊安全性設定** | 設定雙重驗證（MFA）、登入工作階段期間、IP 存取限制、封鎖外部 AI 使用、審核工作流程等團隊安全政策。 |
| **帳務管理** | 變更團隊方案並管理付款方式。 |
| **下載團隊紀錄** | 匯出團隊活動紀錄。 |

## 工作區角色

管理工作區內問卷與回應的相關權限。請點選工作區右上角的齒輪圖示（**工作區設定**）→ **角色與權限** 進行設定。

- **擁有者（Owner）**：工作區建立者或受讓擁有權的使用者，所有權限皆為固定開啟。
- **管理者（Admin）**：預設啟用包含專案管理與成員、邀請管理在內的大部分權限。
- **成員（Member）**：具備專案建立與編輯、回應檢視與下載等實務所需的權限。
- **未指定（Restricted / Unassigned）** *(Enterprise)*：可作為邀請時的預設角色，在預設關閉所有專案與回應權限的狀態下，僅選擇性賦予必要權限。
- **自訂角色** *(Enterprise)*：點選 **新增角色** 按鈕即可建立如「首爾研究員」、「外部稽核」等符合團隊目的的新角色，並在 **權限設定** 與 **成員清單** 分頁中直接指派成員。

## 工作區 17 項細部權限

工作區角色的 **權限設定** 分頁分為 **專案**、**個人資料**、**進階** 三個群組。*（在 Enterprise 方案中，下表「可依專案委派」欄所標示的 8 項權限皆可設為 **依照專案設定**。）*

### 專案（10 項）

| 權限名稱 | 說明 | 可依專案委派 |
| --- | --- | --- |
| **建立專案** | 可在工作區內建立新專案。 | 全部允許／封鎖 |
| **複製專案** | 可複製既有專案。 | 可設為 **依照專案設定** |
| **管理專案** | 可移動、封存或刪除專案。 | 可設為 **依照專案設定** |
| **編輯專案** | 可編輯專案並指派標籤。 | 可設為 **依照專案設定** |
| **管理標籤** | 可建立、重新命名與刪除工作區共用標籤。 | 全部允許／封鎖 |
| **管理自動化** | 可檢視、建立、修改與刪除自動化流程。*（若要在執行紀錄中重新發送過往回應，亦需具備回應檢視權限。）* | 可設為 **依照專案設定** |
| **發送問卷** | 可登錄、修改、刪除收件人並發送問卷。 | 可設為 **依照專案設定** |
| **檢視所有回應** | 檢視問卷的所有回應。關閉時可選擇 **不允許** 或 **依照專案設定**。 | 可設為 **依照專案設定** *（支援條件式回應存取）* |
| **刪除回覆** | 可刪除問卷回覆。 | 可設為 **依照專案設定** |
| **下載回覆** | 可將問卷回覆下載為 CSV、Excel 等格式。 | 可設為 **依照專案設定** |

### 個人資料（3 項）

| 權限名稱 | 說明 |
| --- | --- |
| **編輯遮罩選項** | 可開啟或關閉各題目的[資料遮罩](/zh-TW/docs/help-center/security/data-masking)設定。 |
| **存取已遮罩的原始資料** | 可解除已遮罩回應（`*****`）並查看原始內容。*（解除時可能需填寫事由並套用審核政策。）* |
| **設定回覆自動刪除** | 可設定各問卷的[自動刪除回覆](/zh-TW/docs/help-center/security/auto-delete-responses)週期。 |

### 進階（4 項）

| 權限名稱 | 說明 |
| --- | --- |
| **編輯角色與權限** | 新增、重新命名、刪除工作區角色，並修改各角色的權限組合。 |
| **指派角色** | 變更工作區成員與受邀者的角色。 |
| **新增成員** | 將團隊成員加入工作區或邀請新成員。 |
| **移除成員** | 將現有成員移出工作區。 |

<Callout type="idea" title="說明">
若想僅針對特定專案開放編輯、下載或刪除回覆權限，或限制僅能檢視符合條件的回應，請參考 [專案權限](/zh-TW/docs/help-center/manage-forms/project-permissions) 與 [回應查詢管理](/zh-TW/docs/help-center/security/response-access-control) 文件。
</Callout>
