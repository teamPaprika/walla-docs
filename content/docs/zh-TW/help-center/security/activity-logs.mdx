## 查看活動紀錄的方式

<Steps>
  <Step>
    ### 前往活動紀錄分頁
    團隊設定頁面 → 前往「活動紀錄」分頁。
  </Step>
  <Step>
    ### 確認操作紀錄
    可以依序查看團隊內執行過的重要操作紀錄。
  </Step>
  <Step>
    ### 查看紀錄的詳細資訊
    每筆紀錄都會記下操作者、操作時間與執行的動作。團隊活動紀錄中還能確認連線 IP，並對所有網域套用稽核記錄。
  </Step>
</Steps>
## 主要紀錄項目

### Team Actions（7 項）

| Action | 說明 |
| --- | --- |
| team:leave | 退出團隊 |
| team:member.invite | 邀請團隊成員 |
| team:member.invite.cancel | 取消團隊邀請 |
| team:member.delete | 刪除團隊成員 |
| team:member.role.assign | 變更團隊成員角色 |
| team:security.update | 變更團隊安全性設定 |
| team:audit.log.download | 下載稽核紀錄 |
