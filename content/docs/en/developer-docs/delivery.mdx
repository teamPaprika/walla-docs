# Form Delivery API

The Form Delivery API allows you to send forms to recipients and track their delivery and response status. You can send forms via email or SMS, monitor recipient engagement, and retrieve delivery statistics.

> **⚠️ Important Notice**: The Form Delivery API is available only after prior agreement with Walla. Please contact Walla support to enable this feature for your account.

## Endpoints

### Send Form to Recipients

Send a published form to one or more recipients.

```http
POST /open-api/v1/forms/{formId}/delivery
```

> **Important**: Only published forms can be sent. Unpublished forms will return a 404 error.

#### Parameters

**Path Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `formId` | string | Yes | The unique form identifier |

**Request Body**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `recipients` | array | Yes | Array of recipient objects (minimum 1) |
| `recipients[].customerKey` | string | Yes | Unique customer identifier |
| `recipients[].email` | string | No | Recipient email address |
| `recipients[].phoneNumber` | string | No | Recipient phone number |
| `subject` | string | No | Email subject (default: "설문이 도착했습니다.") |
| `message` | string | No | Delivery message (default: "설문 링크를 확인하세요.") |

> **Note**: Each recipient must have at least one contact method (email or phoneNumber).

#### Request

**Example Request**

```bash
curl -X POST "https://api.walla.my/open-api/v1/forms/form_abc/delivery" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "recipients": [
      {
        "customerKey": "customer_001",
        "email": "john@example.com",
        "phoneNumber": "+821012345678"
      },
      {
        "customerKey": "customer_002",
        "email": "jane@example.com"
      }
    ],
    "subject": "We value your feedback!",
    "message": "Please take a moment to complete our survey."
  }'
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": {
    "totalRecipients": 2,
    "successfulDeliveries": [
      {
        "customerKey": "customer_001",
        "email": "john@example.com",
        "phoneNumber": "+821012345678",
        "aliasId": "8c1a4e2b-7d3f-4a9b-9c2e-1a2b3c4d5e6f",
        "formUrl": "https://walla.my/a/8c1a4e2b-7d3f-4a9b-9c2e-1a2b3c4d5e6f"
      },
      {
        "customerKey": "customer_002",
        "email": "jane@example.com",
        "phoneNumber": null,
        "aliasId": "2f5d6e1c-9a4b-4c3d-8e7f-0a1b2c3d4e5f",
        "formUrl": "https://walla.my/a/2f5d6e1c-9a4b-4c3d-8e7f-0a1b2c3d4e5f"
      }
    ],
    "failedDeliveries": []
  }
}
```

<Callout type="warning" title="Treat alias id as a form access token">
`aliasId` grants access to the form without authentication, so treat it like a token. Avoid exposing it through external systems, logs, or analytics tools — keep it within private channels. `formUrl` embeds the same token, so deliver it only to the intended recipient.
</Callout>


**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data.totalRecipients` | number | Total number of recipients |
| `data.successfulDeliveries` | array | Array of recipient objects that were delivered successfully |
| `data.successfulDeliveries[].customerKey` | string | Customer identifier provided in the request |
| `data.successfulDeliveries[].email` | string \| null | Recipient email (`null` if not included in the request) |
| `data.successfulDeliveries[].phoneNumber` | string \| null | Recipient phone number (`null` if not included in the request) |
| `data.successfulDeliveries[].aliasId` | string (UUID) | Issued alias identifier. Acts as the form access token |
| `data.successfulDeliveries[].formUrl` | string | Alias short URL in the form `https://walla.my/a/<aliasId>` |
| `data.failedDeliveries` | array | List of failed deliveries with error details |

**Error Responses**

- **400 Bad Request**: Invalid request data
  ```json
  {
    "error": "Invalid request: recipients array is required"
  }
  ```

- **401 Unauthorized**: API key missing or invalid
- **403 Forbidden**: No permission for this resource
  ```json
  {
    "error": "Authentication failed or insufficient permissions"
  }
  ```

- **404 Not Found**: Form not found or not published
  ```json
  {
    "error": "Form not found or not published"
  }
  ```

- **500 Internal Server Error**: Server error

### Get All Delivery Recipients

Retrieve all recipients and their status for a specific form.

```http
GET /open-api/v1/forms/{formId}/delivery
```

#### Parameters

**Path Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `formId` | string | Yes | The unique form identifier |

#### Request

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/forms/form_abc/delivery" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "id": "delivery_123",
      "formId": "form_abc",
      "customerKey": "customer_001",
      "email": "john@example.com",
      "phone": "+821012345678",
      "aliasId": "8c1a4e2b-7d3f-4a9b-9c2e-1a2b3c4d5e6f",
      "formUrl": "https://walla.my/a/8c1a4e2b-7d3f-4a9b-9c2e-1a2b3c4d5e6f",
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2024-01-15T11:45:00Z"
    },
    {
      "id": "delivery_456",
      "formId": "form_abc",
      "customerKey": "customer_002",
      "email": "jane@example.com",
      "phone": null,
      "aliasId": null,
      "formUrl": null,
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2024-01-15T10:30:00Z"
    }
  ]
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | array | Array of delivery objects |
| `data[].id` | string | Delivery identifier |
| `data[].formId` | string | Form identifier |
| `data[].customerKey` | string | Customer identifier |
| `data[].email` | string \| null | Recipient email |
| `data[].phone` | string \| null | Recipient phone number |
| `data[].aliasId` | string (UUID) \| null | Issued alias identifier. `null` for legacy rows that have no alias |
| `data[].formUrl` | string \| null | Alias short URL in the form `https://walla.my/a/<aliasId>`. `null` whenever `aliasId` is `null` |
| `data[].createdAt` | string (date-time) | Initial delivery creation timestamp |
| `data[].updatedAt` | string (date-time) | Last update timestamp |

> **Note**: `aliasId` and `formUrl` are returned as `null` for legacy delivery rows created before alias short URLs were introduced.

**Error Responses**

- **401 Unauthorized**: API key missing or invalid
- **403 Forbidden**: No permission for this resource
- **404 Not Found**: Form not found or not published
- **500 Internal Server Error**: Server error

### Get Delivery Status for Specific Recipients

Check the delivery and response status for specific recipients.

```http
POST /open-api/v1/forms/{formId}/delivery/status
```

#### Parameters

**Path Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `formId` | string | Yes | The unique form identifier |

**Request Body**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `customerKeys` | array | Yes | Array of customer keys to check (minimum 1) |

#### Request

**Example Request**

```bash
curl -X POST "https://api.walla.my/open-api/v1/forms/form_abc/delivery/status" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "customerKeys": ["customer_001", "customer_002", "customer_003"]
  }'
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "id": "delivery_123",
      "formId": "form_abc",
      "customerKey": "customer_001",
      "email": "john@example.com",
      "phone": "+821012345678",
      "status": "RESPONDED",
      "lastSentAt": "2024-01-15T10:30:00Z",
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2024-01-15T14:20:00Z"
    },
    {
      "id": "delivery_456",
      "formId": "form_abc",
      "customerKey": "customer_002",
      "email": "jane@example.com",
      "phone": null,
      "status": "OPENED",
      "lastSentAt": "2024-01-15T10:30:00Z",
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2024-01-15T11:15:00Z"
    },
    {
      "id": "delivery_789",
      "formId": "form_abc",
      "customerKey": "customer_003",
      "email": "bob@example.com",
      "phone": null,
      "status": "SENT",
      "lastSentAt": "2024-01-15T10:30:00Z",
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2024-01-15T10:30:00Z"
    }
  ]
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | array | Array of delivery status objects |
| `data[].id` | string | Delivery identifier |
| `data[].formId` | string | Form identifier |
| `data[].customerKey` | string | Customer identifier |
| `data[].email` | string | Recipient email |
| `data[].phone` | string | Recipient phone number |
| `data[].status` | string | Delivery status (see below) |
| `data[].lastSentAt` | string (date-time) | Last delivery timestamp |
| `data[].createdAt` | string (date-time) | Initial delivery creation timestamp |
| `data[].updatedAt` | string (date-time) | Last update timestamp |

**Delivery Status Values**

| Status | Description |
|--------|-------------|
| `NOT_SENT` | Delivery created but not yet sent |
| `SENT` | Form delivered successfully |
| `OPENED` | Recipient opened the form |
| `RESPONDED` | Recipient completed and submitted the form |

**Error Responses**

- **400 Bad Request**: Invalid request (e.g., empty customerKeys array)
- **401 Unauthorized**: API key missing or invalid
- **403 Forbidden**: No permission for this resource
- **404 Not Found**: Form not found or not published
- **500 Internal Server Error**: Server error

## Code Examples

### JavaScript/TypeScript

```typescript
interface Recipient {
  customerKey: string;
  email?: string;
  phoneNumber?: string;
}

interface DeliveryOptions {
  subject?: string;
  message?: string;
}

async function sendForm(
  formId: string,
  recipients: Recipient[],
  options?: DeliveryOptions
) {
  const response = await fetch(
    `https://api.walla.my/open-api/v1/forms/${formId}/delivery`,
    {
      method: 'POST',
      headers: {
        'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        recipients,
        subject: options?.subject || '설문이 도착했습니다.',
        message: options?.message || '설문 링크를 확인하세요.'
      })
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  return await response.json();
}

async function getDeliveryStatus(formId: string, customerKeys: string[]) {
  const response = await fetch(
    `https://api.walla.my/open-api/v1/forms/${formId}/delivery/status`,
    {
      method: 'POST',
      headers: {
        'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ customerKeys })
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  const data = await response.json();
  return data.data;
}

// Usage example
const result = await sendForm('form_abc', [
  {
    customerKey: 'customer_001',
    email: 'john@example.com'
  },
  {
    customerKey: 'customer_002',
    email: 'jane@example.com',
    phoneNumber: '+821012345678'
  }
], {
  subject: 'We need your feedback!',
  message: 'Please help us improve our services.'
});

console.log(`Successfully sent to ${result.data.successfulDeliveries.length} recipients`);

// Check status
const statuses = await getDeliveryStatus('form_abc', ['customer_001', 'customer_002']);
statuses.forEach(status => {
  console.log(`${status.customerKey}: ${status.status}`);
});
```

### Python

```python
import requests
import os
from typing import List, Dict, Any, Optional

class WallaDeliveryAPI:
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.base_url = "https://api.walla.my/open-api/v1"
        self.headers = {
            "X-WALLA-API-KEY": api_key,
            "Content-Type": "application/json"
        }

    def send_form(
        self,
        form_id: str,
        recipients: List[Dict[str, str]],
        subject: Optional[str] = None,
        message: Optional[str] = None
    ) -> Dict[str, Any]:
        """Send form to recipients"""
        url = f"{self.base_url}/forms/{form_id}/delivery"
        payload = {
            "recipients": recipients,
            "subject": subject or "설문이 도착했습니다.",
            "message": message or "설문 링크를 확인하세요."
        }

        response = requests.post(url, headers=self.headers, json=payload)
        response.raise_for_status()
        return response.json()

    def get_all_deliveries(self, form_id: str) -> List[Dict[str, Any]]:
        """Get all delivery recipients for a form"""
        url = f"{self.base_url}/forms/{form_id}/delivery"
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()
        return response.json()["data"]

    def get_delivery_status(
        self,
        form_id: str,
        customer_keys: List[str]
    ) -> List[Dict[str, Any]]:
        """Get delivery status for specific recipients"""
        url = f"{self.base_url}/forms/{form_id}/delivery/status"
        payload = {"customerKeys": customer_keys}

        response = requests.post(url, headers=self.headers, json=payload)
        response.raise_for_status()
        return response.json()["data"]

    def get_response_rate(self, form_id: str) -> float:
        """Calculate response rate for a form"""
        deliveries = self.get_all_deliveries(form_id)
        if not deliveries:
            return 0.0

        customer_keys = [d["customerKey"] for d in deliveries]
        statuses = self.get_delivery_status(form_id, customer_keys)

        responded = sum(1 for s in statuses if s["status"] == "RESPONDED")
        return (responded / len(statuses)) * 100

# Usage
api = WallaDeliveryAPI(os.getenv("WALLA_API_KEY"))

# Send form
result = api.send_form(
    "form_abc",
    [
        {"customerKey": "customer_001", "email": "john@example.com"},
        {"customerKey": "customer_002", "email": "jane@example.com"}
    ],
    subject="Your feedback matters!",
    message="Please take 2 minutes to complete our survey."
)

print(f"Sent to {len(result['data']['successfulDeliveries'])} recipients")

# Check response rate
response_rate = api.get_response_rate("form_abc")
print(f"Response rate: {response_rate:.2f}%")
```

## Best Practices

### Customer Key Management

- Use consistent customer keys across your system
- Customer keys should be unique per customer
- Consider using your internal customer IDs as customer keys
- Store the mapping between customer keys and your internal system

### Delivery Optimization

- **Batch Processing**: Send to multiple recipients in a single request
- **Error Handling**: Always check the `failedDeliveries` array and retry failed deliveries
- **Status Tracking**: Regularly check delivery status to monitor engagement

### Subject and Message Customization

```javascript
// Personalize based on campaign
const campaigns = {
  feedback: {
    subject: 'We value your feedback!',
    message: 'Help us improve our services by completing this quick survey.'
  },
  nps: {
    subject: 'How likely are you to recommend us?',
    message: 'Your opinion matters. Please share your thoughts.'
  }
};

await sendForm(formId, recipients, campaigns.feedback);
```
