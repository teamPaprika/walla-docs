# Workspaces API

The Workspaces API allows you to retrieve information about the workspaces you have access to. Workspaces are the top-level organizational unit in Walla that contain forms and teams.

To list only the forms in a specific workspace, use `GET /workspaces/{workspaceId}/forms`. To list all forms at once, use `GET /forms` in the [Forms API](/en/docs/developer-docs/forms).

When calling with an OAuth token, first look up your team ID with [List teams](#list-teams).

> **Note**: API key calls are subject to a [rate limit](/en/docs/developer-docs/authentication#rate-limiting) of 6,000 requests per hour per API key. OAuth token calls are subject to a separate [per-team call quota](/en/docs/developer-docs/authentication#oauth-token-call-quota). Every operation on this page can also be called with an OAuth token (`project:read`).

## Endpoints

### List teams

Returns the teams you can call through the Open API. With an API key, it returns only the team the key was issued for. With an OAuth token, it returns only the teams the token user belongs to that pass the team's Open API setting and IP access restrictions. Use the returned `id` as `teamId` for `GET /workspaces` and `GET /forms`.

```http
GET /open-api/v1/teams
```

#### Request

**Headers** (one of the following)
- `X-WALLA-API-KEY`: Your API key
- `Authorization: Bearer <access token>`: OAuth access token (requires the `project:read` scope)

**Example Request**

```bash
# API key
curl -X GET "https://api.walla.my/open-api/v1/teams" \
  -H "X-WALLA-API-KEY: your_api_key_here"

# OAuth token
curl -X GET "https://api.walla.my/open-api/v1/teams" \
  -H "Authorization: Bearer $WALLA_OAUTH_TOKEN"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "id": "team_456",
      "name": "Marketing Team",
      "profileUrl": null
    }
  ]
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | array | Array of team objects |
| `data[].id` | string | Team ID |
| `data[].name` | string | Team name |
| `data[].profileUrl` | string \| null | Team profile image URL |

> **Note**: A guest who has not turned on two-factor authentication still sees the team in the list, but operations on that team return `403`.

**Error Responses**

- **401 Unauthorized**: API key or OAuth token missing, invalid or expired
- **403 Forbidden**: The OAuth token lacks the `project:read` scope. For API key calls, this is also returned when the call is blocked by the team's Open API setting or IP access restrictions (for token calls, such teams are left out of the list instead)
- **500 Internal Server Error**: Server error

### Get All Workspaces

Retrieve a list of all workspaces you have access to.

```http
GET /open-api/v1/workspaces
```

#### Request

**Headers**
- `X-WALLA-API-KEY` (required for API key authentication): Your API key
- `Authorization: Bearer <access token>` (required for OAuth authentication): requires the `project:read` scope
- `Content-Type`: application/json

**Query Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `teamId` | string | Required for OAuth token calls | ID of the team to query. Look it up with [List teams](#list-teams). Ignored for API key calls |

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/workspaces" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

When calling with an OAuth token:

```bash
curl -X GET "https://api.walla.my/open-api/v1/workspaces?teamId=team_456" \
  -H "Authorization: Bearer $WALLA_OAUTH_TOKEN"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "id": "workspace_123",
      "name": "Marketing Team",
      "teamId": "team_456",
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2024-01-20T14:45:00Z"
    },
    {
      "id": "workspace_789",
      "name": "Customer Success",
      "teamId": "team_012",
      "createdAt": "2024-02-01T09:00:00Z",
      "updatedAt": "2024-02-10T16:20:00Z"
    }
  ]
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | array | Array of workspace objects |
| `data[].id` | string | Unique workspace identifier |
| `data[].name` | string | Workspace name |
| `data[].teamId` | string | Associated team identifier |
| `data[].createdAt` | string (date-time) | Workspace creation timestamp |
| `data[].updatedAt` | string (date-time) | Last update timestamp |

**Error Responses**

- **400 Bad Request**: `teamId` is missing from an OAuth token call
- **401 Unauthorized**: API key missing or invalid
- **403 Forbidden**: No permission for this resource
  ```json
  {
    "error": "Authentication failed or insufficient permissions"
  }
  ```

- **500 Internal Server Error**: Server error
  ```json
  {
    "error": "Internal server error"
  }
  ```

### Get Workspace by ID

Retrieve detailed information about a specific workspace.

```http
GET /open-api/v1/workspaces/{workspaceId}
```

#### Parameters

**Path Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `workspaceId` | string | Yes | The unique workspace identifier |

#### Request

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/workspaces/workspace_123" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": {
    "id": "workspace_123",
    "name": "Marketing Team",
    "teamId": "team_456",
    "createdAt": "2024-01-15T10:30:00Z",
    "updatedAt": "2024-01-20T14:45:00Z"
  }
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | object | Workspace details |
| `data.id` | string | Unique workspace identifier |
| `data.name` | string | Workspace name |
| `data.teamId` | string | Associated team identifier |
| `data.createdAt` | string (date-time) | Workspace creation timestamp |
| `data.updatedAt` | string (date-time) | Last update timestamp |

**Error Responses**

- **401 Unauthorized**: API key missing or invalid
- **403 Forbidden**: No permission for this resource. For OAuth token calls, if the token user cannot access this workspace, the API returns `{"error":"Access denied"}`
  ```json
  {
    "error": "Authentication failed or insufficient permissions"
  }
  ```

- **404 Not Found**: Workspace not found
  ```json
  {
    "error": "Workspace not found"
  }
  ```

- **500 Internal Server Error**: Server error
  ```json
  {
    "error": "Internal server error"
  }
  ```

### Get Forms in Workspace

Retrieve all forms within a specific workspace.

```http
GET /open-api/v1/workspaces/{workspaceId}/forms
```

#### Parameters

**Path Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `workspaceId` | string | Yes | The unique workspace identifier |

#### Request

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/workspaces/workspace_123/forms" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "form": {
        "id": "form_abc",
        "workspaceId": "workspace_123",
        "title": "Customer Satisfaction Survey",
        "description": "Quarterly customer feedback form",
        "badge": "Q1 2024",
        "teamId": "team_456",
        "creator": "user_789",
        "lastEditedBy": "user_012",
        "isDeleted": false,
        "createdAt": "2024-01-15T10:30:00Z",
        "updatedAt": "2024-01-20T14:45:00Z"
      },
      "formSettings": {
        // Form configuration settings
      },
      "analytics": {
        "submissions": 150
      }
    }
  ]
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | array | Array of form objects with settings and analytics |
| `data[].form` | object | Form details |
| `data[].form.id` | string | Unique form identifier |
| `data[].form.workspaceId` | string | Parent workspace identifier |
| `data[].form.title` | string | Form title |
| `data[].form.description` | string | Form description |
| `data[].form.badge` | string | Form badge/label |
| `data[].form.teamId` | string | Associated team identifier |
| `data[].form.creator` | string | Creator user identifier |
| `data[].form.lastEditedBy` | string | Last editor user identifier |
| `data[].form.isDeleted` | boolean | Deletion status |
| `data[].form.createdAt` | string (date-time) | Form creation timestamp |
| `data[].form.updatedAt` | string (date-time) | Last update timestamp |
| `data[].formSettings` | object | Form configuration settings |
| `data[].analytics` | object | Form analytics data |
| `data[].analytics.submissions` | number | Total number of submissions |

**Error Responses**

- **401 Unauthorized**: API key missing or invalid
- **403 Forbidden**: No permission for this resource
- **404 Not Found**: Workspace not found
- **500 Internal Server Error**: Server error

## Code Examples

### JavaScript/TypeScript

```typescript
async function getAllWorkspaces() {
  const response = await fetch('https://api.walla.my/open-api/v1/workspaces', {
    method: 'GET',
    headers: {
      'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
      'Content-Type': 'application/json'
    }
  });

  const data = await response.json();
  return data.data;
}

async function getWorkspaceById(workspaceId: string) {
  const response = await fetch(
    `https://api.walla.my/open-api/v1/workspaces/${workspaceId}`,
    {
      method: 'GET',
      headers: {
        'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
        'Content-Type': 'application/json'
      }
    }
  );

  const data = await response.json();
  return data.data;
}
```

### Python

```python
import requests
import os

def get_all_workspaces():
    url = "https://api.walla.my/open-api/v1/workspaces"
    headers = {
        "X-WALLA-API-KEY": os.getenv("WALLA_API_KEY"),
        "Content-Type": "application/json"
    }

    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()["data"]

def get_workspace_by_id(workspace_id):
    url = f"https://api.walla.my/open-api/v1/workspaces/{workspace_id}"
    headers = {
        "X-WALLA-API-KEY": os.getenv("WALLA_API_KEY"),
        "Content-Type": "application/json"
    }

    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()["data"]
```

## Use Cases

### Workspace Information Dashboard

```typescript
// Build a dashboard showing every workspace and its form count
async function createWorkspaceDashboard() {
  const workspaces = await getAllWorkspaces();

  for (const workspace of workspaces) {
    const forms = await getWorkspaceForms(workspace.id);
    console.log(`${workspace.name}: ${forms.length} forms`);
  }
}
```

### Filtering Data by Workspace

```python
# Fetch only the workspaces belonging to a specific team
def get_workspaces_by_team(team_id):
    all_workspaces = get_all_workspaces()
    return [ws for ws in all_workspaces if ws['teamId'] == team_id]
```
