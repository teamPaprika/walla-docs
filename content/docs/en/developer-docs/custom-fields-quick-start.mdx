# Quick Start

This guide walks you through building your first custom field — a color picker that integrates with the Walla form builder.

## Prerequisites

- A Walla account with a workspace
- Basic knowledge of HTML and JavaScript
- A way to host static HTML (any web server, CDN, or hosting service)

## Step 1: Install the SDK

### Option A: npm (recommended for bundled projects)

```bash
npm install @wallaform/custom-field-sdk
```

### Option B: CDN (for standalone HTML files)

```html
<script type="module">
  import { WallaField } from 'https://esm.sh/@wallaform/custom-field-sdk';
</script>
```

> The SDK is **ESM-only**. Use `<script type="module">` or a bundler (Vite, webpack, esbuild, etc.).

## Step 2: Create Your Field

Create an `index.html` file with a minimal color picker:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { font-family: system-ui; padding: 12px; }
    .swatches { display: flex; gap: 8px; flex-wrap: wrap; }
    .swatch {
      width: 36px; height: 36px; border-radius: 8px;
      border: 2px solid transparent; cursor: pointer;
    }
    .swatch.selected { border-color: var(--primary, #007eff); }
    .custom-input {
      margin-top: 12px; display: flex; align-items: center; gap: 8px;
    }
    .custom-input input[type="color"] {
      width: 36px; height: 36px; border: none; cursor: pointer;
    }
    .custom-input span {
      font-size: 14px; color: var(--fg, #333);
    }
  </style>
</head>
<body>
  <div class="swatches" id="swatches"></div>
  <div class="custom-input">
    <input type="color" id="picker" value="#007EFF" />
    <span id="hex">#007EFF</span>
  </div>

  <script type="module">
    import { WallaField } from 'https://esm.sh/@wallaform/custom-field-sdk';

    const field = new WallaField({ debug: true });
    const presets = ['#FF6B6B','#4ECDC4','#45B7D1','#96CEB4','#FFEAA7','#DDA0DD','#007EFF','#2D3436'];
    let selectedColor = '#007EFF';

    // Render preset swatches
    const swatchesEl = document.getElementById('swatches');
    presets.forEach(color => {
      const el = document.createElement('div');
      el.className = 'swatch';
      el.style.background = color;
      el.addEventListener('click', () => selectColor(color));
      swatchesEl.appendChild(el);
    });

    // Custom color picker
    const pickerEl = document.getElementById('picker');
    const hexEl = document.getElementById('hex');
    pickerEl.addEventListener('input', (e) => selectColor(e.target.value));

    function selectColor(color) {
      selectedColor = color;
      pickerEl.value = color;
      hexEl.textContent = color.toUpperCase();

      // Update swatch selection UI
      document.querySelectorAll('.swatch').forEach(el => {
        el.classList.toggle('selected', el.style.background === color);
      });

      // Report value to host — auto-saved on every call
      field.setValue(color);
    }

    // 1. Receive initialization data
    field.onInit(({ value, theme, properties }) => {
      // Apply form theme
      document.documentElement.style.setProperty('--primary', theme.primary);
      document.documentElement.style.setProperty('--fg', theme.foreground);
      document.body.style.fontFamily = theme.fontFamily;
      document.body.style.background = theme.background;

      // Restore saved value
      if (value) {
        selectColor(value);
      }

      // Resize iframe to fit content
      field.setHeight(document.body.scrollHeight);
    });

    // 2. Handle validation
    field.onValidate((submitType) => {
      if (!selectedColor) {
        return { valid: false, errors: [{ message: 'Please select a color' }] };
      }
      return { valid: true };
    });
  </script>
</body>
</html>
```

## Step 3: Test Locally

Serve the file with any static server:

```bash
npx serve -l 4567 .
```

Your field will be available at `http://localhost:4567/index.html`.

> There is currently no standalone test harness — you need to register the field in the Walla dashboard to test it within a form. A local mock host is planned for a future release.

## Step 4: Deploy

Host your HTML file on any publicly accessible URL. Some options:

- **Static hosting**: Vercel, Netlify, Cloudflare Pages, GitHub Pages
- **CDN**: Upload to any CDN or cloud storage with public access
- **Your own server**: Any web server that can serve static files

The URL you deploy to becomes the **render URL** that you register in the Walla dashboard.

## Step 5: Register in Walla

> **Note:** Custom field type registration is not self-service at this time. To register a new custom field type, please contact the Walla team to discuss your use case and set up the integration together.

Once your custom field type is registered by the Walla team, you can add it to any form through the form builder's **Custom Fields** tab.

## Understanding the Code

Let's break down the key parts:

### Constructor

```typescript
const field = new WallaField({ debug: true });
```

Creates a new field instance. The SDK automatically:
- Extracts the `fieldId` from the URL query parameter (`?fieldId=xxx`)
- Waits for the host to transfer a `MessagePort`
- Establishes the RPC session

The `debug` option logs all RPC messages to the browser console — useful during development.

### Callbacks

```typescript
field.onInit(callback)     // Receive config, theme, saved value
field.onValidate(callback) // Respond to validation requests
```

Callbacks are registered before the connection is established. When the host connects and calls `init()`, your callback fires with the full initialization payload.

### Actions

```typescript
field.setValue(color)                      // Report value changes
field.setHeight(document.body.scrollHeight) // Resize iframe
```

These methods send RPC calls to the host. `setValue()` is auto-saved by the host on every call (debounced at 50ms). `setHeight()` adjusts the iframe height (throttled at 100ms, clamped to 0–5000px).
