# Forms API

The Forms API allows you to retrieve information about forms (surveys/projects) within your workspaces. You can list all forms, get specific form details, and access form settings.

## Endpoints

### Get All Forms

Retrieve all forms across all workspaces you have access to.

```http
GET /open-api/v1/forms
```

#### Request

**Headers**
- `X-WALLA-API-KEY` (required): Your API key
- `Content-Type`: application/json

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/forms" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "workspaceId": "workspace_123",
      "workspaceName": "Marketing Team",
      "forms": [
        {
          "form": {
            "id": "form_abc",
            "workspaceId": "workspace_123",
            "title": "Customer Satisfaction Survey",
            "description": "Quarterly customer feedback form",
            "badge": "Q1 2024",
            "teamId": "team_456",
            "creator": "user_789",
            "lastEditedBy": "user_012",
            "isDeleted": false,
            "createdAt": "2024-01-15T10:30:00Z",
            "updatedAt": "2024-01-20T14:45:00Z"
          },
          "formSettings": {
            // Form configuration settings
          },
          "analytics": {
            "submissions": 150
          }
        }
      ]
    }
  ]
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | array | Array of workspace objects with their forms |
| `data[].workspaceId` | string | Workspace identifier |
| `data[].workspaceName` | string | Workspace name |
| `data[].forms` | array | Array of forms in the workspace |
| `data[].forms[].form` | object | Form details |
| `data[].forms[].formSettings` | object | Form configuration |
| `data[].forms[].analytics` | object | Form analytics |

**Error Responses**

- **403 Forbidden**: Authentication failed or insufficient permissions
- **500 Internal Server Error**: Server error

### Get Form by ID

Retrieve detailed information about a specific form.

```http
GET /open-api/v1/forms/{formId}
```

#### Parameters

**Path Parameters**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `formId` | string | Yes | The unique form identifier |

#### Request

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/forms/form_abc" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

#### Response

**Success Response (200 OK)**

```json
{
  "success": true,
  "data": {
    "id": "form_abc",
    "title": "Customer Satisfaction Survey",
    "description": "Quarterly customer feedback form",
    "badge": "Q1 2024",
    "teamId": "team_456",
    "workspaceId": "workspace_123",
    "creator": "user_789",
    "lastEditedBy": "user_012",
    "isDeleted": false,
    "createdAt": "2024-01-15T10:30:00Z",
    "updatedAt": "2024-01-20T14:45:00Z"
  }
}
```

**Response Fields**

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | object | Form details |
| `data.id` | string | Unique form identifier |
| `data.title` | string | Form title |
| `data.description` | string | Form description |
| `data.badge` | string | Form badge/label |
| `data.teamId` | string | Associated team identifier |
| `data.workspaceId` | string | Parent workspace identifier |
| `data.creator` | string | Creator user identifier |
| `data.lastEditedBy` | string | Last editor user identifier |
| `data.isDeleted` | boolean | Deletion status |
| `data.createdAt` | string (date-time) | Form creation timestamp |
| `data.updatedAt` | string (date-time) | Last update timestamp |

**Error Responses**

- **403 Forbidden**: Authentication failed or insufficient permissions
  ```json
  {
    "error": "Authentication failed or insufficient permissions"
  }
  ```

- **404 Not Found**: Form not found
  ```json
  {
    "error": "Form not found"
  }
  ```

- **500 Internal Server Error**: Server error
  ```json
  {
    "error": "Internal server error"
  }
  ```

## Form Properties Explained

### Form Status

- **isDeleted**: Boolean flag indicating whether the form has been soft-deleted. Deleted forms may still be accessible via API but are hidden from the main interface.

### Form Badge

The `badge` field is a custom label you can assign to forms for categorization or identification purposes. Common uses include:
- Version numbers (e.g., "v2.0")
- Time periods (e.g., "Q1 2024", "January")
- Status indicators (e.g., "Active", "Draft")
- Campaign names

### Audit Trail

Forms include audit trail information:
- `creator`: User ID of the person who created the form
- `lastEditedBy`: User ID of the person who last modified the form
- `createdAt`: Timestamp when the form was created
- `updatedAt`: Timestamp of the last modification

## Code Examples

### JavaScript/TypeScript

```typescript
interface Form {
  id: string;
  title: string;
  description: string;
  badge: string;
  teamId: string;
  workspaceId: string;
  creator: string;
  lastEditedBy: string;
  isDeleted: boolean;
  createdAt: string;
  updatedAt: string;
}

async function getAllForms(): Promise<any[]> {
  const response = await fetch('https://api.walla.my/open-api/v1/forms', {
    method: 'GET',
    headers: {
      'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
      'Content-Type': 'application/json'
    }
  });

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  const data = await response.json();
  return data.data;
}

async function getFormById(formId: string): Promise<Form> {
  const response = await fetch(
    `https://api.walla.my/open-api/v1/forms/${formId}`,
    {
      method: 'GET',
      headers: {
        'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
        'Content-Type': 'application/json'
      }
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  const data = await response.json();
  return data.data;
}

// Get all active (non-deleted) forms
async function getActiveForms(): Promise<Form[]> {
  const workspaces = await getAllForms();
  const activeForms: Form[] = [];

  workspaces.forEach(workspace => {
    workspace.forms.forEach(formWrapper => {
      if (!formWrapper.form.isDeleted) {
        activeForms.push(formWrapper.form);
      }
    });
  });

  return activeForms;
}
```

### Python

```python
import requests
import os
from typing import List, Dict, Any

class WallaFormsAPI:
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.base_url = "https://api.walla.my/open-api/v1"
        self.headers = {
            "X-WALLA-API-KEY": api_key,
            "Content-Type": "application/json"
        }

    def get_all_forms(self) -> List[Dict[str, Any]]:
        """Get all forms across all workspaces"""
        url = f"{self.base_url}/forms"
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()
        return response.json()["data"]

    def get_form_by_id(self, form_id: str) -> Dict[str, Any]:
        """Get a specific form by ID"""
        url = f"{self.base_url}/forms/{form_id}"
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()
        return response.json()["data"]

    def get_active_forms(self) -> List[Dict[str, Any]]:
        """Get all non-deleted forms"""
        workspaces = self.get_all_forms()
        active_forms = []

        for workspace in workspaces:
            for form_wrapper in workspace["forms"]:
                if not form_wrapper["form"]["isDeleted"]:
                    active_forms.append(form_wrapper["form"])

        return active_forms

# Usage
api = WallaFormsAPI(os.getenv("WALLA_API_KEY"))
forms = api.get_all_forms()
specific_form = api.get_form_by_id("form_abc")
```

## Use Cases

### List All Active Forms

Retrieve all forms that haven't been deleted across all your workspaces:

```javascript
const workspaces = await getAllForms();
const activeForms = workspaces.flatMap(ws =>
  ws.forms
    .filter(f => !f.form.isDeleted)
    .map(f => f.form)
);
```

### Find Forms by Workspace

Get all forms for a specific workspace:

```javascript
const workspaces = await getAllForms();
const targetWorkspace = workspaces.find(ws => ws.workspaceId === 'workspace_123');
const forms = targetWorkspace?.forms || [];
```

### Check Form Analytics

Access submission counts and other analytics:

```javascript
const workspaces = await getAllForms();
workspaces.forEach(ws => {
  ws.forms.forEach(formWrapper => {
    console.log(`${formWrapper.form.title}: ${formWrapper.analytics.submissions} submissions`);
  });
});
```
