# Field Output Schemas API

The Field Output Schemas API provides essential mapping information that helps you understand what data format each field type returns. This is crucial for correctly parsing and processing form response data.

## Overview

When you retrieve form responses, the `response` object contains field values as dynamic properties, where field IDs are keys and values vary by field type. The Field Output Schemas API tells you exactly what data structure to expect for each field type.

## Get Field Output Schemas

Retrieve field type to output schema mapping information.

```http
GET /open-api/v1/field-output-schemas
```

### Request

**Example Request**

```bash
curl -X GET "https://api.walla.my/open-api/v1/field-output-schemas" \
  -H "X-WALLA-API-KEY: your_api_key_here" \
  -H "Content-Type: application/json"
```

## Field Type Categories

### String Types (Simple Text Values)

These field types return a single string value:

- **SHORT_TEXT**: Single-line text input
- **LONG_TEXT**: Multi-line text input
- **EMAIL**: Email address
- **PHONE**: Phone number
- **NUMBER**: Numeric input
- **DATE**: Date value
- **TIME**: Time value
- **URL**: Website URL
- **RADIO**: Single choice from radio buttons
- **DROPDOWN**: Single choice from dropdown menu

**Example Response:**
```json
{
  "field_abc123": "John Doe"
}
```

### Array Types (Multiple Values)

These field types return an array of strings:

- **CHECKBOX**: Multiple selection checkboxes
- **MULTI_SELECT**: Multiple selection dropdown
- **FILE_UPLOAD**: List of uploaded file URLs

**Example Response:**
```json
{
  "field_xyz789": ["Option A", "Option B", "Option C"]
}
```

### Object Types (Structured Data)

These field types return structured objects with multiple properties:

- **ADDRESS**: Address with street, city, state, zipCode
- **NAME**: Name with firstName, lastName
- **PHONE_DETAILED**: Detailed phone with countryCode, number
- **DATE_RANGE**: Date range with startDate, endDate

**Example Response:**
```json
{
  "field_def456": {
    "firstName": "John",
    "lastName": "Doe"
  },
  "field_ghi789": {
    "street": "123 Main St",
    "city": "San Francisco",
    "state": "CA",
    "zipCode": "94102"
  }
}
```

### Grid Types (Table Data)

These field types return nested arrays representing table/grid data:

- **GRID**: Table with rows and columns

**Example Response:**
```json
{
  "field_grid001": {
    "rows": [
      ["Row 1 Col 1", "Row 1 Col 2", "Row 1 Col 3"],
      ["Row 2 Col 1", "Row 2 Col 2", "Row 2 Col 3"]
    ]
  }
}
```

### Null Types (Display-Only)

These field types don't collect input and return null:

- **HEADING**: Section heading
- **DESCRIPTION**: Descriptive text
- **DIVIDER**: Visual separator
- **IMAGE**: Displayed image

**Example Response:**
```json
{
  "field_heading001": null
}
```

## Code Examples

### JavaScript/TypeScript

```typescript
interface FieldOutputSchemas {
  arrayTypes: {
    description: string;
    outputType: string;
    fieldTypes: string[];
    example: string[];
  };
  gridTypes: {
    description: string;
    outputType: string;
    fieldTypes: string[];
    example: object;
  };
  objectTypes: {
    description: string;
    fields: Array<{
      fieldType: string;
      outputType: string;
      schema: object;
    }>;
  };
  stringTypes: {
    description: string;
    outputType: string;
    fieldTypes: string[];
    example: string;
  };
  nullTypes: {
    description: string;
    outputType: string;
    fieldTypes: string[];
  };
}

async function getFieldOutputSchemas(): Promise<FieldOutputSchemas> {
  const response = await fetch(
    'https://api.walla.my/open-api/v1/field-output-schemas',
    {
      headers: {
        'X-WALLA-API-KEY': process.env.WALLA_API_KEY!,
        'Content-Type': 'application/json'
      }
    }
  );

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  const data = await response.json();
  return data.data;
}

// Usage: Parse response data based on field type
async function parseResponseValue(
  fieldType: string,
  value: any,
  schemas: FieldOutputSchemas
): Promise<any> {
  // Check if it's an array type
  if (schemas.arrayTypes.fieldTypes.includes(fieldType)) {
    return value as string[];
  }

  // Check if it's a string type
  if (schemas.stringTypes.fieldTypes.includes(fieldType)) {
    return value as string;
  }

  // Check if it's a null type
  if (schemas.nullTypes.fieldTypes.includes(fieldType)) {
    return null;
  }

  // Check if it's an object type
  const objectField = schemas.objectTypes.fields.find(
    f => f.fieldType === fieldType
  );
  if (objectField) {
    return value as object;
  }

  // Check if it's a grid type
  if (schemas.gridTypes.fieldTypes.includes(fieldType)) {
    return value as object;
  }

  return value;
}

// Example: Processing form responses
const schemas = await getFieldOutputSchemas();
console.log('Array field types:', schemas.arrayTypes.fieldTypes);
console.log('String field types:', schemas.stringTypes.fieldTypes);
```

### Python

```python
import requests
import os
from typing import Dict, Any, List, Union

class WallaFieldSchemas:
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.base_url = "https://api.walla.my/open-api/v1"
        self.headers = {
            "X-WALLA-API-KEY": api_key,
            "Content-Type": "application/json"
        }
        self._schemas = None

    def get_field_output_schemas(self) -> Dict[str, Any]:
        """Get field output schemas mapping"""
        if self._schemas:
            return self._schemas

        url = f"{self.base_url}/field-output-schemas"
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()

        self._schemas = response.json()["data"]
        return self._schemas

    def get_output_type(self, field_type: str) -> str:
        """Get the output type for a given field type"""
        schemas = self.get_field_output_schemas()

        if field_type in schemas["arrayTypes"]["fieldTypes"]:
            return "array"
        elif field_type in schemas["stringTypes"]["fieldTypes"]:
            return "string"
        elif field_type in schemas["nullTypes"]["fieldTypes"]:
            return "null"
        elif field_type in schemas["gridTypes"]["fieldTypes"]:
            return "grid"
        else:
            # Check object types
            for field in schemas["objectTypes"]["fields"]:
                if field["fieldType"] == field_type:
                    return "object"

        return "unknown"

    def parse_response_value(
        self,
        field_type: str,
        value: Any
    ) -> Union[str, List[str], Dict, None]:
        """Parse a response value based on its field type"""
        output_type = self.get_output_type(field_type)

        if output_type == "null":
            return None
        elif output_type == "array":
            return value if isinstance(value, list) else []
        elif output_type == "string":
            return str(value) if value is not None else ""
        else:
            return value

# Usage
api = WallaFieldSchemas(os.getenv("WALLA_API_KEY"))

# Get schemas
schemas = api.get_field_output_schemas()
print(f"String types: {schemas['stringTypes']['fieldTypes']}")
print(f"Array types: {schemas['arrayTypes']['fieldTypes']}")

# Parse response values
field_type = "CHECKBOX"
value = ["Option A", "Option B"]
parsed = api.parse_response_value(field_type, value)
print(f"Parsed value: {parsed}")
```

## Use Cases

### 1. Dynamic Form Response Parser

Use field output schemas to build a generic response parser:

```typescript
async function buildResponseParser(formId: string) {
  // Get field schemas
  const schemas = await getFieldOutputSchemas();

  // Get form fields to know the structure
  const fields = await getFormFields(formId);

  // Create parser map
  const parser = new Map();
  fields.forEach(field => {
    parser.set(field.id, {
      label: field.label,
      fieldType: field.fieldType,
      outputType: field.outputType,
      parser: (value) => parseResponseValue(field.fieldType, value, schemas)
    });
  });

  return parser;
}

// Use the parser
const parser = await buildResponseParser('form_abc');
const responses = await getFormResponses('form_abc');

responses.forEach(response => {
  Object.entries(response.response).forEach(([fieldId, value]) => {
    const fieldParser = parser.get(fieldId);
    if (fieldParser) {
      const parsedValue = fieldParser.parser(value);
      console.log(`${fieldParser.label}: ${parsedValue}`);
    }
  });
});
```

### 2. Response Data Validation

Validate response data types before processing:

```typescript
function validateResponseData(
  fieldType: string,
  value: any,
  schemas: FieldOutputSchemas
): boolean {
  if (schemas.arrayTypes.fieldTypes.includes(fieldType)) {
    return Array.isArray(value);
  }

  if (schemas.stringTypes.fieldTypes.includes(fieldType)) {
    return typeof value === 'string';
  }

  if (schemas.nullTypes.fieldTypes.includes(fieldType)) {
    return value === null;
  }

  if (schemas.gridTypes.fieldTypes.includes(fieldType)) {
    return typeof value === 'object' && value !== null;
  }

  // Object types
  const objectField = schemas.objectTypes.fields.find(
    f => f.fieldType === fieldType
  );
  if (objectField) {
    return typeof value === 'object' && value !== null;
  }

  return true;
}
```

### 3. Export Response Data

Format response data for export based on field types:

```typescript
function formatForExport(
  fieldType: string,
  value: any,
  schemas: FieldOutputSchemas
): string {
  if (schemas.arrayTypes.fieldTypes.includes(fieldType)) {
    return Array.isArray(value) ? value.join(', ') : '';
  }

  if (schemas.stringTypes.fieldTypes.includes(fieldType)) {
    return String(value || '');
  }

  if (schemas.nullTypes.fieldTypes.includes(fieldType)) {
    return '';
  }

  // Object types - convert to JSON string
  if (typeof value === 'object' && value !== null) {
    return JSON.stringify(value);
  }

  return String(value || '');
}
```

## Best Practices

1. **Cache the Schemas**: Field output schemas rarely change. Cache them to avoid repeated API calls.

2. **Validate Before Processing**: Always validate response data types match expected field types before processing.

3. **Handle Unknown Types Gracefully**: If you encounter an unknown field type, log it for investigation but don't break your processing pipeline.

4. **Use with Form Fields API**: Always cross-reference with the Form Fields API to get the complete picture of form structure.

5. **Type-Safe Parsing**: Use TypeScript or type hints to ensure type-safe response parsing.
