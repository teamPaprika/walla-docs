## What is a Panel?

A panel is a list of recipients to send surveys to. In the **Panel** tab of your workspace, you can upload panel lists via CSV or Excel files and organize them into groups for structured management.

## Navigating to the Panel Tab

Click the **Panel** tab at the top of the workspace screen to access panel management.

- Tab order: Projects → Archive → **Panel**

The panel list displays the following information:

| Field | Description |
|-------|-------------|
| Customer Key | Unique identifier for the panel member |
| Name | Panel member's name (masked by default) |
| Email | Panel member's email address (masked by default) |
| Phone Number | Panel member's phone number (masked by default) |
| Group | Group the panel member belongs to |

<Callout type="info" title="Personal Data Masking">
Names, emails, and phone numbers are masked by default to protect personal information. You need to unmask the data to view the actual information.
</Callout>

## Uploading Panels

You can register panel members all at once using a CSV or Excel file.

1. Click the **Panel Upload** button in the Panel tab.
2. Select a **group** to assign to the uploaded panels. (Optional)
3. Click **Select File** and choose your CSV or Excel file.
4. Review the valid data, then click **Upload Panel**.

<Callout type="warn" title="File Format Requirements">
- Name is required. Either email or phone number must also be provided.
- If leading zeros in phone numbers are missing, set the cell format of the phone number column to **Text**, or add a `'` before the phone number.
- If your file has formatting issues, check the **Invalid Data** tab for error details.
- Click **Download Template** to get a file template.
</Callout>

<Callout type="info" title="Currently Supported Delivery Method">
Currently, only **email delivery** is supported for sending surveys to panels.
</Callout>

## Managing Groups

You can categorize panels into groups to organize them by purpose.

1. Click the **Manage Groups** button in the Panel tab.
2. View the existing group list and the number of panel members in each group.
3. Click **Create Group** to add a new group, or use the edit button next to a group to rename it.
4. Select groups to delete and click **Delete Selected** to remove them.

## Unmasking Personal Data

To view panel members' personal information (name, email, phone number), you need to unmask the data.

1. Click the **Unmask** button (lock icon) at the top of the Panel tab.
2. Enter the **reason for unmasking**.
3. Click **Unmask**.

Once unmasked, the search function becomes available as well.

<Callout type="warn" title="Unmasking Notice">
The reason for unmasking is recorded. Please avoid unnecessary access to personal information.
</Callout>

## Filter and View Settings

**Filter**: Filter the panel list to show only members from a specific group.

**View**: Configure sorting and which columns to display.
- Sort by: Creation date (ascending/descending)
- Toggle columns: Customer Key, Name, Email, Phone Number, Group can each be turned on/off
