## What is a Panel?

A panel is a list of recipients to send surveys to. In the **Panel** tab of your workspace, you can upload panel lists via CSV or Excel files and organize them into groups for structured management.

| Field | Description |
| ---- | ------------------- |
| Customer Key | Unique identifier for the panel member |
| Name | Panel member's name (masked by default) |
| Email | Panel member's email address (masked by default) |
| Phone Number | Panel member's phone number (masked by default) |
| Group | Group the panel member belongs to |

<Callout type="info" title="Personal Data Masking">
Names, emails, and phone numbers are masked by default to protect personal information. You need to unmask the data to view the actual information.
</Callout>

## Uploading Panels

You can register an entire panel list at once using a CSV or Excel file.

<Steps>
  <Step>
    ### Click the Panel Upload button
    In the Panel tab, click the **Panel Upload** button.
  </Step>
  <Step>
    ### Select a group
    Choose a **group** to assign the uploaded panels to. (Optional)
  </Step>
  <Step>
    ### Select a file
    Click the **Select File** button and choose your CSV or Excel file.
    Any rows with errors in the name, email, or phone number fields will be excluded from the upload.
  </Step>
  <Step>
    ### Complete the upload
    Review the valid data, then click the **Upload Panel** button.
  </Step>
</Steps>

<Callout type="warn" title="File Format Requirements">
- Name is required, and either email or phone number must also be provided.
- If leading zeros in phone numbers are missing, set the phone number column's cell format to **Text**, or add a `'` before each phone number.
- If your file has formatting issues, check the **Invalid Data** tab for error details.
- Click the **Download Template** button if you need a file template.
</Callout>

<Callout type="info" title="Currently Supported Delivery Method">
Currently, only email delivery is supported when sending surveys to panels.
</Callout>

## Managing Groups

You can categorize panels into groups to organize them by purpose.

<Steps>
  <Step>
    ### Click the Manage Groups button
    In the Panel tab, click the `Manage Groups` button.
  </Step>
  <Step>
    ### Review the group list
    You can see the existing groups along with the number of panel members in each group.
  </Step>
  <Step>
    ### Create or edit a group
    Click `Create Group` to add a new group, or click the edit button next to a group to rename it.
  </Step>
  <Step>
    ### Delete a group
    Select the groups you want to remove, then click `Delete Selected` to delete them.
  </Step>
</Steps>

## Unmasking Personal Data

To view panel members' personal information (name, email, phone number), you need to unmask the data.

<Steps>
  <Step>
    ### Click the Unmask button
    Click the `Unmask` button at the top of the Panel tab.
  </Step>
  <Step>
    ### Enter a reason
    Provide a reason for unmasking.
  </Step>
  <Step>
    ### Complete unmasking
    Click the `Unmask` button.
  </Step>
</Steps>

Once unmasked, the search function becomes available as well.

<Callout type="warn" title="Unmasking Notice">
When data is unmasked, the reason is recorded in the access log. Please avoid unnecessary access to personal information.
</Callout>

### Filter and View Settings

- **Filter**: Filter the panel list to show only members from a specific group.
- **View**: Configure the sort order and which columns to display.
- **Sort by**: Creation date (ascending/descending)
- **Display columns**: Customer Key, Name, Email, Phone Number, and Group can each be toggled on/off.
