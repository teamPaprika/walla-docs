## Adding members to a workspace

<Steps>
  <Step>
    ### Open workspace settings
    Click the `gear icon` in the top right of the workspace.

    <img src="/images/guides/team-workspace/workspace-settings-button.png" alt="The gear (settings) icon in the top right of the workspace page" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Select team members and add them
    Select the team members you want to add to the workspace, or enter the account of someone you want to newly invite to the team/workspace, then click the `Add` button.

    <img src="/images/guides/team-workspace/workspace-member-added.png" alt="A new member added to the workspace member list with the invitation complete toast" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Invitation complete
    Team members are added immediately. Accounts that aren't team members yet are invited to the team and workspace automatically when they click the `Go to invitation` button in the email.

    <img src="/images/guides/team-workspace/workspace-add-member-select.png" alt="The team member selection dropdown and the Add button highlighted" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Inviting with an invite link

### Creating an invite link
Click the `Create invite link` button in the `Invite link` area to generate a new invite link.

<img src="/images/guides/team-workspace/workspace-invite-link-create-button.png" alt="The Create invite link button shown in the initial state with no invite link" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Setting the expiry
A generated link is valid for 7 days by default. Click the `Change expiry` button to the right of the link to reset the remaining validity in hours.

<img src="/images/guides/team-workspace/workspace-invite-link-created.png" alt="A generated invite link showing the expires in 7 days notice and the creation toast" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<img src="/images/guides/team-workspace/workspace-invite-link-change-expiry.png" alt="The remaining validity panel that expands when the Change expiry button is clicked" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Deleting an invite link
If you no longer need the link, click the trash icon to its right. Click `Confirm` in the deletion dialog and the link is invalidated immediately. Members who already joined stay as they are.

<img src="/images/guides/team-workspace/workspace-invite-link-delete-button.png" alt="The trash icon to the right of the invite link highlighted" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<img src="/images/guides/team-workspace/workspace-invite-link-delete-confirm.png" alt="The deletion confirmation dialog shown when deleting an invite link" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<img src="/images/guides/team-workspace/workspace-invite-link-deleted.png" alt="The invite link deleted, returning to the initial state with the deletion complete toast" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
