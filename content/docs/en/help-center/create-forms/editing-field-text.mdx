## Applying Text Styles

- Type your text, then drag to select it and apply styles.
- The available text styles include:
  - Heading styles
  - Body styles
  - Special styles (quote, emphasis, etc.)
- Fonts: Choose from 8 English fonts.
- Font size: Choose from 5 size levels.
- Several options are available to make text stand out:
  - Highlight color
  - Text color
  - Insert link
  - Insert annotation
  - Text alignment (left, right, center)

## Using Slash (/) Commands for More Features

- Press '/' (slash) on your keyboard to insert additional content such as:
  - Heading 1, 2, 3
  - Bullet list, numbered list, to-do list, toggle text
  - Quote
  - Code block
  - Table
  - Two columns
  - Image insertion and resizing
  - Divider
