## How to Use the File Upload Field

1. Respondents click the `Choose File` button to pick the file they want to upload.
2. After selecting, they must click `Upload This File` to complete the upload.
3. Uploaded files are only saved once the survey response is submitted, so respondents must finish uploading and then submit the survey.

## Upload Size Limits

- Free plan: Up to 15MB per field
- Pro plan and above: Up to 500MB per field
- You can set a custom maximum upload size in the settings menu at the bottom right.
  - Free plan: up to 15MB
  - Pro plan and above: up to 500MB
- Available options
  - Required
  - Data masking
  - Auto-delete responses

<Callout type="warning" title="Warning">
Files are not saved unless the survey is submitted after the upload is complete.
</Callout>
