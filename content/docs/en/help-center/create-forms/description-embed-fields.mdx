## Description Field

- Use this for cover pages, section dividers, instructional text, or any free-form descriptive content.
- The text editor lets you apply various styles such as text color, size, and weight.
- You can also use slash (/) commands to easily insert images, tables, headings, and more.

<Callout title="Tip">
Using description fields effectively to separate sections or add guidance helps respondents understand the survey content more easily.
</Callout>

## Embed Field

- Paste a website URL to display that web page directly inside your Walla form.

<Callout type="warning" title="Caution">
Depending on the external site's security policies or HTTPS configuration, the embed may not display properly.
</Callout>
