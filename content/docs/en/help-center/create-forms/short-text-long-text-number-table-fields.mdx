---
title: Short Text, Long Text, Number, and Table Fields
description: Open-ended fields where respondents type in their own answers. Choose the right field based on the expected length and format of the response.
---

## Short Text Field

- Use for brief, one-line text responses.
- Great for names, job titles, or short opinions.
- Click the pencil icon to edit the placeholder text.
- Available options
  - Required
  - Response length
  - Response include
  - Response exclude
  - Regular expression

## Long Text Field

- Use for longer, multi-line text responses.
- Perfect for detailed opinions, feedback, or descriptive answers.
- Click the pencil icon to edit the placeholder text.
- Available options
  - Required
  - Response length
  - Response include
  - Response exclude
  - Regular expression

## Number Field

- A field for numeric input only.
- Use this to collect quantities, ages, scores, and other numeric values.
- Click the pencil icon to edit the placeholder text.
- Available options
  - Required
  - Number range

<Callout type="warning" title="Warning">
If you collect phone numbers in a number field, numbers that start with '0' (like 010XXXXYYYY) will have the leading zero stripped because the input is treated as a number. Use the short text field or the dedicated phone number field for phone numbers.
</Callout>

## Table Field

- A table-style field for collecting multiple open-ended answers at once.
- The row-and-column structure makes it easy to compare or evaluate multiple items side by side.
- Available options
  - Required
