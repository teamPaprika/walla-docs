## Date Field

- Allows respondents to choose a date.
- Available options
  - Required
  - Data masking
  - Auto-delete responses

## Time Field
- Allows respondents to choose a time.
- Available options
  - Required
  - Data masking
  - Auto-delete responses

<Callout title="Tip">
Date and time fields are useful when building time-related surveys such as booking requests, scheduling, or event sign-ups.
</Callout>
