## What is a custom field?
A custom field is a field you create from a plain-language description, for input methods that Walla's built-in field types (multiple choice, short text, dropdown, and so on) can't express.

In a traditional form builder, anything missing from the field list simply couldn't be built. Custom fields remove that limit. Describe what you want — "make me a signature pad field" — and a working field is built from that description.


<Steps>
  <Step>
    ### Install the [Walla MCP](https://docs.walla.my/en/docs/help-center/getting-started/installing-walla-mcp)
    Go to [claude.ai](https://claude.ai/) and install the Walla MCP.

    <img src="/images/guides/getting-started/mcp-06-connected.png" alt="Tool list and permissions for the Walla Form connector after connecting" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Ask Claude
    Tell Claude about the field you want to create.

    <img src="/images/guides/create-forms/custom-field-star-rating.png" alt="A star rating custom field generated by asking Claude" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Review the preview and approve
    Check the preview and adjust anything you want to change. Once the custom field looks the way you intended, approve the build.

    <img src="/images/guides/create-forms/custom-field-approve.png" alt="Approving after reviewing the preview registers the custom field type for the team" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Add the custom field to a form
    In the editor, choose the `Custom Fields` tab when adding a field to pick from the custom fields you've built.

    <img src="/images/guides/create-forms/custom-field-add-to-form.png" alt="Selecting a custom field from the Custom Fields tab in the form editor" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Use the custom field
    The selected custom field is added to your form. Edit its question and description like any other field, then publish to start collecting responses.

    <img src="/images/guides/create-forms/custom-field-in-form.png" alt="A star rating custom field added to a form" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
