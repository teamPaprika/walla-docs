## Picture Choice

- Adjust the image height in pixels.
- Click the `...` (more) button at the bottom right to access these features:
  - Set option values: Assign a custom value to each option. (e.g., set the first option to '1' — it will appear as 1 in the response sheet.)
  - Multiple select: Allow respondents to pick more than one option.
  - Single row on mobile: Without this option, picture choices are displayed in two columns on mobile devices.
  - Shuffle options: Randomize the order of the options when the survey is displayed.

- Available options
  - Required
  - Selection count
  - Include options
  - Exclude options
  - Per-option response limit
  - Data masking
  - Auto-delete responses

<Callout type="warning" title="Warning">
- Large image files can slow down load times, so upload images at an appropriate size.
- Keeping image aspect ratios and styles consistent leads to higher-quality responses.
</Callout>
