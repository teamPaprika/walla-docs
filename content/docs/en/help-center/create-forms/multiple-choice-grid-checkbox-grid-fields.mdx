---
title: Multiple Choice Grid and Checkbox Grid Fields
description: A selection-style question laid out as a table of rows and columns. Respondents can compare and pick options at a glance — often used for satisfaction surveys and ranking questions.
---

## Multiple Choice Grid Field

- Freely add rows and columns.
  - Click the dashed area below the table to add a row, and the dashed area on the right to add a column.
  - Type the row and column titles directly inside the table.
- Use the six-dot handle next to a row or column title to reorder it or open its menu.
  - Drag and drop to change the order of rows and columns.
  - Click it to open the `Duplicate row` and `Delete row` menu (`Duplicate column` and `Delete column` for columns).
- Use `Set option values` at the bottom left to assign a value to each option. (e.g., set the first option to value 1)
- Click the `...` (more) button at the bottom right for these features:
  - Restrict duplicate columns: Prevent respondents from picking the same column more than once. This lets you design ranking-style questions such as 1st choice, 2nd choice, and so on.

## Checkbox Grid Field

- Like the standard grid, you can add rows and columns and type their titles directly inside the table.
- You can also assign custom values to each option.
- The difference is that while a regular grid allows only one column per row, the checkbox grid lets respondents select any number of columns.
- Turn on `Stand-alone answer` in a column menu to make that column — such as 'None of the above' — impossible to pick together with the others. When a respondent selects it, every other selection in that row is cleared.

<Callout title="Tip">
Multiple choice grids are great for ranking or priority questions, while checkbox grids are useful for comparative or evaluative surveys that allow multiple answers.
</Callout>
