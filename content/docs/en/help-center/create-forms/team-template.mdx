## Creating a Team Template

<Steps>
  <Step>
    ### Go to the template library
    Navigate to the template library.
  </Step>
  <Step>
    ### Import template
    Click the `Import Template` button.
  </Step>
  <Step>
    ### Pick a project
    Choose the project you want to use as a template.
  </Step>
  <Step>
    ### Configure options
    Optionally set whether to import as a copy, the preview orientation (horizontal/vertical), and a template description.
  </Step>
  <Step>
    ### Save
    Click `Import` to save it as a team template.
  </Step>
</Steps>

- Imported team templates become shared team assets that everyone on the team can use.

## Using a Team Template

<Steps>
  <Step>
    ### Create a new project
    Start by creating a new project.
  </Step>
  <Step>
    ### Choose Use Template
    Select `Use Template`.
  </Step>
  <Step>
    ### Pick Team Templates
    Choose Team Templates from the template list.
  </Step>
  <Step>
    ### Select the template you want
    Pick the team template you want and click `Use Template`.
  </Step>
  <Step>
    ### Done
    A new project is created based on the selected template.
  </Step>
</Steps>

## When to Use Team Templates

- Frequently used surveys like customer inquiries, sales inquiries, or satisfaction surveys
- Surveys that need a consistent format across your company or team
- When new team members need a standard template to start building surveys quickly

<Callout title="Tip">
- Team templates are team assets, so we recommend not saving unnecessary projects as templates.
- Projects created from a template are edited independently from the original.
</Callout>
