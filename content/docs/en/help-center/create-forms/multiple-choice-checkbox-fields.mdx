## Multiple Choice Field

- A basic multiple-choice question where respondents pick only one option.
- Click `Add Option` at the bottom left to add more choices, or enable 'Add Other input' to let respondents write in their own answer.
- Click the `...` (more) button at the bottom right to access these features:
  - Bulk add options: Enter multiple options at once. *(Separate each option with Enter.)*
  - Set option values: Assign a custom value to each option. (e.g., set the first option to '1' — it will appear as 1 in the response sheet.)
  - Shuffle options: Randomize the order of the options when the survey is displayed.

- Available options
  - Required
  - Selection count
  - Include options
  - Exclude options
  - Per-option response limit
  - Data masking
  - Auto-delete responses

## Checkbox (Multiple Select) Field
- A multiple-choice question where respondents can select more than one option at the same time.
- You can also use `Add Option` and `Add Other input`.
- Click the `... (more)` button at the bottom right for these features:
  - Bulk add options: Enter multiple options at once. *(Separate each option with Enter.)*
  - Set option values: Assign a custom value to each option. (e.g., set the first option to '1' — it will appear as 1 in the response sheet.)
  - Shuffle options: Randomize the order of the options when the survey is displayed.

- Available options
  - Required
  - Selection count
  - Include options
  - Exclude options
  - Per-option response limit
  - Data masking
  - Auto-delete responses
