## How to Create a Project

<Steps>
  <Step>
    ### Click the Create Project button
    On the workspace screen, click the `Create Project` button.
  </Step>
  <Step>
    ### Configure the project
    Set the project name and tags.
  </Step>
  <Step>
    ### Finish creating the project
    Click the `Create Project` button. The new project will be added to your workspace.
  </Step>
</Steps>

<Callout title="Note">
You can create multiple projects within a single workspace to manage different surveys at the same time.
</Callout>
