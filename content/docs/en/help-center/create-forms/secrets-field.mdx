## Secrets Field

Input is not displayed in plain text on the screen, and additional security settings can be applied for extra protection.

## When to Use It

We recommend using the secrets field in the following cases:

- Entering a password or PIN
- Entering verification codes or access keys
- Verifying authorized users in internal surveys
- Collecting sensitive information that must not be exposed externally

## Input Behavior and Security Features

- Input masking
  - What the respondent types is displayed as ●●●.
  - The actual value is not visible on the response screen.

- Data masking
  - The collected response data is also shown masked.
  - Security is preserved in the admin view and when sharing results.

- Click the `...(more)` button at the bottom right for these features:
  - Allow paste
    - Allow or disable copy-and-paste.
    - We recommend disabling this when you need the respondent to type the value directly.

  - Require confirmation input
    - Ask the respondent to enter the same value twice.
    - Useful for passwords and similar fields.

- Available options
  - Required
  - Response length
  - Response include / Response exclude
  - Regular expression (Regex)
  - Data masking (default)
  - Auto-delete responses

<Callout type="warning" title="Warning">
- Avoid using the secrets field to collect unnecessary personal information.
- Depending on applicable laws and policies, you should also provide appropriate personal information handling notices.
</Callout>
