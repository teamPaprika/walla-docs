## Creating a field template from the project editor

You can instantly save fields from the survey you are currently building as a template.

- Save an individual field: In the survey field list, click the `...` (more) menu on the field you want, then select `Save as field template`.

- Save multiple fields at once:

<Steps>
  <Step>
    ### Select fields and save
    Hold `Shift` to select the fields you want to include in the template at once, then click the `Save as field template` button.
  </Step>
  <Step>
    ### Enter the template name
    Enter a template name in the popup and create the template.
  </Step>
</Steps>

<Callout type="warning" title="Note">
Some fields that require workspace verification, such as 'Toss Payments', may be restricted from being saved as templates.
</Callout>

## Editing directly from the field template library

You can edit templates saved in the library, or build new templates from scratch in the library.

- Access templates: Go to \[Team Library\] > \[Field Templates\] in the left side of the dashboard.

- Configure detailed properties:

<Steps>
  <Step>
    ### Click a field
    Click the field you want to edit to modify the field title, response validation (required, etc.), and security settings in the `Options` panel on the right.
  </Step>
  <Step>
    ### Check changes
    When you make changes, an 'Unsaved changes' notification appears at the top.
  </Step>
  <Step>
    ### Save the template
    After finishing all edits, click the `Save template` button at the top right to apply your changes.
  </Step>
</Steps>

## Loading a saved template

When creating a new project, load your preset fields with a single click.

<Steps>
  <Step>
    ### Find the template section
    A `Template` section appears at the bottom of the add field screen (center popup) in the survey editor.
  </Step>
  <Step>
    ### Select a template
    Click the template you want to use (e.g., 'Contact Information', 'Example 2', etc.).
  </Step>
  <Step>
    ### Applied
    All fields and settings included in the template are immediately applied to the survey.
  </Step>
</Steps>

<Callout title="Tip">
Even if you modify the content to fit a specific project after loading a template, the original template in the library remains unchanged.
</Callout>
