## Types of Ending Fields

### End Page
   - A custom end screen displayed after a response is submitted.
   - Like a description field, you can include various content such as text, images, and tables.
	   - Use the [text editor](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0) to apply various styles such as text color, size, and weight.
	   - You can also easily insert images, tables, headings, and more with the [slash (/) command](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0).
   - Examples:
     - "Your response has been submitted. If you have any questions, please contact [cs@walla.my](mailto:cs@walla.my)."
     - "Exclusive promo code for respondents: WALLA10"

### Redirect to URL
   - Redirect respondents to a specific web page after they submit.
   - In the ending field settings on the project edit screen, enter the URL you want to redirect to.

## Using It with Logic

To redirect to an ending field after submission, you must configure logic.

<Steps>
  <Step>
    ### Click the Submit button
    On the logic page, click the 'Submit' button.
  </Step>
  <Step>
    ### Specify the ending field
    Choose which ending field to navigate to based on your conditions.
  </Step>
  <Step>
    ### Publish
    Logic settings only take effect on the live survey after you click `Publish`.
  </Step>
</Steps>

<Callout type="warning" title="Note">
If you only add an ending field without configuring logic, the default end page ("Your response has been successfully submitted.") will be displayed automatically.
</Callout>

<Callout title="Tip">
- Ending fields are great for wrapping up your survey with a thank-you message, additional guidance, or promotional information.
- For brand campaigns or marketing surveys, use a URL-redirect ending field to seamlessly connect respondents to your website or event page.
</Callout>
