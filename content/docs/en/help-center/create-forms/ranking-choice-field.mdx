## Ranking Choice Field

- This question lets respondents rank multiple choices.
- Click `Add option` at the bottom left to add more choices, or click `Add "Other" option` to let respondents enter their own answer.
- Set how many ranks respondents can choose with `Number of ranks` at the bottom right.
- Use the [text editor](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text) to apply styles such as text color, size, and weight.
- Use [slash (/) commands](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text) to insert images, tables, headings, and more.

- Click the `...` (more) button at the bottom right to access these features:
  - Bulk add options: Enter multiple choices at once. *(Separate each option with Enter.)*
  - Set option values: Assign a custom value to each choice. (e.g., set the first choice to `1` → it appears as `1` in the response sheet.)

- Available settings
  - Required
  - Include choices
  - Exclude choices
  - Response limit per option
  - Data masking
  - Auto-delete responses
