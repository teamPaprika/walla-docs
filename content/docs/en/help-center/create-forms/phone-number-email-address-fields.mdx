## Phone Number Field

<img src="/images/guides/manage-forms/phone-number-field-example.png" alt="A phone number field with a country dropdown and the 010-2000-0000 placeholder" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Respondents can enter their phone number.
- Click the flag icon to switch to a different country's phone format.
- The [text editor](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text#applying-text-styles) lets you apply various styles such as text color, size, and weight.
- You can also use [slash (/) commands](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text#using-slash--commands-for-more-features) to easily insert images, tables, headings, and more.
- The default is the Korean mobile format (010-0000-0000).
- Available options
  - Required
  - Response length
  - Response include / exclude
  - Regular expression (Regex)
  - Require phone verification
  - Data masking
  - Auto-delete responses

### Require phone verification

- Turning on 'Require phone verification' means only phone numbers that actually exist can be collected.
- Respondents must verify their phone number with an SMS code before submitting.
- For verification, the phone number is sent to our SMS provider (Twilio Inc., United States).

## Email Field

<img src="/images/guides/manage-forms/email-field-example.png" alt="An email field with the example@email.com placeholder" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Respondents can enter their email address.
- The input must follow the `~~~@~~~.~~~` format; otherwise the response cannot be submitted.
- The [text editor](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text#applying-text-styles) lets you apply various styles such as text color, size, and weight.
- You can also use [slash (/) commands](https://docs.walla.my/en/docs/help-center/create-forms/editing-field-text#using-slash--commands-for-more-features) to easily insert images, tables, headings, and more.
- Click the pencil icon to edit the placeholder text.
- Available options
  - Required
  - Response length
  - Response include / exclude
  - Regular expression (Regex)
  - Require email verification
  - Data masking
  - Auto-delete responses

### Email verification

Turn on `Require email verification` to have respondents verify the email address they enter with a 6-digit code before submitting that address as a response. Use it alongside email format validation to check that the respondent can access the mailbox.

<Steps>
  <Step>
    #### Turn on email verification

    Select the email field in the form editor, then turn on `Require email verification` in the settings panel on the right. Publish the form to apply the updated setting for respondents.

    <img src="/images/guides/create-forms/email-verification-enable.png" alt="Turn on email verification in the email field settings panel" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Enter an email address and click Verify

    The respondent enters an email address, then clicks `Verify` next to the input.

    <img src="/images/guides/create-forms/email-verification-start.png" alt="Enter an email address and select the verification button" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Send the verification code

    In the email verification dialog, check the address and click `Send code`. A 6-digit verification code is sent to the entered email address.

    <img src="/images/guides/create-forms/email-verification-send-code.png" alt="Select the send-code button in the email verification dialog" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Enter the code and confirm verification

    Enter the 6-digit code received by email and click `Verify`. After successful verification, `Verified` appears below the email field.

    <img src="/images/guides/create-forms/email-verification-enter-code.png" alt="Enter the 6-digit code received by email" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/create-forms/email-verification-complete.png" alt="Verified status displayed below the email field" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

- **If the email address changes**: The new address must be verified again.
- **If the code is invalid or expired**: Check the email address and the code you entered. Once the resend waiting period has passed, click `Resend code` to receive a new code.
- **Use with Required**: To collect an email address from every respondent, also turn on `Required`. An optional question with email verification enabled can still be submitted blank.

<Callout type="info" title="Check the published form">
Verification emails are not sent in preview mode. Open the published form to try the actual verification flow. This setting verifies the address entered in an email field and is separate from email verification for form access permissions.
</Callout>

## Address Field

<img src="/images/guides/manage-forms/address-field-example.png" alt="A delivery address field showing the address search input" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Only Korean addresses are supported. Respondents can search for an address and add detailed address information.
- Available options
  - Required
  - Data masking
  - Auto-delete responses

<Callout title="Tip">
To protect personal information, we recommend enabling data masking and auto-delete responses on phone number, email, and address fields.
</Callout>
