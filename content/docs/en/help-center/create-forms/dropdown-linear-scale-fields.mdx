## Dropdown Field

- A field for choosing one option from a collapsible list.
- Useful when you want to save space.
- Click the `Edit Options` button at the bottom left to add new options.
- Click the `…` (more) button at the bottom right to use these features.
  - Bulk add options: Enter multiple options at once. *(Separate each option with Enter)*
  - Set option values: Assign a custom value to each option. (e.g., set the first option to '1' → it will appear as 1 in the response sheet)

## Dropdown (Multi-select) Field

- This field lets respondents choose multiple options from a dropdown list. Even with many options, the list can collapse to keep the screen compact.
- Click the `Edit Options` button at the bottom left to add new options.
- Use the [text editor](/en/docs/help-center/create-forms/editing-field-text#applying-text-styles) to apply styles such as text color, size, and bold.
- You can also use [slash (/) commands](/en/docs/help-center/create-forms/editing-field-text#using-slash--commands-for-more-features) to insert images, tables, headings, and more.
- Click the `…` (more) button at the bottom right to use these features.
  - Bulk add options: Enter multiple options at once. *(Separate each option with Enter)*
  - Set option values: Assign a custom value to each option. (e.g., set the first option to '1' → it will appear as 1 in the response sheet)

## Linear Scale Field

- A numeric scale selection field, great for satisfaction surveys or rating questions.
- You can set the minimum and maximum values directly.
  - Minimum: 1 or 0
  - Maximum: 2 to 10

- Add minimum and maximum labels at each end to clearly explain what each number represents.
