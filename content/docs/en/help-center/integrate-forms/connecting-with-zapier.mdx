## How to Set It Up

<Steps>
  <Step>
    ### Pick Zapier and log in
    In the 'Connect' menu, choose Zapier and log in.

    <img src="/images/guides/integrate/zapier-01-select.png" alt="Choosing Zapier" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Select Walla Form
    In the App & event step, select 'Walla Form'.

    <img src="/images/guides/integrate/zapier-02-walla-form.png" alt="Selecting Walla Form" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Set the Event
    Set the Event to 'New Response'.

    <img src="/images/guides/integrate/zapier-03-trigger-event.png" alt="Setting the trigger event" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Sign in with your Walla account
    Under Account, log in with your Walla account.

    <img src="/images/guides/integrate/zapier-04-account.png" alt="Signing in with a Walla account" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Pick a project
    Select your team, workspace, and project in order to choose the project you want to receive response notifications from.

    <img src="/images/guides/integrate/zapier-05-project.png" alt="Choosing a project" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Choose a response for testing
    To test the Zap, select one of your existing responses, then click the `Continue with selected account` button.

    <img src="/images/guides/integrate/zapier-06-test-record.png" alt="Choosing a response for testing" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Connect an external service
    In the next Account step, pick the external service to connect to. (e.g., Google Sheets, Slack, etc.)

    <img src="/images/guides/integrate/zapier-06-external-service.png" alt="Connecting an external service" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Configure the details
    Set up the detailed delivery options for the external service, such as Gmail or Google Sheets.

    <img src="/images/guides/integrate/zapier-08-details.png" alt="Configuring the details" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Run a test
    Click `Test Step` if you want to verify it with a test, or click `Skip Test` if testing isn't needed.

    <img src="/images/guides/integrate/zapier-09-test.png" alt="Running a test" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Save it
    Once the test is complete, click the `Publish` button to save.

    <img src="/images/guides/integrate/zapier-10-publish.png" alt="Saving the Zap" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/integrate/zapier-10-published.png" alt="The Zap published" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>


<Callout type="warning" title="Heads up when connecting to Google Sheets">
To sync with Google Sheets through Zapier, the first row of your sheet must contain headers (column names). Walla responses will only be recorded properly when those headers exist.
</Callout>
