## Enabling IP Address Verification
- Turn on 'IP Address Verification' in the project settings to only allow access from registered IP addresses.
- While IP verification is enabled, you must register at least one IP address.
## Managing Allowed IPs and Ranges
- You can register IP addresses or ranges in any of the following formats:
  - Individual IP: `192.168.1.1`
  - CIDR range: `192.168.1.0/24` (192.168.1.0 to 192.168.1.255)
  - Wildcard: `192.168.*.*` (192.168.0.0 to 192.168.255.255)
