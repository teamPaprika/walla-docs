## Basic Features

- View response data: See all raw data collected through the survey.
- Each row is one response, and each column corresponds to a question (field) in the survey.

## Downloading Responses

- Click `Download all responses` at the top right to download your full response data.
- You can export to CSV or XLSX; CSV is the default format.

<img src="/images/guides/result-analysis/response-sheet-download.png" alt="Downloading responses" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

- For file upload fields, click the download icon at the top of that column to download every file respondents uploaded at once.

<img src="/images/guides/result-analysis/response-sheet-file-download.png" alt="The file download button on a file upload field column" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

## Deleting Responses

- Select individual responses and click `Delete` to remove them immediately.
- Deleted responses cannot be recovered, so delete with care.

## Viewing Individual Responses from the Sheet

<img src="/images/guides/result-analysis/response-sheet-individual.png" alt="Viewing an individual response from the response sheet" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

You can view the full details of a specific response without leaving the sheet.

1. Hover over the response row you want to check, then click the icon that appears next to the row number to open the response detail view on the right.
2. Use the `◀️` and `▶️` icons at the top of the detail view to move to the previous or next response.
   - Any filters and sort order applied to the sheet are preserved, so you can browse only the responses that match your conditions in order.
   - The current position is shown at the top, such as "3 / 37", and pressing next on the last response loops back to the first one.
   - As you navigate, the corresponding row in the sheet is automatically highlighted.
3. To close the detail view, click outside of it or click the `X` icon.

### What You Can Do in the Detail View

- **Show all questions**: Toggle this on to display all questions, including those without answers.
- **Copy link**: Copies the link to this response's Individual Responses page. Share it with workspace members who have permission to view responses so they can check it directly.
- **Download PDF**: Saves the current response as a PDF file.
- **Delete**: Deletes the response. After deletion, it automatically moves to the next response.

At the bottom of the detail view, you can find a summary of the project name, response time, survey ID, and response ID for easy identification.

<Callout title="Tip">
Use filters to quickly analyze only the data you need by period, field value, keyword, and more. Open the response detail view with filters applied, and you can browse only the filtered responses in order.
</Callout>
