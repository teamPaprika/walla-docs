## Scheduling a Start Time

- In the project editor, click the `⚙️` button at the top right to open the settings tab.
- Set the survey start time to a future moment, and the survey will automatically go live at that time.

## Scheduling an End Time

- On the same settings screen, select 'Close Survey' to schedule when the survey should automatically end.
- End-time scheduling can also only be set to a future time.
