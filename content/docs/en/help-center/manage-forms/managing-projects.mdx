## Renaming a Project

1. Go to the Share page for the project.
2. Find the 'Share preview settings' section.
3. Enter the title you want in the title input field — that's it.

<Callout type="warning" title="Warning">
If you don't enter a title, the default "Walla Form" title will be shown when the project is shared.
</Callout>

## Moving a Project

- Projects can only be moved between workspaces within the same team.
- You cannot move a project to a workspace in a different team.
- To move a project, click `...` (more) on the project card → 'Move to Workspace', then choose the destination.

## Deleting and Restoring a Project

- In the workspace, click '... (more)' on the project card.
  - 'Move to Archive': Moves the project to the archive, where you can restore it later.
  - 'Delete': Permanently deletes the project.
    <Callout type="warning" title="Warning">Projects moved to the archive can be restored to a workspace, but once you delete a project it cannot be recovered — please proceed carefully.</Callout>

## Duplicating a Project

- Click `...` (more) → `Duplicate` to create a new project with the same structure.
- The duplicated project's name is automatically prefixed with (Copy).
- Duplicated projects are unpublished, and items created after publish — such as custom URLs and automations — are not carried over.

## Editing Project Info

- Click `Edit Info` on the project card to change the project's name, icon, and color.

<Callout title="Tip">
To avoid accidental deletion, we recommend moving a project to the archive first, confirming it, and then deleting it.
</Callout>
