Walla provides an MCP (Model Context Protocol) server. Connect the Walla MCP to ChatGPT or Claude, and you can look up forms and responses, create new forms, or build custom fields while chatting with your AI assistant.

## Connect the ChatGPT plugin
<Steps>
  <Step>
    ### Install the Walla plugin
    On the Walla plugin page in ChatGPT, click `Install plugin`.

    <img src="/images/guides/getting-started/chatgpt-plugin-01-install.png" alt="Clicking the Install plugin button on the Walla plugin page in ChatGPT" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Sign in to your Walla account
    Choose the sign-in method that matches your account: `Continue with Google`, `Sign in with SSO`, or `Sign in with email`.

    <img src="/images/guides/getting-started/chatgpt-plugin-02-sign-in.png" alt="Choosing a sign-in method on the Walla sign-in page" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Grant access
    On the app authorization screen, review the permissions requested by ChatGPT, then click `Allow`.

    <img src="/images/guides/getting-started/chatgpt-plugin-03-authorize.png" alt="Clicking Allow on the Walla app authorization screen" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Confirm installation
    When the installation confirmation appears, click `Try it in chat` to start using the Walla plugin.

    <img src="/images/guides/getting-started/chatgpt-plugin-04-installed.png" alt="The Walla plugin installation confirmation with the Try it in chat button" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Connect the Claude connector

Add and connect Walla from the [Walla page in the Claude directory](https://claude.ai/directory/walla-form).

<Steps>
  <Step>
    ### Open the Walla directory page
    Open the [Walla page in Claude](https://claude.ai/directory/walla-form). Sign in to Claude, then click `Connect to Claude`.

    <img src="/images/guides/getting-started/claude-directory-01-connect.png" alt="Click Connect to Claude on the Walla directory page" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Sign in to your Walla account
    If the Walla sign-in screen appears, sign in with Google, SSO, or email, depending on your account. If you are already signed in, continue to the next step.

    <img src="/images/guides/getting-started/claude-directory-02-sign-in.png" alt="Choose Google, SSO, or email on the Walla sign-in screen" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Grant access
    On the app authorization screen, review the permissions requested by Claude, then click `Allow`.

    <img src="/images/guides/getting-started/claude-directory-03-authorize.png" alt="Click Allow on the Claude app authorization screen" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Confirm the connection
    When the Walla directory page shows `Connected`, the connection is complete. Use Walla tools in your conversation to look up forms or create a new one.

    <img src="/images/guides/getting-started/claude-directory-04-connected.png" alt="The Walla directory page shows the Connected status" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
