## 個別回答を見る

1. プロジェクトで **結果を見る** タブをクリックし、**個別回答** タブを選びます。
2. 最新の回答から全画面で表示されます。
3. 左右の矢印で前後の回答へ移動でき、上部に「3 / 15」のように現在位置が表示されます。

- **全設問を表示** をオンにすると、回答者が答えなかった設問も含めてすべての設問を見られます。
- ワークスペースのメンバーから特定の回答リンクを共有された場合も、このページへ直接移動します。
- 下部にはプロジェクト名、回答時刻、フォーム ID、回答 ID がまとめられていて、回答の識別に役立ちます。

## 回答の管理

- **リンクをコピー**: 現在の回答の個別回答ページのリンクをコピーします。回答の閲覧権限があるワークスペースメンバーに共有すると、このページでその回答をすぐに確認できます。
- **PDF ダウンロード**: 現在の回答を PDF ファイルとして保存します。
- **削除**: 回答を完全に削除します。削除した回答は復元できません。

<Callout title="ヒント">
回答シートでフィルターや並び替えを適用したあと行のアイコンをクリックすると、シートを離れずに個別回答の詳細表示を開けます。詳しくは[回答シート](/ja/docs/help-center/result-analysis/response-sheet)をご覧ください。
</Callout>
