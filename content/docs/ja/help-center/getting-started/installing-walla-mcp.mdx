Walla は MCP（Model Context Protocol）サーバーを提供しています。Walla MCP を ChatGPT または Claude に接続すると、AI アシスタントと会話しながら Walla のフォームや回答を確認したり、新しいフォームを作成したり、カスタムフィールドを作ったりできます。

## ChatGPT プラグインを接続する
<Steps>
  <Step>
    ### Walla プラグインをインストールする
    ChatGPT の Walla プラグインページで `プラグインをインストール` をクリックします。

    <img src="/images/guides/getting-started/chatgpt-plugin-01-install.png" alt="ChatGPT の Walla プラグインページでインストールボタンをクリック" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Walla アカウントにログインする
    アカウントに合ったログイン方法（Google、SSO、メール）を選択します。

    <img src="/images/guides/getting-started/chatgpt-plugin-02-sign-in.png" alt="Walla のログインページでログイン方法を選択" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### アクセスを許可する
    アプリのアクセス権限リクエスト画面で ChatGPT が要求する権限を確認し、`許可` をクリックします。

    <img src="/images/guides/getting-started/chatgpt-plugin-03-authorize.png" alt="Walla のアプリ認可画面で許可ボタンをクリック" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### インストール完了を確認する
    完了メッセージが表示されたら `チャットで試す` をクリックして Walla プラグインを使い始めます。

    <img src="/images/guides/getting-started/chatgpt-plugin-04-installed.png" alt="Walla プラグインのインストール完了画面" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Claude コネクタを接続する

[Claude ディレクトリの Walla ページ](https://claude.ai/directory/walla-form)からコネクタを追加して接続できます。

<Steps>
  <Step>
    ### Walla のディレクトリページを開く
    [Claude の Walla ページ](https://claude.ai/directory/walla-form)を開きます。Claude にログインし、`Claude に接続` ボタンをクリックします。

    <img src="/images/guides/getting-started/claude-directory-01-connect.png" alt="Walla のディレクトリページで Claude に接続ボタンをクリック" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Walla アカウントにログインする
    Walla のログイン画面が表示されたら、アカウントに合った方法（Google、SSO、メール）でログインします。ログイン済みの場合は次の手順に進みます。

    <img src="/images/guides/getting-started/claude-directory-02-sign-in.png" alt="Walla のログイン画面で Google、SSO、メールから選択" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### アクセスを許可する
    アプリのアクセス権限リクエスト画面で Claude が要求する権限を確認し、`許可` をクリックします。

    <img src="/images/guides/getting-started/claude-directory-03-authorize.png" alt="Claude のアプリ認可画面で許可ボタンをクリック" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 接続を確認する
    Walla のディレクトリページに `接続済み` と表示されたら、接続は完了です。会話で Walla のツールを使ってフォームを確認したり、新しいフォームを作成したりしてみましょう。

    <img src="/images/guides/getting-started/claude-directory-04-connected.png" alt="Walla のディレクトリページに接続済みと表示" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
