## パネルとは？

パネルとは、フォームを送信する対象者のリストです。ワークスペースの **パネル** タブでパネル名簿を CSV または Excel ファイルでアップロードし、グループに分類して体系的に管理できます。

| 項目 | 説明 |
| ---- | ------------------- |
| 顧客キー | パネルを識別する固有のキー |
| 氏名 | パネルの氏名（デフォルトでマスキング） |
| メールアドレス | パネルのメールアドレス（デフォルトでマスキング） |
| 電話番号 | パネルの電話番号（デフォルトでマスキング） |
| グループ | パネルが属するグループ |

<Callout type="info" title="個人情報のマスキング">
個人情報保護のため、パネルの氏名・メールアドレス・電話番号はデフォルトでマスキングされます。実際の情報を閲覧するにはマスキングの解除が必要です。
</Callout>

## パネルをアップロードする

CSV または Excel ファイルでパネル名簿を一括登録できます。

<Steps>
  <Step>
    ### パネルアップロードボタンをクリックする
    パネルタブで **パネルをアップロード** ボタンをクリックします。
  </Step>
  <Step>
    ### グループを選択する
    アップロードするパネルの **グループを選択** します。（任意）
  </Step>
  <Step>
    ### ファイルを選択する
    **ファイルを選択** ボタンをクリックして CSV または Excel ファイルを選びます。
    氏名・メールアドレス・電話番号などにエラーがある行は除外してアップロードされます。
  </Step>
  <Step>
    ### アップロード完了
    適合データを確認してから **パネルをアップロード** ボタンをクリックします。
  </Step>
</Steps>

<Callout type="warn" title="ファイル形式について">
- 氏名は必須項目で、メールアドレスか電話番号のどちらかは必ず入力する必要があります。
- 電話番号の先頭の 0 が消える場合は、電話番号列のセル書式をテキストに設定するか、番号の前に `'` を付けてください。
- ファイル形式が合わない場合は、不適合データタブでエラー項目を確認できます。
- テンプレートが必要な場合はテンプレートダウンロードボタンをクリックしてください。
</Callout>

<Callout type="info" title="現在サポートしている送信方法">
現在、フォーム送信機能ではメール送信のみをサポートしています。
</Callout>

## グループを管理する

パネルをグループに分類して、目的に合わせて管理できます。

<Steps>
  <Step>
    ### グループ管理ボタンをクリックする
    パネルタブで `グループ管理` ボタンをクリックします。
  </Step>
  <Step>
    ### グループ一覧を確認する
    既存のグループ一覧と、各グループのパネル数を確認できます。
  </Step>
  <Step>
    ### グループを作成または編集する
    `グループを作成` ボタンで新しいグループを作るか、グループ右側の編集ボタンで名前を変更できます。
  </Step>
  <Step>
    ### グループを削除する
    削除するグループを選択し、`選択項目を削除` ボタンでグループを削除できます。
  </Step>
</Steps>

## マスキングを解除する

パネルの個人情報（氏名・メールアドレス・電話番号）を閲覧するには、マスキングを解除する必要があります。

<Steps>
  <Step>
    ### マスキング解除ボタンをクリックする
    パネルタブ上部の `マスキング解除` ボタンをクリックします。
  </Step>
  <Step>
    ### 解除理由を入力する
    解除理由を入力します。
  </Step>
  <Step>
    ### マスキング解除の完了
    `マスキング解除` ボタンをクリックします。
  </Step>
</Steps>

マスキングを解除すると、検索機能も有効になります。

<Callout type="warn" title="マスキング解除時の注意">
マスキングを解除すると、解除理由がログ記録に残ります。不必要な個人情報の閲覧はお控えください。
</Callout>

### フィルターと表示設定

- **フィルター**: 特定のグループのパネルだけを絞り込んで表示できます。
- **表示**: パネル一覧の並び順と表示する項目を設定できます。
- **並び順**: 作成日（昇順／降順）
- **表示項目**: 顧客キー、氏名、メールアドレス、電話番号、グループをそれぞれオン／オフ可能
