Walla の権限体系は、**チーム権限**、**ワークスペースのロール権限**、**個別プロジェクト権限**の 3 階層で動作します。チーム全体のセキュリティ・管理機能はチーム管理で、フォームの作成・編集・回答閲覧およびダウンロード権限はワークスペースとプロジェクト単位で制御します。

## プラン別のロール権限の違い

| 区分 | Free・Pro プラン | Enterprise プラン |
| --- | --- | --- |
| **ロール別の権限編集** | 管理者とメンバーが同じワークスペース権限を保有（`オーナー`・`管理者`・`メンバー` 固定） | **ロール追加**、**未指定** ロールの利用、ロール別の権限細分化編集が可能 |
| **招待時のデフォルトロール** | メンバー *（招待時にデフォルト適用）* | **未指定** *（招待リンク・招待時のデフォルト値）* |
| **権限の適用範囲** | ワークスペース全体で一括 ON/OFF | 一部のプロジェクト・回答権限を **プロジェクトの設定に従う** に委任可能 |
| **回答アクセス制御** | 非対応 | ロール別の条件付き回答閲覧（[回答閲覧の管理](/ja/docs/help-center/security/response-access-control)）に対応 |

<Callout type="info" title="参考">
Free・Pro プランでは管理者とメンバーが同じワークスペース権限を持ちます。**ロール追加**・**未指定** ロール・ロール別の権限カスタマイズは **Enterprise プラン** で利用できます。
</Callout>

## チーム権限

チーム全体にわたるメンバー・請求・ワークスペース作成・セキュリティ設定に関する権限です。左側のサイドバーの **チーム管理 → ロール別の権限** から管理します。

| 権限名 | 説明 |
| --- | --- |
| **チームメンバーを招待** | メールまたは招待リンクでチームメンバーを招待します。 |
| **ワークスペースを作成** | チーム内に新しいワークスペースを作成します。 |
| **チームメンバーを削除** | チームから既存のチームメンバーを除外します。 |
| **ロールを変更** | チームメンバーのチームロール（管理者・メンバー）を変更します。 |
| **チームセキュリティ設定** | 2 要素認証（MFA）、ログインセッション期間、IP アクセス制限、外部 AI 利用のブロック、承認ワークフローなどのチームセキュリティポリシーを設定します。 |
| **決済管理** | チームプランの変更および決済手段を管理します。 |
| **チームログをダウンロード** | チームアクティビティログをエクスポートします。 |

## ワークスペースのロール

ワークスペース内のフォームと回答に対する権限を管理します。ワークスペース右上の歯車（**ワークスペース設定**）→ **ロールと権限** から確認できます。

- **オーナー（Owner）**: ワークスペースの作成者または所有権を移譲されたユーザーで、すべての権限が固定で付与されています。
- **管理者（Admin）**: プロジェクト管理およびメンバー・招待管理を含むほとんどの権限がデフォルトで有効になります。
- **メンバー（Member）**: プロジェクトの作成・編集および回答の閲覧・ダウンロードなど、実務に必要な権限が付与されます。
- **未指定（Restricted / Unassigned）** *(Enterprise)*: 招待時のデフォルトロールとして活用でき、初期状態ではすべてのプロジェクト・回答権限がオフになった状態で、必要な権限だけを選択的に付与します。
- **カスタムロール** *(Enterprise)*: **ロール追加** ボタンをクリックして `ソウルリサーチャー` や `外部監査` のようにチーム目的に合わせた新しいロールを作成し、**権限設定** と **メンバー一覧** タブでメンバーを直接割り当てることができます。

## ワークスペースの詳細権限（全 17 種）

ワークスペースロールの **権限設定** タブは、**プロジェクト**、**個人情報**、**高度な設定** の 3 つのグループに分かれています。*（Enterprise プランでは、下表の「プロジェクト別の委任可否」列に示されている 8 つの権限を **プロジェクトの設定に従う** に設定できます。）*

### プロジェクト（10 種）

| 権限名 | 説明 | プロジェクト別の委任可否 |
| --- | --- | --- |
| **プロジェクト作成** | ワークスペースに新しいプロジェクトを作成できます。 | 全体許可／遮断 |
| **プロジェクト複製** | 既存のプロジェクトを複製できます。 | **プロジェクトの設定に従う** 可能 |
| **プロジェクト管理** | プロジェクトを移動、アーカイブ、削除できます。 | **プロジェクトの設定に従う** 可能 |
| **プロジェクト編集** | プロジェクトを編集し、タグを指定できます。 | **プロジェクトの設定に従う** 可能 |
| **タグ管理** | ワークスペースの共通タグを作成、名前変更、削除できます。 | 全体許可／遮断 |
| **自動化管理** | 自動化を閲覧、作成、編集、削除できます。*（実行履歴から過去の回答を再送信するには回答閲覧権限も必要です。）* | **プロジェクトの設定に従う** 可能 |
| **フォーム送信** | 受信者を登録、編集、削除し、フォームを送信できます。 | **プロジェクトの設定に従う** 可能 |
| **すべての回答を閲覧** | フォームのすべての回答を閲覧します。オフにすると **許可しない** または **プロジェクトの設定に従う** から選択します。 | **プロジェクトの設定に従う** 可能 *（条件付き回答アクセス対応）* |
| **回答削除** | フォームの回答を削除できます。 | **プロジェクトの設定に従う** 可能 |
| **回答ダウンロード** | フォームの回答を CSV・Excel などでダウンロードできます。 | **プロジェクトの設定に従う** 可能 |

### 個人情報（3 種）

| 権限名 | 説明 |
| --- | --- |
| **マスキングオプション編集** | 設問ごとの[データマスキング](/ja/docs/help-center/security/data-masking)設定をオン・オフできます。 |
| **マスクされた回答の原文アクセス** | マスクされた回答（`*****`）の原文を解除して確認できます。*（解除時に理由の記録や承認ポリシーが適用される場合があります。）* |
| **回答の自動削除設定** | フォームごとの[回答の自動削除](/ja/docs/help-center/security/auto-delete-responses)周期を設定できます。 |

### 高度な設定（4 種）

| 権限名 | 説明 |
| --- | --- |
| **ロールと権限の編集** | ワークスペースロールの追加・名前変更・削除および各ロールの権限構成を編集します。 |
| **ロールの付与** | ワークスペースのメンバーおよび招待のロールを変更します。 |
| **メンバー追加** | ワークスペースにチームメンバーを追加したり、新しいメンバーを招待したりします。 |
| **メンバー削除** | ワークスペースから既存のメンバーを除外します。 |

<Callout type="idea" title="参考">
特定のプロジェクトにのみ編集・ダウンロード・回答削除権限を開放したり、条件に一致する回答のみを閲覧するよう制限したりしたい場合は、[プロジェクト権限](/ja/docs/help-center/manage-forms/project-permissions)および[回答閲覧の管理](/ja/docs/help-center/security/response-access-control)のドキュメントをご参照ください。
</Callout>
