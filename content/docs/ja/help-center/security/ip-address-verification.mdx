---

## IP アドレス検証を有効にする
- プロジェクト設定ページで「IP アドレス検証」を有効にすると、登録した IP アドレスからのみフォームにアクセスできるようになります。
- IP 検証をオンにした状態では、必ず 1 つ以上の IP アドレスを登録する必要があります。
## 許可した IP アドレス／範囲を管理する
- 以下のいずれかの形式で IP アドレスまたは範囲を登録できます。
  - 個別の IP: `192.168.1.1`
  - CIDR 範囲: `192.168.1.0/24`（192.168.1.0 〜 192.168.1.255）
  - ワイルドカード: `192.168.*.*`（192.168.0.0 〜 192.168.255.255）
