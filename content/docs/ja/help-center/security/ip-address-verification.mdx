## IPアクセス制限を有効にする

<Steps>
  <Step>
    ### セキュリティ設定へ移動
    `チーム管理` → `セキュリティ` 画面に移動します。
  </Step>
  <Step>
    ### IPアクセス制限を有効化し、許可するIPを登録
    `IPアクセス制限` をオンにし、許可する IP アドレスまたは範囲を追加します。IP アクセス制限が有効な場合は、IP アドレスまたは範囲を少なくとも 1 つ登録する必要があります。
  </Step>
  <Step>
    ### 適用範囲を確認して保存
    下の適用範囲を確認したあと `変更を保存` をクリックすると適用されます。この設定はチームの**ウェブダッシュボードと関連 API** へのアクセスを制限するもので、回答者がフォームに回答するアクセスには適用されません。
  </Step>
</Steps>

## 適用範囲
IP アクセス制限をオンにすると、選択した連携に下の許可 IP リストを共通で適用できます。変更は `変更を保存` のあとに適用されます。

- `MCP連携にも適用`：登録した許可 IP リストを MCP ツール呼び出しにも適用します。
- `Open API・回答連携にも適用`：すべての Open API 呼び出し（API キーおよび OAuth トークンを含む）と、外部連携による回答の取得・添付ファイルのダウンロードが対象です。

IP アクセス制限を初めて有効にするときは、この 2 つの適用範囲が初期状態で選択されています。

<Callout type="warning" title="連携の中断に関する注意">
クラウド連携では呼び出し元サーバーのパブリック IP アドレスを使用します。制限を適用すると既存の連携が中断される場合があるため、必要なサーバーの IP アドレスもあわせて登録してください。
</Callout>

## 許可IPリストを管理する
以下のいずれかの形式で IP アドレスまたは範囲を登録できます。

- 個別 IP：`192.168.1.1`
- CIDR 範囲：`192.168.1.0/24`（192.168.1.0 〜 192.168.1.255）
- ワイルドカード：`192.168.*.*`（192.168.0.0 〜 192.168.255.255）

<Callout type="warning" title="注意事項">
保存する前に、現在接続している IP アドレスが許可リストに含まれていることを確認してください。含まれていない場合、管理者もチームにアクセスできなくなります。
</Callout>
