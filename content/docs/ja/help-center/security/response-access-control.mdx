同じフォームプロジェクトに参加しているメンバーであっても、担当地域・部署・スコア帯などに応じて **自分が担当する回答のみを閲覧** させたい場合があります。**Enterprise プラン** の回答アクセス制御機能を使うと、ソウル地域担当のリサーチャーに対して `居住地域 = ソウル` の回答だけを表示し、京畿・釜山の回答は非表示にするといった形で、プロジェクトごとの回答閲覧範囲を制御できます。

回答アクセス制御は次の **2 段階** で適用されます。

1. **ワークスペースロール段階**: **ワークスペース設定 → ロールと権限** で対象ロールの **すべての回答を閲覧** トグルをオフにし、**プロジェクトの設定に従う** を選択します。
2. **プロジェクト段階**: フォーム編集画面の **フォーム設定 → プロジェクト権限 → 回答アクセス** で、該当ロールの閲覧範囲を **許可しない**、**すべての回答**、**条件に一致する回答** のいずれかに指定し、**保存する** をクリックします。

## 条件フィルター動作シミュレーター

以下のシミュレーターで **ソウルリサーチャー** ロールに適用するルールを変えながら、実際の回答シート・回答統計・訪問・行動分析にどのように反映されるかを試すことができます。

## 設定の流れ

実際の画面でワークスペースロールを設定し、プロジェクト権限で条件を保存したあと、制限されたリサーチャーアカウントで回答シートとアナリティクスを確認する流れは次のとおりです。

<Steps>
  <Step>
    ### ワークスペースロールで「プロジェクトの設定に従う」を選択

    **ワークスペース設定 → ロールと権限** で、対象ロール（例：`ソウルリサーチャー`）の **すべての回答を閲覧** を **プロジェクトの設定に従う** に設定します。
  </Step>
  <Step>
    ### フォーム設定 → プロジェクト権限で「条件に一致する回答」を選択

    各プロジェクトで許可設定を保存するまでは回答閲覧がブロックされます。**プロジェクト権限** タブの **回答アクセス** で条件付き閲覧を有効にします。
  </Step>
  <Step>
    ### 条件ルールを設定して即時適用

    `居住地域 = ソウル` などの条件を追加して **保存する** をクリックすると、そのロールのメンバーの回答シート・個別回答・回答統計・ダウンロードに即座に適用されます。
  </Step>
  <Step>
    ### 制限されたメンバーの回答シート画面

    制限されたロールでログインしたメンバーの回答シートには、上部に **「アクセスできる回答のみを表示しています。」** という案内が表示され、条件に一致する回答行のみが表示されます。
  </Step>
  <Step>
    ### 訪問・行動分析の制限案内

    回答アクセスが制限されているメンバーがアナリティクスを開くと、訪問・行動分析は提供されず、**回答統計** でアクセス可能な回答を分析するよう案内文が表示されます。
  </Step>
</Steps>

## 条件ルールの作成方法

**条件に一致する回答** を選択すると、**ルール** と **条件** を組み合わせて設定できます。

- **条件（AND）**: 1 つのルール内に複数の条件を追加すると、**すべての条件を同時に満たす**回答のみが許可されます。*（例：`居住地域 次のいずれかを含む [ソウル]` **かつ** `総合満足度 以上 4`）*
- **ルール（OR）**: **ルールを追加** で別のルールを追加すると、**いずれか 1 つのルールでも満たす**回答を閲覧できます。
- **対応フィールドタイプ**: `送信日時`、選択式／ドロップダウン／リニアスケールなどの選択型設問、短文テキスト、数値、日付設問などを基準にフィルタリングできます。

<Callout type="warn" title="注意事項">
ワークスペースロールで **すべての回答を閲覧** を **プロジェクトの設定に従う** に変更した直後は、個別フォームにルールを保存するまで、該当ロールのメンバーは回答を閲覧できません（**許可しない** 状態）。必ず各フォームの **フォーム設定 → プロジェクト権限 → 回答アクセス** で **すべての回答** または **条件に一致する回答** を保存してください。
</Callout>

## 結果閲覧・管理画面での動作の違い

回答アクセスが制限されたロールのメンバーがプロジェクトの結果画面にアクセスすると、次のように動作します。

| 機能エリア | 動作仕様 |
| --- | --- |
| **回答シート** | 上部に **「アクセスできる回答のみを表示しています。」** という案内が表示され、条件を満たす回答行のみが表示されます。*（検索結果やフィルター条件と重なるアクセス可能な回答が 0 件の場合は、「現在のフィルターに該当する回答のうち、アクセスできる回答がありません。」と表示されます。）* |
| **個別回答・回答統計** | アクセス可能な回答のみが集計・表示されるため、非表示の回答の数値や原文は露出しません。 |
| **回答のダウンロード・削除** | ダウンロードまたは削除権限がある場合でも、アクセス可能な回答のみをダウンロードまたは削除できます。*（ダウンロード可能な回答が 0 件の場合はダウンロードできません。）* |
| **アナリティクス（訪問・行動分析）** | 訪問数や離脱率などの全体トラフィック指標が回答集合と分離して露出しないよう、**訪問・行動分析は提供されません。** *（上部バナーで回答統計へ移動するよう案内します。）* |
| **プロジェクトのワークスペース移動** | 別のワークスペースへフォームを移動すると、元のワークスペースロール基準の **回答アクセスルールはすべて削除** されます。移動後、新しいワークスペースでルールを再設定してください。 |

<Callout type="info" title="参考">
回答アクセスポリシーを保存すると、**フォームの再公開有無にかかわらず即座に適用**されます。ただし、すでに公開済みのフォーム設問を基準に条件フィールドを選択するため、新しい設問を追加した場合は先にフォームを公開してから条件ルールで選択してください。
</Callout>
