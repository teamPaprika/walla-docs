---
title: "承認"
description: "チームメンバーの招待、回答のダウンロード、マスク解除、アンケートの削除といった機微な操作に管理者の承認を必須にする機能です。誰がいつ何を承認したかがすべて記録に残ります。"
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

承認をオンにすると、メンバーは機微な操作を行う前に管理者の承認を受ける必要があります。設定から処理まで以下の流れで進みます。

<Steps>
  <Step>
    ### 承認が必要な操作をオンにする

    チーム管理 → `セキュリティ` → `承認が必要な操作` で操作ごとのスイッチをオンにし、`変更を保存` を押します。

    | 操作 | 承認の効力 |
    | --- | --- |
    | チームメンバーを招待 | リクエストしたメールアドレスへの招待 1 件に承認が適用されます |
    | 回答をダウンロード | アンケートへの期間限定のダウンロード権限を付与します |
    | 回答のマスクを解除 | アンケートへの期間限定のマスク解除権限を付与します |
    | アンケートを削除 | 削除 1 件に承認が適用されます |

    管理者（admin）以上は承認なしで操作できます。承認はそれより下の等級のメンバーに適用されます。設定の変更にはチームのセキュリティ設定権限が必要です。
  </Step>
  <Step>
    ### メンバーが承認を申請

    メンバーが承認の必要な操作を試みると申請ダイアログが開きます。理由を書き、通知を受け取る管理者を選んで申請を送ります。

    - 選ばれた管理者にアプリ内通知とメールが届きます。
    - 申請は 7 日後に自動的に期限切れになります。
    - 同じ操作・同じ対象の申請がすでに保留中なら、新しい申請は作られず既存の申請にまとめられます。
  </Step>
  <Step>
    ### 管理者が承認または却下

    チーム管理 → `承認` に移動し、`保留中` タブで申請者、操作、対象、理由、申請時刻、期限を確認して `承認` または `却下` を押します。処理待ちがあるとメニューに件数が表示されます。自分が出した申請を自分で承認することはできません。
  </Step>
  <Step>
    ### 承認する期間を決める

    回答のダウンロードとマスク解除は期間を決めて承認します。`承認` を押すと期間を選べ、その期間内であればメンバーは繰り返し操作できます。

    チームメンバーの招待とアンケートの削除は期間ではなく **1 回限り** です。承認された操作を一度行うと、その承認は使用済みになります。
  </Step>
  <Step>
    ### 承認完了

    処理結果は申請者にメールで届きます。承認されるとその時点から申請した操作を行えます。期間承認は決めた期間中、1 回限りの承認は一度行うまで有効です。

    却下された場合、その操作は引き続きできません。必要なら理由を書き直して再度申請できます。
  </Step>
</Steps>

<Callout title="ご参考">
承認を新しくオンにできるのは Enterprise プランのみです。すでにオンにした設定はプランに関係なく適用され続け、オフにすることはいつでもできます。
</Callout>

## 履歴を確認する

`履歴` タブで処理済みの申請をすべて確認できます。状態・操作・申請者で絞り込み、並べ替えができます。

- 状態は承認済み、却下、使用済み、取り消し済み、キャンセル、期限切れで表示されます。
- 期間承認はいつまで有効かも表示されます。
- メンバーは自分の申請だけ、管理者はチームのすべての申請を見られます。

## 承認を取り消す

すでに出した承認をその場で取り消せます。まだ使われていない 1 回限りの承認と、期間が残っている承認が対象です。

`履歴` タブで該当する申請の `取り消し` ボタンを押し、理由を入力します。理由は監査ログに記録されます。

取り消すとその時点で承認が無効になり、期間が残っていてもその操作はできません。取り消せるのは管理者だけです。

<Callout title="ご参考">
承認の申請と処理の内容は[ログ記録](/ja/docs/help-center/security/activity-logs)にも残ります。ダウンロードやマスク解除が実際に行われた記録には、どの承認によるものかが紐づきます。
</Callout>
