`チーム管理` → `セキュリティ` 画面から、チーム全体に適用するセキュリティポリシーや連携のアクセス制御を設定できます。設定を変更したあとは、画面下部の `変更を保存` をクリックすると反映されます。

<Callout title="ご参考">
ほとんどのチームセキュリティ設定は **Enterprise** プランで利用できます。ただし、`Open API を許可` はプランに関係なくチーム管理者が設定でき、すでに有効になっている `承認が必要な操作` のポリシーを無効にすることもプランを問わず行えます。
</Callout>

## 一覧

| 設定項目 | 主な機能 | 詳細案内 |
| --- | --- | --- |
| `二要素認証（MFA）` | チームメンバー全員に二要素認証を必須化 | [2 段階認証](/ja/docs/help-center/security/two-factor-authentication) |
| `ログインセッションの有効期間` | チーム内の個人ログインセッション上限期間を制限 | 下の説明を参照 |
| `IPアクセス制限` | 登録済み IP アドレスからのみダッシュボード・API へアクセス許可 | [IPアクセス制限](/ja/docs/help-center/security/ip-address-verification) |
| `ダウンロード理由の必須化` | 回答ダウンロード時の理由入力を必須化 | 下の説明を参照 |
| `マスク解除した情報のコピー防止` | 回答シートでのマスク解除値のコピー・切り取りを制限 | [データマスキング](/ja/docs/help-center/security/data-masking) |
| `自動化の使用をブロック` | Webhook・Zapier・Google Sheets・Gmail 自動化をブロック | 下の説明を参照 |
| `外部AIの使用をブロック` | AI アンケート生成・Walla AI チャットなど外部 AI 送信を遮断 | [外部 AI の利用をブロックする](/ja/docs/help-center/security/blocking-external-ai) |
| `MCP（AI連携）を許可` | チームデータへの MCP ツール呼び出しと機能別許可を制御 | 下の説明を参照 |
| `Open API を許可` | チームのすべての Open API 呼び出しの許可・ブロックを制御 | 下の説明を参照 |
| `承認が必要な操作` | 機微な操作の実行前に管理者の承認を必須化 | [承認](/ja/docs/help-center/security/approval-workflow) |

## 設定項目の案内

### 二要素認証（MFA）
チームメンバーに二要素認証の使用を要求します。有効にすると、二要素認証を設定していないメンバーは認証を完了するまでチームにアクセスできません。
詳しい手順は[2 段階認証](/ja/docs/help-center/security/two-factor-authentication)のガイドをご覧ください。

### ログインセッションの有効期間
各チームメンバーの個人設定で、ログインセッションの有効期間をチームで指定した上限以下にするよう求めます。初期値は `各メンバーの個人設定を使用` で、チームポリシーとして上限期間を指定できます。
チームの上限より長く設定しているメンバーは、個人設定で期間を短くするまでチームにアクセスできません。

### IPアクセス制限
ウェブダッシュボードと関連 API へのアクセスを、登録済みの IP アドレスからのみに制限します。許可 IP リストを管理し、MCP 連携や Open API・回答連携にも同じ制限を適用するかどうかを選択できます。
詳しい設定方法は [IPアクセス制限](/ja/docs/help-center/security/ip-address-verification)のガイドをご覧ください。

### ダウンロード理由の必須化
回答をダウンロードする際に、ユーザーに理由の入力を要求します。入力された理由は[ログ記録](/ja/docs/help-center/security/activity-logs)で確認できます。

### マスク解除した情報のコピー防止
回答シートでマスクを解除した回答値をコピーまたは切り取りできないように制限します。
データマスキングの詳細は[データマスキング](/ja/docs/help-center/security/data-masking)のガイドをご覧ください。

### 自動化の使用をブロック
Webhook、Zapier、Google Sheets、Gmail 自動化の新規利用と実行リクエストをブロックします。

### 外部AIの使用をブロック
有効にすると、AI アンケート生成や Walla AI チャットなど外部 AI を使用する機能が無効になり、回答データが外部 LLM プロバイダーに送信されなくなります。
詳細は[外部 AI の利用をブロックする](/ja/docs/help-center/security/blocking-external-ai)のガイドをご覧ください。

### MCP（AI連携）を許可
オフにすると、このチームのデータに対するすべての MCP ツール呼び出しがブロックされ、AI クライアントのチーム一覧にも表示されなくなります。この設定は `外部AIの使用をブロック` とは別に動作します。

`MCP（AI連携）を許可` がオンのときは、機能ごとに許可するかどうかを細かく制御できます。

- `フォーム・ワークスペースの閲覧`：AI がこのチームのワークスペースとフォーム構造を読み取れるようにします。
- `回答データの閲覧`：AI がマスキングされた回答データを読み取れるようにします。
- `フォームの作成・編集`：AI がフォームの作成、質問の編集、公開を行えるようにします。
- `自動化の管理`：AI が自動化の一覧表示、作成、更新を行えるようにします。

### Open API を許可
オフにすると、既存の API キーおよび OAuth トークンを使用した呼び出しを含め、このチームのすべての Open API 呼び出しがブロックされます。API エラー応答の詳細は[エラーコード](/ja/docs/developer-docs/error-codes)の開発者ドキュメントをご覧ください。
この設定はプランに関係なくチーム管理者が変更できます。

### 承認が必要な操作
チームメンバーが招待、回答ダウンロード、マスク解除、アンケート削除などの機微な操作を実行する前に、管理者の承認を必須にできます。
詳しい運用手順は[承認](/ja/docs/help-center/security/approval-workflow)のガイドをご覧ください。
