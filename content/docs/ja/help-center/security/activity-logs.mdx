## ログ記録の確認方法

<Steps>
  <Step>
    ### ログ記録タブへ移動する
    チーム設定ページ →「ログ記録」タブへ移動します。
  </Step>
  <Step>
    ### 操作履歴を確認する
    チーム内で行われた主要な操作の履歴を、順を追って確認できます。
  </Step>
  <Step>
    ### ログの詳細情報を確認する
    各ログには操作者、操作時刻、実行されたアクションが記録されます。チーム活動ログではアクセス元 IP も確認でき、全ドメインに監査ログが適用されます。
  </Step>
</Steps>
## 主なログ項目

### Team Actions（7 件）

| Action | 説明 |
| --- | --- |
| team:leave | チームからの退出 |
| team:member.invite | チームメンバーの招待 |
| team:member.invite.cancel | チーム招待のキャンセル |
| team:member.delete | チームメンバーの削除 |
| team:member.role.assign | チームメンバーの役割変更 |
| team:security.update | チームのセキュリティ設定の変更 |
| team:audit.log.download | 監査ログのダウンロード |
