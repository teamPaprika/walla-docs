## プロジェクトタグ

プロジェクトにタグを付けて分類・管理できます。

### 従来の絵文字バッジからの変更点

- プロジェクトごとの絵文字バッジ（絵文字 + 背景色）はタグシステムに置き換わりました
- アップデート時、既存の絵文字バッジは自動的にタグへ変換されます
- 今後、個別のプロジェクトに絵文字バッジを設定することはできません

<Callout type="warning" title="注意事項">
タグ名は絵文字を基準に生成されます。同じ絵文字を使っていたプロジェクトは、背景色が違っても 1 つのタグに統合されます。
</Callout>

## タグを作る

### 方法 1. タグ管理から作成する

<Steps>
  <Step>
    ### タグ管理を選ぶ
    ワークスペースで `タグ管理` を選択します。
  </Step>
  <Step>
    ### タグを作成する
    タグの作成をクリックします。
  </Step>
  <Step>
    ### 名前を入力する
    名前を入力します。（例: マーケティング、緊急、完了）
  </Step>
  <Step>
    ### 色を選んで保存する
    色を選んで保存します。
  </Step>
</Steps>

### 方法 2. プロジェクトから直接作成する

<Steps>
  <Step>
    ### タグを追加をクリックする
    プロジェクトカード／リストの `+ タグを追加` をクリックします。
  </Step>
  <Step>
    ### タグの作成をクリックする
    タグ選択のポップオーバーでタグの作成をクリックします。
  </Step>
  <Step>
    ### 名前と色を入力して保存する
    名前と色を入力して保存します。
  </Step>
</Steps>

<Callout type="warning" title="注意事項">タグ名はワークスペース内で重複できません。</Callout>

## プロジェクトにタグを付ける

### プロジェクト作成時に追加する

- 作成の過程でタグを選択できます
- カラムヘッダーの追加（+）ボタンからすばやく作成できます
  - ステータスカラム: 未公開カラムでのみ作成可能
  - タグカラム: 作成時にそのタグが自動的に適用されます

### あとから追加する -（1）個別に追加する

プロジェクトカード／リストの `+ タグを追加` ボタンをクリック

### あとから追加する -（2）複数プロジェクトに一括で追加する

<Steps>
  <Step>
    ### プロジェクトを選択する
    `Shift` を押しながら複数のプロジェクトを選択します。
  </Step>
  <Step>
    ### タグをクリックする
    下部のアクションバーでタグをクリックします。
  </Step>
  <Step>
    ### タグを追加または削除する
    タグを追加、または削除します。
  </Step>
</Steps>

## タグを統合する

似たタグを 1 つに整理できます。

<Steps>
  <Step>
    ### タグ管理を開く
    タグ管理を開きます。
  </Step>
  <Step>
    ### 統合するタグを選ぶ
    統合するタグを選択します。（Shift による複数選択は非対応）
  </Step>
  <Step>
    ### 統合をクリックする
    統合をクリックします。
  </Step>
  <Step>
    ### 統合完了
    最後に選択したタグに統合されます。
  </Step>
</Steps>

例: `マーケティング / MKT / マーケティングチーム → マーケティング`

## プロジェクトのフィルター

### ステータス別フィルター

- 未公開: まだ公開前
- 公開中: 回答を収集中
- 終了: 締め切ったプロジェクト

### タグ別フィルター

- 複数のタグを選択した場合: いずれか 1 つでも含まれていれば表示
- 「タグなし」を選択した場合: タグが付いていないプロジェクトのみ表示

### 複合フィルター

ステータス + タグを同時に選ぶと、**両方の条件を満たす** プロジェクトだけが表示されます。
- 例: `公開中 + マーケティング` → 公開中かつマーケティングタグが付いたプロジェクト

## 表示モード

### カードビュー／リストビュー

| カードビュー | リストビュー |
| --- | --- |
| カード形式 | 一覧形式 |
| 情報を一目で確認 | より多くのプロジェクトを表示 |
| デフォルト設定 | シンプルな構造 |

### グループにまとめて見る

#### 列（グループ）

- ステータス別
- タグ別

#### 行（サブグループ）

- グループ分けなし
- ステータス別
- タグ別

### 並び順

- 更新日
- 作成日
- 回答数
  （昇順／降順の切り替え可）

### 表示設定の保存

- ワークスペースごとに自動保存
- 再読み込み後も維持
- リセットボタンでデフォルト値に戻せます

## 活用例

1. チーム別の管理（チーム名のタグを作成 → フィルターでチーム別プロジェクトを確認）
1. カンバンボードのように使う（表示モード: 列 = ステータス → ドラッグでステータスを変更）
1. 完了したプロジェクトの整理（終了フィルター → 複数選択 → アーカイブへ移動）
2. 重複タグの整理（タグ管理 → 統合）

## 主な用語

| 用語 | 説明 |
| --- | --- |
| タグ | プロジェクト分類用のラベル |
| フィルター | 条件別にプロジェクトを表示 |
| グループ分け | カテゴリ別にまとめる |
| 一括アクション | 複数プロジェクトへの同時操作 |
| アーカイブ | 使っていないプロジェクトの保管場所 |
