アンケートのエクスポートを使うと、現在編集中のアンケートを**編集可能なWordファイル**（.docx）として保存できます。設問の確認や承認用の文書作成にご活用ください。

## Wordにエクスポートする

<Steps>
  <Step>
    ### アンケート設定を開く
    エクスポートするプロジェクトの**編集画面**へ移動し、右上の歯車アイコンをクリックして`アンケート設定`を開きます。

    <img src="/images/guides/manage-forms/survey-export-open-settings.png" alt="編集画面右上のフォーム設定の歯車アイコン" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### アンケートのエクスポートを選ぶ
    設定画面の左側のメニューから`アンケートのエクスポート`を選びます。

    <img src="/images/guides/manage-forms/survey-export-select-menu.png" alt="設定メニューでフォームのエクスポートを選択" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 表示形式と含める内容を選ぶ
    `標準表示`または`グループ別表示`のいずれかを選びます。下のチェックボックスで、設問番号・回答設定・分岐条件など、必要な項目をオンにし、含めない項目をオフにしてください。各オプションの意味は以下で確認できます。

    <img src="/images/guides/manage-forms/survey-export-options.png" alt="表示形式とエクスポートする内容を選択" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    #### 表示形式を選ぶ

    - **標準表示**：編集画面で設定した改ページに合わせてアンケートを構成します。改ページで区切られた範囲の設問を続けて確認したいときにお使いください。
    - **グループ別表示**：編集画面の各設問グループを別のページに分けます。グループごとに内容を分けて確認したいときに便利です。

    最初は`標準表示`が選択されています。ここで選んだ表示形式はエクスポートするWord文書に適用され、回答者に共有したオンラインアンケートの表示形式は変わりません。設問の量によっては、Wordでさらにページが分かれることがあります。

    #### エクスポートのオプション

    | オプション | 含まれる内容 | 初期設定 |
    | --- | --- | --- |
    | 設問番号を表示 | 設問にQ1、Q2などの番号を表示します。 | オン |
    | 回答設定を含める | 入力条件や選択肢のランダム配置など、設問ごとの回答設定を表示します。 | オン |
    | 設問ごとの分岐条件を含める | 各設問の条件に応じた移動先を表示します。 | オン |
    | 分岐条件に設問番号を使用 | 分岐条件で参照する設問を番号で表示します。`設問番号を表示`がオンの場合に選択できます。 | オン |
    | アンケートの流れを含める | 文書の冒頭に、セクションの順序と分岐先の概要を表示します。 | オン |
    | 選択肢の保存値を表示 | 選択肢のテキストとともに、実際に保存される値を表示します。 | オフ |
    | ドロップダウンの選択肢を省略 | 選択肢が3個以上のドロップダウンでは、最初と最後の選択肢のみを表示し、選択肢の総数を案内します。 | オフ |

    <Callout title="分岐条件とアンケートの流れは個別に設定します">
    `設問ごとの分岐条件を含める`をオフにしても、`アンケートの流れを含める`がオンの場合は、文書の冒頭にある流れの概要に分岐先が表示されます。分岐の内容を文書に含めない場合は、両方のオプションをオフにしてください。
    </Callout>

    <Callout title="用途に合わせてオプションを選ぶ">
    - **チームメンバーと設問やロジックを確認するとき**：初期設定でオンになっている設問番号、回答設定、設問ごとの分岐条件、分岐条件の設問番号、アンケートの流れをそのままにしてみてください。設問ごとの条件と全体の分岐を一緒に確認できます。
    - **印刷するときや設問の内容を中心に共有するとき**：設問番号は表示したまま、不要な回答設定・設問ごとの分岐条件・アンケートの流れをオフにしてみてください。ダウンロードしたWord文書で余白や回答欄を調整してから印刷できます。
    - **選択肢のテキストと保存値を一緒に確認するとき**：`選択肢の保存値を表示`をオンにします。たとえば「とても満足」という選択肢で`5`を保存する設定なら、テキストと値を一緒に確認できます。
    - **ドロップダウンの選択肢が多いとき**：`ドロップダウンの選択肢を省略`をオンにすると、文書を短くできます。すべての選択肢のテキストを確認する必要がある場合は、オフにしてください。
    </Callout>
  </Step>
  <Step>
    ### Wordファイルをダウンロードする
    `Wordにエクスポート`をクリックし、ファイルの作成が完了するまで待ちます。アンケートのタイトルをファイル名とした`.docx`ファイルがダウンロードされたら、Wordで開いて設問の内容やページ構成を確認・編集できます。

    <img src="/images/guides/manage-forms/survey-export-download-word.png" alt="Wordにエクスポートするボタンをクリック" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout title="現在編集中の内容が含まれます">
エクスポートのために、先にアンケートを公開する必要はありません。エクスポートした時点の編集内容が文書に含まれるため、最新の変更が同期されてからエクスポートしてください。エクスポートの操作でアンケートが公開されることはありません。
</Callout>

## ダウンロードした文書を確認する

- 設問の内容や選択肢、回答を書き込む欄が文書にまとめられます。
- 画像は元の画像の代わりに案内文やリンクなどで表示され、動画や埋め込みコンテンツもWord内では再生・実行されません。実際の表示はオンラインのアンケートでご確認ください。
- 決済、ファイルアップロード、本人確認などのオンライン入力機能は、Word文書では動作しません。
- 文書を編集しても、Wallaの元のアンケートには反映されません。アンケートの内容を変更する場合は、Wallaの編集画面で修正してください。

<Callout title="実際の回答は含まれません">
アンケートのエクスポートは、設問とアンケートの構成を文書として保存する機能です。収集した回答をCSV・Excelファイルでダウンロードする方法は[回答シート](/ja/docs/help-center/result-analysis/response-sheet)を、回答1件をPDFで保存する方法は[個別回答](/ja/docs/help-center/result-analysis/individual-responses)をご確認ください。
</Callout>
