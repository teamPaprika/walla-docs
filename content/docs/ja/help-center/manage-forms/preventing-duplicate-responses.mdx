## 重複回答を制限する
同じ人が同じフォームに何度も回答するのを防ぎたいときは、重複回答の制限機能を使います。
制限方式は 2 つあり、両方を同時にオンにすることもできます。

|方式|判定の基準|特徴|
|---|---|---|
|ブラウザ重複回答防止|回答者のブラウザ|設定は手軽ですが、別のブラウザやシークレットモードでは再度回答できます|
|認証ユーザーごとに 1 回|認証済みのメールアドレス、電話番号、または外部会員 ID|端末を変えても制限が維持されます|

## 設定方法

<Steps>
  <Step>
    ### 回答者タブへ移動する
    編集画面右上の `⚙️` アイコンを押してフォーム設定を開き、左のタブ一覧から `回答者` を選びます。
  </Step>

  <Step>
    ### 制限方式を選ぶ
    `重複回答` セクションで、使いたいトグルをオンにします。セクション上部の要約文で、現在の設定状態をすぐに確認できます。

|設定状態|表示される要約文|
|---|---|
|何もオンにしていない|同じ人が何度も回答できます|
|`認証ユーザーごとに 1 回` がオン|認証済みのメールアドレス、電話番号、または外部会員 ID ごとに 1 回だけ回答できます|

### 1. ブラウザ重複回答防止

- 同じブラウザですでに回答を終えている場合、再度回答できません。
- 回答完了後はフォームのページが開かず、すでに回答を送信済みである旨の案内メッセージが表示されます。
- 別のブラウザや端末、シークレットモードでは再度回答できます。

### 2. 認証ユーザーごとに 1 回

- 認証済みのメールアドレス、電話番号、または外部会員 ID を基準に、1 回だけ回答できます。端末やブラウザを変えても制限が維持されるため、より確実に重複を防げます。

- このトグルをオンにするには、回答者を識別する手段が必要です。認証手段がない状態でオンにすると、メール認証も一緒にオンになります。

- 識別の基準は設定によって変わります。
	- `回答者` タブでメール認証を使う場合 → 認証済みのメールアドレス
	- `回答者` タブで電話番号認証を使う場合 → 認証済みの電話番号
	- `埋め込み` タブでホスト署名トークン + 会員識別を使う場合 → トークンに含まれる外部会員 ID

<Callout title="ご参考">
`ユーザー認証` をオフにすると、`認証ユーザーごとに 1 回` も一緒にオフになります。認証設定をオフにしてから再びオンにした場合は、重複制限が解除されていないか改めて確認してください。
</Callout>

  </Step>
</Steps>
