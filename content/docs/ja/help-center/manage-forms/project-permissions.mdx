**Enterprise プラン**のチームで、ワークスペースのロール管理またはプロジェクト権限管理の権限を持つオーナー・管理者および許可されたロールは、個別フォームの **フォーム設定 → プロジェクト権限** タブから、ロール別の操作権限と回答へのアクセス範囲をフォームごとに個別に設定できます。

## プロジェクト権限の設定手順

<Steps>
  <Step>
    ### フォーム設定を開く

    プロジェクト編集画面の右上にある歯車（**フォーム設定**）アイコンをクリックします。
  </Step>
  <Step>
    ### プロジェクト権限タブを選択

    Enterprise プランのチームで管理権限を持つメンバーには、左側のメニューに **プロジェクト権限** タブが表示されます。クリックして設定画面を開きます。
  </Step>
  <Step>
    ### このプロジェクトのロール権限を指定

    ワークスペースのロール設定で **プロジェクトの設定に従う** に指定した 7 つの操作権限について、このフォームに限り個別のトグルをオン・オフできます。
  </Step>
  <Step>
    ### ロールごとの回答アクセス範囲を選択

    **回答アクセス** セクションで、対象ロールごとに **許可しない**、**すべての回答**、または **条件に一致する回答** のいずれかを選択します。
  </Step>
  <Step>
    ### 条件ルールを追加して保存

    「居住地域 等しい ソウル」などの条件を追加し、**保存する** をクリックすると、フォームの公開状態にかかわらず変更内容が即座に適用されます。
  </Step>
</Steps>

## このプロジェクトのロール権限

ワークスペースの **ロールと権限** で以下の 7 つのプロジェクト単位の権限のうち 1 つ以上を **プロジェクトの設定に従う** に指定すると、該当ロールが **このプロジェクトのロール権限** 一覧に表示されます。

この画面でオンにできる 7 つの権限は次のとおりです。

| 権限名 | 説明 |
| --- | --- |
| **プロジェクトの複製** | このプロジェクトを複製できます。 |
| **プロジェクトの管理** | このプロジェクトを移動、アーカイブ、削除できます。 |
| **プロジェクトの編集** | このプロジェクトを編集し、タグを指定できます。 |
| **自動化の管理** | このプロジェクトの自動化を閲覧、作成、編集、削除できます。 |
| **フォームの送信** | このプロジェクトで受信者を登録、編集、削除し、フォームを送信できます。 |
| **回答の削除** | このプロジェクトの回答を削除できます。 |
| **回答のダウンロード** | このプロジェクトの回答をダウンロードできます。 |

<Callout type="warn" title="ご注意">
ワークスペースのロール設定ですでに **許可（すべてのプロジェクト）** または **許可しない** に固定されている権限は、個別プロジェクトの設定には表示されません。その権限の適用範囲をプロジェクトごとに変更したい場合は、先に[ワークスペース設定 → ロールと権限](/ja/docs/help-center/team-workspace/managing-workspaces)で **プロジェクトの設定に従う** に変更してください。
</Callout>

対象ロールのトグルをオンにしたあと **保存する** をクリックすると、変更内容がすぐに反映されます。

## 回答アクセス

**回答アクセス** セクションでは、ワークスペースのロール設定で **すべての回答を閲覧** を **プロジェクトの設定に従う** に指定したロールが、このフォームでどの回答まで閲覧できるかを設定します。

- **許可しない**: このフォームの回答を閲覧できません。（デフォルト状態）
- **すべての回答**: このフォームのすべての回答を閲覧できます。
- **条件に一致する回答**: 指定した条件ルールを満たす回答のみを閲覧できます。

フォーム内の回答削除・ダウンロード権限がある場合でも、実際に削除・ダウンロードできる範囲はここで許可された回答の集合内に制限されます。

条件ルールの作成方法や、回答シート・回答統計・訪問・行動分析での動作については、[回答閲覧の管理](/ja/docs/help-center/security/response-access-control)ガイドで詳しく確認できます。
