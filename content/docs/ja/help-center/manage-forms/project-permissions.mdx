**Enterprise プラン**のチームで、ロールと権限を編集する権限を持つオーナー・管理者および許可されたロールは、個別フォームの **フォーム設定 → プロジェクト権限** から、ロール別の操作権限と回答の閲覧範囲をフォームごとに個別に設定できます。

## プロジェクト権限の設定手順

<Steps>
  <Step>
    ### フォーム設定を開く

    プロジェクト編集画面の右上にある歯車（**フォーム設定**）アイコンをクリックします。
  </Step>
  <Step>
    ### プロジェクト権限でロールを選択

    Enterprise プランのチームで管理権限を持つメンバーには、左側のメニューに **プロジェクト権限** が表示されます。クリックするとロール一覧が展開され、設定したいロールを選択できます。
  </Step>
  <Step>
    ### ロールの操作権限を指定

    選択したロールの画面では、**編集**・**連携**・**共有**・**回答** の 4 つのグループが 1 画面に表示されます。ワークスペースのロール設定で **プロジェクトごとに設定** に指定した操作権限のトグルをオン・オフできます（ワークスペース設定で固定されている項目は読み取り専用で表示されます）。
  </Step>
  <Step>
    ### 回答の閲覧範囲を選択

    **回答** グループの **回答の閲覧** ドロップダウンから、**許可しない**、**すべての回答**、または **条件に一致する回答** のいずれかを選択します。
  </Step>
  <Step>
    ### 条件ルールを追加して保存

    必要に応じて「居住地域 等しい ソウル」などの条件を追加し、画面下部の **保存する** をクリックすると、フォームの公開状態にかかわらず変更内容が即座に適用されます。
  </Step>
</Steps>

## ロール別の操作権限設定

**フォーム設定** の左メニューで **プロジェクト権限** をクリックするとロール一覧が展開され、ロールを選択すると **編集**、**連携**、**共有**、**回答** の 4 つのグループに整理された権限画面が開きます。

ワークスペースの **ロールと権限** で以下の 7 つの操作権限のうち **プロジェクトごとに設定** に指定した項目は、この画面でトグルをオン・オフできます。

この画面の 7 つの操作権限は次のとおりです。

| グループ | 権限名 | 説明 |
| --- | --- | --- |
| **編集** | **プロジェクトを複製** | このプロジェクトを複製できます。 |
| **編集** | **プロジェクトを編集** | このプロジェクトを編集し、タグを付けることができます。 |
| **編集** | **プロジェクトを管理** | このプロジェクトを移動、アーカイブ、削除できます。 |
| **連携** | **自動化を管理** | このプロジェクトの自動化を閲覧、作成、編集、削除できます。 |
| **共有** | **アンケートを送信** | このプロジェクトで受信者を登録、編集、削除し、フォームを送信できます。 |
| **回答** | **回答を削除** | このプロジェクトの回答を削除できます。 |
| **回答** | **回答をダウンロード** | このプロジェクトの回答をダウンロードできます。 |

<Callout type="warn" title="ご注意">
ワークスペースのロール設定ですでに **すべて許可** または **許可しない** に固定されている権限もこの画面にあわせて表示されますが、無効化された読み取り専用状態（ワークスペース設定に応じて **許可** または **許可しない**）でロックされています。プロジェクトごとにオン・オフを切り替えたい場合は、先に[ワークスペース設定 → ロールと権限](/ja/docs/help-center/team-workspace/managing-workspaces)で該当権限を **プロジェクトごとに設定** に変更してください。
</Callout>

## 回答の閲覧範囲

**回答** グループの **回答の閲覧** 項目では、ワークスペースのロール設定で **回答を表示** を **プロジェクトごとに設定** に指定したロールが、このフォームでどの回答まで閲覧できるかをドロップダウンで選択します。

- **許可しない**: このフォームの回答を閲覧できません。（デフォルト状態）
- **すべての回答**: このフォームのすべての回答を閲覧できます。
- **条件に一致する回答**: 指定した条件ルールを満たす回答のみを閲覧できます。

フォーム内の回答削除・ダウンロード権限がある場合でも、実際に削除・ダウンロードできる範囲はここで許可された回答の集合内に制限されます。操作権限のトグルと回答の閲覧ルールをすべて調整したあと、画面下部の **保存する** ボタンをクリックすると、変更内容がすぐに反映されます。

条件ルールの作成方法や、回答シート・回答統計・訪問・行動分析での動作については、[回答閲覧の管理](/ja/docs/help-center/security/response-access-control)ガイドで詳しく確認できます。
