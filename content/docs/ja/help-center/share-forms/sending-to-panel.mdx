## パネル送信の準備

フォームを送信するには、まずワークスペースの **パネル** タブに送信対象者が登録されている必要があります。パネルのアップロード方法は[パネルを管理する](/ja/docs/help-center/team-workspace/workspace-panel)のページをご覧ください。

## 送信方法

<Steps>
  <Step>
    ### 共有ページへ移動する
    プロジェクト編集画面の上部にある `共有` タブへ移動し、`フォームを送信` エリアまでスクロールします。
  </Step>
  <Step>
    ### 登録済みパネルがない場合 - データアップロードをクリックする
    事前に登録したパネルがない場合や、パネル以外の相手にプロジェクトを送りたい場合は、`データをアップロード` ボタンをクリックしてください。エラーがある行や不適切な行は除外してアップロードされます。
  </Step>
  <Step>
    ### 登録済みパネルがある場合 - パネルから読み込むをクリックする
    すでに登録したパネルがある場合は、`パネルから読み込む` をクリックします。

    パネルに部署・役職などの追加情報が登録されている場合は、読み込み画面の `パネル情報 → 非表示フィールドマッピング` で非表示フィールドに割り当てられます。既存の非表示フィールドを選ぶか、`新しい非表示フィールドを作成` を選んで名前を入力すると、パネルの読み込み時にその情報も一緒に連携されます。
  </Step>
  <Step>
    ### 送信内容を作成する
    フォーム送信ボタンをクリックしたあと、送信アカウントと一緒に送る文面を入力します。
  </Step>
  <Step>
    ### 送信する
    送信が完了すると、各行の `ステータス`、`送信回数`、`最終送信時刻` の列で送信結果を確認できます。

    パネルごとに異なる個別リンクが生成され、回答シートにもパネルに登録された CUSTOMER Key で記録されます。
  </Step>
  <Step>
    ### 受信メールの例
    「フォームを送信」から送られたフォームは、メールで届きます。
  </Step>
</Steps>

## 送信先一覧を Excel でダウンロードする

`アンケートを送信` に登録されている送信先一覧と送信状況を、Excel ファイル（.xlsx）でダウンロードできます。顧客 ID、名前、メールアドレス、電話番号、送信ステータス、送信回数、専用リンク、非表示フィールドの値、関連する日時が含まれます。

<img src="/images/guides/share-forms/sending-to-panel-excel-download.png" alt="フォーム送信先一覧のダウンロードボタンとマスキング解除の案内" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

1. プロジェクトの `共有` タブから `アンケートを送信` に移動します。
2. 個人情報がマスキングされている場合は、一覧の上にあるマスキング解除アイコンを押し、理由を入力して解除します。チームのポリシーによっては管理者の承認が必要です。
3. 一覧の上にある `ダウンロード` を押します。
4. ダウンロード理由の入力や承認リクエストの案内が表示された場合は、手続きを完了してからファイルをダウンロードします。ダウンロード権限がないと表示された場合は、ワークスペースの管理者に問い合わせてください。

<Callout type="info" title="ダウンロードにはすべての送信先が含まれます">
一覧に適用したステータス・期間フィルターや選択した行に関係なく、そのフォームのすべての送信先がダウンロードされます。特定の送信先だけが必要な場合は、ダウンロードした Excel で絞り込んでください。ファイル内の日時は UTC 基準のため、韓国時間と比較する際は 9 時間の差を考慮してください。
</Callout>

フォームに送信された回答をダウンロードする場合は、[回答シートの回答ダウンロード](/ja/docs/help-center/result-analysis/response-sheet#回答をダウンロードする)を利用してください。

## 未回答者を絞り込んで選択した送信先に再送信する

すでにフォームを送信したものの、まだ回答していない送信先を選び、参加案内を再送信できます。

<img src="/images/guides/share-forms/sending-to-panel-filter-resend.png" alt="ステータスと最終送信日時で送信先を絞り込む画面" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

1. `共有` → `アンケートを送信` で `フィルター` を押します。
2. ステータスで `送信済み` と `開封済み` を選び、未回答の送信先を絞り込みます。初めて案内を送る対象者も含める場合は、`未送信` も選んでください。
3. 必要に応じて `最終送信日時` の `期間を選択` で送信時期を絞り込みます。
4. 絞り込み結果を確認し、一覧左側のチェックボックスで今回の送信先の行を選択します。
5. `アンケートを送信` を押し、送信元アカウント、件名、メッセージを確認して、選択した送信先に送信します。送信後は `送信回数` と `最終送信日` を確認してください。

| ステータス | 意味 |
| --- | --- |
| 未送信 | まだフォームを送信していない送信先です。 |
| 送信済み | フォームを送信済みで、開封済み・回答済みには変わっていない送信先です。 |
| 開封済み | フォームを開封しましたが、まだ回答していない送信先です。 |
| 回答済み | フォームに回答した送信先です。再送信から除外する場合は、このステータスを選択しないでください。 |

<Callout type="info" title="フィルターを変更したら送信先を選び直してください">
ステータス・期間フィルターを変更するか、`リセット` を押すと、行の選択が解除されます。先にフィルターを適用してから、送信する行を選び直してください。期間フィルターは回答日ではなく最終送信日時を基準にします。一度も送信しておらず送信日時がない対象者は、期間フィルターを適用すると表示されません。
</Callout>
