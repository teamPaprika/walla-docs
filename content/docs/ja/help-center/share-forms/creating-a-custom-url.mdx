## カスタム URL を作る

- 共有リンクはデフォルトで `walla.my/a/カスタム部分` の形式で生成されます。
- ルールに沿った URL を入力する必要があります。

### 設定方法

<Steps>
  <Step>
    ### リンクのカスタマイズへ移動する
    共有ページで `リンクのカスタマイズ` エリアへ移動します。
  </Step>
  <Step>
    ### カスタム URL を入力して保存する
    希望のカスタム URL を入力してから保存します。
  </Step>
  <Step>
    ### 表示方式を選ぶ
    基本ビュー／グループ別ビューのうち希望する表示方式を先に選んでから保存すると、その設定は公開を押さなくてもすぐに反映されます。
  </Step>
</Steps>

### カスタム URL のルール

- 0 文字以上 30 文字以下で入力可能
- スラッシュ（`/`）は使用不可
- ピリオド 1 つ（`.`）または 2 つ（`..`）だけで構成することは不可
- 正規表現 `__.*__` に一致する文字列は使用不可

## 共有プレビューの設定

- カスタム URL の下で、プロジェクトのタイトル・説明・サムネイル画像を設定できます。
- 保存するだけですぐに反映され、別途の公開作業は不要です。
- サムネイル画像を登録しない場合は、プロジェクトのタイトルとテーマを反映したデフォルトのサムネイルが表示されます。
<Callout type="warning" title="注意事項">
タイトルやサムネイルを変更したのに LINE や Slack などのメッセンジャーで以前の画像やテキストが表示される場合、それはテスト中に保存されたそのアプリまたはブラウザのキャッシュ（以前のデータの保存）が原因です。そのリンクを初めて受け取る人には正しく変更後のプレビューが表示されますので、心配は要りません。
</Callout>
