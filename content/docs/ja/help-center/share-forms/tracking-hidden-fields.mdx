## トラッキング項目（隠しフィールド）を追加する

<Steps>
  <Step>
    ### トラッキング管理ページを開く
    共有ページで `管理` ボタンをクリックします。
  </Step>
  <Step>
    ### トラッキング項目を入力する
    トラッキング名（隠しフィールド名）を入力したあと、Enter キーを押して登録しないと項目が作成されません。
  </Step>
  <Step>
    ### 保存する
    `保存` ボタンを押して保存します。
  </Step>
  <Step>
    ### 活用する
    登録した隠しフィールドは「流入経路を区別するためのカテゴリ」の役割を果たします。
    - ① SNS 別の流入を確認 → 隠しフィールド名を `SNS` に設定（例: Instagram、YouTube など）
    - ② 顧客グループ別に区別 → 隠しフィールド名を `customer` に設定
  </Step>
</Steps>
## 隠しフィールドの URL を作る

隠しフィールドを設定したら、フォームのリンク（URL）にそのフィールドを自分で追加する必要があります。

<Steps>
  <Step>
    ### 基本のフォーム URL を用意する
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4
    ```
  </Step>
  <Step>
    ### 隠しフィールド名を追加する
    `?フィールド名=` の形式で追加します。
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=
    ```
  </Step>
  <Step>
    ### フィールドの値を入力する
    例: YouTube から流入した場合
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=youtube
    ```
  </Step>
  <Step>
    ### チャネル別にリンクを共有する
    各リンクをチャネルごとに共有すると、回答シートで流入経路（例: YouTube、Instagram など）を確認できます。
  </Step>
</Steps>
## 複数の隠しフィールドを使う

- URL に複数の隠しフィールドを追加するには、「?」の代わりに「&」でつなげます。
```
https://walla.my/v/QA9S0imWeo232fSbd4?source=instagram&media=video
```
→ Instagram の動画広告からの流入という意味になります。
<Callout type="warning" title="注意事項">
- トラッキング項目の登録時は Enter を押さないと保存されません。
- 隠しフィールド名は英数字とアンダースコア（_）だけで構成することをおすすめします。
</Callout>
<Callout title="ヒント">
大量の隠しフィールド URL を作る必要がある場合は、[隠しフィールドのリンク生成 Google スプレッドシートのテンプレート](https://docs.google.com/spreadsheets/d/14F7iSY6yNiEV78eceveOkPNCTHzaMK5LIEqtYE4bo_I/edit?usp=sharing)を複製して使うと便利です。
</Callout>

## 隠しフィールドでロジック条件を作る

隠しフィールドの値に応じて、回答者を別の設問へ移動させられます。次は、広告リンクから来た回答者を別の設問へ移動させる例です。

<Steps>
  <Step>
    ### 隠しフィールドを登録する
    トラッキング管理ページで隠しフィールド `utm_source` を登録し、`保存` を押します。
  </Step>
  <Step>
    ### リンクを作る
    広告で使うリンクの末尾に値を付けます。
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads
    ```
  </Step>
  <Step>
    ### ロジック条件を作る
    ロジック画面で基準となる設問として `utm_source` を選び、条件は `等しい`、比較値は `ads` にします。
  </Step>
  <Step>
    ### 移動先の設問を選ぶ
    広告から来た回答者が移動する設問を選びます。
  </Step>
</Steps>

- 隠しフィールドの値は文字として比較します。リンクに値がないと隠しフィールドは空になり、`等しくない` を含めどの条件も満たしません。
- 公開する前は、プロジェクトの編集画面のプレビューで確認できます。プレビューは編集画面のアドレスに付いた値をそのまま使います。ブラウザのアドレスバーで、編集画面のアドレスの末尾に `?utm_source=ads` を付けてから、プレビューを開いてください。アドレスにすでに `?` がある場合は、`&utm_source=ads` を付けます。
- 公開したあとは、値を付けたリンクと値のないリンクをそれぞれ開いて、両方の経路を確認してください。
- 詳しい方法は[ロジックを設定するの「隠しフィールドで条件を作る」](/ja/docs/help-center/create-forms/setting-up-logic#隠しフィールドで条件を作る)をご覧ください。

## ロジックで使っている隠しフィールドを削除する

ロジックの条件で使われている隠しフィールドは削除できません。編集中のロジックだけでなく、公開済みのフォームのロジックで使われている場合も同じです。
このような隠しフィールドを削除して保存すると、`条件で使用中の非表示フィールドは削除できません。先に該当する条件を変更してください。` と表示されます。次の手順で先に条件を整理してから削除してください。

<Steps>
  <Step>
    ### 条件を変更する
    ロジック画面で、その隠しフィールドを使っている条件を探して削除するか、別の基準となる設問に変更します。
  </Step>
  <Step>
    ### もう一度公開する
    公開済みのフォームにもその条件があった場合は、変更したロジックでフォームをもう一度公開します。
  </Step>
  <Step>
    ### 隠しフィールドを削除する
    トラッキング管理ページで隠しフィールドを削除し、`保存` を押します。
  </Step>
</Steps>
