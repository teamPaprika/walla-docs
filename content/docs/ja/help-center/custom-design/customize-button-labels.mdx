import { Step, Steps } from 'fumadocs-ui/components/steps';

## 次へボタンをカスタマイズする

- グループ別ビューのフォームは基本的に 1 設問ずつ表示され、次の設問へ移動するときに「次へ」ボタンが表示されます。
- **このボタンを非表示にするには**

<Steps>
  <Step>
    ### 設定タブへ移動する
    プロジェクト編集画面の右側にある「設定」タブへ移動してください。
  </Step>
  <Step>
    ### ボタンを隠すを有効にする
    「次へボタン」のカテゴリで「ボタンを隠す」を有効にします。
  </Step>
</Steps>

- 「次へ」の代わりに **別の文言を入れたい場合** は、「ボタン名を変更」の項目に希望のテキストを入力してください。

## 回答送信ボタンをカスタマイズする

- デフォルトの文言は「回答を送信」と表示されます。
- 文言を変えたい場合は、ボタンをクリックしてから希望のテキストを直接入力すると、新しい文言に変更されます。

<Callout title="ご参考">
ボタンの文言をブランドやフォームのトーンに合わせて変えると、回答率の向上に役立ちます。
</Callout>
