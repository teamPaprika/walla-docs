## 終了フィールドの種類

### 終了ページ
   - 回答送信後に表示される、カスタマイズした終了画面です。
   - 説明フィールドと同じように、テキスト・画像・表などさまざまなコンテンツを入れて装飾できます。
	   - [テキストエディタ](/ja/docs/help-center/create-forms/editing-field-text)で、文字色・サイズ・太さなどさまざまなスタイルを適用できます。
	   - [スラッシュ（/）コマンド](/ja/docs/help-center/create-forms/editing-field-text)で、画像・表・見出しなどをかんたんに挿入することもできます。
   - 例:
     - 「フォームを送信しました。ご不明な点は [cs@walla.my](mailto:cs@walla.my) までお問い合わせください。」
     - 「回答者限定の特別プロモーションコード: WALLA10」

### URL へ移動
   - 回答送信後に特定の Web ページへ移動させられます。
   - プロジェクト編集画面の終了フィールド設定で、移動先の URL を直接入力するだけです。

## ロジックと組み合わせて使う方法

送信後に終了フィールドへ移動させるには、必ずロジックを設定する必要があります。

<Steps>
  <Step>
    ### 送信ボタンをクリックする
    ロジックページで「送信」ボタンをクリックします。
  </Step>
  <Step>
    ### 終了フィールドを指定する
    条件に応じて移動する終了フィールドを指定します。
  </Step>
  <Step>
    ### 公開する
    設定したロジックは `公開` を押さないと実際のフォームに反映されません。
  </Step>
</Steps>

<Callout type="warning" title="注意事項">
終了フィールドを追加しただけでロジックを設定しないと、デフォルトの終了ページ（「回答が正常に送信されました。」）が自動的に表示されます。
</Callout>

<Callout title="ヒント">
- 終了フィールドは、フォームの締めくくりにお礼、追加案内、プロモーション情報などを伝えるのに向いています。
- ブランドキャンペーンやマーケティングのフォームなら、URL 移動型の終了フィールドを活用して、Web サイトやイベントページへ自然につなげられます。
</Callout>
