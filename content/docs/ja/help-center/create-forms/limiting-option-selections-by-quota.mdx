import { Step, Steps } from 'fumadocs-ui/components/steps';

## 設定方法

<Steps>
  <Step>
    ### 機能を有効にする
    対象の設問を選択し、「オプション別の回答数制限」機能を有効にしてください。
  </Step>
  <Step>
    ### 最大回答数を入力する
    「設定」ボタンを押して、各オプションの最大回答数を入力します。
  </Step>
  <Step>
    ### 公開する
    公開すると、全回答のうちそのオプションが選ばれた回数が、設定した数を超えないようになります。
  </Step>
</Steps>

<Callout type="warning" title="注意事項">
- オプションを削除または変更すると、そのオプションの制限設定はリセットされます。
- 回答数の制限は、フォームを公開した時点から適用されます。
</Callout>

## 適用時の表示

1. **選択肢がすでにすべて締め切られている場合** → そのオプションは無効になり、選択できません。

2. **回答の途中で選択肢が締め切られた場合** → `回答を送信` ボタンを押すと「特定の設問の送信回数が上限を超えました。」というエラーメッセージが表示されます。

<Callout title="ご参考">
オプション別の回答数制限を活用すると、先着順の募集や席の予約といった場面で重複回答を防ぎ、公平に回答を集められます。
</Callout>
