---
title: "決済フィールド: Toss Payments"
description: "決済フィールドを使うと、回答者がフォーム上でそのまま決済できます。"
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
  <Step>
    ### Toss Payments で新しい加盟店を登録する
    Toss Payments で新しい加盟店を登録してください。

    - 詳細は以下のリンクをご覧ください。
      - [Toss Payments 加盟店登録ガイド](https://tosspublic.notion.site/b99d2cb71d29401c82eecb64ae6f712c)
      - [Toss Payments 手数料のご案内](https://www.tosspayments.com/about/fee)
    - すでに登録済みの場合は、そのまま次のステップに進めます。
  </Step>
  <Step>
    ### 決済フィールドを追加する
    プロジェクト編集画面で決済フィールドを追加してください。
  </Step>
  <Step>
    ### 決済情報を入力する

    決済に必要な情報を入力してください。

    #### バリアントキー
    - 決済 UI を区別する固有の値で、決済フィールドの `決済 UI バリアントキーを確認` から確認できます。
    - ライブ UI を入れると実際の決済が行われ、テスト UI を入れると実際の決済は行われないため、よく区別して入力してください。
    - 初めて利用する場合は、`UI を追加` ボタンからさまざまな決済 UI を設定できます。
    - `UI を追加` ボタンを押したあと、`国内一般決済` を選択してください。

    <Callout type="warning" title="バーチャル口座は利用不可">
    バーチャル口座は利用できません。決済 UI 編集の [機能]-[決済手段リスト] で、バーチャル口座のチェックを必ず **外して** ください。Walla は決済リクエスト後に回答が送信された時点で決済が完了したものとして記録しますが、バーチャル口座は即時決済されないため、回答シートには決済完了と記録されても実際には入金されていない、という事態が起こり得ます。
    </Callout>

    #### クライアントキー／シークレットキー
    - [Toss Payments 開発者センター](https://developers.tosspayments.com/)の「マイ開発情報」で確認できます。左側で加盟店を選択し、その加盟店のクライアントキーとシークレットキーをコピーしてください。

    #### 注文 ID
    - 注文した決済を識別するための固有の値で、「注文ID\_ランダムキー\_時刻」の形式で表示されます。例）あんこたい焼き → `redbean`、カスタードたい焼き → `chouxcream`

    #### 商品名／商品価格
    - 回答者が注文する商品の名前と価格を入力してください。
  </Step>
  <Step>
    ### 注文書の作成完了
    これで決済フィールドを使って注文書を作成できます。

    - 決済 UI にバリアントキーを入力し、決済ウィジェットにクライアントキーとシークレットキーを入力します。
    - 注文 ID と商品名、商品価格などを入力して保存すれば完了です。
    - テスト UI を使うと実際の決済は行われないため、ライブ UI とよく区別して入力してください。
    - ロジックを使って、選択肢に応じて異なる決済フィールドが表示されるように設定できます。
  </Step>
</Steps>
