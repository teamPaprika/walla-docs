## ロジックの考え方

- ロジックは「回答に応じて次の設問がどこにつながるか」を決めます。
- デフォルト経路とは、すべての回答者が必ず通る流れのことです。（「必須入力」とは別の概念です。）

## ロジックを追加する

<Steps>
  <Step>
    ### ロジック設定画面へ移動する
    プロジェクト編集画面で `ロジック` ボタンを押すと、ロジック設定画面へ移動できます。
  </Step>
  <Step>
    ### 条件と移動先の構成を理解する
    ロジックは「条件」と「移動先」の 2 つの部分で構成されます。
  </Step>
  <Step>
    ### 条件
    1. **基準となる設問を選ぶ** – どの設問の回答を基準にするかを選びます。
       - グリッド・ランキング・テーブル・カスタムフィールドの設問では、さらに `サブ項目` を選びます。[サブ項目で条件を作る](#サブ項目で条件を作る)をご覧ください。
       - 隠しフィールドも基準として選べます。[隠しフィールドで条件を作る](#隠しフィールドで条件を作る)をご覧ください。
    2. **条件を選ぶ** – 条件の種類を選びます。条件は大きくテキスト／値・選択肢・数値・日付の比較に分かれます。詳しい種類は下の[条件の種類をくわしく知る](#条件の種類をくわしく知る)をご覧ください。
    3. **オプション／回答を選ぶ** – その条件がどの回答で作動するかを選びます。
       - 複数の回答を同時に選ぶこともできます。
  </Step>
  <Step>
    ### 条件を複数追加する
    - `+ 新しい条件を追加` を押すと、複数の条件を組み合わせられます。
    - 条件を結合するときは、次の 2 つから選んでください。
      - **AND**: 前の条件と後の条件を両方満たしたときにロジックが作動
      - **OR**: 前の条件か後の条件のどちらかを満たせばロジックが作動
  </Step>
  <Step>
    ### 移動先
    - 条件をすべて設定したら、回答者が移動するフィールドを選びます。
    - 設定が完了すると、その条件を満たした回答者は指定した設問へ直接移動します。
  </Step>
</Steps>

## 条件の種類をくわしく知る

### テキスト／値の比較

| 条件 | 意味 | 例 | 回答例 |
| ------ | -------------- | ---------------- | ----------------- |
| 等しい | 値が完全に一致する | 答えが `ソウル` と一致するとき | ソウル |
| 等しくない | 値が一致しない | 答えが `ソウル` でないとき | 仁川 |
| 前方一致 | 特定の値で始まる | 答えが `010` で始まるとき | 010-1234-5678 |
| 後方一致 | 特定の値で終わる | 答えが `.com` で終わるとき | example<span>@</span>walla.com |
| 文字を含む | 特定の文字を含む | 答えに `株式会社` が含まれるとき | 株式会社パプリカデータラボ |
| 文字を含まない | 特定の文字を含まない | 答えに `りんご` が含まれないとき | ぶどうジュース |

### 選択肢の比較
選択式・複数選択のように複数の項目を選べる設問で、どの選択肢を選んだかを判定するときに使います。

| 条件 | 意味 | 例 |
| -------- | --------------------- | ----------------------- |
| すべて含む | 指定した項目をすべて選択している | `A`、`B` を両方選んだとき |
| 1 つ以上含む | 指定した項目のうち 1 つ以上を選択している | `A` か `B` のどちらかを選んだとき |
| すべて未選択 | 指定した項目を 1 つも選択していない | `A`、`B` のどちらも選ばなかったとき |
| 1 つ以上未選択 | 指定した項目のうち 1 つ以上を選択していない | `A`、`B` のうち少なくとも 1 つが未選択のとき |


### 数値の比較

| 条件 | 意味 | 例 |
| ----- | ------------ | ------------------------ |
| より大きい | 基準値より大きい（超過） | 年齢が `19` より大きいとき |
| 以上 | 基準値以上 | 年齢が `19` 以上のとき |
| より小さい | 基準値より小さい（未満） | 点数が `60` より小さいとき |
| 以下 | 基準値以下 | 点数が `60` 以下のとき |

### 日付の比較

| 条件 | 意味 | 例 |
| -------- | ----------------------- | --------------------- |
| より前 | 基準日より前（当日を含まない） | `2026-01-01` より前のとき |
| 以前 | 基準日または それより前（当日を含む） | `2026-01-01` かそれ以前のとき |
| より後 | 基準日より後（当日を含まない） | `2026-01-01` より後のとき |
| 以降 | 基準日または それより後（当日を含む） | `2026-01-01` かそれ以降のとき |

## サブ項目で条件を作る

1 つの回答に複数の欄がある設問があります。
このような設問では、基準となる設問を選んだあと、比較する欄を 1 段階ずつ選びます。

<Steps>
  <Step>
    ### 基準となる設問を選ぶ
    基準となる設問を選びます。
    その設問に細かい欄があると、下に `サブ項目` の選択欄が表示されます。
  </Step>
  <Step>
    ### サブ項目を選ぶ
    `サブ項目` で、比較する行・列・プロパティを選びます。
    選択欄がさらに表示されたら、最後の欄まで選びます。
  </Step>
  <Step>
    ### 条件と比較値を決める
    条件の種類を選び、比較値を入力します。
    比較値の入力欄は、最後に選んだ欄の形式に合わせて変わります。
  </Step>
</Steps>

### 設問ごとの選ぶ順番

| 設問 | 選ぶ順番 | 比較値 |
| ------------- | ------------------- | ---------------------- |
| 複数選択グリッド | 行 | その行で選んだ選択肢 1 つ |
| チェックボックスグリッド | 行 | その行で選んだ選択肢（複数可） |
| ランキング | 順位 | その順位に置かれた選択肢 1 つ |
| テーブル | 行 → 列 | そのセルに入力された文字 |
| カスタムフィールド | プロパティ → 必要に応じて項目の位置 | そのプロパティの形式に合う値 |

- 複数選択グリッド・チェックボックスグリッド・ランキングでは、行を選ぶとすぐに比較値を決めます。項目の位置は選びません。
- ランキングの設問で回答者が選択肢を自分で入力できる場合は、比較値で `オプション選択` か `カスタム` を選びます。`カスタム` では値を入力して Enter を押します。
- `この回答は条件に使用できません` と表示された欄は、条件に使えません。別のサブ項目を選んでください。

### カスタムフィールドのサブ項目

- 決まったプロパティがある場合は、`サブ項目` で選びます。
- キーを自分で入力できるプロパティでは、`プロパティを選択` と `キーを入力` のボタンが表示されます。一覧にないキーは、`キーを入力` を押して入力します。
- 回答がリスト形式の場合は、`項目の位置` 欄が表示されます。
  - 1 は最初の項目、2 は 2 番目の項目です。
  - 回答全体がリストのカスタムフィールドでは、最初に `項目の位置` を必ず入力します。
- `項目の位置（任意）` 欄は空欄のままにできます。
  - 空欄の場合は、リスト全体を比較します。
  - 数字を入力すると、その項目 1 つだけを比較します。

### 比較値を入力する

- 比較値に決まった形式（JSON など）を使う必要はありません。画面の選択欄と入力欄だけを使います。
- **選択肢がある値** – 一覧から選択肢を選びます。複数を選べる欄もあります。
- **リストの値を直接入力** – 値を 1 つ入力して Enter を押します。値が小さなチップとして追加されます。次の値も同じ方法で追加します。
- **数値** – 数値を入力します。0 と比較するには `0` を入力してください。空欄は 0 として扱われません。
- **真／偽** – `真` か `偽` を選びます。何も選ばないと `偽` としては扱われません。リストの欄では `true` か `false` を入力して Enter を押します。

### 入力が終わっていない条件

- 条件の下に `条件を確認し、値の入力を完了してください。` と表示されたら、その条件はまだ完成していません。
- 入力欄に文字が残っている場合は、Enter を押してチップとして追加します。
- 値が形式に合わないと、文字が入力欄に残り、`指定された型の値を入力してください。` と表示されます。値を直してから、もう一度 Enter を押します。
- `項目の位置` が空欄か範囲外の場合は、案内が表示されます。案内に従って数字を直します。
- この状態ではフォームを公開できません。公開しようとすると `公開する前に、条件の未入力やエラーを解消してください。` と表示されます。

### 設問を変更したあとに条件が壊れたとき

- 設問の行・列・選択肢を削除または変更すると、条件に `項目が見つかりません` または `この値は選択肢にありません。別の値を選択してください。` と表示されることがあります。
- 別のサブ項目や値を選び直してください。
- このような条件が保存されたままだと、公開できません。公開しようとすると `回答値の条件が無効です。質問、下位項目、比較値を確認してください。` と表示されます。

## 隠しフィールドで条件を作る

リンクで受け取った隠しフィールドの値に応じて、回答者を別の設問へ移動させられます。
隠しフィールドは、先に共有ページのトラッキングで登録する必要があります。登録方法は[トラッキング（隠しフィールド）](/ja/docs/help-center/share-forms/tracking-hidden-fields)をご覧ください。

<Steps>
  <Step>
    ### 隠しフィールドを選ぶ
    基準となる設問の一覧から、隠しフィールドの名前を選びます。
  </Step>
  <Step>
    ### 条件と値を入力する
    [テキスト／値の比較](#テキスト値の比較)の条件から 1 つを選びます。
    比較値は文字で入力します。
  </Step>
  <Step>
    ### 移動先の設問を選ぶ
    条件を満たした回答者が移動する設問を選びます。
  </Step>
</Steps>

- 例: 隠しフィールド `utm_source`、`等しい`、`ads`
  - リンクが `https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads` なら、条件を満たします。
  - 広告から来た回答者だけが、指定した設問へ移動します。
- リンクに隠しフィールドの値がない場合、値は空になります。値が空のときは、`等しくない` を含め、どの条件も満たしません。
- 隠しフィールドは移動先として選べません。条件の基準としてだけ使います。
- ロジックの条件で使われている隠しフィールドは削除できません。[ロジックで使っている隠しフィールドを削除する](/ja/docs/help-center/share-forms/tracking-hidden-fields#ロジックで使っている隠しフィールドを削除する)をご覧ください。

## ノードを活用してロジックを設定する

<Steps>
  <Step>
    ### ノードと接続線を見る
    ロジック画面では各設問がノードとして表示され、ノード間の接続線で移動の流れを確認できます。`デフォルト経路` はすべての回答者が通る基本の流れを、`ロジック #1`、`ロジック #2` のように番号の付いた分岐は条件によって分かれる経路を表します。
  </Step>
  <Step>
    ### デフォルト経路を設定する
    ノード上の `デフォルト経路` ラベルを押すと、`次のフィールド` を選ぶドロップダウンが開きます。フィールドを検索するか一覧から選んで、条件に当てはまらない回答者が移動するデフォルトの設問を指定できます。
  </Step>
  <Step>
    ### ロジックノードで条件を編集する
    `ロジック #1`、`ロジック #2` のように番号の付いた分岐ラベルを押すと、条件エリアがその場で開きます。基準となる設問、条件、オプションをノード上で直接修正したり、`新しい条件` を追加したりできます。
  </Step>
  <Step>
    ### 接続線を押して直接修正する
    フィールドを選んだあと、ノード上の `ロジック` や `デフォルト経路` ラベルを押さずに、ノード間の接続線を直接押しても、その流れを修正できます。
  </Step>
  <Step>
    ### ノードをドラッグしてつなぐ
    ノード下部の接続点を引っ張って別の設問ノードに置くと、2 つの設問を直接つないで移動の流れを作れます。新しい接続線を引くと、回答者はその経路へ移動します。
  </Step>
</Steps>

## ロジックの活用例

- #### 例 1. 個人情報の同意による分岐
  - 条件: `個人情報収集フィールド` =「同意する」
  - 移動先: `個人情報を収集する設問（電話番号フィールドなど）` 以降の設問
- #### 例 2. 年齢による不適格処理
  - 条件: `年齢の設問（選択式／ドロップダウンフィールド）`、等しくない、「10 代」
  - 移動先: `不適格フィールド`
- #### 例 3. キーワードを含む場合に特定の設問へ移動
  - 条件: `短文／長文フィールド`、文字を含む、「りんご」
  - 移動先: `りんごジュース販売の決済フィールド`

## その他の設定と注意事項

- ロジックが途中で切れる場合は、**不適格フィールドが途中にあるか、前の設問のロジック設定が誤っている** 可能性が高いです。

- フィールドグループ内の設問にも個別にロジックを設定でき、特定の設問へ移動するよう設定すると、その設問が含まれるグループから表示されます。
- `リセット` ボタンを押すと、その設問のロジックがすべて削除されます。
