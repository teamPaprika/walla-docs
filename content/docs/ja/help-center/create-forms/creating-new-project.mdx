---

import { Step, Steps } from 'fumadocs-ui/components/steps';

## プロジェクトの作成方法

<Steps>
  <Step>
    ### プロジェクト作成ボタンをクリックする
    ワークスペース画面で `プロジェクトを作成` ボタンをクリックします。
  </Step>
  <Step>
    ### プロジェクトを設定する
    プロジェクト名とタグを設定します。
  </Step>
  <Step>
    ### 作成完了
    `プロジェクトを作成` ボタンを押すと、新しいプロジェクトがワークスペースに追加されます。
  </Step>
</Steps>

<Callout title="ご参考">
1 つのワークスペース内に複数のプロジェクトを作成して、さまざまなフォームを同時に管理できます。
</Callout>
