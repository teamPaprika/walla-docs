## 説明フィールド

- フォームの表紙、セクションの区切り、案内文など、自由な説明用コンテンツを入れられます。
- [テキストエディタ](/ja/docs/help-center/create-forms/editing-field-text)で、文字色・サイズ・太さなどさまざまなスタイルを適用できます。
- [スラッシュ（/）コマンド](/ja/docs/help-center/create-forms/editing-field-text)で、画像・表・見出しなどをかんたんに挿入することもできます。

<Callout title="ヒント">
説明フィールドをうまく活用してフォームの構造を区切ったり案内を追加したりすると、参加者が内容をより理解しやすくなります。
</Callout>

## 埋め込みフィールド

- Web サイトの URL を貼り付けると、Walla フォームの中にその Web ページを直接表示できます。

### YouTube 動画を埋め込む

YouTube 動画の共有 URL または埋め込みコードを埋め込みフィールドに貼り付けると、フォームの中で動画をそのまま再生できます。

<Steps>
  <Step>
    ### YouTube で共有ボタンをクリックする
    埋め込みたい動画を YouTube で開き、動画の下の共有ボタンをクリックします。
  </Step>
  <Step>
    ### 共有モーダルで埋め込みを選ぶ
    共有モーダルが開いたら、いちばん左の埋め込みオプションをクリックします。
  </Step>
  <Step>
    ### 埋め込みコードから URL だけをコピーする
    iframe タグ全体ではなく、src 属性の中にある https://www.youtube.com/embed/... で始まる URL だけをドラッグしてコピーします。
  </Step>
  <Step>
    ### Walla の埋め込みフィールドで URL 埋め込みをクリックする
    Walla のプロジェクト編集画面で埋め込みフィールドを追加し、フィールド内の URL 埋め込みボタンをクリックします。
  </Step>
  <Step>
    ### URL を貼り付けて埋め込みをクリックする
    コピーした YouTube の埋め込み URL を入力欄に貼り付けてから、埋め込みボタンを押します。
  </Step>
  <Step>
    ### 埋め込み結果を確認する
    フォームの中で YouTube 動画がそのまま再生できる形で表示されていることを確認できます。
  </Step>
</Steps>

### Google カレンダーを埋め込む

Google カレンダーの共有 URL を埋め込みフィールドに貼り付けると、予定や予約の情報をフォームの中でそのまま表示できます。

<Steps>
  <Step>
    ### Google カレンダーで共有オプションを開く
    埋め込みたい予定／予約をクリックし、ポップアップの `⋮`（その他）メニューから `その他の共有オプション` を選びます。
  </Step>
  <Step>
    ### Web サイトに埋め込む → インライン予約ページを開く
    共有モーダル上部の `Web サイトに埋め込む` タブを選び、下部の `インライン予約ページ` をクリックして開きます。
  </Step>
  <Step>
    ### 埋め込みコードから URL だけをコピーする
    `埋め込みコード` エリアの iframe タグ全体ではなく、`src="..."` の中にある `https://calendar.google.com/...` で始まる URL だけをドラッグしてコピーします。
  </Step>
  <Step>
    ### Walla の埋め込みフィールドで URL 埋め込みをクリックする
    Walla のプロジェクト編集画面で埋め込みフィールドを追加し、フィールド内の `URL 埋め込み` ボタンをクリックします。
  </Step>
  <Step>
    ### URL を貼り付けて埋め込みをクリックする
    コピーした Google カレンダーの URL を入力欄に貼り付けてから、`埋め込み` ボタンを押します。
  </Step>
  <Step>
    ### 埋め込み結果を確認する
    フォームの中にカレンダーの予約時間選択画面がそのまま表示されることを確認できます。
  </Step>
</Steps>

<Callout type="warning" title="注意事項">
- 外部サイトのセキュリティポリシーや HTTPS 設定によっては、埋め込みが表示されない場合があります。
- 通常の URL を入れて「…への接続が拒否されました」と表示される場合は、そのサイトが提供する埋め込み専用リンクで再度お試しください。
</Callout>
