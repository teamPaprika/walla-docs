import { Step, Steps } from 'fumadocs-ui/components/steps';

## テンプレートを読み込む

<Steps>
  <Step>
    ### プロジェクト作成ボタンをクリックする
    ワークスペース画面で `プロジェクトを作成` ボタンをクリックします。
  </Step>
  <Step>
    ### テンプレートを使うを選択する
    `テンプレートを使う` を選択します。
  </Step>
  <Step>
    ### 使いたいテンプレートを選ぶ
    使いたいチームテンプレートを選んでから `テンプレートを使う` をクリックします。
  </Step>
  <Step>
    ### 完了
    選んだテンプレートをもとに新しいプロジェクトが作成されます。
  </Step>
</Steps>
