複数の設問に同じ設定を適用したい場合は、設問をまとめて選択して編集してみてください。選択したすべての設問に適用できる設定が、右側のサイドバーに表示されます。

## 複数の設問を選択する

<Steps>
  <Step>
    ### フォーム編集を開く

    編集するフォームを開き、上部の `作成` に移動します。
  </Step>
  <Step>
    ### 最初の設問を選ぶ

    左側の `フォームフィールド` 一覧で、選択する範囲の最初の設問をクリックします。

    <img src="/images/guides/manage-forms/bulk-edit-select-first.png" alt="左側のフォームフィールド一覧で最初の編集対象の設問を選択した画面" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Shift で範囲を選ぶ

    `Shift` キーを押したまま、最後の設問をクリックします。最初から最後までの間にある設問がまとめて選択されます。

    <img src="/images/guides/manage-forms/bulk-edit-select-range.png" alt="Shift で複数の設問を選び、左側の一覧に選択範囲が表示された画面" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 共通の設定を確認する

    選択した設問を確認し、右側のサイドバーで変更する設定を探します。

    <img src="/images/guides/manage-forms/bulk-edit-common-settings.png" alt="複数の設問を選択し、右側の共通設定パネルを確認する画面" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

1 つの設問の編集に戻るには、`Shift` キーを押さずに左側の一覧の設問をクリックしてください。

## まとめて変更できる設定

| 場所 | 項目 | できること | 表示・利用条件 |
| --- | --- | --- | --- |
| 回答検証 | 必須入力 | 選択した設問への回答を必須にするかどうかをまとめて設定します。 | 選択したすべての設問がこの設定に対応している場合に表示されます。 |
| セキュリティ | データマスキング | 選択した設問のデータマスキングを設定します。 | 選択したすべての設問がこの機能に対応している場合に表示されます。プランや権限によって利用が制限される場合があります。 |
| セキュリティ | 回答を自動削除 | 選択した設問の回答を自動削除するかどうかと、削除までの期間を設定します。 | 選択したすべての設問がこの機能に対応している場合に表示されます。プランや権限によって利用が制限される場合があります。 |
| 質問テンプレート | 質問テンプレートとして保存 | 選択した設問の組み合わせをテンプレートとして保存します。 | プランや権限によって利用が制限される場合があります。 |


詳しくは、[回答を検証する](/ja/docs/help-center/create-forms/response-validation)、[データマスキング](/ja/docs/help-center/security/data-masking)、[回答を自動削除する](/ja/docs/help-center/security/auto-delete-responses)、[フィールドテンプレート](/ja/docs/help-center/create-forms/field-template)を参照してください。

## 設定を変更して確認する

<Steps>
  <Step>
    ### 共通の設定を変更する

    設問をまとめて選択した状態で、右側のサイドバーの設定を変更します。たとえば、`回答検証` の `必須入力` を有効にすると、選択した設問への回答を必須にできます。
  </Step>
  <Step>
    ### 設問ごとの適用を確認する

    設問を 1 つずつ選択して、意図した設定が適用されたか確認します。選択した設問の元の設定はそれぞれ異なる場合があるため、変更前後を確認してください。
  </Step>
  <Step>
    ### プレビューを確認して公開する

    プレビューで回答時の動作を確認し、回答者に変更を反映するにはフォームを公開します。
  </Step>
</Steps>

設問のタイトル・選択肢・ロジックを修正する場合は、各設問を選択して該当する編集機能を利用してください。

<Callout type="info" title="目的の設定が表示されない場合">

- 複数の設問が選択されているか確認してください。1 つだけ選択すると、その設問の個別設定が表示されます。
- 選択したすべての設問タイプがその機能に対応しているか確認してください。必要な設問だけを選び直すと、共通で適用できる設定を確認できます。
- 機能が無効になっている場合は、まず画面の案内と選択した設問の条件を確認してください。プランの案内が表示される場合は、現在のチームのプランと編集権限を確認してください。
</Callout>
