## 回答検証

| 検証ルール | 説明 |
|---|---|
| 必須入力 | 必ず回答する必要があります。 |
| 回答の長さ制限 | 最小／最大文字数を設定できます。 |
| 回答に含める | 特定のテキストが含まれていないとエラーメッセージが表示されます。 |
| 回答に含めない | 特定のテキストが含まれているとエラーメッセージが表示されます。 |
| 数値範囲の制限 | 入力できる最小値／最大値を指定できます。 |
| 選択数の設定 | 最小・最大の選択数、または正確な個数を指定できます。 |
| 選択肢を含む | 必ず特定の選択肢を含める必要があります。 |
| 選択肢を除外 | 特定の選択肢は絶対に選べないようにします。 |
| オプション別の回答数制限 | 全回答のうち、特定オプションが選ばれる回数を制限します。先着順の募集、席数・数量の制限などに活用できます。 |
| 正規表現（Regex） | パターンを自分で指定して、形式の検証を細かく行えます。 |

<Callout title="正規表現の例">
- 英字のみ入力: `^[A-Za-z]+$`
- URL 形式の確認: `^(https?:\/\/)?([\w-]+\.)+[\w-]+(\/[\w-./?%&=]*)?$`
- 韓国の住民登録番号の形式（ハイフンあり）: `^\d{6}-\d{7}$`
- 郵便番号（5 桁の数字）: `^\d{5}$`
</Callout>

<Callout type="warning" title="住民登録番号を収集する際の注意">
実際の住民登録番号を収集する場合は法的な制限があるため、必ず **データマスキング** と **回答の自動削除** 機能を有効にしてください。
</Callout>
