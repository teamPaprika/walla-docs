## チーム／ワークスペース

<Accordions>

  <Accordion title="Walla を開くとログインではなく会員登録の画面に移動します。">
    そのアカウントに長期間アクセスしていなかったため、アカウント保護を目的とした本人確認と利用規約への同意の手続きが再度表示されている状況と思われます。エラーやアカウントの問題ではありませんので、再度ログインして表示される手続きを完了していただければ、これまでどおりご利用いただけます。そのアカウントで作成したフォームや収集したデータはすべてそのまま保持されていますので、ご安心ください。
  </Accordion>

  <Accordion title="Free チームでもメンバーを招待できますか？">
    はい、Walla は無料プランを提供しています。無料プランでも、フォームの作成や回答の収集といった主要な機能をご利用いただけます。さらに多くの機能が必要な場合は、有料プランをご検討ください。
  </Accordion>

  <Accordion title="チームに招待したのにプロジェクトが表示されません。">
    チームへの招待は完了しているものの、ワークスペースにはまだメンバーとして追加されていない状態と思われます。ワークスペース上部の歯車アイコンをクリックし、[メンバー管理] から該当のユーザーをワークスペースに追加してください。追加が完了すると、招待されたワークスペースを確認できます。
  </Accordion>

  <Accordion title="特定のメンバーだけが回答結果を閲覧できるようにしたいです。">
    特定のメンバーだけが回答結果を閲覧できるようにするには、ワークスペースメンバーの権限を調整してください。ワークスペース上部の歯車アイコンをクリックし、[役割と権限] メニューから役割ごとに利用できる機能を設定できます。

    ※ この機能は Enterprise プランでのみ提供されます。
  </Accordion>

  <Accordion title="チームの所有権を別のアカウントに引き継ぎたいです。">
    現在、チームの移管は原則としてサポートしておらず、チームのオーナーご自身が Pro プランを契約したうえで「オーナー移管」を申請し、その後カスタマーサポートへ返金を依頼する方法でのみ対応可能です。ただし、前オーナーとの連絡が取れないやむを得ない場合に限り、データ保護とセキュリティの手続きに従い、同一組織（会社／ドメイン）からの正式な依頼であることを確認したうえで、例外的に移管をお手伝いしています。詳細は [cs@walla.my](mailto:cs@walla.my) までお問い合わせください。
  </Accordion>

</Accordions>

## サブスクリプションと決済

<Accordions>

  <Accordion title="Walla は無料で使えますか？">
    はい。Walla では無料で、フォームの無制限作成、回答の無制限収集、統計と回答結果の確認が可能です。
  </Accordion>

  <Accordion title="決済後に有料機能を使っていないのですが、返金してもらえますか？">
    Walla はプロジェクトの作成以外にも、フォームリンクの共有、回答の収集、アナリティクスの確認、既存プロジェクトに適用された有料機能の維持など、さまざまな形でご利用いただけるサービスです。とくにサービスの性質上、明確な作業履歴が残らなくても実際の利用が発生している場合があるため、単純な「未使用」を基準に利用の有無を判断することが難しい点をご了承ください。
  </Accordion>

  <Accordion title="サブスクリプションを解約するにはどうすればよいですか？">
    「チーム設定 → チーム管理」ページで `プラン管理` ボタンを押すと決済情報のページへ移動でき、そこで `サブスクリプションを解約` ボタンを押すと解約できます。詳細は[プランを解約する](/ja/docs/help-center/getting-started/starting-or-changing-subscription)をご覧ください。
  </Accordion>

  <Accordion title="サブスクリプションを解約して返金を受けられますか？">
    返金の可否は決済時点とプランの種類によって異なります。月額サブスクリプションの場合、決済後 24 時間が経過するとサービスが利用されたものとみなされ、返金はできません。年額サブスクリプションの場合、決済後 14 日以内の解約であれば全額返金が可能で、それ以降は一部金額を差し引いたうえで返金されます。返金をご希望の場合は [cs@walla.my](mailto:cs@walla.my) までお問い合わせください。詳細は[返金ポリシー](https://home.walla.my/en/policy/refund-latest)をご参照ください。
  </Accordion>

  <Accordion title="決済された金額が料金プランのページに記載された金額と違います。">
    Walla は海外の決済代行会社を利用しているため、プランの契約やギフト券の決済時に、カード会社の方針によって海外決済手数料がかかる場合があります。
  </Accordion>

</Accordions>

## プロジェクトを作成する

<Accordions>

  <Accordion title="フォームに画像を追加できますか？">
    どのフィールドでも、設問のタイトルや説明を入力する欄で「スラッシュ（/）」を入力すると画像を挿入できます。先に説明を書いてから「スラッシュ（/）」で画像を挿入することも、先に画像を挿入してからドラッグして位置を調整することもできます。[スラッシュ（/）コマンドをくわしく見る →](/ja/docs/help-center/create-forms/editing-field-text)
  </Accordion>

  <Accordion title="「回答を送信」などの文言を翻訳できますか？">
    フォームの標準文言（必須入力、回答の送信、エラーメッセージ、送信完了の文言など）は、回答者のブラウザ言語に合わせて韓国語・英語・日本語・中国語（簡体字）・ベトナム語・タイ語などへ自動的に翻訳されます。
  </Accordion>

  <Accordion title="不適格フィールドは終了フィールドとどう違いますか？">
      不適格フィールドは、回答対象者でない場合にフォームの進行を止めるためのフィールドで、不適格フィールドへ移動した回答は保存されません。回答送信後に案内メッセージを表示したい場合は「終了フィールド」の利用をおすすめします。あわせて、不適格フィールドを削除するか、ロジック設定で前の設問とつながらないようにすることをおすすめします。
  </Accordion>

  <Accordion title="1 ページに複数の設問を表示したいです。">
    基本ビューを使うと 1 ページにすべての設問が表示され、スクロールして次の設問へ進みます。基本ビューでは設問の間に `ページ分割` を追加して、好きな基準で画面を区切れます。グループ別ビューでは、フィールドグループを使って複数の設問を 1 つの画面にまとめられます。
  </Accordion>

  <Accordion title="フォームを開いたのに次の設問へ進めません。">
    その設問のロジックが、見つからないフィールドを参照しているためです。ロジック設定を変更してから再度お試しください。「見つからないフィールド／オプション」と表示されている部分を修正して公開すれば解決します。
  </Accordion>

  <Accordion title="回答者の答えに応じて別の設問へ移動するよう設定できますか？">
    はい。[ロジック設定](/ja/docs/help-center/create-forms/setting-up-logic)の機能を活用すると、回答者の選択に応じて特定の設問を表示したり非表示にしたりできます。
  </Accordion>

  <Accordion title="終了フィールドを追加したのに、デフォルトの終了画面しか表示されません。">
    終了フィールドを追加しただけでロジックを設定しないと、デフォルトの終了ページ（「回答が正常に送信されました。」）が自動的に表示されます。送信後に別の終了フィールドへ移動させるには:
1. ロジックページで「送信」ボタンをクリックします。
2. 条件に応じて移動する終了フィールドを指定します。

とくにロジックを使わず常に特定の終了フィールドへ移動させたい場合は、デフォルト経路をその終了フィールドに変更してください。
  </Accordion>

</Accordions>

## プロジェクトを管理する
<Accordions>

  <Accordion title="作成したプロジェクトが見つかりません。">
      プロジェクトを削除したのでなければ、別のアカウント／チーム／ワークスペースにアクセスしていて見つからない可能性があります。まず、現在アクセスしているアカウント・チーム・ワークスペースが、プロジェクトを作成した環境と一致しているかご確認ください。

#### 1. 現在のアカウントを確認する方法

右上のプロフィールアイコンを押すと、現在ログインしているアカウントを確認できます。別のアカウントでログインし直したい場合は「ログアウト」をクリックします。

#### 2. 現在のチームを確認する方法

左上のチーム一覧から、現在アクセスしているチームを確認できます。

#### 3. 現在のワークスペースを確認する方法

チーム一覧の下にあるワークスペース一覧から、現在アクセスしているワークスペースを確認できます。
  </Accordion>

  <Accordion title="誤ってフォームや回答を削除してしまいました。復元できますか？">
      個人情報保護とデータセキュリティを最優先とする方針により、削除されたフォームおよび回答データはただちに完全削除され、復元できません。誤ってデータを削除しないよう、ワークスペースの役割別権限を設定してください。Enterprise プラン以上では、削除の時刻やアカウントなどのログ記録を確認できます。
  </Accordion>

  <Accordion title="フォームの開始／終了時刻を予約できますか？">
      はい、フォームを特定の時刻に自動で開始または締め切るよう予約できます。[予約機能](/ja/docs/help-center/manage-forms/scheduling-survey-start-end-times)を使えば、毎回手動で変更しなくても、決めたスケジュールどおりにフォームが開き、終了します。
  </Accordion>

</Accordions>

## プロジェクトを連携する

<Accordions>

  <Accordion title="回答が送信されたら通知を受け取れますか？">
    はい。「連携する」ページから Slack、Discord、Gmail などの通知を設定できます。また Webhook を自分で設定して、好きな外部プラットフォームで通知を受け取ることもできます。
  </Accordion>

  <Accordion title="回答者に回答の控えを送れますか？">
    回答者に回答の控えを送るには、Gmail の自動化をご利用ください。自動化設定で Gmail を選んだあと、宛先（To）の項目に回答者のメールアドレスを収集したフィールドをマッピングします。設定が完了すると、回答者がメールアドレスを含めてフォームに回答するたびに、そのメールアドレス宛に回答内容が自動送信されます。
  </Accordion>

  <Accordion title="Google スプレッドシートでリアルタイムに回答を確認できますか？">
    はい。Google スプレッドシート連携を行うと、現在ログインしている Google アカウントに新しいシートが作成されます。以後、そのアカウントで回答が収集されるたびに、作成されたシートへ新しい行が自動的に追加されます。
  </Accordion>

</Accordions>

## プロジェクトを共有する

<Accordions>

  <Accordion title="LINE などの SNS で共有した URL のサムネイル／タイトルが変わりません。">
    LINE などで URL を共有したあとにサムネイルやタイトルを変更して再度共有すると、以前のサムネイルやタイトルが表示されることがあります。これは、LINE などのアプリが読み込み時間を短縮するため、その端末で送信履歴のある URL などについてキャッシュを保存していることが原因です。これを減らしたい場合は[こちら](https://developers.kakao.com/tool/debugger/sharing)からキャッシュを初期化してください。送信履歴のない端末で URL を受け取った場合は、正しく変更後のサムネイル／タイトルで表示されます。
  </Accordion>

  <Accordion title="基本ビューはグループ別ビューと何が違いますか？">
    基本ビューは 1 ページに全設問が表示される方式で、グループ別ビューは 1 ページに 1 設問（1 フィールドグループ）ずつ表示される方式です。
  </Accordion>

  <Accordion title="プロジェクトの流入経路を記録できますか？">
    トラッキング（隠しフィールド）を設定したうえで、URL にパラメータを追加して回答者に共有してみてください。回答が収集されると、回答シートと統計画面で、各回答者がどの経路から流入したかを確認できます。
  </Accordion>
   <Accordion title="プロジェクトを共有するとき、自社ブランドのサムネイルと URL を使えますか？">
    プロジェクトを共有するとき、ブランドに合わせたサムネイルと URL を設定できます。「共有」ページでプレビュー画像とリンクを好みの形にカスタマイズして保存してください。設定が完了すると、共有時にそのサムネイルと URL が適用されます。
  </Accordion>
     <Accordion title="すでに回答者リストを持っているのですが、その対象者にフォームへの参加を依頼して送信状況を確認できますか？">
    はい、可能です。お持ちの回答者リストを CSV または XLSX ファイルでアップロードしてパネルとして登録すると、各プロジェクトでそのパネルを対象にフォームを送信できます。送信後は、パネルごとの回答状況もあわせて確認できます。
  </Accordion>

</Accordions>

## 回答結果を確認する
<Accordions>
  <Accordion title="アナリティクスをダウンロードできますか？">
    アナリティクスはダウンロードできず、各フォームの「アナリティクス」タブでのみ閲覧できます。
</Accordion>
  <Accordion title="削除された回答を復元できますか？">
    削除をリクエストした回答はただちに削除され、削除された回答は決して復元できませんのでご注意ください。「ログ記録」で、回答を削除したアカウントと IP の情報を確認できます。
</Accordion>
  <Accordion title="回答の customerKey にあらかじめ定義した値を入れられますか？">
    あらかじめ定義した customerKey の値を含む回答者リストを CSV または XLSX ファイルでアップロードしてパネルとして登録すると、各プロジェクトでそのパネルを対象にフォームを送信できます。この場合、回答シートの customerKey にはあらかじめ定義した値が入ります。
</Accordion>

</Accordions>

## リワードを送る

<Accordions>

  <Accordion title="リワードを送るにはどうすればよいですか？">
    まず、フォームに電話番号フィールド（推奨）を追加して回答者の電話番号を収集する必要があります。そのうえでリワードを購入し、送信対象者を選んでリワードを送信してください。詳しい方法は[ギフト券を送る](/ja/docs/help-center/reward/sending-gifticons)をご覧ください。
  </Accordion>
   <Accordion title="フォームで回答者の電話番号を収集していないのですが、リワードを送れますか？">
    申し訳ありませんが、回答者の電話番号を収集していない場合はリワードを送れません。リワードの送信には、フォームへの回答時に電話番号など送信に必要な情報を必ず収集してください。
  </Accordion>
     <Accordion title="Walla にないブランドのギフト券も送れますか？">
    はい、可能です。cs@walla.my までご希望のブランドや価格帯・数量をお知らせいただければ、検討のうえ Walla リワードショップで購入いただけるようお手伝いします。
  </Accordion>
       <Accordion title="自社ブランド独自のリワード（自社モールのポイントなど）をリワードとして提供できますか？">
    はい、可能です。ただしこの機能はカスタムプラン以上でのみ提供されます。詳細は cs@walla.my までお問い合わせください。
  </Accordion>

</Accordions>
