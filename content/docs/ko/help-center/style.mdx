## 표 (Table)

| 컴포넌트 | import 경로 | 설명 |
|---|---|---|
| Accordion | `fumadocs-ui/components/accordion` | 접고 펼치는 아코디언 |

| Tabs | `fumadocs-ui/components/tabs` | 탭 전환 |
| Files | `fumadocs-ui/components/files` | 파일 트리 |
| TypeTable | `fumadocs-ui/components/type-table` | API 타입 문서 |
