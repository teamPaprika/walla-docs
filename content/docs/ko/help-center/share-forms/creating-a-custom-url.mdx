## 커스텀 URL 만들기
- 공유 링크는 기본적으로 `walla.my/a/커스텀부분` 형태로 생성됩니다.
- 규칙에 맞게 URL을 입력해야 합니다.
- 설정 방법
  1. 공유하기 페이지 → 링크 커스터마이징으로 이동합니다.
  2. 원하는 커스텀 URL을 입력 후 저장합니다.
  3. 가로보기/세로보기 중 원하는 보기 방식을 먼저 선택한 뒤 저장하면, 해당 설정이 게시하기를 누르지 않아도 바로 반영됩니다.

- 커스텀 URL 규칙
  - 0자 이상 30자 이하로 입력 가능
  - 슬래시(`/`) 포함 불가
  - 마침표(`.`) 하나 또는 두 개(`..`)만으로 구성 불가
  - 정규 표현식 `__.*__` 과 일치하는 문자열은 사용할 수 없음

## 공유 미리보기 설정
- 커스텀 URL 아래에서 프로젝트 제목, 설명, 썸네일 이미지를 설정할 수 있습니다.
- 저장만 해도 즉시 반영되며, 별도의 게시 작업은 필요하지 않아요.
### ⚠️ 주의사항
제목이나 썸네일을 변경했는데도 카카오톡·슬랙 등 메신저에서 이전 이미지나 텍스트가 보인다면, 이는 테스트 과정에서 저장된 해당 메신저 앱 또는 브라우저의 캐시(이전 데이터 저장) 때문이에요. 그 링크를 처음 받는 사람에게는 정상적으로 변경된 미리보기가 표시되니 걱정하지 않아도 됩니다.
