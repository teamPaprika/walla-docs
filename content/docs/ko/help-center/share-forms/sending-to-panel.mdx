## 패널 발송 준비하기

설문을 발송하려면 먼저 워크스페이스의 **패널** 탭에 발송 대상자가 등록되어 있어야 해요. 패널 업로드 방법은 [패널 관리하기](/ko/docs/help-center/team-workspace/workspace-panel) 페이지를 참고하세요.

## 발송 방법

<Steps>
  <Step>
    ### 공유하기 페이지로 이동
    프로젝트 편집 화면 상단의 `공유하기` 탭으로 이동해 `설문 보내기` 영역으로 스크롤합니다.

    <img src="/images/guides/share-forms/sending-to-panel-share-page.png" alt="공유하기 탭의 설문 보내기 영역" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 등록된 패널이 없는 경우 - `데이터 업로드` 클릭
    사전에 등록한 패널이 없거나, 패널 이외의 인원에게 프로젝트를 발송하고 싶다면, `데이터 업로드` 버튼을 클릭해주세요. 오류가 있거나 부적합한 행은 제외하고 업로드됩니다.

    <img src="/images/guides/share-forms/sending-to-panel-upload.png" alt="설문 보내기 영역의 데이터 업로드 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/share-forms/sending-to-panel-upload-popup.png" alt="고객 업로드 팝업에서 파일 미리보기 후 업로드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 등록된 패널이 있는 경우 - `패널에서 가져오기` 클릭
    이미 등록한 패널이 있는 경우, `패널에서 가져오기`를 클릭합니다.

    <img src="/images/guides/share-forms/sending-to-panel-from-panel.png" alt="설문 보내기 영역의 패널에서 가져오기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/share-forms/sending-to-panel-from-panel-popup.png" alt="패널에서 가져오기 팝업에서 발송 대상 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 발송 내용 작성
    설문 보내기 버튼을 클릭한 후, 발송 계정 및 함께 발송된 문구를 입력합니다.

    <img src="/images/guides/share-forms/sending-to-panel-send-button.png" alt="설문 보내기 영역의 설문 보내기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/share-forms/sending-to-panel-compose.png" alt="설문 보내기 팝업의 발신자·제목·메시지 입력" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 발송하기
    발송이 완료되면 각 행의 `상태`, `전송횟수`, `마지막 전송시간` 컬럼에서 발송 결과를 확인할 수 있어요.

    <img src="/images/guides/share-forms/sending-to-panel-status.png" alt="설문 보내기 영역의 발송 상태·전송횟수·마지막 전송시간 컬럼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    각 패널에게는 서로 다른 개별 링크가 생성되고, 응답 시트에도 패널에 등록된 CUSTOMER Key로 기록됩니다.

    <img src="/images/guides/share-forms/sending-to-panel-individual-link.png" alt="패널별로 생성된 개별 설문 링크와 고객 ID" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 수신 이메일 예시
    '설문 보내기'를 통해 발송된 설문은 아래와 같이 전달됩니다.

    <img src="/images/guides/share-forms/sending-to-panel-email-preview.png" alt="패널에게 발송된 설문 이메일 예시" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
