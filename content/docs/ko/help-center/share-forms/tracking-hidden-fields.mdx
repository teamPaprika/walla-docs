## 트래킹 항목(히든 필드) 추가하기

1. 공유하기 페이지 → `관리` 버튼 클릭 → 를 클릭합니다.
2. 트래킹 이름(히든 필드명)을 입력한 뒤 엔터 키를 눌러 등록해야 항목이 생성됩니다.
3. `저장` 버튼을 눌러 저장합니다.
4. 등록된 히든 필드는 “유입 경로를 구분하기 위한 카테고리” 역할을 합니다.
- 예시
  - ① SNS별 유입 확인 → 히든 필드 이름을 `SNS` 로 설정 (예: 인스타그램, 유튜브 등)
  - ② 고객 그룹별 구분→ 히든 필드 이름을 `customer` 로 설정
## 히든 필드 URL 만들기

- 히든 필드를 설정했다면, 설문 링크(URL)에 해당 필드를 직접 추가해야 해요.
1. 기본 설문 URL 준비
```
https://walla.my/v/QA9S0i0UfZn5rZTfSbd4
```

2. 히든 필드 이름 추가 (`?필드명=` 형식)
```
https://walla.my/v/QA9S0i0UfZn5rZTfSbd4?source=
```

3. 필드 값 입력 (예: 유튜브에서 유입된 경우)
```
https://walla.my/v/QA9S0i0UfZn5rZTfSbd4?source=youtube
```

4. 이제 각 링크를 채널별로 공유하면, 응답 시트에서 유입 경로(예: YouTube, Instagram 등)를 확인할 수 있습니다.
## 여러 히든 필드 사용하기

- URL에 여러 히든 필드를 추가하려면 ‘?’ 대신 ‘&’로 이어붙이면 돼요.
```
https://walla.my/v/QA9S0i0UfZn5rZTfSbd4?source=instagram&media=video
```
→ 인스타그램 비디오 광고를 통한 유입이라는 의미예요.
<Callout type="warning" title="주의사항">
- 트래킹 항목 등록 시 엔터를 눌러야 저장됩니다.
- 히든 필드 이름은 영문, 숫자, 밑줄(_)로만 구성하는 걸 추천드려요.
</Callout>
