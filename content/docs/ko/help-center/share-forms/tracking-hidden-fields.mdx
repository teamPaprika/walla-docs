## 트래킹 항목(히든 필드) 추가하기

<Steps>
  <Step>
    ### 트래킹 관리 페이지 열기
    공유하기 페이지에서 `관리` 버튼을 클릭합니다.

    <img src="/images/guides/share-forms/tracking-01-manage.png" alt="트래킹 관리 페이지 열기" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 트래킹 항목 입력
    트래킹 이름(히든 필드명)을 입력한 뒤 엔터 키를 눌러 등록해야 항목이 생성됩니다.

    <img src="/images/guides/share-forms/tracking-02-input.png" alt="트래킹 항목 입력" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 저장
    `저장` 버튼을 눌러 저장합니다.

    <img src="/images/guides/share-forms/tracking-03-save.png" alt="저장" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 활용
    등록된 히든 필드는 “유입 경로를 구분하기 위한 카테고리” 역할을 합니다.
    - ① SNS별 유입 확인 → 히든 필드 이름을 `SNS` 로 설정 (예: 인스타그램, 유튜브 등)
    - ② 고객 그룹별 구분 → 히든 필드 이름을 `customer` 로 설정

    <img src="/images/guides/share-forms/tracking-04-fields.png" alt="등록된 히든 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
## 히든 필드 URL 만들기

히든 필드를 설정했다면, 설문 링크(URL)에 해당 필드를 직접 추가해야 해요.

<Steps>
  <Step>
    ### 기본 설문 URL 준비
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4
    ```
  </Step>
  <Step>
    ### 히든 필드 이름 추가
    `?필드명=` 형식으로 추가합니다.
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=
    ```
  </Step>
  <Step>
    ### 필드 값 입력
    예: 유튜브에서 유입된 경우
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=youtube
    ```
  </Step>
  <Step>
    ### 채널별 링크 공유
    각 링크를 채널별로 공유하면, 응답 시트에서 유입 경로(예: YouTube, Instagram 등)를 확인할 수 있습니다.
  </Step>
</Steps>
## 여러 히든 필드 사용하기

- URL에 여러 히든 필드를 추가하려면 ‘?’ 대신 ‘&’로 이어붙이면 돼요.
```
https://walla.my/v/QA9S0imWeo232fSbd4?source=instagram&media=video
```
→ 인스타그램 비디오 광고를 통한 유입이라는 의미예요.
<Callout type="warning" title="주의사항">
- 트래킹 항목 등록 시 엔터를 눌러야 저장됩니다.
- 히든 필드 이름은 영문, 숫자, 밑줄(_)로만 구성하는 걸 추천드려요.
</Callout>
<Callout title="팁">
대량의 히든 필드 URL을 만들어야 한다면, [히든필드 링크 생성기 구글시트 템플릿](https://docs.google.com/spreadsheets/d/14F7iSY6yNiEV78eceveOkPNCTHzaMK5LIEqtYE4bo_I/edit?usp=sharing)을 복제해 사용하면 편리합니다.
</Callout>

## 히든 필드로 로직 조건 만들기

히든 필드 값에 따라 응답자를 다른 문항으로 보낼 수 있어요. 아래는 광고 링크로 들어온 응답자를 따로 보내는 예시예요.

<Steps>
  <Step>
    ### 히든 필드 등록
    트래킹 관리 페이지에서 히든 필드 `utm_source`를 등록하고 `저장`을 눌러요.
  </Step>
  <Step>
    ### 링크 만들기
    광고에 쓸 링크 끝에 값을 붙여요.
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads
    ```
  </Step>
  <Step>
    ### 로직 조건 만들기
    로직 화면에서 기준 문항으로 `utm_source`를 고르고, 조건은 `같음`, 비교값은 `ads`로 정해요.
  </Step>
  <Step>
    ### 이동할 문항 고르기
    광고로 들어온 응답자가 이동할 문항을 골라요.
  </Step>
</Steps>

- 히든 필드 값은 글자로 비교해요. 링크에 값이 없으면 해당 히든 필드의 비교 조건은 `같지 않음`을 포함해 어느 것도 성립하지 않아요.
- 발행 전에는 프로젝트 편집 화면의 미리보기로 확인할 수 있어요. 미리보기는 편집 화면 주소에 붙은 값을 그대로 가져가요. 브라우저 주소창에서 편집 화면 주소 끝에 `?utm_source=ads`를 붙인 뒤 미리보기를 여세요. 주소에 이미 `?`가 있으면 `&utm_source=ads`를 붙여요.
- 발행한 뒤에는 값을 붙인 링크와 값이 없는 링크를 각각 열어 두 경로를 모두 확인해 보세요.
- 자세한 방법은 [로직 설정하기의 히든 필드로 조건 만들기](/ko/docs/help-center/create-forms/setting-up-logic#히든-필드로-조건-만들기)를 참고하세요.

## 로직에 쓰인 히든 필드 삭제하기

로직 조건에 쓰인 히든 필드는 삭제할 수 없어요. 편집 중인 로직뿐 아니라 이미 발행된 설문의 로직에 쓰여 있어도 마찬가지예요.
이런 히든 필드를 삭제하고 저장하면 `로직 조건에서 사용 중인 히든필드는 삭제할 수 없습니다. 해당 조건을 먼저 변경하세요.` 안내가 보여요. 아래 순서대로 조건을 먼저 정리한 뒤 삭제하세요.

<Steps>
  <Step>
    ### 조건 바꾸기
    로직 화면에서 그 히든 필드를 쓰는 조건을 찾아 지우거나, 다른 기준 문항으로 바꿔요.
  </Step>
  <Step>
    ### 다시 발행하기
    발행된 설문에도 그 조건이 있었다면 바꾼 로직으로 설문을 다시 발행해요.
  </Step>
  <Step>
    ### 히든 필드 삭제
    트래킹 관리 페이지에서 히든 필드를 삭제하고 `저장`을 눌러요.
  </Step>
</Steps>
