## 비밀 정보 입력 필드

<img src="/images/guides/manage-forms/secrets-field-example.png" alt="인증 코드 입력란과 동일한 값을 한 번 더 입력받는 확인란이 표시된 비밀 정보 입력 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

응답 내용이 화면에 그대로 표시되지 않으며, 보안 강화를 위한 다양한 설정을 함께 사용할 수 있습니다.

## 언제 사용하면 좋을까요?

다음과 같은 경우에 비밀 정보 입력 필드를 사용하시는 것을 권장드립니다.

- 비밀번호 또는 PIN 번호 입력
- 인증 코드, 접근 키 입력
- 내부 설문에서 제한된 사용자 확인
- 외부에 노출되면 안 되는 민감 정보 수집

## 입력 방식 및 보안 기능

- 입력값 마스킹
  - 응답자가 입력한 내용은 ●●● 형태로 표시됩니다.
  - 응답 화면에서 실제 값이 노출되지 않습니다.

- 데이터 마스킹
  - 수집된 응답 데이터에서도 값이 마스킹되어 표시됩니다.
  - 관리자 화면 및 결과 공유 시 보안이 유지됩니다.

- 우측 하단의 ‘…(더보기)’ 버튼을 클릭하면 아래 기능을 사용할 수 있어요.
  - 붙여넣기 허용
    - 복사·붙여넣기를 허용하거나 제한할 수 있습니다.
    - 직접 입력을 유도해야 하는 경우 비활성화를 권장드립니다.

  - 확인 입력 요구
    - 동일한 값을 한 번 더 입력하도록 설정할 수 있습니다.

- 설정 가능한 옵션
  - 필수 입력
  - 응답 길이 제한
  - 응답 포함 / 응답 불포함
  - 정규표현식(Regex)
  - 데이터 마스킹 (기본 설정)
  - 응답 자동 삭제

<Callout type="warning" title="주의사항">
- 비밀 정보 입력 필드는 불필요한 개인정보 수집을 지양하는 용도로 사용해 주세요.
- 법적·정책적 요구사항에 따라 개인정보 처리 안내를 함께 제공하시는 것을 권장드립니다.
</Callout>
