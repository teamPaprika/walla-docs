## 필드 추가하기

### 좌측 필드 목록의 '+' 아이콘 클릭
원하는 필드를 선택하면 추가됩니다. 특정 필드를 선택한 상태에서 추가하면 그 필드 아래에 자동 추가돼요.

<img src="/images/guides/manage-forms/add-field-plus-icon.png" alt="좌측 설문 필드 목록 상단의 + 아이콘 클릭 시 표시되는 필드 추가 패널" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### 편집 화면 중간에서 추가
필드와 필드 사이에 커서를 올리면 `추가하기` 버튼이 나타납니다.
클릭하면 해당 위치에 새로운 필드를 추가할 수 있어요.

<img src="/images/guides/manage-forms/add-field-between.png" alt="편집 화면에서 필드 사이에 커서를 올리면 나타나는 추가하기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### 필드 그룹 안에서 추가
필드 그룹 하단에 커서를 올리면 `추가하기` 버튼이 생깁니다. 클릭하면 그룹 내부에 문항을 추가할 수 있어요.

<img src="/images/guides/manage-forms/add-field-group.png" alt="필드 그룹 하단에 커서를 올리면 나타나는 추가하기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## 필드 삭제 또는 복제하기

<Steps>
  <Step>
    ### 더보기 아이콘 확인
    좌측 필드 목록에서 필드 위로 마우스를 올리면 필드 오른쪽에 `...`(더보기) 아이콘이 나타납니다.

    <img src="/images/guides/manage-forms/field-more-icon.png" alt="좌측 필드 목록의 필드 오른쪽에 표시되는 더보기 아이콘" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 삭제 또는 복제 선택
    아이콘을 클릭하면 '삭제' 또는 '복제'를 선택할 수 있어요.

    <img src="/images/guides/manage-forms/field-more-menu.png" alt="더보기 아이콘 클릭 시 표시되는 필드 복제·문항 템플릿으로 저장·필드 삭제 메뉴" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout type="warning" title="주의사항">
필드를 삭제하면 해당 필드의 응답 데이터도 함께 삭제됩니다. 삭제 전 꼭 필요한 데이터는 미리 백업해두세요.
</Callout>
