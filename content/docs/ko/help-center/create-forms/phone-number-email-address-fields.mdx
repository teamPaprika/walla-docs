## 전화번호 필드

<img src="/images/guides/manage-forms/phone-number-field-example.png" alt="국가 선택 드롭다운과 010-2000-0000 자리표시자가 표시된 전화번호 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 사용자가 전화번호를 입력할 수 있습니다.
- 국기 아이콘을 눌러 다른 국가의 전화번호 형식으로 변경할 수 있어요.
- [텍스트 편집기](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0)를 통해 글자 색상, 크기, 굵기 등 다양한 스타일을 적용할 수 있어요.
- [슬래시(/) 명령](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)으로 이미지, 표, 제목 글자 등을 쉽게 삽입할 수도 있습니다.
- 기본값은 한국 휴대전화 형식(010-0000-0000)입니다.
- 설정 가능 옵션
  - 필수 입력
  - 응답 길이 제한
  - 응답 포함 / 불포함
  - 정규표현식(Regex)
  - 전화번호 인증 필수
  - 데이터 마스킹
  - 응답 자동 삭제

### 전화번호 인증 필수

- '전화번호 인증 필수' 옵션을 활성화하면 실제로 존재하는 전화번호만 수집 가능합니다.
- 응답자는 제출 전에 SMS 코드로 전화번호를 인증해야 합니다.
- 인증을 위해 전화번호가 문자 발송 업체(Twilio Inc., 미국)에 전달됩니다.

## 이메일 필드

<img src="/images/guides/manage-forms/email-field-example.png" alt="example@email.com 자리표시자가 표시된 이메일 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 사용자가 이메일 주소를 입력할 수 있습니다.
- 반드시 `~~~@~~~.~~~` 형식으로 입력해야 하며, 형식이 맞지 않으면 제출이 불가능합니다.
- [텍스트 편집기](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0)를 통해 글자 색상, 크기, 굵기 등 다양한 스타일을 적용할 수 있어요.
- [슬래시(/) 명령](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)으로 이미지, 표, 제목 글자 등을 쉽게 삽입할 수도 있습니다.
- 연필 아이콘을 눌러 입력 대기 문구를 수정할 수 있습니다.
- 설정 가능 옵션
  - 필수 입력
  - 응답 길이 제한
  - 응답 포함 / 불포함
  - 정규표현식(Regex)
  - 이메일 인증
  - 데이터 마스킹
  - 응답 자동 삭제

### 이메일 인증

`이메일 인증` 옵션을 켜면, 응답자는 입력한 이메일 주소로 받은 6자리 인증번호를 확인한 뒤 해당 주소를 응답으로 제출할 수 있습니다. 이메일 형식 검사에 더해, 응답자가 해당 메일함을 사용할 수 있는지 확인할 때 활용하세요.

<Steps>
  <Step>
    #### 이메일 인증 켜기

    설문 편집 화면에서 이메일 필드를 선택한 뒤, 오른쪽 설정 패널의 `이메일 인증`을 켭니다. 변경한 설정을 응답자에게 적용하려면 설문을 게시해 주세요.

    <img src="/images/guides/create-forms/email-verification-enable.png" alt="이메일 필드 설정 패널에서 이메일 인증 옵션 켜기" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### 이메일 입력 후 인증하기

    응답자는 이메일 주소를 입력한 뒤 입력란 옆의 `인증하기`를 클릭합니다.

    <img src="/images/guides/create-forms/email-verification-start.png" alt="이메일 주소를 입력한 뒤 인증하기 버튼 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### 인증번호 발송

    이메일 인증 창에서 주소를 확인하고 `인증번호 발송`을 클릭합니다. 입력한 이메일 주소로 6자리 인증번호가 발송됩니다.

    <img src="/images/guides/create-forms/email-verification-send-code.png" alt="이메일 인증 창에서 인증번호 발송 버튼 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### 인증번호 입력 및 완료 확인

    이메일로 받은 6자리 인증번호를 입력하고 `인증하기`를 클릭합니다. 인증에 성공하면 이메일 필드 아래에 `인증 완료`가 표시됩니다.

    <img src="/images/guides/create-forms/email-verification-enter-code.png" alt="이메일로 받은 6자리 인증번호 입력" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/create-forms/email-verification-complete.png" alt="이메일 필드 아래에 인증 완료가 표시된 응답 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

- **이메일 주소를 변경한 경우**: 변경한 주소로 다시 인증해야 합니다.
- **인증번호가 올바르지 않거나 만료된 경우**: 주소와 입력한 번호를 확인하세요. 재발송 대기 시간이 지난 뒤 `재발송`을 눌러 새 인증번호를 받을 수 있습니다.
- **필수 입력과 함께 설정하기**: 이메일 주소를 반드시 수집하려면 `필수 입력` 옵션도 함께 켜 주세요. 이메일 인증만 켠 선택 문항은 빈칸으로 제출할 수 있습니다.

<Callout type="info" title="게시된 설문에서 확인해 주세요">
미리보기에서는 인증 메일을 발송하지 않습니다. 실제 인증 과정을 확인하려면 게시된 설문을 열어 주세요. 이 기능은 이메일 필드에 입력한 주소를 확인하는 설정이며, 설문 접근 권한의 이메일 인증과는 별개입니다.
</Callout>
