## 탈락 필드의 특징

- 탈락 필드가 노출되면 응답은 저장되지 않습니다.
- 설문에서 응답 수집 제외 대상을 구분할 때 유용해요.
  - 예: 응답 대상자가 아닌 경우, 응답 기한이 지난 경우 등

## 배치 방법

- 항상 설문 맨 마지막에 두는 것을 권장합니다.
  - 세로보기의 경우 한 페이지에 모든 문항이 보이기 때문에 탈락 필드가 중간에 있으면 페이지가 열리자마자 바로 탈락될 수 있어요.
  - 가로보기에서도 맨 처음에 두면 설문을 시작하자마자 탈락될 수 있습니다.
- 탈락 필드 앞에는 `페이지 나누기`를 추가하는 게 좋아요.

## 활용 예시

#### 예시 1. 연령으로 응답 대상 판별하기
  - **조건**: `연령 판별 문항` `같지 않음` `10대`
  - **이동**: `탈락 필드`
  - **결과**: 응답자가 10대가 아닌 경우 설문이 즉시 종료됩니다.
#### 예시 2. 설문 마감 안내로 사용하기
  - 설문이 마감된 경우 기본 마감 페이지 대신 직접 안내하고 싶다면, 탈락 필드를 맨 첫 문항으로 이동시켜주세요.
  - **예**: "이 설문은 마감되었습니다."

<Callout type="warning" title="주의사항">
- 탈락 필드와 엔딩 필드를 혼동하지 마세요.
  - **엔딩 필드**: 응답 제출 "후" 안내 페이지 또는 URL로 이동
  - **탈락 필드**: 응답 "도중에" 설문 종료, 기록 수집 안 됨
- 탈락된 응답은 절대 확인하거나 복구할 수 없으니, 조건을 설정할 때 신중히 검토해주세요.
</Callout>
