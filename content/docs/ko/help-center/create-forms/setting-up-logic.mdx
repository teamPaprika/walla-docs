## 로직의 개념

- 로직은 "응답에 따라 다음 문항이 어디로 이어질지"를 정합니다.
- 기본 이동은 모든 응답자가 반드시 지나게 되는 흐름을 의미합니다. ('필수 응답'과는 다른 개념이에요.)

## 로직 추가하기

<Steps>
  <Step>
    ### 로직 설정 화면으로 이동
    프로젝트 편집 화면에서 `로직` 버튼을 눌러 로직 설정 화면으로 이동할 수 있습니다.

    <img src="/images/guides/create-forms/logic-button.png" alt="프로젝트 편집 화면 우측 상단의 로직 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 조건과 이동하기 구성 이해
    로직은 '조건'과 '이동하기' 두 부분으로 구성돼요.

    <img src="/images/guides/create-forms/logic-condition-action.png" alt="로직의 조건 영역과 이동하기 영역" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 조건
    1. **기준 문항 선택** – 어떤 문항의 응답을 기준으로 삼을지 선택합니다.
       - 객관식 표·표·순위 선택·커스텀 필드 문항은 비교할 칸을 `하위 항목`에서 한 번 더 골라요. 자세한 방법은 [세부 응답으로 조건 만들기](#세부-응답으로-조건-만들기)를 참고하세요.
       - 링크로 받은 히든 필드 값도 기준으로 쓸 수 있어요. 자세한 방법은 [히든 필드로 조건 만들기](#히든-필드로-조건-만들기)를 참고하세요.
    2. **조건 선택** – 조건의 종류를 선택합니다. 조건은 크게 텍스트/값·선택지·숫자·날짜 비교로 나뉘며, 자세한 종류는 아래 [조건 종류 자세히 알아보기](#조건-종류-자세히-알아보기)를 참고하세요.
    3. **옵션/응답 선택** – 해당 조건이 어떤 응답에서 작동할지 선택합니다.
       - 여러 응답을 동시에 선택할 수도 있어요.

    <img src="/images/guides/create-forms/logic-condition.png" alt="로직의 조건 영역 - 기준 문항, 조건, 옵션 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 조건 여러개 추가하기
    - `+ 새로운 조건 추가`를 눌러 여러 조건을 조합할 수 있습니다.
    - 조건을 결합할 때는 아래 두 가지 중 하나를 선택하세요.
      - **AND**: 앞 조건과 뒤 조건을 모두 만족해야 로직이 작동
      - **OR**: 앞 조건 또는 뒤 조건 중 하나만 만족해도 로직이 작동

    <img src="/images/guides/create-forms/logic-condition-multiple.png" alt="새로운 조건 추가와 AND/OR 결합 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 이동하기
    - 조건을 모두 설정했다면, 응답자가 이동할 필드를 선택합니다.
    - 설정이 완료되면 해당 조건을 만족한 응답자는 지정한 문항으로 바로 이동합니다.

    <img src="/images/guides/create-forms/logic-action.png" alt="로직의 이동하기 영역에서 이동할 필드 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## 조건 종류 자세히 알아보기

### 텍스트/값 비교

| 조건     | 의미             | 예시               | 예시 답변             |
| ------ | -------------- | ---------------- | ----------------- |
| 같음     | 값이 정확히 같음      | 답이 `서울`과 일치하면    | 서울                |
| 같지 않음  | 값이 같지 않음       | 답이 `서울`이 아니면     | 인천                |
| 시작이 일치 | 특정 값으로 시작함     | 답이 `010`으로 시작하면  | 010-1234-5678     |
| 끝이 일치  | 특정 값으로 끝남      | 답이 `.com`으로 끝나면  | example<span>@</span>walla.com |
| 문자 포함  | 특정 글자를 포함함     | 답에 `주식회사`가 들어있으면 | 주식회사 파프리카데이터랩     |
| 문자 미포함 | 특정 글자를 포함하지 않음 | 답에 `사과`가 안 들어있으면 | 포도 주스             |

### 선택지 비교
객관식·다중선택처럼 여러 항목을 고를 수 있는 문항에서 어떤 보기를 골랐는지 따질 때 사용합니다.

| 조건       | 의미                    | 예시                      |
| -------- | --------------------- | ----------------------- |
| 모두 포함    | 지정한 항목을 전부 선택함        | `A`, `B`를 모두 골랐으면       |
| 하나 이상 포함 | 지정한 항목 중 하나 이상 선택함    | `A` 또는 `B` 중 하나라도 골랐으면  |
| 모두 누락    | 지정한 항목 중 아무것도 선택하지 않음 | `A`, `B` 둘 다 안 골랐으면     |
| 하나 이상 누락 | 지정한 항목을 하나 이상 선택하지 않음 | `A`, `B` 중 적어도 하나가 누락이면 |


### 숫자 비교

| 조건    | 의미           | 예시                       |
| ----- | ------------ | ------------------------ |
| 보다 큼  | 기준값보다 큼(초과)  | 나이가 `19`보다 크면            |
| 이상    | 기준값보다 크거나 같음 | 나이가 `19`와 같거나 `19`보다 크면  |
| 보다 작음 | 기준값보다 작음(미만) | 점수가 `60`보다 작으면           |
| 이하    | 기준값보다 작거나 같음 | 점수가 `60`과 같거나 `60`보다 작으면 |

### 날짜 비교

| 조건       | 의미                      | 예시                    |
| -------- | ----------------------- | --------------------- |
| 이전       | 기준 날짜보다 이전(해당 날짜 제외)    | `2026-01-01` 이전이면     |
| 이전 또는 같음 | 기준 날짜이거나 그 이전(해당 날짜 포함) | `2026-01-01` 또는 그 전이면 |
| 이후       | 기준 날짜보다 이후(해당 날짜 제외)    | `2026-01-01` 이후면      |
| 이후 또는 같음 | 기준 날짜이거나 그 이후(해당 날짜 포함) | `2026-01-01` 또는 그 후면  |

## 세부 응답으로 조건 만들기

객관식 표나 표처럼 응답 하나에 여러 칸이 있는 문항은, 기준 문항을 고른 뒤 비교할 칸을 한 단계 더 골라요.

<Steps>
  <Step>
    ### 기준 문항 고르기
    기준 문항을 고르면, 세부 칸이 있는 문항에서는 바로 아래에 `하위 항목` 선택칸이 나타나요.
  </Step>
  <Step>
    ### 하위 항목 고르기
    `하위 항목`에서 비교할 행, 열 또는 속성을 골라요. 선택칸이 하나 더 나타나면 마지막 칸까지 이어서 고르면 돼요.
  </Step>
  <Step>
    ### 조건과 비교값 정하기
    조건 종류를 고르고 비교값을 넣어요. 비교값 입력칸은 마지막에 고른 칸에 맞춰 바뀌어요. 예를 들어 표에서 칸을 골랐다면 글자를 입력하고, 객관식 표에서 행을 골랐다면 그 행의 보기를 골라요.
  </Step>
</Steps>

### 문항별로 고르는 순서

| 문항            | 고르는 순서              | 비교값                    |
| ------------- | ------------------- | ---------------------- |
| 객관식 표         | 행                   | 그 행에서 고른 보기 1개         |
| 객관식 표 (다중선택)  | 행                   | 그 행에서 고른 보기(여러 개 가능)   |
| 순위 선택         | 순위 칸                | 그 순위에 놓인 보기 1개         |
| 표             | 행 → 열               | 그 칸에 입력된 글자            |
| 커스텀 필드        | 속성 → 필요하면 몇 번째 항목   | 그 속성의 형식에 맞는 값         |

- 객관식 표, 객관식 표 (다중선택), 순위 선택은 행(순위 선택은 순위 칸)을 고르면 바로 비교값을 정할 수 있어요.
- 순위 선택 문항에서 응답자가 보기를 직접 입력할 수 있다면, 비교값에서 `옵션 선택`과 `커스텀` 중 하나를 골라요. 목록에 없는 값과 비교하려면 `커스텀`을 고르고 값을 입력한 뒤 Enter를 누르세요.
- 하위 항목에 `조건에 사용할 수 없는 응답입니다`가 보이면 그 칸은 조건에 쓸 수 없으니 다른 하위 항목을 골라 주세요.

### 커스텀 필드의 하위 항목

- 속성이 정해져 있으면 `하위 항목` 목록에서 골라요.
- `속성 선택`과 `키 직접 입력` 버튼이 보이는 속성은 키를 직접 넣을 수 있어요. 목록에 없는 키라면 `키 직접 입력`을 누르고 입력하세요.
- 응답이 목록 형태이면 `몇 번째 항목` 칸이 나타나요. 첫 번째 항목은 1, 두 번째 항목은 2를 입력해요. 응답 전체가 목록인 커스텀 필드는 처음에 나오는 `몇 번째 항목`을 꼭 입력해야 해요.
- `몇 번째 항목 (선택)` 칸은 비워 두면 목록 전체를 비교하고, 숫자를 넣으면 그 항목 하나만 비교해요.

### 비교값 넣기

비교값은 마지막에 고른 칸에 맞는 선택칸이나 입력칸에서 고르거나 입력해요.

- **보기가 있는 값** – 목록에서 보기를 골라요. 칸에 따라 여러 개를 고를 수도 있어요.
- **목록 값 직접 입력** – 값을 하나 입력하고 Enter를 누르면 작은 칩으로 추가돼요. 다음 값도 같은 방법으로 추가해요.
- **숫자** – 입력칸이 비어 있는 상태로 시작하니 비교할 숫자를 입력하세요. 0과 비교할 때도 `0`을 입력해요.
- **참/거짓** – 비교할 값으로 `참` 또는 `거짓`을 직접 골라 주세요. 목록 칸에서는 `true` 또는 `false`를 입력하고 Enter를 눌러요.

### 입력을 끝내지 않은 조건

조건 아래에 `항목과 비교값을 확인하고 입력을 완료하세요.`가 보이면 아직 입력이 끝나지 않은 거예요. 아래를 확인해 마무리하세요.

- 입력칸에 글자가 남아 있으면 Enter를 눌러 칩으로 추가해요.
- 값이 형식에 맞지 않으면 글자가 입력칸에 그대로 남고 `자료형에 맞는 값을 입력하세요.`가 보여요. 값을 고친 뒤 다시 Enter를 누르세요.
- `몇 번째 항목`이 비어 있거나 범위를 벗어났다는 안내가 보이면 안내에 맞게 숫자를 고쳐요.

이 상태로는 설문을 발행할 수 없어요. 발행을 누르면 `조건의 미완성 입력이나 오류를 먼저 해결하세요.` 안내가 보여요.

### 문항을 바꾼 뒤 조건이 깨졌을 때

문항에서 행, 열, 보기를 지우거나 바꾸면 조건에 `찾을 수 없는 항목` 또는 `더 이상 선택지에 없는 값입니다.`가 보일 수 있어요. 이때는 다른 하위 항목이나 값을 다시 골라 주세요.

이런 조건이 저장된 채로 남아 있으면 설문을 발행할 수 없어요. 발행을 누르면 `응답값 조건이 올바르지 않습니다. 문항, 하위 항목, 비교값을 확인하세요.` 안내가 보여요.

## 히든 필드로 조건 만들기

링크에 붙여 보낸 히든 필드 값에 따라 응답자를 다른 문항으로 보낼 수 있어요. 예를 들어 광고 링크로 들어온 응답자만 광고 관련 문항으로 보낼 수 있어요.
먼저 공유하기 페이지의 트래킹에서 히든 필드를 등록해 두세요. 등록 방법은 [트래킹 (히든필드)](/ko/docs/help-center/share-forms/tracking-hidden-fields)를 참고하세요.

<Steps>
  <Step>
    ### 히든 필드 고르기
    기준 문항 목록에서 히든 필드 이름을 골라요.
  </Step>
  <Step>
    ### 조건과 값 넣기
    [텍스트/값 비교](#텍스트값-비교) 조건 중 하나를 고르고, 비교할 값을 글자로 입력해요.
  </Step>
  <Step>
    ### 이동할 문항 고르기
    히든 필드 값이 조건에 맞을 때 보여 줄 다음 문항을 골라요.
  </Step>
</Steps>

- 예: 히든 필드 `utm_source`, `같음`, `ads`로 조건을 만들면, `https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads` 링크로 들어온 응답자만 지정한 문항으로 이동해요.
- 값이 없는 히든 필드는 `같지 않음`을 포함해 어떤 비교 조건도 만족하지 않아요.
- 로직 조건에 쓰인 히든 필드는 삭제할 수 없어요. 삭제하는 순서는 [로직에 쓰인 히든 필드 삭제하기](/ko/docs/help-center/share-forms/tracking-hidden-fields#로직에-쓰인-히든-필드-삭제하기)를 참고하세요.

## 노드 활용하여 로직 설정하기

<Steps>
  <Step>
    ### 노드와 연결선 살펴보기
    로직 화면에서는 각 문항이 노드로 표시되고, 노드 사이의 연결선으로 이동 흐름을 확인할 수 있습니다. `기본 이동`은 모든 응답자가 지나는 기본 흐름을, `로직 #1`, `로직 #2`처럼 번호가 붙은 분기는 조건에 따라 갈라지는 경로를 나타냅니다.

    <img src="/images/guides/create-forms/logic-node-overview.png" alt="로직 노드 화면에서 기본 이동과 로직 #1, #2, #3 분기 연결선이 강조된 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 기본 이동 설정하기
    노드 위의 `기본 이동` 라벨을 누르면 `다음 필드`를 선택하는 드롭다운이 열립니다. 필드를 검색하거나 목록에서 골라, 조건에 해당하지 않는 응답자가 이동할 기본 문항을 지정할 수 있습니다.

    <img src="/images/guides/create-forms/logic-node-default-move.png" alt="기본 이동 노드를 눌러 다음 필드를 선택하는 드롭다운과 필드 검색 목록" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 로직 노드에서 조건 편집하기
    `로직 #1`, `로직 #2`처럼 번호가 붙은 분기 라벨을 누르면 조건 영역이 바로 펼쳐집니다. 기준 문항과 포함 조건, 옵션을 노드 위에서 직접 수정하거나 `새로운 조건`을 추가할 수 있습니다.

    <img src="/images/guides/create-forms/logic-node-condition.png" alt="로직 #3 노드를 눌러 펼쳐진 조건 영역에서 기준 문항과 옵션을 편집하는 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 연결선을 눌러 바로 수정하기
    필드를 선택한 뒤 노드 위의 `로직`이나 `기본 이동` 라벨을 누르지 않고, 노드 사이의 연결선만 바로 눌러도 해당 흐름을 수정할 수 있습니다.

    <img src="/images/guides/create-forms/logic-node-line-edit.png" alt="노드 사이의 연결선을 눌러 로직 #1 라벨이 강조되며 흐름을 바로 수정하는 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 노드를 드래그해 연결하기
    노드 하단의 연결점을 끌어 다른 문항 노드에 놓으면 두 문항을 직접 이어 이동 흐름을 만들 수 있습니다. 연결선을 새로 그리면 응답자가 해당 경로로 이동합니다.

    <img src="/images/guides/create-forms/logic-node-connect.png" alt="노드의 연결점을 드래그해 다른 문항 노드로 연결선을 그리는 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## 로직 활용 예시

- #### 예시 1. 개인정보 동의에 따른 분기
  - 조건: `개인정보 수집 필드` = "동의합니다"
  - 이동하기: `개인정보 수집 관련 문항(전화번호 필드 등)` 이후의 문항
- #### 예시 2. 연령에 따른 탈락 처리
  - 조건: `연령 문항(객관식/드롭다운 필드)`, 같지 않음, "10대"
  - 이동하기: `탈락 필드`
- #### 예시 3. 키워드 포함 시 특정 문항으로 이동
  - 조건: `단답형/장문형 필드`, 문자 포함, "사과"
  - 이동하기: `사과주스 판매 결제 필드`

## 기타 설정 및 주의사항

- 로직이 중간에서 끊어지면, **탈락 필드가 중간에 있거나 앞선 문항의 로직이 잘못 설정된 경우**일 가능성이 높아요.

  <img src="/images/guides/create-forms/logic-broken-conflict.png" alt="로직이 찾을 수 없는 옵션으로 이동하도록 설정되어 충돌한 경우" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 필드 그룹 내부의 문항도 각각 로직 설정 가능하며, 특정 문항으로 이동하도록 설정하면 그 문항이 포함된 그룹부터 표시됩니다.
- `초기화` 버튼을 누르면 해당 문항의 로직이 모두 삭제됩니다.
