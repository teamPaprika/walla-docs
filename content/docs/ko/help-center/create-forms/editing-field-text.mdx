## 텍스트 스타일 지정하기

- 텍스트를 입력한 뒤 드래그하여 선택하면 스타일을 지정할 수 있습니다.
- 사용할 수 있는 텍스트 스타일은 아래와 같아요.
  - 제목 스타일
  - 본문 스타일
  - 특수 스타일 (인용, 강조 등)

- 폰트: 8가지의 영문 폰트 중에서 선택할 수 있어요.
- 글자 크기: 총 5단계 크기 중에서 선택할 수 있습니다.
- 텍스트를 더 눈에 띄게 꾸밀 수 있는 여러 옵션이 있어요.
  - 하이라이트 색상 지정
  - 텍스트 색상 변경
  - 링크 추가
  - 주석 삽입
  - 텍스트 정렬 (좌, 우, 가운데)

## 슬래시(/) 명령으로 추가 기능 사용하기

- 키보드에서 ‘/’(슬래시)를 입력하면 다음과 같은 추가 콘텐츠를 삽입할 수 있어요.
  - 제목 1, 2, 3
  - 불렛 리스트, 숫자 리스트, 할일 리스트, 토글식 텍스트
  - 인용
  - 코드블럭
  - 표(Table)
  - 이중 칼럼(Column)
  - 이미지 삽입 및 크기 조절
  - 구분선
