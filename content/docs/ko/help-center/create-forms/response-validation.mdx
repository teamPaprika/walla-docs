## 응답 검증

| 검증 규칙 | 설명 |
|---|---|
| 필수 입력 | 반드시 응답해야 합니다. |
| 응답 길이 제한 | 최소/최대 글자 수를 설정할 수 있어요. |
| 응답 포함 | 특정 텍스트가 포함되지 않으면 에러 메시지가 표시됩니다. |
| 응답 불포함 | 특정 텍스트가 포함되면 에러 메시지가 표시됩니다. |
| 숫자 범위 제한 | 입력 가능한 최소/최대 값을 지정할 수 있어요. |
| 선택 개수 설정 | 최소·최대 선택 수 또는 정확한 개수를 지정할 수 있어요. |
| 선택지 포함 | 반드시 특정 선택지를 포함해야 합니다. |
| 선택지 제외 | 절대 특정 선택지를 선택하면 안 됩니다. |
| 옵션별 응답 수 제한 | 전체 응답 중 특정 옵션의 선택 횟수를 제한합니다. 선착순 모집, 좌석/분량 제한 등에 활용할 수 있어요. |
| 정규표현식 (Regex) | 패턴을 직접 지정해 형식 검증을 세밀하게 할 수 있어요. |

<Callout title="정규표현식 예시">
- 한글만 입력: `^[가-힣]+$`
- 영어만 입력: `^[A-Za-z]+$`
- URL 형식 확인: `^(https?:\/\/)?([\w-]+\.)+[\w-]+(\/[\w-./?%&=]*)?$`
- 주민등록번호 형식 (하이픈 포함): `^\d{6}-\d{7}$`
- 우편번호 (5자리 숫자): `^\d{5}$`
</Callout>

<Callout type="warning" title="주민등록번호 수집 시 주의">
실제 주민등록번호를 수집할 때는 법적 제한이 있으므로 반드시 **데이터 마스킹** 및 **응답 자동 삭제** 기능을 활성화해주세요.
</Callout>
