## 팀 템플릿 만들기

<Steps>
  <Step>
    ### 템플릿 보관함으로 이동
    템플릿 보관함으로 이동합니다.
  </Step>
  <Step>
    ### 템플릿 불러오기
    `템플릿 불러오기` 버튼을 클릭합니다.
  </Step>
  <Step>
    ### 프로젝트 선택
    템플릿으로 사용할 프로젝트를 선택합니다.
  </Step>
  <Step>
    ### 옵션 설정
    필요 시 복제본으로 불러오기 여부, 미리보기 방향(가로/세로), 템플릿 설명을 설정합니다.
  </Step>
  <Step>
    ### 저장
    `불러오기`를 클릭하면 팀 템플릿으로 저장됩니다.
  </Step>
</Steps>

- 팀 템플릿으로 불러온 팀 전체 자산으로 관리되며, 팀원 모두가 사용할 수 있습니다.

## 팀 템플릿 사용하기

<Steps>
  <Step>
    ### 새 프로젝트 생성
    새 프로젝트를 생성합니다.
  </Step>
  <Step>
    ### 템플릿 사용하기 선택
    `템플릿 사용하기`를 선택합니다.
  </Step>
  <Step>
    ### 팀 템플릿 선택
    템플릿 목록에서 팀 템플릿을 선택합니다.
  </Step>
  <Step>
    ### 원하는 템플릿 선택
    원하는 팀 템플릿을 선택한 후 `템플릿 사용하기`를 클릭합니다.
  </Step>
  <Step>
    ### 완료
    선택한 템플릿을 기반으로 새 프로젝트가 생성됩니다.
  </Step>
</Steps>

## 이런 경우에 활용해 보세요

- 고객 문의, 도입 문의, 만족도 조사처럼 자주 사용하는 설문
- 회사 또는 팀 차원에서 형식을 통일해야 하는 설문
- 신규 팀원이 빠르게 설문을 만들 수 있도록 기준 템플릿이 필요한 경우

<Callout title="팁">
- 팀 템플릿은 팀 자산이므로, 불필요한 프로젝트는 템플릿으로 저장하지 않는 것을 권장드립니다.
- 템플릿을 사용해 생성된 프로젝트는 원본 템플릿과 독립적으로 수정됩니다.
</Callout>
