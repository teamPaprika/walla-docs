## 템플릿 불러오기

<Steps>
  <Step>
    ### 템플릿 페이지 접속
    [템플릿 페이지](https://home.walla.my/template-kr)에 접속해주세요.
  </Step>
  <Step>
    ### 템플릿 선택
    원하는 템플릿을 선택한 후, '바로 사용하기'를 눌러주세요.
  </Step>
  <Step>
    ### 팀과 워크스페이스 설정
    템플릿을 불러올 팀과 워크스페이스를 설정한 후 \[템플릿 복제\]를 눌러주세요.
  </Step>
  <Step>
    ### 완료
    템플릿을 성공적으로 불러왔어요.
  </Step>
</Steps>
