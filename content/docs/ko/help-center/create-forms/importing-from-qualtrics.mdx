## Qualtrics 설문 가져오기

<Steps>
  <Step>
    ### 프로젝트 만들기 버튼 클릭
    워크스페이스 화면에서 `프로젝트 만들기` 버튼을 클릭합니다.

    <img src="/images/guides/manage-forms/team-template-create-project.png" alt="워크스페이스 우측 상단의 프로젝트 만들기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Qualtrics에서 가져오기 선택
    `Qualtrics에서 가져오기`를 선택합니다.

    <img src="/images/guides/manage-forms/import-qualtrics-select.png" alt="새로운 프로젝트 만들기 팝업에서 Qualtrics에서 가져오기 카드 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Qualtrics에서 export한 파일 선택
    `찾아보기` 버튼을 눌러 Qualtrics에서 export한 `.txt` 또는 `.docx` 파일을 선택합니다.

    <img src="/images/guides/manage-forms/import-qualtrics-file-select.png" alt="Qualtrics에서 가져오기 팝업에서 파일을 선택하면 변환된 문항이 미리보기로 표시되는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### 스킵된 필드 확인
    파일을 선택하면 문항이 자동으로 변환되며, 변환 결과는 `변환됨`·`근사 변환`·`스킵됨` 탭으로 나뉘어 표시됩니다. `스킵됨` 탭에서는 왈라에서 지원하지 않는 타입이라 가져오지 못한 문항을 확인할 수 있어요. 해당 문항은 자리만 표시되므로, 폼을 생성한 뒤 빌더에서 직접 다시 만들어 주세요.

    <img src="/images/guides/manage-forms/import-qualtrics-skipped-fields.png" alt="Qualtrics에서 가져오기 팝업의 스킵됨 탭에서 지원하지 않는 문항 타입 목록이 표시되는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 프로젝트 이름 입력 후 폼 생성하기
    `프로젝트 이름`을 입력하고, 필요하면 태그를 추가합니다. 오른쪽 미리보기에서 변환된 폼을 확인한 뒤 `폼 생성하기` 버튼을 클릭하면 가져오기가 완료됩니다.

    <img src="/images/guides/manage-forms/import-qualtrics-create-form.png" alt="프로젝트 이름을 입력하고 폼 생성하기 버튼을 클릭하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 완료
    업로드한 파일을 기반으로 새 프로젝트가 생성됩니다.

    <img src="/images/guides/manage-forms/import-qualtrics-complete.png" alt="가져오기가 완료되어 빌더에 변환된 폼이 표시되는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
