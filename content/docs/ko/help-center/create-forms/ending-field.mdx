## 엔딩 필드 종류

### 종료 페이지
   - 응답 제출 후 노출되는 맞춤형 종료 화면이에요.
   - 설명 필드처럼 텍스트, 이미지, 표 등 다양한 콘텐츠를 넣어 꾸밀 수 있습니다.
	   - [텍스트 편집기](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0)를 통해 글자 색상, 크기, 굵기 등 다양한 스타일을 적용할 수 있어요.
	   - [슬래시(/) 명령](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)으로 이미지, 표, 제목 글자 등을 쉽게 삽입할 수도 있습니다.
   - 예시:
     - "설문이 제출되었습니다. 궁금한 점은 [cs@walla.my](mailto:cs@walla.my) 로 문의해주세요."
     - "응답자 전용 특별 프로모션 코드: WALLA10"

### URL로 이동
   - 응답 제출 후 특정 웹페이지로 이동시킬 수 있습니다.
   - 프로젝트 편집 화면의 엔딩 필드 설정에서 이동할 URL을 직접 입력하면 됩니다.

<img src="/images/guides/manage-forms/ending-url-redirect.png" alt="좌측 엔딩 필드 추가 메뉴와 이동할 URL 주소 입력란이 있는 편집 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## 로직과 함께 사용하는 방법

제출 후 엔딩 필드로 이동시키려면 반드시 로직을 설정해야 합니다.

<Steps>
  <Step>
    ### 제출하기 버튼 클릭
    로직 페이지에서 '제출하기' 버튼을 클릭합니다.

    <img src="/images/guides/manage-forms/ending-logic-submit-click.png" alt="로직 페이지에서 선택된 제출하기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 엔딩 필드 지정
    조건에 따라 이동할 엔딩 필드를 지정합니다.

    <img src="/images/guides/manage-forms/ending-logic-select-ending.png" alt="필드 검색 드롭다운에서 이동할 엔딩 필드 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 게시하기
    설정한 로직은 `게시하기`를 눌러야 실제 설문에 반영됩니다.
  </Step>
</Steps>

<Callout type="warning" title="주의사항">
엔딩 필드를 추가만 하고 로직을 설정하지 않으면, 기본 종료 페이지("응답이 성공적으로 제출되었습니다.")가 자동으로 표시됩니다.
</Callout>

<Callout title="팁">
- 엔딩 필드는 설문을 마무리하며 감사 인사, 추가 안내, 프로모션 정보 등을 제공하기에 좋아요.
- 브랜드 캠페인이나 마케팅 설문이라면 URL 이동형 엔딩 필드를 활용해 웹사이트나 이벤트 페이지로 자연스럽게 연결할 수 있습니다.
</Callout>
