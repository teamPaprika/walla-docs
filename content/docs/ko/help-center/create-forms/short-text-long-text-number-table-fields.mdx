## 단답형 필드

- 한 줄 정도의 짧은 텍스트 응답을 받을 때 사용합니다.
- 이름, 직업, 간단한 의견 등 짧은 응답에 적합해요.
- 연필 아이콘을 눌러 입력 대기 문구를 수정할 수 있습니다.
- 설정 가능 옵션
  - 필수입력
  - 응답 길이 제한
  - 응답 포함
  - 응답 불포함
  - 정규표현식

## 장문형 필드

- 여러 줄의 긴 텍스트 응답을 받을 때 사용합니다.
- 상세한 의견, 피드백, 서술형 답변 등에 활용하기 좋아요.
- 연필 아이콘을 눌러 입력 대기 문구를 수정할 수 있습니다.
- 설정 가능 옵션
  - 필수입력
  - 응답 길이 제한
  - 응답 포함
  - 응답 불포함
  - 정규표현식

## 숫자 필드

- 숫자 입력 전용 필드입니다.
- 수량, 나이, 점수 등 숫자 응답을 수집할 때 사용하세요.
- 연필 아이콘을 눌러 입력 대기 문구를 수정할 수 있습니다.
- 설정 가능 옵션
  - 필수입력
  - 숫자 범위 제한

<Callout type="warning" title="주의사항">
전화번호를 숫자 필드로 받으면 ‘0’으로 시작하는 번호(010AAAABBBB)가 숫자로 인식되어 앞자리 0이 자동으로 사라집니다. 전화번호는 단답형 필드 또는 전화번호 전용 필드를 사용해주세요.
</Callout>

## 표 필드

- 표(테이블) 형태로 여러 주관식 응답을 한 번에 받을 수 있는 필드예요.
- 행·열 구조로 항목을 나눠 작성할 수 있어,다수의 항목을 동시에 비교하거나 평가할 때 유용합니다.
- 설정 가능 옵션
  - 필수입력
