## 프로젝트 생성 방법

<Steps>
  <Step>
    ### 프로젝트 만들기 버튼 클릭
    워크스페이스 화면에서 `프로젝트 만들기` 버튼을 선택합니다.
  </Step>
  <Step>
    ### 프로젝트 설정
    프로젝트 이름과 태그를 설정합니다.
  </Step>
  <Step>
    ### 프로젝트 생성 완료
    `프로젝트 생성` 버튼을 눌러주세요. 새로운 프로젝트가 워크스페이스에 추가됩니다.
  </Step>
</Steps>

<Callout title="참고">
한 워크스페이스 안에서 여러 프로젝트를 만들어 다양한 설문을 동시에 관리할 수 있습니다.
</Callout>
