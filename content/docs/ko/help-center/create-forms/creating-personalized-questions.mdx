## 응답 파이핑 활용 예시

- 이름 문항에서 "홍길동"이라고 입력했다면, 다음 문항에서 "홍길동님, 안녕하세요!" 처럼 표시할 수 있습니다.
- 특정 응답 내용을 다시 보여주며 "이 정보를 다시 확인해주세요"처럼 응답 검증용 문항을 만들 수도 있어요.

## 설정 방법

<Steps>
  <Step>
    ### 입력란으로 이동
    프로젝트 편집 화면에서 필드 제목 또는 설명 입력란으로 이동합니다.
  </Step>
  <Step>
    ### '@' 기호 입력
    '@' 기호를 입력하면 이전에 추가한 문항 목록이 아래에 표시됩니다.
  </Step>
  <Step>
    ### 문항 선택
    불러오고 싶은 문항을 선택하면 파란색 태그 형태로 필드명이 삽입됩니다.
  </Step>
  <Step>
    ### 실제 설문에서 확인
    설문이 실제로 표시될 때는 해당 문항의 응답값이 자동으로 대체되어 보여집니다.
    - 예시: "`@이름 문항`님, 안녕하세요!" 라는 문항에 응답자가 '수지'라고 입력했다면, 실제 설문에서는 "수지님, 안녕하세요!" 로 표시됩니다.
  </Step>
</Steps>

<Callout title="팁">
- 응답 파이핑은 응답자의 참여 몰입도와 맞춤형 경험을 높일 수 있어요. 이름, 지역, 선택한 서비스 등 응답자 고유 정보를 다음 문항에 자연스럽게 연결할 때 활용해보세요.
- 단, 파이핑은 이미 존재하는 문항의 응답만 불러올 수 있으므로, 반드시 불러올 문항을 앞쪽에 배치해야 합니다.
</Callout>
