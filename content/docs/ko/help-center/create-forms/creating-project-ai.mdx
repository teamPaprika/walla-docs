import { Step, Steps } from 'fumadocs-ui/components/steps';

## AI로 설문 만들기

<Steps>
  <Step>
    ### `프로젝트 만들기` 버튼 클릭
    워크스페이스 화면에서 `프로젝트 만들기` 버튼을 클릭합니다.

    <img src="/images/guides/manage-forms/team-template-create-project.png" alt="워크스페이스 우측 상단의 프로젝트 만들기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### AI로 설문 만들기 선택
    [AI로 설문 만들기]를 선택합니다.

    <img src="/images/guides/manage-forms/ai-create-form-select.png" alt="새로운 프로젝트 만들기 팝업에서 AI로 설문 만들기 카드 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 프롬프트 입력
    원하는 설문 내용을 프롬프트로 입력합니다.

    <img src="/images/guides/manage-forms/ai-prompt-input.png" alt="AI로 설문 만들기 모달에서 프롬프트를 입력하고 초안 만들기를 누르는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <Callout title="기본 예시">
    - 고객 만족도 조사 설문을 만들어 주세요.
    - 제품 사용 경험에 대한 피드백 설문을 생성해 주세요.
    - 서비스 개선을 위한 사용자 의견 조사를 만들어 주세요.
    </Callout>

    <Callout title="대상·목적이 명확한 예시">
    - 20대 직장인 대상 재택근무 만족도 조사 설문을 만들어 주세요.
    - 신규 앱 출시 전 베타 테스터 피드백 수집 설문을 생성해 주세요.
    - 온라인 강의 수강생 대상 강의 품질 평가 설문을 만들어 주세요.
    </Callout>

    <Callout title="조건이 포함된 예시">
    - 객관식 5문항과 주관식 2문항으로 구성된 설문을 만들어 주세요.
    - 3분 이내로 완료 가능한 간단한 설문을 생성해 주세요.
    - NPS 점수와 함께 상세 피드백을 받을 수 있는 설문을 만들어 주세요.
    </Callout>
  </Step>
  <Step>
    ### 미리보기 확인
    우측 미리보기에서 생성될 설문 구성을 확인합니다. 결과가 마음에 들지 않으면 프롬프트를 다시 입력할 수 있습니다.

    <img src="/images/guides/manage-forms/ai-preview-result.png" alt="AI가 생성한 설문 문항이 우측 미리보기 영역에 표시된 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 설문 생성 및 편집
    생성된 설문이 마음에 들었다면 [생성하기]를 눌러 설문을 생성합니다. 이후 편집 화면에서 자유롭게 수정·편집할 수 있습니다.

    <img src="/images/guides/manage-forms/ai-form-editor.png" alt="AI가 생성한 설문이 편집 화면에 적용된 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout title="팁">
- 프롬프트를 구체적으로 작성할수록 더 정교한 설문이 생성됩니다.
- 설문을 외국어로 생성하고 싶을 경우, 해당 언어로 요청하시면 됩니다.
  - 예: "프랑스어로 고객 만족도 설문을 만들어 주세요."
</Callout>
