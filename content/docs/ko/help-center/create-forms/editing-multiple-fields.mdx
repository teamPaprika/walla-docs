여러 문항에 같은 설정을 적용하고 싶다면 문항을 함께 선택해 편집해 보세요. 선택한 문항에 공통으로 적용할 수 있는 설정이 오른쪽 사이드바에 표시됩니다.

## 여러 문항 선택하기

<Steps>
  <Step>
    ### 설문 편집 열기

    편집할 설문을 열고 상단의 `만들기`로 이동합니다.
  </Step>
  <Step>
    ### 첫 번째 문항 선택하기

    왼쪽 `설문 필드` 목록에서 선택할 범위의 첫 번째 문항을 클릭합니다.

    <img src="/images/guides/manage-forms/bulk-edit-select-first.png" alt="왼쪽 설문 필드 목록에서 첫 번째 편집 대상 문항을 선택한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Shift로 범위 선택하기

    `Shift` 키를 누른 상태로 마지막 문항을 클릭합니다. 첫 번째 문항부터 마지막 문항까지 사이에 있는 문항이 함께 선택됩니다.

    <img src="/images/guides/manage-forms/bulk-edit-select-range.png" alt="Shift로 여러 문항을 선택해 왼쪽 문항 목록에 선택 범위가 표시된 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 공통 설정 확인하기

    선택된 문항들을 확인하고, 오른쪽 사이드바에서 변경할 설정을 찾습니다.

    <img src="/images/guides/manage-forms/bulk-edit-common-settings.png" alt="여러 문항을 선택한 뒤 오른쪽 공통 설정 패널을 확인하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

다시 한 문항만 편집하려면 `Shift` 키를 누르지 않은 상태로 왼쪽 목록의 문항을 클릭해 주세요.

## 함께 변경할 수 있는 설정

| 위치 | 항목 | 할 수 있는 일 | 표시·이용 조건 |
| --- | --- | --- | --- |
| 응답 검증 | 필수 입력 | 선택한 문항의 필수 응답 여부를 함께 설정합니다. | 선택한 문항이 모두 해당 설정을 지원할 때 표시됩니다. |
| 보안 | 데이터 마스킹 | 선택한 문항의 데이터 마스킹을 설정합니다. | 선택한 문항이 모두 해당 기능을 지원할 때 표시됩니다. 요금제와 권한에 따라 이용이 제한될 수 있어요. |
| 보안 | 응답 자동 삭제 | 선택한 문항의 응답 자동 삭제 여부와 삭제 기간을 설정합니다. | 선택한 문항이 모두 해당 기능을 지원할 때 표시됩니다. 요금제와 권한에 따라 이용이 제한될 수 있어요. |
| 문항 템플릿 | 문항 템플릿으로 저장 | 선택한 문항 조합을 템플릿으로 저장합니다. | 요금제와 권한에 따라 이용이 제한될 수 있어요. |

설정별 자세한 안내는 [응답 검증하기](/ko/docs/help-center/create-forms/response-validation), [데이터 마스킹](/ko/docs/help-center/security/data-masking), [응답 자동으로 삭제하기](/ko/docs/help-center/security/auto-delete-responses), [문항 템플릿](/ko/docs/help-center/create-forms/field-template)에서 확인할 수 있습니다.

## 설정 변경하고 확인하기

<Steps>
  <Step>
    ### 공통 설정 변경하기

    문항을 함께 선택한 상태에서 오른쪽 사이드바의 설정을 변경합니다. 예를 들어 `응답 검증`의 `필수 입력`을 켜면 선택한 문항을 필수 응답으로 설정할 수 있어요.
  </Step>
  <Step>
    ### 문항별 적용 확인하기

    문항을 하나씩 선택해 의도한 설정이 적용됐는지 확인합니다. 선택한 문항들의 기존 설정은 서로 다를 수 있으므로 변경 전후를 확인해 주세요.
  </Step>
  <Step>
    ### 미리보기 확인하고 게시하기

    미리보기에서 응답 동작을 확인한 뒤, 응답자에게 변경사항을 반영하려면 설문을 게시합니다.
  </Step>
</Steps>

문항 제목·선택지·로직을 수정하려면 각 문항을 선택해 해당 편집 기능을 이용해 주세요.

<Callout type="info" title="원하는 설정이 보이지 않을 때">

- 여러 문항이 함께 선택되어 있는지 확인해 주세요. 한 문항만 선택하면 해당 문항의 개별 설정이 표시됩니다.
- 선택한 문항 유형이 해당 기능을 모두 지원하는지 확인해 주세요. 필요한 문항만 다시 선택하면 공통으로 적용 가능한 설정을 확인할 수 있어요.
- 기능이 비활성화되어 있다면 화면의 안내와 선택한 문항의 조건을 먼저 확인해 주세요. 요금제 안내가 표시되면 현재 팀의 요금제와 편집 권한을 확인해 주세요.
</Callout>
