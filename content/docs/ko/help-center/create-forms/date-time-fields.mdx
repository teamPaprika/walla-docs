## 날짜 필드

- 사용자가 원하는 날짜를 선택할 수 있습니다.
- 설정 가능 옵션
  - 필수 입력
  - 데이터 마스킹
  - 응답 자동 삭제

## 시간 필드
- 사용자가 원하는 시간을 선택할 수 있습니다.
- 설정 가능 옵션
  - 필수 입력
  - 데이터 마스킹
  - 응답 자동 삭제

<Callout title="팁">
날짜·시간 필드는 예약 신청, 일정 조율, 이벤트 참여 등 시간 관련 설문을 만들 때 유용하게 활용할 수 있습니다.
</Callout>
