## 객관식 표 필드

<img src="/images/guides/manage-forms/grid-single-choice-example.png" alt="행에 암 종류, 열에 없다/있다/모름 옵션이 표시된 객관식 표 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 행(Row) 과 열(Column) 을 자유롭게 추가할 수 있습니다.
  - 표 아래쪽의 점선 영역을 클릭하면 행이, 오른쪽의 점선 영역을 클릭하면 열이 추가돼요.
  - 행과 열의 제목은 표 안에서 바로 입력하면 됩니다.
- 행·열 제목 옆의 `::`로 순서를 바꾸거나 메뉴를 열 수 있어요.
  - 끌어서 놓으면 행·열 순서가 바뀝니다.
  - 클릭하면 `행 복제`, `행 삭제` (열은 `열 복제`, `열 삭제`) 메뉴가 열려요.
- 좌측 하단의 `옵션 값 설정` 에서 각 선택지의 값을 지정할 수 있어요. (예: 첫 번째 선택지를 값 1로 설정)
- [텍스트 편집기](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0)를 통해 글자 색상, 크기, 굵기 등 다양한 스타일을 적용할 수 있어요.
- [슬래시(/) 명령](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)으로 이미지, 표, 제목 글자 등을 쉽게 삽입할 수도 있습니다.
- 오른쪽 사이드바의 `문항 동작`에서 중복열 제한, 행·열 순서 섞기, 행·열 고정, `모바일에서 세로로 표시`를 설정할 수 있어요.
  - 중복열 제한: `중복열 제한`을 켜면 한 행에서 선택한 열을 다른 행에서 다시 선택할 수 없어요. 1순위, 2순위 같은 순위형 설문에 활용할 수 있습니다. 이 기능은 일반 객관식 표에서만 사용할 수 있어요.
  - 행·열 순서 섞기: `행 순서 섞기`와 `열 순서 섞기`를 각각 켜면 응답 화면에서 해당 방향의 항목이 무작위로 표시돼요. 둘 다 켤 수도 있습니다.
  - 행·열 고정: 순서 섞기를 켜면 나타나는 `고정할 행` 또는 `고정할 열`에서 위치를 유지할 항목을 선택해 주세요. 여러 항목을 고정할 수 있고, 선택을 해제하면 고정이 풀려요. 예를 들어 마지막 열의 ‘기타’를 고정하면 다른 열을 섞어도 ‘기타’는 마지막에 유지됩니다.

    <img src="/images/guides/manage-forms/grid-shuffle-pin.png" alt="문항 동작에서 열 순서 섞기를 켜고 고정할 열로 버스와 자가용을 선택한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

  - 모바일에서 세로로 표시: 이 설정을 켜면 모바일에서 각 행을 열어 선택지를 세로로 확인하며 응답할 수 있어요. 데스크톱에서는 기존 표 형태로 표시됩니다.
  - 미리보기에서 순서와 고정 위치, 모바일 표시를 확인한 뒤 응답자에게 반영하려면 설문을 게시해 주세요.

## 객관식 표(다중선택) 필드

<img src="/images/guides/manage-forms/grid-multi-choice-example.png" alt="수업 방식별 행과 만족 요소 열에서 여러 개의 체크를 선택한 객관식 표(다중선택) 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 기본 객관식 표와 마찬가지로 행과 열을 추가하고, 표 안에서 바로 제목을 입력할 수 있습니다.
- 각 선택지에 옵션 값 지정도 가능해요.
- 차이점은 일반 객관식 표가 행 하나당 한 개의 열만 선택 가능했다면, 다중선택 표는 제한 없이 여러 개의 열을 선택할 수 있다는 점이에요.

<span id="순서-섞기와-행열-고정" />

- 오른쪽 사이드바의 `문항 동작`에서 행·열 순서 섞기, 행·열 고정, `모바일에서 세로로 표시`를 설정할 수 있어요.
  - 행·열 순서 섞기: `행 순서 섞기`와 `열 순서 섞기`를 각각 켜면 응답 화면에서 해당 방향의 항목이 무작위로 표시돼요. 둘 다 켤 수도 있습니다.
  - 행·열 고정: 순서 섞기를 켜면 나타나는 `고정할 행` 또는 `고정할 열`에서 위치를 유지할 항목을 선택해 주세요. 여러 항목을 고정할 수 있고, 선택을 해제하면 고정이 풀려요. 예를 들어 마지막 열의 ‘기타’를 고정하면 다른 열을 섞어도 ‘기타’는 마지막에 유지됩니다.

  - 모바일에서 세로로 표시: 이 설정을 켜면 모바일에서 각 행을 열어 선택지를 세로로 확인하며 응답할 수 있어요. 데스크톱에서는 기존 표 형태로 표시됩니다.
  - 미리보기에서 순서와 고정 위치, 모바일 표시를 확인한 뒤 응답자에게 반영하려면 설문을 게시해 주세요.


<Callout title="팁">
객관식 표는 순위나 우선순위를 묻는 설문에 적합하고, 객관식 표(다중선택) 은 복수 응답을 허용하는 비교·평가형 설문에 유용합니다.
</Callout>
