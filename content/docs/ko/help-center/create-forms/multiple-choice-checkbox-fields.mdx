## 객관식 필드

<img src="/images/guides/manage-forms/single-choice-field-example.png" alt="단일 선택 라디오 옵션이 표시된 객관식 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 응답자가 한 가지 선택지만 선택할 수 있는 기본 객관식 문항이에요.
- 좌측 하단의 `옵션 추가` 버튼을 눌러 선택지를 더 추가하거나, ‘직접 입력란 추가’를 통해 응답자가 기타 의견을 직접 입력하도록 설정할 수도 있습니다.
- [텍스트 편집기](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0)를 통해 글자 색상, 크기, 굵기 등 다양한 스타일을 적용할 수 있어요.
- [슬래시(/) 명령](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)으로 이미지, 표, 제목 글자 등을 쉽게 삽입할 수도 있습니다.
- 우측 하단의 `…`(더보기) 버튼을 클릭하면 아래 기능을 사용할 수 있어요.
  - 옵션 일괄 추가: 여러 선택지를 한 번에 입력할 수 있습니다. *(각 옵션은 엔터로 구분)*
  - 옵션 값 설정: 선택지의 값을 직접 지정할 수 있습니다. (예: 첫 번째 선택지를 ‘1’로 지정 → 응답 시트에 1로 표기됨)
  - 선택지 섞기: 응답 시 선택지 순서를 랜덤으로 표시할 수 있습니다.

- 설정 가능한 옵션
  - 필수 입력
  - 선택 개수 설정
  - 선택지 포함
  - 선택지 제외
  - 옵션별 응답 수 제한
  - 데이터 마스킹
  - 응답 자동 삭제

## 객관식(다중선택) 필드

<img src="/images/guides/manage-forms/multi-choice-field-example.png" alt="최대 2개까지 선택 가능한 안내와 함께 키워드 옵션이 표시된 객관식(다중선택) 필드" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 응답자가 여러 개의 선택지를 동시에 선택할 수 있는 객관식 문항이에요.
- 마찬가지로 `옵션 추가` 및 `직접 입력란 추가` 기능을 사용할 수 있습니다.
- [텍스트 편집기](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%ED%85%8D%EC%8A%A4%ED%8A%B8-%EC%8A%A4%ED%83%80%EC%9D%BC-%EC%A7%80%EC%A0%95%ED%95%98%EA%B8%B0)를 통해 글자 색상, 크기, 굵기 등 다양한 스타일을 적용할 수 있어요.
- [슬래시(/) 명령](https://docs.walla.my/ko/docs/help-center/create-forms/editing-field-text#%EC%8A%AC%EB%9E%98%EC%8B%9C-%EB%AA%85%EB%A0%B9%EC%9C%BC%EB%A1%9C-%EC%B6%94%EA%B0%80-%EA%B8%B0%EB%8A%A5-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0)으로 이미지, 표, 제목 글자 등을 쉽게 삽입할 수도 있습니다.
- 우측 하단의 `…(더보기)` 버튼을 클릭하면 아래 기능을 사용할 수 있어요.
  - 옵션 일괄 추가: 여러 선택지를 한 번에 입력할 수 있습니다. *(각 옵션은 엔터로 구분)*
  - 옵션 값 설정: 선택지의 값을 직접 지정할 수 있습니다. (예: 첫 번째 선택지를 ‘1’로 지정 → 응답 시트에 1로 표기됨)
  - 선택지 섞기: 응답 시 선택지 순서를 랜덤으로 표시할 수 있습니다.

## 단독 선택

- ‘해당 없음’처럼 다른 선택지와 함께 고를 수 없는 선택지를 지정할 수 있어요.
- 응답자가 단독 선택지를 고르면 같은 문항의 다른 선택은 모두 해제되고, 반대로 다른 선택지를 고르면 단독 선택지가 해제돼요.
-  단독 선택지에는 선택 개수 설정(최소·최대·정확히)이 적용되지 않습니다.
- 선택지 위에 마우스를 올린 뒤 `…`(더보기) 버튼을 클릭하고 단독 선택을 켜면 됩니다.
	<img src="/images/guides/manage-forms/exclusive-option-menu.png" alt="선택지 오른쪽의 더보기 버튼을 눌러 단독 선택 메뉴를 연 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 단독 선택으로 지정된 선택지에는 ‘단독 선택’ 표시가 붙어요.
	<img src="/images/guides/manage-forms/exclusive-option-applied.png" alt="해당하지 않음 선택지에 단독 선택 표시가 붙은 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
