## 파일 업로드 필드 사용 방법

<Steps>
  <Step>
    ### 파일 선택
    응답자는 `파일 선택` 버튼을 눌러 업로드할 파일을 선택합니다.
  </Step>
  <Step>
    ### 업로드 완료
    선택 후 `이 파일 업로드` 버튼을 눌러 업로드를 완료해야 합니다.
  </Step>
  <Step>
    ### 응답 제출
    업로드한 파일은 응답을 제출해야 최종 저장되므로, 반드시 업로드 완료 후 설문 제출까지 마무리해야 합니다.
  </Step>
</Steps>

## 업로드 용량 제한

- Free 플랜: 한 필드당 최대 15MB까지 업로드 가능
- Pro 플랜 이상: 한 필드당 최대 500MB까지 업로드 가능
- 우측 하단 설정 메뉴에서 응답자가 업로드할 수 있는 최대 용량을 직접 지정할 수도 있습니다.
  - Free 플랜은 15MB 이하, Pro 이상은 500MB 이하로 설정할 수 있어요.

## 설정 가능 옵션
  - 필수입력
  - 민감 파일 접근 제어
  - 데이터 자동 삭제

## 민감 파일 접근 제어

민감 파일 접근 제어를 활성화하면 파일이 비공개 상태로 저장되며, 지정된 권한을 가진 사용자만 해당 파일에 접근할 수 있습니다. 또한 파일 접근 시 반드시 **사유 입력 절차**를 거치며, 모든 접근 기록은 활동 로그에 자동으로 저장됩니다.

<img src="/images/guides/manage-forms/sensitive-file-access-control.png" alt="파일 업로드 필드의 민감 파일 접근 제어 활성화 확인 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />


- 파일을 열람하거나 다운로드할 때마다 반드시 사유를 입력해야 하고, 입력한 사유는 활동 로그에 기록됩니다.
- 한번 활성화한 뒤에는 해제할 수 없습니다.

<Callout type="warning" title="주의사항">
Enterprise 플랜에서 Free나 Pro 플랜으로 다운그레이드 시, 민감 파일의 열람/다운로드가 제한됩니다.
</Callout>

- 응답 시트와 내보내기에는 원본 링크 대신 보안 다운로드 링크로 표시되며, 파일 일괄 다운로드 시 해당 필드는 제외된 채로 다운로드 됩니다.
- 토글을 켜기 전에 받은 기존 응답의 파일도 자동으로 보호됩니다. (적용까지 시간이 소요될 수 있습니다)

<Callout type="warning" title="주의사항">
업로드 완료 후 설문을 제출하지 않으면 파일은 저장되지 않습니다.
</Callout>
