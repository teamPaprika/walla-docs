## 파일 업로드 필드 사용 방법

1. 응답자는 `파일 선택` 버튼을 눌러 업로드할 파일을 선택합니다.
2. 선택 후 `이 파일 업로드` 버튼을 눌러 업로드를 완료해야 합니다.
3. 업로드한 파일은 응답을 제출해야 최종 저장되므로, 반드시 업로드 완료 후 설문 제출까지 마무리해야 합니다.

## 업로드 용량 제한

- Free 플랜: 한 필드당 최대 15MB까지 업로드 가능
- Pro 플랜 이상: 한 필드당 최대 500MB까지 업로드 가능
- 우측 하단 설정 메뉴에서 응답자가 업로드할 수 있는 최대 용량을 직접 지정할 수도 있습니다.
  - Free 플랜은 15MB 이하,
  - Pro 이상은 500MB 이하로 설정할 수 있어요.
- 설정 가능 옵션
  - 필수입력
  - 데이터 마스킹
  - 데이터 자동 삭제

<Callout type="warning" title="주의사항">
업로드 완료 후 설문을 제출하지 않으면 파일은 저장되지 않습니다.
</Callout>
