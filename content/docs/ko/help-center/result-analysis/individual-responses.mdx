## 개별 응답 보기

<img src="/images/guides/result-analysis/individual-responses.png" alt="개별 응답 페이지" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

1. 프로젝트에서 **결과 보기** 탭을 클릭한 뒤, **개별 응답** 탭을 선택합니다.
2. 가장 최근 응답부터 전체 화면으로 표시됩니다.
3. 좌우 화살표로 이전·다음 응답을 넘길 수 있으며, 상단에 "3 / 15"처럼 현재 위치가 표시됩니다.

- **전체 문항 보기**를 켜면 응답자가 답하지 않은 문항까지 포함해 모든 문항을 볼 수 있어요.
- 워크스페이스 멤버에게 특정 응답 링크를 공유받았을 때도 이 페이지로 바로 이동합니다.
- 하단에는 프로젝트명, 응답 시간, 설문 ID, 응답 ID가 요약되어 있어 응답을 식별하는 데 유용합니다.

## 응답 관리

- **링크 복사**: 현재 응답의 개별 응답 페이지 링크를 복사합니다. 응답 확인 권한이 있는 워크스페이스 멤버에게 공유하면 이 페이지에서 해당 응답을 바로 확인할 수 있어요.
- **PDF 다운로드**: 현재 응답을 PDF 파일로 저장합니다.
- **삭제**: 응답을 영구적으로 삭제합니다. 삭제된 응답은 복구할 수 없습니다.

<Callout title="팁">
응답 시트에서 필터나 정렬을 적용한 뒤 행 아이콘을 클릭하면, 시트를 떠나지 않고 개별 응답 상세보기를 열 수 있어요. 자세한 내용은 [응답 시트](/ko/docs/help-center/result-analysis/response-sheet#시트에서-개별-응답-바로-보기)를 참고하세요.
</Callout>
