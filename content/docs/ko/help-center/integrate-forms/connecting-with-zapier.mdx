import { Step, Steps } from 'fumadocs-ui/components/steps';

## 연동 설정 방법

<Steps>
  <Step>
    ### Zapier 선택 및 로그인
    '연동하기' 메뉴에서 Zapier를 선택하고 로그인해주세요.

    <img src="/images/guides/integrate/zapier-01-select.png" alt="Zapier 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Walla Form 선택
    App & event 단계에서 'Walla Form'을 선택합니다.

    <img src="/images/guides/integrate/zapier-02-walla-form.png" alt="Walla Form 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Event 설정
    Event는 'New Response'로 설정해주세요.

    <img src="/images/guides/integrate/zapier-03-trigger-event.png" alt="Trigger event 설정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 왈라 계정 로그인
    Account 항목에서 왈라 계정으로 로그인합니다.

    <img src="/images/guides/integrate/zapier-04-account.png" alt="왈라 계정 로그인" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 프로젝트 선택
    팀, 워크스페이스, 프로젝트를 차례로 선택해 응답 알림을 받고 싶은 프로젝트를 지정합니다.

    <img src="/images/guides/integrate/zapier-05-project.png" alt="프로젝트 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### 테스트용 응답 선택
    Zapier테스트를 위해 기존 수집된 응답 중 하나를 선택한 후, `Continue with selected account` 버튼을 클릭합니다.

    <img src="/images/guides/integrate/zapier-06-test-record.png" alt="테스트용 응답 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 외부 서비스 연결
    다음 Account 단계에서 연결할 외부 서비스를 선택합니다. (예: Google Sheets, Slack 등)

    <img src="/images/guides/integrate/zapier-06-external-service.png" alt="외부 서비스 연결" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 세부 옵션 설정
    Gmail, Google Sheets 등 외부 서비스의 세부 발송 옵션을 설정합니다.

    <img src="/images/guides/integrate/zapier-08-details.png" alt="세부 옵션 설정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### 테스트하기
    테스트하여 확인하고 싶다면 `Test Step`을, 테스트가 필요하지 않다면 `Skip Test`를 클릭합니다.

    <img src="/images/guides/integrate/zapier-09-test.png" alt="테스트하기" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 저장하기
    테스트를 완료했다면 `Publish` 버튼을 눌러 저장합니다.

    <img src="/images/guides/integrate/zapier-10-publish.png" alt="저장하기" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/integrate/zapier-10-published.png" alt="Zap 게시 완료" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>


<Callout type="warning" title="Google Sheets로 연동할 때 주의사항">
Zapier를 이용해 구글시트와 연동하려면, 구글시트의 첫 번째 행에 반드시 헤더(열 이름)가 설정되어 있어야 합니다. 이 헤더 값이 있어야 응답이 올바르게 기록돼요.
</Callout>
