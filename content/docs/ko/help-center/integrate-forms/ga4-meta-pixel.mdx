## 연동 방법

<Steps>
  <Step>
    ### 설문 설정 열기
    설문 편집 화면 오른쪽 상단의 설정(톱니바퀴) 버튼을 클릭해 설문 설정을 엽니다.

    <img src="/images/guides/integrate/ga4-pixel-01-settings.png" alt="설문 설정 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 외부 트래킹 탭으로 이동
    설문 설정 창에서 왼쪽 메뉴의 '외부 트래킹' 탭을 선택합니다.

    <img src="/images/guides/integrate/ga4-pixel-02-external-tracking.png" alt="외부 트래킹 탭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 측정 ID 입력
    추적할 플랫폼의 ID를 입력합니다. 입력한 값은 자동으로 저장돼요.
    - Meta 픽셀 ID: 예) 123456789012345
    - GA4 측정 ID: 예) G-XXXXXXXXXX

    <img src="/images/guides/integrate/ga4-pixel-03-ids.png" alt="Meta 픽셀 ID와 GA4 측정 ID 입력" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## 전송되는 이벤트

연동하면 응답자의 행동에 따라 다음 표준 이벤트가 각 플랫폼으로 전송됩니다.

- 폼 조회 시: PageView (Meta) / page_view (GA4)
- 제출 완료 시: Lead (Meta) / generate_lead (GA4)

전환 이벤트에는 walla_response_id, walla_customer_key 파라미터가 함께 포함됩니다. 광고 전환 목표를 설정할 때 위 표준 이벤트 이름을 선택하세요.
