## 커스텀 웹훅 생성하기

자동화 생성 후 상세 편집 화면으로 이동하면 더 정교한 설정이 가능합니다.
<Steps>
  <Step>
    ### 연동하기 페이지 진입
    프로젝트 편집 화면 상단의 `연동하기`를 클릭합니다.
  </Step>
  <Step>
    ### 새로운 자동화 추가
    '내 자동화' 섹션에서 `새로운 자동화` 버튼을 클릭하여 시작합니다.
  </Step>
  <Step>
    ### 생성하기
    팝업창에서 자동화의 이름 등의 정보를 입력하고, 트리거 유형을 선택한 뒤 `만들기`를 클릭합니다.
	    - **자동화 이름**: 자동화를 구분할 수 있는 이름입니다.
	    - **트리거 유형**: 폼 제출 시 / 응답자 탈락 등 자동화를 작동할 조건을 의미하며, 트리거 유형은 생성 후 변경할 수 없습니다.
  </Step>
  <Step>
    ### 경로 설정(로직)
    특정 조건(객관식 답변이 A일 때, 단답형 응답에 B가 포함될 때 등)에 따라 알림이 가도록 필터를 걸 수 있습니다.
	    - 우측 상단의 `+`를 눌러 통해 여러 경로를 생성할 수 있습니다. 이때, 각각의 경로에 별도로 자동화 모듈을 연결하지 않으면 기본 경로(모든 응답 제출에 대한 알림)로 작동합니다.
	    - 각 경로 하단의 `+ 조건 추가`를 눌러 복합적인 조건을 설정할 수 있습니다.
  </Step>
  <Step>
    ### 웹훅 주소 입력
    **웹훅 주소**: 데이터를 받을 서버 주소입니다.
  </Step>
  <Step>
    ### 웹훅 전송 포맷 지정
	    자동(기본 웹훅 Body)으로 전송할지, 커스텀 Body를 지정할지 선택합니다. 자동을 선택한 경우에는 저장 후 바로 활성화하여 이용할 수 있고, 커스텀 Body를 선택한 경우에는 다음의 단계로 넘어갑니다.
    
  </Step>
  <Step>
    ### 요청 종류와 Headers 설정
	    - **요청 종류**: POST / GET / PUT 등
	    - **Headers 설정**: `Content-Type`, 인증 토큰 등 필요 시 추가
  </Step>
    <Step>
    ### Body 편집
	    전송될 메시지 문구를 자유롭게 수정하거나, 응답 값(`{{responseKey}}`)을 변수로 삽입할 수 있습니다.
  </Step>
    <Step>
    ### 인증 방식 설정 (선택)
    웹훅 사용 시 `Bearer Token`, `Basic Auth`, `API Key` 등 보안 인증 방식을 선택할 수 있습니다.
  </Step>
    <Step>
    ### 변경사항 저장 및 활성화
    변경사항을 저장하고, 활성화를 눌러야 웹훅이 실제로 작동합니다.
  </Step>
</Steps>
## Slack 연동- 응답 제출 시 Slack 알림

<Steps>
 <Step>
    ### Create New App 클릭
    [https://api.slack.com/apps](https://api.slack.com/apps)에서 'Create New App'을 클릭합니다.
  </Step>
  <Step>
    ### From scratch 선택
    'From scratch'를 선택합니다.
  </Step>
  <Step>
    ### App 이름 및 워크스페이스 설정
    'App Name'에 App의 이름을 입력하고, 어떤 워크스페이스에서 작동할지 선택합니다.
  </Step>
  <Step>
    ### Incoming Webhooks 활성화
    'Incoming Webhooks'를 활성화한 후 'Add New Webhook'을 클릭합니다.
  </Step>
  <Step>
    ### 채널 선택
    워크스페이스 내에서 웹훅을 적용할 채널을 선택합니다.
  </Step>
  <Step>
    ### Webhook URL 복사
    'Install App'에서 Webhook URL을 복사합니다.
  </Step>
<Step>
    ### 연동하기 페이지 진입
    프로젝트 편집 화면 상단의 `연동하기`를 클릭합니다.

    ### 새로운 Slack 자동화 추가
    '내 자동화' 섹션에서 `Slack` 버튼을 클릭하여 시작합니다.

## Gmail 연동 - 응답 제출 시 이메일 발송

<Steps>
  <Step>
    ### 연동하기 페이지 진입
    프로젝트 편집 화면 상단의 `연동하기`를 클릭합니다.
  </Step>
  <Step>
    ### 새로운 자동화 추가
    '내 자동화' 섹션에서 `Gmail` 버튼을 클릭하여 시작합니다.
  </Step>
  <Step>
    ### 생성하기
    팝업창에서 자동화의 이름 등의 정보를 입력하고, 트리거 유형을 선택한 뒤 `만들기`를 클릭합니다.
	    - **자동화 이름**: 자동화를 구분할 수 있는 이름입니다.
	    - **트리거 유형**: 폼 제출 시 / 응답자 탈락 등 자동화를 작동할 조건을 의미하며, 트리거 유형은 생성 후 변경할 수 없습니다.
	    - 발신자: Gmail을 발신할 구글 계정입니다. 기존에 워크스페이스에 연동된 계정을 선택하거나, 새로운 구글 계정에 로그인합니다.
  </Step>
  <Step>
    ### 경로 설정(로직)
    특정 조건(객관식 답변이 A일 때, 단답형 응답에 B가 포함될 때 등)에 따라 알림이 가도록 필터를 걸 수 있습니다.
	    - 우측 상단의 `+`를 눌러 통해 여러 경로를 생성할 수 있습니다. 이때, 각각의 경로에 별도로 자동화 모듈을 연결하지 않으면 기본 경로(모든 응답 제출에 대한 알림)로 작동합니다.
	    - 각 경로 하단의 `+ 조건 추가`를 눌러 복합적인 조건을 설정할 수 있습니다.
  </Step>
  <Step>
    ### 발신자 지정
	    Gmail을 발신할 구글 계정을 선택하고 발신자 이름을 입력합니다.
    
  </Step>
  <Step>
    ### 수신자 지정
	    - 이메일을 수신할 계정을 입력합니다.
	    - 이메일 주소를 직접 입력하거나, 값 참조(@)를 사용하여 동적으로 설정할 수 있습니다.
	    - 여러 개의 이메일 주소를 추가하려면 쉼표(,), 공백 또는 엔터 키로 구분하세요.
	    - responseKey, timestamp 와 같은 일부 사전 정의된 참조값은 이메일 주소로 사용할 수 없습니다.
	    - 이메일 필드를 참조값으로 사용하는것을 권장합니다. 이메일 형식이 맞지 않을경우 전송에 실패할 수 있습니다.
  </Step>
    <Step>
    ### 참조, 숨은참조, 회신 이메일 지정
	    - 이메일을 참조/숨은참조로 수신하거나 회신할 계정을 입력합니다.
	    - 이메일 주소를 직접 입력하거나, 값 참조(@)를 사용하여 동적으로 설정할 수 있습니다.
	    - 여러 개의 이메일 주소를 추가하려면 쉼표(,), 공백 또는 엔터 키로 구분하세요.
	    - responseKey, timestamp 와 같은 일부 사전 정의된 참조값은 이메일 주소로 사용할 수 없습니다.
  </Step>
    <Step>
    ### 변경사항 저장 및 활성화
    변경사항을 저장하고, 활성화를 눌러야 웹훅이 실제로 작동합니다.
  </Step>
</Steps>
