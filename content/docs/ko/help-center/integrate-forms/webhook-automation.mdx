## 1. 자동화 메뉴 진입 및 생성
1. Walla 대시보드 왼쪽 사이드바에서 [자동화] 아이콘을 클릭합니다.
2. '내 자동화' 섹션에서 생성하고자 하는 자동화 버튼을 클릭하여 시작합니다.
3. 팝업창에서 자동화의 이름을 입력하고, 트리거 유형을 선택한 뒤 [만들기]를 누릅니다.
## 2. 새로운 자동화 - 커스텀 웹훅 생성
- 자동화 이름: 자동화를 구분할 수 있는 이름입니다.
- 트리거 유형: 폼 제출 시 / 응답자 탈락 등 자동화를 작동할 조건입니다.
  - 트리거 유형은 생성 후 변경할 수 없습니다.

자동화 생성 후 상세 편집 화면으로 이동하면 더 정교한 설정이 가능합니다.

- 트리거: '응답 제출 시' 혹은 ‘응답자 탈락 시’ 작동하는 시작점입니다.
- 경로 설정(로직): 특정 조건(객관식 답변이 A일 때, 단답형 응답에 B가 포함될 때 등)에 따라 알림이 가도록 필터를 걸 수 있습니다.
  - 우측 상단의 [+]를 눌러 통해 여러 경로를 생성할 수 있습니다. 이때, 각각의 경로에 별도로 자동화 모듈을 연결하지 않으면 기본 경로(모든 응답 제출에 대한 알림)로 작동합니다.
  - 각 경로 하단의 [+ 조건 추가]를 눌러 복합적인 조건을 설정할 수 있습니다.

- 웹훅 연결: 실제 수행할 작업을 연결합니다.
  - 웹훅 주소: 데이터를 받을 서버 주소입니다.
  - 요청 종류: POST / GET / PUT 등
  - Headers 설정: `Content-Type`, 인증 토큰 등 필요 시 추가
  - Body 편집: 전송될 메시지 문구를 자유롭게 수정하거나, 응답 값(`{{responseKey}}`)을 변수로 삽입할 수 있습니다.
  - 고급 방식
    - 인증 설정: 웹훅 사용 시 `Bearer Token`, `Basic Auth`, `API Key` 등 보안 인증 방식을 선택할 수 있습니다.

## 3. Slack - 응답 제출 시 Slack 알림
- 자동화 이름: 자동화를 구분할 수 있는 이름입니다.
- 트리거 유형: 폼 제출 시 / 응답자 탈락 등 자동화를 작동할 조건입니다.
  - 트리거 유형은 생성 후 변경할 수 없습니다.

- Webhook URL: 데이터를 받을 서버 주소입니다.
  - Slack Webhook URL 설정 방법은 [여기](https://docs.slack.dev/messaging/sending-messages-using-incoming-webhooks/)에서 확인할 수 있습니다.
  - 간단 요약
    - [https://api.slack.com/apps에서](https://api.slack.com/apps%EC%97%90%EC%84%9C) ‘Create New App’ 클릭
    - ‘From scratch’ 선택
    - ‘App Name’에 App의 이름을 입력하고, 어떤 워크스페이스에서 작동할지 선택
    - ‘Incoming Webhooks’ 활성화 후 ‘Add New Webhook’ 클릭
    - 워크스페이스 내에서 웹훅을 적용할 채널 선택
    - ‘Install App’에서 Webhook URL 복사

- Body Presets: Simple은 일반 메시지처럼 오는 거고 Blocks는 개별 메시지를 구분할 수 있는 양식으로 발송됨

## 5. Gmail - 응답 제출 시 이메일 발송
- 자동화 이름: 자동화를 구분할 수 있는 이름입니다.
- 트리거 유형: 폼 제출 시 / 응답자 탈락 등 자동화를 작동할 조건입니다.
  - 트리거 유형은 생성 후 변경할 수 없습니다.

- 발신자: Gmail에 연동할 계정을 선택해주세요.

자동화 생성 후 상세 편집 화면으로 이동하면 더 정교한 설정이 가능합니다.

- 트리거: '응답 제출 시' 혹은 ‘응답자 탈락 시’ 작동하는 시작점입니다.
- 경로 설정(로직): 특정 조건(객관식 답변이 A일 때, 단답형 응답에 B가 포함될 때 등)에 따라 알림이 가도록 필터를 걸 수 있습니다.
  - 우측 상단의 [+]를 눌러 통해 여러 경로를 생성할 수 있습니다. 이때, 각각의 경로에 별도로 자동화 모듈을 연결하지 않으면 기본 경로(모든 응답 제출에 대한 알림)로 작동합니다.
  - 각 경로 하단의 [+ 조건 추가]를 눌러 복합적인 조건을 설정할 수 있습니다.

- 웹훅 연결: 실제 수행할 작업을 연결합니다.
  - 발신자
  - 발신자 이름
  - 수신자
  - 고급 설정
    - 참조:
    - 숨은참조:
    - 회신 이메일

주의

  - 이메일 주소를 직접 입력하거나, 값 참조(@)를 사용하여 동적으로 설정할 수 있습니다.
  - 여러 개의 이메일 주소를 추가하려면 쉼표(,), 공백 또는 엔터 키로 구분하세요.
  - responseKey, timestamp 와 같은 일부 사전 정의된 참조값은 이메일 주소로 사용할 수 없습니다.
    - 이메일 필드를 참조값으로 사용하는것을 권장합니다. 이메일 형식이 맞지 않을경우 전송에 실패할 수 있습니다.

모든 설정이 완료되면 상단의 [변경 사항 저장]과 [활성화] 토글 스위치를 켜야 실제로 자동화가 작동합니다.

설정 마무리하기
1. 모든 설정이 완료되면 상단의 [변경 사항 저장] 버튼을 누릅니다.
2. '활성화' 토글 스위치를 켜야 실제로 자동화가 작동합니다.
3. 우측의 '실행 로그'를 통해 자동화가 성공적으로 수행되었는지 실시간으로 확인할 수 있습니다.
