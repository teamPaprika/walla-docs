## 커스텀 웹훅 생성하기

자동화 생성 후 상세 편집 화면으로 이동하면 더 정교한 설정이 가능합니다.
<Steps>
  <Step>
    ### 연동하기 페이지 진입
    프로젝트 편집 화면 상단의 `연동하기`를 클릭합니다.

    <img src="/images/guides/integrate/automation-page.png" alt="자동화 연동 페이지" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### 새로운 자동화 추가
    '내 자동화' 섹션에서 `새로운 자동화` 버튼을 클릭하여 시작합니다.

    <img src="/images/guides/integrate/automation-new-custom.png" alt="새로운 자동화 추가" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### 생성하기
    팝업창에서 자동화의 이름 등의 정보를 입력하고, 트리거 유형을 선택한 뒤 `만들기`를 클릭합니다.
	    - **자동화 이름**: 자동화를 구분할 수 있는 이름입니다.
	    - **트리거 유형**: 폼 제출 시 / 응답자 탈락 등 자동화를 작동할 조건을 의미하며, 트리거 유형은 생성 후 변경할 수 없습니다.

    <img src="/images/guides/integrate/automation-create-custom.png" alt="새로운 자동화 만들기" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### 경로 설정(로직)
    특정 조건(객관식 답변이 A일 때, 단답형 응답에 B가 포함될 때 등)에 따라 알림이 가도록 필터를 걸 수 있습니다.
	    - 우측 상단의 `+`를 눌러 통해 여러 경로를 생성할 수 있습니다. 이때, 각각의 경로에 별도로 자동화 모듈을 연결하지 않으면 기본 경로(모든 응답 제출에 대한 알림)로 작동합니다.
	    - 각 경로 하단의 `+ 조건 추가`를 눌러 복합적인 조건을 설정할 수 있습니다.

    <img src="/images/guides/integrate/automation-route-custom.png" alt="경로 설정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### 웹훅 주소 입력
    **웹훅 주소**: 데이터를 받을 서버 주소입니다.

    <img src="/images/guides/integrate/automation-webhook-url.png" alt="웹훅 주소 입력" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### 웹훅 전송 포맷 지정
	    자동(기본 웹훅 Body)으로 전송할지, 커스텀 Body를 지정할지 선택합니다. 자동을 선택한 경우에는 저장 후 바로 활성화하여 이용할 수 있고, 커스텀 Body를 선택한 경우에는 다음의 단계로 넘어갑니다.

    <img src="/images/guides/integrate/automation-webhook-format.png" alt="웹훅 전송 포맷 지정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### 요청 종류와 Headers 설정
	    - **요청 종류**: POST / GET / PUT 등
	    - **Headers 설정**: `Content-Type`, 인증 토큰 등 필요 시 추가

    <img src="/images/guides/integrate/automation-headers.png" alt="요청 종류와 Headers 설정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
    <Step>
    ### Body 편집
	    전송될 메시지 문구를 자유롭게 수정하거나, 응답 값(`{{responseKey}}`)을 변수로 삽입할 수 있습니다.

    <img src="/images/guides/integrate/automation-body.png" alt="Body 편집" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### 인증 방식 설정 (선택)
    웹훅 사용 시 `Bearer Token`, `Basic Auth`, `API Key` 등 보안 인증 방식을 선택할 수 있습니다.

    <img src="/images/guides/integrate/automation-auth.png" alt="인증 방식 설정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### 변경사항 저장 및 활성화
    변경사항을 저장하고, 활성화를 눌러야 웹훅이 실제로 작동합니다.

    <img src="/images/guides/integrate/automation-save-activate.png" alt="변경사항 저장 및 활성화" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## 웹훅 재발송하기 (웹훅 발송에 실패한 경우)

<img src="/images/guides/integrate/webhook-resend.png" alt="웹훅 재발송" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

- 웹훅 발송에 실패했다면, 재발송할 수 있습니다.
- 오류 요약에서 어떤 이유로 발송에 실패했는지 확인할 수 있습니다.
	- 예를 들어, Gmail 자동화에서 'At least one 'to' recipient is required'라고 표시된다면, 수신자를 입력하지 않아 발송이 불가능한 상황을 의미합니다.
	- 'Webhook failed with status: 400'라고 표시된다면, 웹훅 서버가 요청을 받았지만 “잘못된 요청(Bad Request)”이라 거절했다는 뜻으로, 보낸 데이터 형식이 올바르지 않아서 오류가 발생했음을 의미합니다.
### 재발송 방법
- **원본 설정으로 재시도**: 실행 당시 저장된 원본 설정으로 재발송합니다. 설정 변경 없이 동일 조건으로 다시 시도할 때 유용합니다. 일시적인 서버 오류로 인한 발송 실패라면 원본 설정으로 재시도해보세요.
- **현재 설정으로 재발송**: 현재 저장된 자동화 설정으로 재발송합니다. 설정을 저장한 후 다시 시도할 때 유용합니다. 수신인을 입력하지 않았거나 데이터 형식을 올바르게 입력하지 않아 오류가 발생했다면, 해당 내용을 수정한 후 현재 설정으로 재발송을 클릭해주세요.
