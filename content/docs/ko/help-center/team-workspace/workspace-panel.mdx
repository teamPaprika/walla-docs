## 패널이란?

패널은 설문을 발송할 대상자 목록이에요. 워크스페이스의 **패널** 탭에서 패널 명단을 CSV 또는 Excel 파일로 업로드하고, 그룹으로 분류해 체계적으로 관리할 수 있습니다.

## 패널 탭으로 이동하기

워크스페이스 화면에서 상단의 **패널** 탭을 클릭하면 패널 관리 화면으로 이동해요.

- 탭 순서: 프로젝트 → 보관함 → **패널**

패널 목록에는 다음 정보가 표시됩니다.

| 항목   | 설명                  |
| ---- | ------------------- |
| 고객 키 | 패널을 식별하는 고유 키       |
| 이름   | 패널의 이름 (기본 마스킹)     |
| 이메일  | 패널의 이메일 주소 (기본 마스킹) |
| 전화번호 | 패널의 전화번호 (기본 마스킹)   |
| 그룹   | 패널이 속한 그룹           |

<Callout type="info" title="개인정보 마스킹">
패널의 이름, 이메일, 전화번호는 개인정보 보호를 위해 기본적으로 마스킹 처리돼요. 실제 정보를 열람하려면 마스킹 해제가 필요합니다.
</Callout>

## 패널 업로드하기

CSV 또는 Excel 파일로 패널 명단을 한 번에 등록할 수 있어요.

1. 패널 탭에서 **패널 업로드** 버튼을 클릭합니다.
2. 업로드할 패널의 **그룹을 선택**합니다. (선택 사항)
3. **파일 선택** 버튼을 클릭해 CSV 또는 Excel 파일을 선택합니다.
4. 적합 데이터를 확인한 후 **패널 업로드** 버튼을 클릭합니다.

<Callout type="warn" title="파일 형식 안내">
- 이름은 필수 항목이며, 이메일 또는 전화번호 중 하나는 반드시 입력해야 해요.
- 전화번호 앞자리 0이 사라졌다면, 전화번호 열의 셀 서식을 **텍스트**로 설정하거나 전화번호 앞에 `'`를 붙여주세요.
- 파일 형식이 맞지 않으면 **부적합 데이터** 탭에서 오류 항목을 확인할 수 있어요.
- 템플릿이 필요하다면 **템플릿 다운로드** 버튼을 클릭하세요.
</Callout>

<Callout type="info" title="현재 지원 발송 방법">
현재 설문 보내기 기능에서는 **이메일 발송만** 지원합니다.
</Callout>

## 그룹 관리하기

패널을 그룹으로 분류해 목적에 맞게 관리할 수 있어요.

1. 패널 탭에서 **그룹 관리** 버튼을 클릭합니다.
2. 기존 그룹 목록과 각 그룹의 패널 수를 확인할 수 있어요.
3. **그룹 생성** 버튼을 눌러 새 그룹을 만들거나, 그룹 우측의 편집 버튼으로 이름을 변경할 수 있습니다.
4. 삭제할 그룹을 선택한 후 **선택 삭제** 버튼으로 그룹을 삭제할 수 있어요.

## 마스킹 해제하기

패널의 개인정보(이름, 이메일, 전화번호)를 열람하려면 마스킹을 해제해야 해요.

1. 패널 탭 상단의 **마스킹 해제** 버튼(자물쇠 아이콘)을 클릭합니다.
2. **해제 사유**를 입력합니다.
3. **마스킹 해제** 버튼을 클릭합니다.

![마스킹 해제 다이얼로그](/images/guides/workspace-panel/step-06-unmask.png)

마스킹이 해제되면 검색 기능도 활성화돼요.

<Callout type="warn" title="마스킹 해제 주의사항">
마스킹 해제 시 해제 사유가 기록됩니다. 불필요한 개인정보 열람을 삼가주세요.
</Callout>

## 필터 및 보기 설정

**필터**: 특정 그룹의 패널만 필터링해 볼 수 있어요.

**보기**: 패널 목록의 정렬 기준과 표시할 항목을 설정할 수 있어요.
- 정렬 기준: 생성일 (오름차순/내림차순)
- 표시 항목: 고객 키, 이름, 이메일, 전화번호, 그룹 각각 on/off 가능
