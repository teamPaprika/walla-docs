## 멤버 관리 (초대)

<img src="/images/guides/team-workspace/workspace-member-invite.png" alt="워크스페이스 설정 모달의 멤버 관리 탭에서 팀 멤버를 추가하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- '멤버 관리'를 누르면 팀 멤버를 워크스페이스로 초대할 수 있어요.
- Free 플랜은 팀 멤버 초대가 불가하므로 워크스페이스 초대 기능도 사용할 수 없습니다.

## 역할 및 권한

<img src="/images/guides/team-workspace/workspace-roles-permissions.png" alt="워크스페이스 설정 모달의 역할 및 권한 탭에서 Admin / Member 권한을 토글로 관리하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 역할은 Admin(관리자), Member(멤버)로 구분돼요.
- 역할별로 아래 기능에 대한 허용/제한을 설정할 수 있습니다.
<Callout title="권한으로 관리할 수 있는 기능">
- 역할 및 권한 편집: 역할 생성/수정, 권한 변경
- 역할 부여: 멤버에게 역할 할당
- 멤버 추가/삭제: 워크스페이스에 멤버 초대 또는 내보내기
- 프로젝트 관리: 프로젝트 이동, 복제, 삭제
- 프로젝트 편집: 프로젝트 내용 편집
- 응답 확인: 응답 관련 페이지 접근
- 응답 삭제: 수집된 응답 삭제
- 응답 다운로드: 응답 데이터 내보내기
- 마스킹 옵션 편집: 프로젝트 편집 시 마스킹 옵션 사용
- 마스킹 정보 접근 제한: 마스킹된 응답 열람 권한 제어
- 응답 자동 삭제 설정: 자동 삭제 기간 설정
</Callout>

## 워크스페이스 삭제하기

<img src="/images/guides/team-workspace/workspace-delete-menu.png" alt="워크스페이스 관리 목록에서 더보기 메뉴를 통해 워크스페이스 삭제를 선택하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

  - 좌측 상단의 '팀 관리 → 워크스페이스 관리'에서 '워크스페이스 삭제하기'를 누르면 워크스페이스가 삭제됩니다.

<Callout type="warn" title="주의">
워크스페이스 삭제는 되돌릴 수 없기 때문에, 필요한 데이터는 미리 백업하는 것을 권장드려요.
</Callout>

## 워크스페이스 소유주 변경

<img src="/images/guides/team-workspace/workspace-owner-transfer.png" alt="워크스페이스 관리 목록에서 더보기 메뉴를 통해 소유권 이전을 선택하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 좌측 상단의 '팀 관리 → 워크스페이스 관리'에서 팀 내의 워크스페이스 목록을 확인할 수 있으며, 각 워크스페이스의 소유주 변경이 가능합니다.
