워크스페이스 내 **멤버 관리**, **초대**, **역할 및 권한**은 워크스페이스 화면 우측 상단의 톱니바퀴(**워크스페이스 설정**) 아이콘을 눌러 한곳에서 관리합니다.

<img src="/images/guides/team-workspace/workspace-settings-button.png" alt="워크스페이스 화면 우측 상단의 워크스페이스 설정 톱니바퀴 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## 멤버 및 역할 관리하기

### 멤버 관리

**멤버 관리** 탭에서는 현재 워크스페이스에 속한 멤버 목록과 각 멤버의 역할을 확인하고, 역할 드롭다운이나 더보기(`⋯`) 메뉴로 역할을 변경하거나 워크스페이스에서 내보낼 수 있습니다.

<img src="/images/guides/team-workspace/workspace-member-invite.png" alt="워크스페이스 설정 모달의 멤버 관리 탭에서 멤버 목록과 역할을 관리하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

새로운 팀원을 추가하거나 이메일·초대 링크로 초대하려면 왼쪽 메뉴의 **초대** 탭(**초대 링크**, **초대하기**, **보낸 초대**)을 이용하세요. 자세한 절차는 [워크스페이스 멤버 초대하기](/ko/docs/help-center/team-workspace/inviting-workspace-members)를 참고해 주세요.

### 역할 및 권한

**역할 및 권한** 탭에서는 역할별로 **프로젝트**(10종), **개인정보**(3종), **고급**(4종) 권한을 설정합니다. Free · Pro 플랜에서는 관리자와 멤버가 같은 워크스페이스 권한을 가지며, **Enterprise 플랜**에서는 **역할 추가**, **미지정** 역할 사용, 역할별 권한 커스터마이징과 **프로젝트별 설정에 따름** 위임까지 사용할 수 있습니다.

<img src="/images/guides/team-workspace/workspace-roles-permissions.png" alt="워크스페이스 설정 모달의 역할 및 권한 탭에서 사용자 지정 역할의 권한 설정을 편집하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

각 역할을 선택해 상단의 **멤버 목록** 탭으로 전환하면 해당 역할이 부여된 멤버를 조회하고 **멤버 추가** 버튼으로 다른 멤버에게 역할을 바로 배정할 수 있습니다.

<img src="/images/guides/team-workspace/workspace-role-members.png" alt="워크스페이스 설정 모달의 역할 상세 화면에서 멤버 목록 탭을 통해 배정된 멤버를 관리하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

역할 체계와 17가지 세부 권한의 전체 설명은 [역할별 권한 관리](/ko/docs/help-center/security/managing-permissions)를 확인해 주세요.

## 워크스페이스 삭제 및 소유권 이전

워크스페이스를 삭제하거나 소유권을 넘기는 작업은 **소유자** 권한과 팀 관리 메뉴에서 제어합니다.

### 워크스페이스 삭제

- **워크스페이스 설정 모달 하단**: 워크스페이스 설정 왼쪽 메뉴 하단의 **워크스페이스 삭제** 버튼을 눌러 삭제할 수 있습니다. *(일반 멤버에게는 **워크스페이스 나가기**가 표시됩니다.)*
- **팀 관리 페이지**: 좌측 사이드바 **팀 관리 → 워크스페이스 관리** 목록에서 해당 워크스페이스 우측 더보기(`⋯`) 메뉴의 **삭제**를 선택할 수도 있습니다.

<img src="/images/guides/team-workspace/workspace-delete-menu.png" alt="워크스페이스 관리 목록에서 더보기 메뉴를 통해 워크스페이스 삭제를 선택하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<Callout type="warn" title="주의사항">
워크스페이스를 삭제하면 포함된 모든 프로젝트와 응답 데이터, 초대 링크가 함께 삭제되며 복구할 수 없습니다.
</Callout>

### 소유권 이전

현재 소유자를 다른 팀원에게 변경하려면 **팀 관리 → 워크스페이스 관리**에서 해당 워크스페이스의 더보기(`⋯`) 메뉴 → **소유권 이전**을 선택하세요.

<img src="/images/guides/team-workspace/workspace-owner-transfer.png" alt="워크스페이스 관리 목록에서 더보기 메뉴를 통해 소유권 이전을 선택하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
