## IP 주소 검증 활성화하기
- 프로젝트 설정 페이지에서 ‘IP 주소 검증’을 활성화하면 등록된 IP 주소만 설문에 접속할 수 있게 됩니다.
- IP 검증이 켜진 상태에서는 최소 하나 이상의 IP 주소를 반드시 등록해야 합니다.
## 허용된 IP 주소 / 범위 관리
- 아래 형식 중 하나로 IP 주소 또는 범위를 등록할 수 있습니다.
  - 개별 IP: `192.168.1.1`
  - CIDR 범위: `192.168.1.0/24` (192.168.1.0 ~ 192.168.1.255)
  - 와일드카드: `192.168.*.*` (192.168.0.0 ~ 192.168.255.255)
