## IP 접근 제한 활성화하기

<Steps>
  <Step>
    ### 보안 메뉴로 이동
    `팀 관리` → `보안` 화면으로 이동합니다.
  </Step>
  <Step>
    ### IP 접근 제한 활성화 및 허용 IP 등록
    `IP 접근 제한`을 활성화하고 허용할 IP 주소 또는 범위를 등록합니다. IP 접근 제한이 켜진 상태에서는 최소 하나 이상의 IP 주소 또는 범위를 반드시 등록해야 합니다.
  </Step>
  <Step>
    ### 적용 범위 확인 후 저장
    아래 적용 범위를 확인한 뒤 `변경사항 저장`을 누르면 적용됩니다. 이 설정은 팀의 **웹 대시보드와 관련 API** 접근을 제한하며, 설문 응답자가 설문에 참여하는 접속에는 적용되지 않습니다.
  </Step>
</Steps>

## 적용 범위
IP 접근 제한을 켜면 아래 연동 범위에 허용 IP 목록을 공통 적용할지 선택할 수 있습니다. 변경사항은 `변경사항 저장` 후 적용됩니다.

- `MCP 연동에도 적용`: 등록된 허용 IP 목록을 MCP 도구 호출에도 적용합니다.
- `Open API·응답 연동에도 적용`: 모든 Open API 호출(API 키 및 OAuth 토큰 포함)과 외부 연동의 응답 조회·첨부 파일 다운로드에 적용합니다.

IP 접근 제한을 처음 켤 때는 두 적용 범위가 기본으로 선택되어 있습니다.

<Callout type="warning" title="연동 중단 주의">
클라우드 연동은 호출 서버의 공인 IP 주소를 사용합니다. 적용 범위에 따라 제한을 적용하면 기존 연동이 중단될 수 있으므로, 연동 서버의 IP 주소를 함께 등록해 주세요.
</Callout>

## 허용 IP 목록 관리
아래 형식 중 하나로 IP 주소 또는 범위를 등록할 수 있습니다.

- 개별 IP: `192.168.1.1`
- CIDR 범위: `192.168.1.0/24` (192.168.1.0 ~ 192.168.1.255)
- 와일드카드: `192.168.*.*` (192.168.0.0 ~ 192.168.255.255)

<Callout type="warning" title="주의사항">
저장 전에 현재 접속 IP가 허용 목록에 포함되어 있는지 확인하세요. 포함되지 않으면 관리자도 팀에 접근할 수 없습니다.
</Callout>
