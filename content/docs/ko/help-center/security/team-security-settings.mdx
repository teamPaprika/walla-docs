`팀 관리` → `보안` 화면에서 팀 전체에 적용되는 보안 정책과 연동 접근 제어를 설정할 수 있습니다. 설정을 변경한 뒤에는 화면 하단의 `변경사항 저장` 버튼을 눌러야 실제로 적용됩니다.

<Callout title="참고">
대부분의 팀 보안 설정은 **Enterprise** 플랜에서 사용할 수 있습니다. 단, `Open API 허용`은 플랜과 관계없이 팀 관리자가 설정할 수 있으며, 이미 켜져 있는 `승인이 필요한 작업` 정책을 비활성화하는 것도 플랜과 무관하게 가능합니다.
</Callout>

## 설정 항목 안내

### 2차 인증 (MFA)
팀 멤버들에게 2차 인증 사용을 요구합니다. 활성화하면 2차 인증을 설정하지 않은 멤버는 인증을 완료해야 팀에 접근할 수 있습니다.
자세한 설정 절차는 [2차 인증](/ko/docs/help-center/security/two-factor-authentication) 가이드를 참고하세요.

### 로그인 세션 기간
팀 멤버의 개인 로그인 세션 기간을 팀에서 지정한 값 이하로 설정하도록 요구합니다. 기본값은 `각 멤버의 개인 설정 사용`이며, 팀 정책으로 특정 상한 기간을 정할 수 있습니다.
팀 허용 기간보다 길게 설정한 멤버는 개인 설정에서 세션 기간을 줄여야 팀에 접속할 수 있습니다.

### IP 접근 제한
웹 대시보드와 관련 API에 등록된 IP 주소에서만 접근할 수 있도록 제한합니다. 허용 IP 목록을 관리하고 MCP 연동 및 Open API·응답 연동에도 동일하게 적용할지 선택할 수 있습니다.
자세한 설정 방법은 [IP 접근 제한](/ko/docs/help-center/security/ip-address-verification) 가이드를 참고하세요.

### 응답 다운로드 사유 요청
팀원이 응답 데이터를 다운로드할 때 사유를 입력하도록 설정합니다. 입력된 사유는 [로그 기록](/ko/docs/help-center/security/activity-logs)에서 확인할 수 있습니다.

### 마스킹 해제 정보 복사 방지
응답 시트에서 마스킹을 해제한 응답값을 복사하거나 잘라낼 수 없도록 제한합니다.
데이터 마스킹에 대한 자세한 내용은 [데이터 마스킹](/ko/docs/help-center/security/data-masking) 가이드를 참고하세요.

### 자동화 사용 차단
웹훅, Zapier, Google Sheets, Gmail 자동화의 신규 사용과 실행 요청을 차단합니다.

### 외부 AI 사용 차단
켜면 AI 설문 생성과 왈라 AI 채팅 등 외부 AI를 사용하는 기능이 비활성화되며, 응답 데이터가 외부 LLM 제공자로 전송되지 않습니다.
자세한 내용은 [외부 AI 사용 차단](/ko/docs/help-center/security/blocking-external-ai) 가이드를 참고하세요.

### MCP(AI 연동) 허용
끄면 이 팀의 데이터에 대한 모든 MCP 도구 호출이 차단되고, AI 클라이언트의 팀 목록에서도 이 팀이 보이지 않습니다. 이 설정은 `외부 AI 사용 차단`과 별개로 동작합니다.

`MCP(AI 연동) 허용`이 켜져 있을 때는 아래 기능별로 허용 여부를 세밀하게 제어할 수 있습니다.

- `폼·워크스페이스 조회`: AI가 팀의 워크스페이스와 폼 구조를 읽을 수 있습니다.
- `응답 데이터 조회`: AI가 마스킹된 응답 데이터를 읽을 수 있습니다.
- `폼 생성·편집`: AI가 폼을 만들고 질문을 편집하고 게시할 수 있습니다.
- `자동화 관리`: AI가 자동화를 조회·생성·수정할 수 있습니다.

### Open API 허용
끄면 기존 API 키와 OAuth 토큰을 포함해 이 팀의 모든 Open API 호출이 차단됩니다. API 오류 응답에 대한 자세한 내용은 [오류 코드](/ko/docs/developer-docs/error-codes) 개발자 문서를 참고하세요.
이 설정은 플랜과 관계없이 팀 관리자가 변경할 수 있습니다.

### 승인이 필요한 작업
팀원 초대, 응답 다운로드, 응답 마스킹 해제, 설문 삭제처럼 민감한 작업을 수행하기 전에 관리자 승인을 받도록 설정할 수 있습니다.
자세한 운영 방법은 [승인이 필요한 작업](/ko/docs/help-center/security/approval-workflow) 가이드를 참고하세요.
