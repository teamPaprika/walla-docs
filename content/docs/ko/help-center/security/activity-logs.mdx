## 로그 기록 확인 방법

<Steps>
  <Step>
    ### 로그 기록 탭으로 이동
    팀 설정 페이지 → '로그 기록' 탭으로 이동합니다.
  </Step>
  <Step>
    ### 작업 내역 확인
    팀 내에서 이루어진 주요 작업 내역을 순서대로 확인할 수 있습니다.
  </Step>
  <Step>
    ### 로그 상세 정보 확인
    각 로그에는 작업자, 작업 시각, 수행된 액션이 기록돼요.
  </Step>
</Steps>
