## 설정 방법

1. 프로젝트 편집 화면으로 이동합니다.
2. 자동 삭제가 필요한 문항(예: 개인정보 입력 필드)을 선택합니다.
3. 옵션 하단의 ‘응답 자동 삭제’ 항목을 찾아 기간을 설정합니다.
  - 설정 가능한 기간: 3개월 ~ 5년
1. 설문을 게시하면 설정이 활성화되고, 해당 기간이 지난 응답은 자동으로 삭제됩니다.
## 작동 방식

- 선택한 기간이 지나면 해당 문항의 응답 데이터가 응답 시트에서 완전히 삭제됩니다.
- 삭제된 데이터는 복구가 불가능하며, 이후에는 다시 확인할 수 없습니다.
<Callout type="warning" title="주의사항">
- 자동 삭제는 문항 단위로 적용되므로, 개인정보를 수집하는 필드에는 반드시 보관 기간을 설정하는 걸 추천합니다.
- 삭제된 데이터는 법적으로 파기된 것으로 간주되므로 별도 백업이 필요하다면 기간 내에 데이터를 내려받으세요.
</Callout>
