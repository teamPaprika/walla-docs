## 데이터 마스킹하기
- 민감한 데이터를 마스킹 처리하고, 권한 있는 사용자만 원본을 확인할 수 있어요.
- 데이터 마스킹 활성화 후 프로젝트를 게시하면 해당 문항의 모든 응답이 마스킹 처리됩니다.
- 마스킹은 원본 데이터를 숨기는 기능이기 때문에, 한 번 설정하면 되돌릴 수 없어요.
## 마스킹된 데이터 확인하기
- 마스킹된 데이터는 응답 시트에서 열 제목 위에 마우스를 갖다대면 볼 수 있어요. (해당 권한이 있어야만 열람 가능)
- 만약 마스킹된 데이터를 열람해야 할 경우, 관리자의 보안 설정에 따라 해제 사유를 작성해야 해요. 작성된 해제 사유는 ‘팀 설정’의 ‘로그 기록’에서 확인할 수 있어요.
<Callout type="warning" title="주의사항">
- 한 번 마스킹을 활성화하면 절대 비활성화할 수 없습니다!
- 마스킹이 활성화된 문항에는 옵션별 응답 수 제한 기능을 설정할 수 없어요.
- 민감데이터를 수집해야 한다면, 마스킹을 먼저 활성화한 상태에서 수집하는 게 안전해요.
</Callout>
