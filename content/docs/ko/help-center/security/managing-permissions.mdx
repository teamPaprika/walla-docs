왈라(Walla)의 권한 체계는 **팀 권한**, **워크스페이스 역할 권한**, **개별 프로젝트 권한** 세 계층으로 동작합니다. 팀 전체의 보안·관리 기능은 팀 관리에서, 설문 생성·편집·응답 조회 및 다운로드 권한은 워크스페이스와 프로젝트 단위로 제어합니다.

## 플랜별 역할 권한 차이

| 구분 | Free · Pro 플랜 | Enterprise 플랜 |
| --- | --- | --- |
| **역할별 권한 편집** | 관리자와 멤버가 동일한 워크스페이스 권한 보유 (`소유자`·`관리자`·`멤버` 고정) | **역할 추가**, **미지정** 역할 사용, 역할별 권한 세분화 편집 가능 |
| **초대 기본 역할** | 멤버 *(초대 시 기본 적용)* | **미지정** *(초대 링크·초대하기 기본값)* |
| **권한 적용 범위** | 워크스페이스 전체 일괄 ON/OFF | 일부 프로젝트·응답 권한을 **프로젝트별 설정에 따름**으로 위임 가능 |
| **응답 접근 제어** | 미지원 | 역할별 조건부 응답 조회([응답 조회 관리](/ko/docs/help-center/security/response-access-control)) 지원 |

<Callout type="info" title="참고">
Free · Pro 플랜에서는 관리자와 멤버가 같은 워크스페이스 권한을 가지며, **역할 추가**·**미지정** 역할·역할별 권한 커스터마이징은 **Enterprise 플랜**에서 사용할 수 있습니다.
</Callout>

## 팀 권한

팀 전체에 걸친 멤버·결제·워크스페이스 생성·보안 설정 권한입니다. 좌측 사이드바의 **팀 관리 → 역할별 권한**에서 관리합니다.

<img src="/images/guides/team-workspace/team-roles-admin.png" alt="팀 관리의 역할별 권한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

| 권한 이름 | 설명 |
| --- | --- |
| **팀원 초대** | 이메일 또는 초대 링크로 팀원을 초대합니다. |
| **워크스페이스 생성** | 팀 내에 새 워크스페이스를 만듭니다. |
| **팀원 삭제** | 팀에서 기존 팀원을 내보냅니다. |
| **역할 변경** | 팀원의 팀 역할(관리자 · 멤버)을 변경합니다. |
| **팀 보안 설정** | 2차 인증(MFA), 로그인 세션 기간, IP 접근 제한, 외부 AI 사용 차단, 승인 워크플로우 등 팀 보안 정책을 설정합니다. |
| **결제 관리** | 팀 플랜 변경 및 결제 수단을 관리합니다. |
| **팀 로그 다운로드** | 팀 활동 로그를 내보냅니다. |

## 워크스페이스 역할

워크스페이스 내 설문과 응답에 대한 권한을 관리합니다. 워크스페이스 우측 상단 톱니바퀴(**워크스페이스 설정**) → **역할 및 권한**에서 확인합니다.

- **소유자 (Owner)**: 워크스페이스 생성자 또는 소유권을 이전받은 사용자로 모든 권한이 고정되어 있습니다.
- **관리자 (Admin)**: 프로젝트 관리 및 멤버·초대 관리를 포함한 대부분의 권한이 기본 활성화됩니다.
- **멤버 (Member)**: 프로젝트 생성·편집 및 응답 조회·다운로드 등 실무에 필요한 권한을 부여받습니다.
- **미지정 (Restricted / Unassigned)** *(Enterprise)*: 초대 시 기본 역할로 활용하며, 기본적으로 모든 프로젝트·응답 권한이 꺼진 상태에서 필요한 권한만 선별적으로 부여합니다.
- **사용자 지정 역할** *(Enterprise)*: **역할 추가** 버튼을 눌러 `서울 리서처`, `외부 감사`처럼 팀 목적에 맞는 새 역할을 만들고 **워크스페이스 권한**, **프로젝트별 권한**, **멤버 목록** 탭에서 세부 권한과 배정 멤버를 관리할 수 있습니다. *(역할에 **프로젝트별 설정에 따름**으로 지정된 권한이 하나 이상 있을 때 **프로젝트별 권한** 탭이 함께 표시됩니다.)*

## 워크스페이스 세부 권한 17종

워크스페이스 역할의 **워크스페이스 권한** 탭은 **프로젝트**, **개인정보**, **고급** 세 그룹으로 나뉩니다. *(Enterprise 플랜에서는 아래 표의 '프로젝트별 위임 가능' 열에 표시된 8가지 권한을 드롭다운에서 **모두 허용**, **프로젝트별 설정에 따름**, **허용 안 함** 중 하나로 설정할 수 있습니다.)*

### 프로젝트 (10개)

| 권한 이름 | 설명 | 프로젝트별 위임 가능 |
| --- | --- | --- |
| **프로젝트 생성** | 워크스페이스에 새 프로젝트를 생성할 수 있습니다. | 전체 허용/차단 |
| **프로젝트 복제** | 기존 프로젝트를 복제할 수 있습니다. | **프로젝트별 설정에 따름** 가능 |
| **프로젝트 관리** | 프로젝트를 이동, 보관, 삭제할 수 있습니다. | **프로젝트별 설정에 따름** 가능 |
| **프로젝트 편집** | 프로젝트를 편집하고 태그를 지정할 수 있습니다. | **프로젝트별 설정에 따름** 가능 |
| **태그 관리** | 워크스페이스 공용 태그를 만들고, 이름을 바꾸고, 삭제할 수 있습니다. | 전체 허용/차단 |
| **자동화 관리** | 자동화를 보고, 만들고, 수정하고, 삭제할 수 있습니다. *(실행 기록에서 과거 응답을 재발송하려면 ‘응답 확인’ 권한도 필요합니다.)* | **프로젝트별 설정에 따름** 가능 |
| **설문 발송** | 수신자를 등록, 수정, 삭제하고 설문을 발송할 수 있습니다. | **프로젝트별 설정에 따름** 가능 |
| **응답 보기** | 이 역할이 볼 수 있는 응답 범위입니다. **모두 허용**, **프로젝트별 설정에 따름**, **허용 안 함** 중 선택합니다. | **프로젝트별 설정에 따름** 가능 *(조건부 응답 접근 지원)* |
| **응답 삭제** | 설문 응답을 삭제할 수 있습니다. | **프로젝트별 설정에 따름** 가능 |
| **응답 다운로드** | 설문 응답을 CSV·Excel 등으로 다운로드할 수 있습니다. | **프로젝트별 설정에 따름** 가능 |

### 개인정보 (3개)

| 권한 이름 | 설명 |
| --- | --- |
| **마스킹 옵션 편집** | 문항별 [데이터 마스킹](/ko/docs/help-center/security/data-masking) 설정을 켜거나 끌 수 있습니다. |
| **마스킹된 응답 원문 접근** | 마스킹된 응답(`*****`)의 원문을 해제하여 확인할 수 있습니다. *(해제 시 사유 기록 및 승인 정책이 적용될 수 있습니다.)* |
| **응답 자동 삭제 설정** | 설문별 [응답 자동 삭제](/ko/docs/help-center/security/auto-delete-responses) 주기를 설정할 수 있습니다. |

### 고급 (4개)

| 권한 이름 | 설명 |
| --- | --- |
| **역할 및 권한 편집** | 워크스페이스 역할 추가·이름 변경·삭제 및 각 역할의 권한 구성을 수정합니다. |
| **역할 부여** | 워크스페이스 멤버와 초대의 역할을 변경합니다. |
| **멤버 추가** | 워크스페이스에 팀원을 추가하거나 새 멤버를 초대합니다. |
| **멤버 삭제** | 워크스페이스에서 기존 멤버를 내보냅니다. |

<Callout type="idea" title="참고">
특정 프로젝트에만 편집·다운로드·응답 삭제 권한을 열어 주거나 조건에 맞는 응답만 조회하도록 제한하려면 [프로젝트 권한](/ko/docs/help-center/manage-forms/project-permissions) 및 [응답 조회 관리](/ko/docs/help-center/security/response-access-control) 문서를 참고하세요.
</Callout>
