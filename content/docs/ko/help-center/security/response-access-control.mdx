같은 설문 프로젝트에 참여한 멤버라도 담당 지역·부서·점수 구간 등에 따라 **자신이 맡은 응답만 조회**해야 할 때가 있습니다. **Enterprise 플랜**의 응답 접근 제어 기능을 사용하면 서울 지역 담당 리서처에게 `거주 지역 = 서울`인 응답만 보여주고 경기·부산 응답은 숨기는 식으로 프로젝트별 응답 조회 범위를 제어할 수 있습니다.

응답 접근 제어는 다음 **2단계**로 적용됩니다.

1. **워크스페이스 역할 단계**: **워크스페이스 설정 → 역할 및 권한**에서 대상 역할의 **응답 보기** 드롭다운을 **프로젝트별 설정에 따름**으로 선택합니다.
2. **프로젝트 단계**: 설문 편집 화면 **설문 설정 → 프로젝트 권한**에서 대상 역할을 선택한 뒤, **응답 → 응답 보기** 드롭다운에서 **허용 안 함**, **모든 응답**, **조건에 맞는 응답** 중 하나를 지정하고 하단의 **저장하기**를 누릅니다.

## 조건 규칙 작성 방법

**조건에 맞는 응답**을 선택하면 **규칙**과 **조건**을 조합할 수 있습니다.

- **조건 (AND)**: 한 규칙 안에 여러 조건을 추가하면 **모든 조건을 동시에 만족**하는 응답만 허용됩니다. *(예: `거주 지역 다음 중 하나 이상 포함 [서울]` **그리고** `전반적인 만족도 이상 4`)*
- **규칙 (OR)**: **규칙 추가**로 별도 규칙을 추가하면 **어느 한 규칙이라도 만족**하는 응답을 볼 수 있습니다.
- **지원 필드 유형**: `제출 시각`, 객관식/드롭다운/선형배율 등 선택형 문항, 단답형 텍스트, 숫자, 날짜 문항 등을 기준으로 필터링할 수 있습니다.

<Callout type="warn" title="주의사항">
워크스페이스 역할에서 **응답 보기**를 **프로젝트별 설정에 따름**으로 바꾼 직후에는 개별 설문에 규칙을 저장하기 전까지 해당 역할 멤버가 응답을 볼 수 없습니다(**허용 안 함** 상태). 반드시 각 설문의 **설문 설정 → 프로젝트 권한 → 응답 → 응답 보기**에서 **모든 응답** 또는 **조건에 맞는 응답**을 선택해 **저장하기**를 눌러 주세요.
</Callout>

## 결과 보기·관리 화면에서의 동작 차이

응답 접근이 제한된 역할 멤버가 프로젝트 결과 화면에 접속하면 다음과 같이 동작합니다.

| 기능 영역 | 동작 방식 |
| --- | --- |
| **응답 시트** | 상단에 **접근할 수 있는 응답만 표시합니다.** 안내가 표시되며 조건을 만족하는 응답 행만 보입니다. *(검색 결과나 필터 조건과 겹치는 접근 가능 응답이 0건이면 "현재 필터에 해당하는 응답 중 접근할 수 있는 응답이 없습니다."가 표시됩니다.)* |
| **개별 응답 · 응답 통계** | 접근 가능한 응답만 집계·표시되므로 숨겨진 응답의 수치나 원문은 노출되지 않습니다. |
| **응답 다운로드 · 삭제** | 다운로드 또는 삭제 권한이 있더라도 접근 가능한 응답만 내려받거나 삭제할 수 있습니다. *(다운로드 가능한 응답이 0건이면 다운로드할 수 없습니다.)* |
| **애널리틱스 (방문·행동 분석)** | 방문 수·이탈률 등 전체 트래픽 지표가 응답 집합과 분리되어 노출되지 않도록 **방문·행동 분석을 제공하지 않습니다.** *(상단 배너에서 응답 통계로 이동하도록 안내합니다.)* |
| **프로젝트 워크스페이스 이동** | 다른 워크스페이스로 설문을 이동하면 기존 워크스페이스 역할 기준의 **응답 접근 규칙은 모두 삭제**됩니다. 이동 후 새 워크스페이스에서 규칙을 다시 설정해야 합니다. |

<Callout type="info" title="알아두세요">
응답 접근 정책을 저장하면 **설문 재게시 여부와 무관하게 즉시 적용**됩니다. 단, 이미 게시된 설문 문항 기준으로 조건 필드를 선택하므로 새 문항을 추가했다면 먼저 설문을 게시한 뒤 조건 규칙에서 선택하세요.
</Callout>
