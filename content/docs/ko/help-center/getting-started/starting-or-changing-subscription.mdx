## 플랜 구독 시작하기

<Steps>
  <Step>
    ### 팀 관리 탭 열기
    팀 설정 → `팀 관리` 탭으로 이동합니다.

    <img src="/images/guides/getting-started/team-management-tab.png" alt="팀 설정 사이드바의 팀 관리 → 팀 정보 메뉴" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 플랜 변경 클릭
    상단의 `플랜 변경` 버튼을 클릭합니다.

    <img src="/images/guides/getting-started/plan-change-button.png" alt="팀 정보 화면 플랜 영역의 플랜 변경 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 원하는 플랜 선택 및 적용
    가격정책 페이지를 참고해 원하는 플랜을 선택한 뒤, `플랜 적용` 버튼을 누르면 결제 페이지로 이동합니다.

    <img src="/images/guides/getting-started/plan-selection-modal.png" alt="Free / Pro / Enterprise 플랜을 비교해 선택할 수 있는 플랜 선택 모달" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 결제 정보 입력
    이메일, 카드 정보 등 결제 정보를 입력하면 구독이 시작됩니다. 프로모션 코드가 있는 경우 `프로모션 코드 추가`에 코드를 입력하면 할인된 가격으로 결제됩니다.

    <img src="/images/guides/getting-started/payment-checkout.png" alt="카드 정보를 입력하고 구독하기 버튼을 누르는 결제 페이지" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout type="info" title="참고">
왈라는 해외 PG사를 사용하고 있습니다. 
결제 전, 카드사 앱에서 '해외 원화 결제 차단' 설정을 반드시 해제해야 하며, 일부 카드사는 해외 결제 수수료가 부과될 수 있습니다.
</Callout>

    ### 팀 정보 페이지에서 구독 관리 버튼 클릭

    ### 활성 플랜 클릭

    <img src="/images/guides/getting-started/stripe-billing-portal.png" alt="Stripe 결제 관리 페이지에서 활성 플랜, 결제 방식, 청구 정보, 청구서 내역을 확인하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 플랜 취소 클릭

    <img src="/images/guides/getting-started/stripe-plan-cancel-button.png" alt="Pro 플랜 상세 화면에서 플랜 업데이트와 플랜 취소 버튼이 표시된 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<Callout type="warn" title="주의사항">
- 결제 시점에 해외 원화 결제 차단이 설정되어 있으면 결제가 실패할 수 있습니다.
- 다운그레이드 시 팀 구성원과 응답 데이터에 영향이 있으니 반드시 백업과 용량 정리를 먼저 진행한 뒤 변경하세요.
- 변경 전, [가격정책 페이지](https://home.walla.my/ko/pricing/main)에서 각 플랜의 세부 기능을 꼭 확인하세요.
</Callout>
