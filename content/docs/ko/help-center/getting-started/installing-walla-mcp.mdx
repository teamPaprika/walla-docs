왈라는 MCP(Model Context Protocol) 서버를 제공합니다. ChatGPT나 Claude에 왈라 MCP를 연결하면, AI와 대화하면서 바로 왈라의 폼과 응답을 조회하거나 새 폼을 만들거나, 커스텀 필드를 만들 수 있어요.
## Chat GPT 플러그인 연결하기
<Steps>
  <Step>
    ### 왈라 플러그인 설치
    ChatGPT의 왈라 플러그인 페이지에서 `플러그인 설치`를 클릭합니다.

    <img src="/images/guides/getting-started/chatgpt-plugin-01-install.png" alt="ChatGPT의 Walla 플러그인 페이지에서 플러그인 설치 버튼 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 왈라 계정으로 로그인
    사용하는 계정에 맞춰 `Google 계정으로 로그인`, `SSO로 로그인`, `이메일로 로그인` 중 하나를 선택합니다.

    <img src="/images/guides/getting-started/chatgpt-plugin-02-sign-in.png" alt="Walla 로그인 페이지에서 로그인 방식 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 접근 권한 허용
    '앱 접근 권한 요청' 화면에서 ChatGPT가 요청하는 권한을 확인한 뒤 `허용`을 클릭합니다.

    <img src="/images/guides/getting-started/chatgpt-plugin-03-authorize.png" alt="Walla 앱 접근 권한 요청 화면에서 허용 버튼 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 설치 완료 확인
    설치 완료 안내가 나타나면 `채팅에서 사용해 보기`를 클릭해 왈라 플러그인을 시작합니다.

    <img src="/images/guides/getting-started/chatgpt-plugin-04-installed.png" alt="Walla 플러그인 설치 완료 후 채팅에서 사용해 보기 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Claude 커넥터 연결하기

Claude는 [디렉터리의 Walla 페이지](https://claude.ai/directory/walla-form)에서 커넥터를 추가해 연결할 수 있어요.

<Steps>
  <Step>
    ### Walla 디렉터리 페이지 열기
    [Claude의 Walla 페이지](https://claude.ai/directory/walla-form)를 엽니다. Claude에 로그인한 뒤 `Claude에 연결` 버튼을 클릭합니다.

    <img src="/images/guides/getting-started/claude-directory-01-connect.png" alt="Walla 디렉터리 페이지에서 Claude에 연결 버튼 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 왈라 계정으로 로그인
    왈라 로그인 화면이 나타나면 사용하는 계정에 맞춰 Google, SSO, 이메일 중 하나로 로그인합니다. 이미 로그인되어 있다면 다음 단계로 넘어갑니다.

    <img src="/images/guides/getting-started/claude-directory-02-sign-in.png" alt="Walla 로그인 화면에서 Google, SSO, 이메일 로그인 중 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 접근 권한 허용
    '앱 접근 권한 요청' 화면에서 Claude가 요청하는 권한을 확인한 뒤 `허용`을 클릭합니다.

    <img src="/images/guides/getting-started/claude-directory-03-authorize.png" alt="Claude 앱 접근 권한 요청 화면에서 허용 버튼 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 연결 확인
    Walla 디렉터리 페이지에 `연결됨`이 표시되면 연결이 완료된 상태입니다. 대화에서 Walla 도구를 사용해 폼을 조회하거나 새 폼을 만들어보세요.

    <img src="/images/guides/getting-started/claude-directory-04-connected.png" alt="Walla 디렉터리 페이지에 연결됨 상태 표시" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
