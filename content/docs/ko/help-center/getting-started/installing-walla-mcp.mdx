title: 왈라 MCP 설치하기
description: 왈라 MCP를 Claude에 커스텀 커넥터로 연결하면, Claude에서 바로 왈라의 폼과 응답 데이터를 다룰 수 있어요.
---

import { Step, Steps } from 'fumadocs-ui/components/steps';

왈라는 MCP(Model Context Protocol) 서버를 제공합니다. Claude에 왈라 MCP를 커스텀 커넥터로 연결하면, Claude와 대화하면서 바로 왈라의 폼과 응답을 조회하거나 새 폼을 만들거나, 커스텀 필드를 만들 수 있어요.

<Steps>
  <Step>
    ### 커넥터 설정 열기
    [claude.ai](https://claude.ai) 접속 후, 왼쪽 사이드바에서 `Customize` 메뉴를 연 뒤 `Connectors` 메뉴로 이동합니다.

    <img src="/images/guides/getting-started/mcp-01-connectors.png" alt="Customize 화면에서 Connectors 메뉴로 이동" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 커스텀 커넥터 추가 시작
    Connectors 화면 오른쪽 위의 더하기 버튼을 누르고 `Add custom connector`를 선택합니다.

    <img src="/images/guides/getting-started/mcp-02-add-custom-connector.png" alt="더하기 버튼 메뉴에서 Add custom connector 선택" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 커넥터 정보 입력
    `Add custom connector` 창에 아래 정보를 입력한 뒤 `Add` 버튼을 클릭합니다. OAuth 항목은 비워두어도 됩니다.

    - 이름(Name): Walla Form (왈라)
    - Remote MCP server URL: {"https://app.walla.my/api/mcp"}

    <img src="/images/guides/getting-started/mcp-03-connector-info.png" alt="Add custom connector 창에 이름과 URL 입력 후 Add 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 왈라 계정 연결
    목록에 추가된 Walla Form (왈라) 커넥터를 선택한 뒤 `Connect` 버튼을 클릭합니다.

    <img src="/images/guides/getting-started/mcp-04-connect.png" alt="Walla Form 커넥터에서 Connect 버튼 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 접근 권한 허용
    '앱 접근 권한 요청' 화면에서 Claude가 요청하는 권한(프로젝트 읽기, 프로젝트 응답 읽기, 프로젝트 응답 다운로드, 프로젝트 쓰기, 오프라인 접근)을 확인한 뒤 `허용`을 클릭합니다.

    <img src="/images/guides/getting-started/mcp-05-authorize.png" alt="앱 접근 권한 요청 화면에서 허용 클릭" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 연결 확인
    연결이 완료되면 커넥터가 Connected 상태로 바뀝니다. 오른쪽 패널에서 Claude가 사용할 수 있는 도구 목록과 권한을 확인할 수 있어요.

    <img src="/images/guides/getting-started/mcp-06-connected.png" alt="연결 완료 후 Walla Form 커넥터의 도구 목록과 권한" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
