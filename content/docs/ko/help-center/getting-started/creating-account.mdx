## 회원가입한 후 로그인하기

- 이메일, 이름, 비밀번호를 입력해 간단히 회원가입할 수 있습니다.
- 회원가입 후에는 입력한 이메일과 비밀번호로 로그인하면 됩니다.

## Google 계정으로 로그인하기

- 로그인 화면에서 'Google 계정으로 로그인' 버튼을 눌러주세요.
- 구글 계정을 선택하면 바로 접속됩니다.

## 회사 SSO로 로그인하기

SSO(통합 로그인)는 회사에서 사용하는 계정으로 왈라에 로그인하는 방법이에요. 회사에서 왈라 SSO 연결을 설정한 경우에 사용할 수 있습니다.

1. 왈라 로그인 화면에서 `SSO로 로그인`을 클릭합니다.
2. 회사에서 사용하는 이메일 주소를 입력한 뒤 `계속하기`를 누릅니다.
3. 회사의 인증 화면으로 이동하면 회사 계정으로 로그인합니다. 추가 인증이 필요한 경우 화면의 안내를 따라주세요.
4. 인증을 마치면 왈라로 돌아옵니다. 처음 이용하는 경우 표시되는 가입 절차도 완료해주세요.

<Callout type="info" title="회사에서 SSO 설정이 먼저 필요해요">
회사 이메일 주소만으로 SSO를 이용할 수 있는 것은 아니에요. 회사에서 해당 이메일 도메인의 SSO 연결을 설정했는지 관리자에게 확인해주세요.
</Callout>

### SSO 로그인이 되지 않을 때

- 입력한 회사 이메일 주소에 오타가 없는지 확인해주세요.
- SSO가 설정되지 않았다는 안내가 나오거나 회사 인증에 실패하면, 회사 관리자에게 SSO 연결 상태와 해당 계정의 이용 권한을 확인해주세요.
- `SSO로 로그인` 버튼이 보이지 않으면 다른 로그인 입력 화면에서 뒤로가기를 눌러 로그인 방법 선택 화면으로 돌아와 확인해주세요. 그래도 보이지 않으면 회사 관리자에게 이용 중인 환경의 SSO 지원 여부를 문의해주세요.
