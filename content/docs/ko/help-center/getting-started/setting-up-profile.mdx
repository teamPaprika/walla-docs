---

## 프로필 설정

- 프로필 아이콘을 클릭하면 현재 로그인된 계정을 확인할 수 있습니다.
- 이름이나 프로필 이미지를 수정해 계정을 원하는 대로 설정할 수 있습니다.

## 로그인 세션

- 로그인 세션 기간을 지정해두면, 설정된 기간이 지나면 자동으로 로그아웃됩니다.
- 이 기능은 보안을 위해 로그인 상태를 일정 기간 후 자동으로 해제하는 용도로 사용합니다.

## 2단계 인증(보안 강화)

- 계정 보안을 강화하고 싶다면 2차 인증(2FA) 기능을 설정할 수 있습니다.
- 로그인 시 추가 인증 단계를 거쳐, 계정을 더 안전하게 보호할 수 있습니다.

## 맞춤 정보 알림 받기

- 왈라에서 보내는 유용한 소식이나 업데이트 소식을 받고 싶다면 '맞춤 정보 알림 받기' 옵션을 활성화해주세요.

## 언어

- 왈라에서 사용할 언어를 자유롭게 선택하실 수 있습니다.  
- 설문에 참여하는 응답자에게는 해당 설정과 관계없이 각 응답자의 브라우저 언어 환경에 맞는 설문이 자동으로 노출됩니다.
