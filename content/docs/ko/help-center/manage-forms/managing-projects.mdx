## 프로젝트 이동하기

- 프로젝트는 같은 팀 내의 워크스페이스 간의 이동만 가능합니다.
- 다른 팀의 워크스페이스로는 이동할 수 없어요.
- 이동하려면 프로젝트 카드의 `...`(더보기) → '워크스페이스 이동'를 눌러 옮길 워크스페이스를 선택하면 됩니다.

<img src="/images/guides/manage-forms/project-move.png" alt="프로젝트 카드 더보기 메뉴에서 워크스페이스 이동" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## 프로젝트 삭제 및 복구하기

- 워크스페이스 → 프로젝트 카드의 `...`(더보기) 클릭
  - **보관함으로 이동**: 프로젝트가 보관함으로 옮겨지며, 이후 보관함에서 다시 복구할 수 있습니다.
  - **삭제하기**: 프로젝트가 완전히 삭제됩니다.
    <Callout type="warning" title="주의사항">보관함으로 이동한 프로젝트는 워크스페이스로 복구할 수 있지만, 프로젝트를 삭제한 경우에는 **절대 복구가 불가능**하니 신중히 진행해주세요.</Callout>

<img src="/images/guides/manage-forms/project-delete.png" alt="프로젝트 카드 더보기 메뉴에서 삭제" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## 프로젝트 복제하기

- `...`(더보기) → `복제하기`를 클릭하면 동일한 구조의 새 프로젝트가 생성됩니다.
- 복제된 프로젝트 이름 앞에는 자동으로 (Copy)가 붙습니다.
- 복제된 프로젝트는 미게시 상태이며, 커스텀 URL, 자동화 설정 등 게시 후 항목은 복제되지 않습니다.

<img src="/images/guides/manage-forms/project-duplicate.png" alt="프로젝트 카드 더보기 메뉴에서 복제하기" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## 프로젝트 정보 수정하기

- 프로젝트 카드의 `정보 수정` 버튼을 클릭하면 프로젝트의 이름, 아이콘, 색상을 변경할 수 있습니다.

<img src="/images/guides/manage-forms/rename-project-menu.png" alt="프로젝트 카드 더보기 메뉴에서 프로젝트 정보 수정" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<Callout title="팁">
실수로 삭제하지 않도록, 삭제 전에는 꼭 보관함으로 이동 → 확인 후 삭제 순서로 진행하는 걸 추천드립니다.
</Callout>
