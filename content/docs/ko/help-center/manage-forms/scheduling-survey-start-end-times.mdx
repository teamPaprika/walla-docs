## 설문 시작 예약

- 프로젝트 편집 화면 → 우측 상단 `⚙️` 버튼을 눌러 설정 탭으로 이동하세요.
- 설문 시작 시간을 현재 시각 이후로 설정하면 지정된 시각에 설문이 자동으로 공개됩니다.

## 설문 종료 예약

- 같은 설정 화면에서 '설문 마감'을 선택하면 설문이 자동으로 종료될 시간을 예약할 수 있습니다.
- 마감 예약 또한 현재 시각 이후로만 설정 가능합니다.
