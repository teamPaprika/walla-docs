## 설정 방법

<Steps>
  <Step>
    ### 설정 탭으로 이동
    프로젝트 편집 화면에서 우측 상단 `⚙️` 버튼을 눌러 설정 탭으로 이동합니다.

    <img src="/images/guides/manage-forms/settings-button.png" alt="설정 탭으로 이동" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 중복 응답 방지 활성화
    '중복 응답 방지' 스위치를 활성화해주세요.

    <img src="/images/guides/manage-forms/prevent-duplicate.png" alt="중복 응답 방지" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## 동작 방식

- 해당 설문에서 이미 응답 기록이 있는 참여자는 링크에 다시 접속해도 응답할 수 없습니다.
- 응답 완료 이후에는 설문 페이지가 열리지 않으며, "이미 응답을 제출했습니다"와 같은 안내 메시지가 표시됩니다.

<Callout title="팁">
중복 응답 방지를 '이메일 로그인 요청' 기능과 함께 사용하면, Google 계정 기준으로 응답을 제한해 더 정확하게 중복을 방지할 수 있어요.
</Callout>
