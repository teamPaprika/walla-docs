## 중복 응답 제한하기
같은 사람이 같은 설문에 여러 번 응답하는 것을 막고 싶을 때 중복 응답 제한 기능을 사용하면 돼요.
제한 방식은 두 가지이고, 둘을 함께 켤 수도 있습니다.

|방식|기준|특징|
|---|---|---|
|브라우저 중복 응답 방지|응답자의 브라우저|설정이 간편하지만, 다른 브라우저나 시크릿 모드로는 다시 응답할 수 있습니다|
|인증된 사용자당 1회|인증된 이메일, 전화번호 또는 외부 회원 ID|기기를 바꿔도 제한이 유지됩니다|

## 설정 방법

<Steps>
  <Step>
    ### 응답자 탭으로 이동
    편집 화면 우측 상단의 `⚙️` 아이콘을 눌러 설문 설정을 열고, 좌측 탭 목록에서 `응답자`를 선택합니다.

    <img src="/images/guides/manage-forms/duplicate-response-settings.png" alt="프로젝트 편집 화면 우측 상단의 설문 설정 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>

  <Step>
    ### 제한 방식 선택
    `중복 응답` 섹션에서 원하는 토글을 켭니다. 섹션 상단의 요약 문장으로 현재 설정 상태를 바로 확인할 수 있습니다.


|설정 상태|표시되는 요약 문장|
|---|---|
|아무것도 켜지 않음|같은 사람이 여러 번 응답할 수 있습니다|
|`인증된 사용자당 1회` 켜짐|인증된 이메일, 전화번호 또는 외부 회원 ID마다 한 번만 응답할 수 있습니다|



### 1. 브라우저 중복 응답 방지

<img src="/images/guides/manage-forms/duplicate-response-browser.png" alt="설문 설정 응답자 탭에서 브라우저 중복 응답 방지를 활성화한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 같은 브라우저에서 이미 응답을 마친 경우 다시 응답할 수 없습니다.
- 응답 완료 이후에는 설문 페이지가 열리지 않으며, 이미 응답을 제출했다는 안내 메시지가 표시됩니다.
- 다른 브라우저나 기기, 시크릿 모드에서는 다시 응답할 수 있습니다.

<img src="/images/guides/manage-forms/duplicate-blocked.png" alt="중복 응답 제한 안내" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

### 2. 인증된 사용자당 1회

<img src="/images/guides/manage-forms/duplicate-response-authenticated-user.png" alt="설문 설정 응답자 탭에서 인증된 사용자당 1회를 활성화한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- 인증된 이메일, 전화번호 또는 외부 회원 ID를 기준으로 한 번만 응답할 수 있습니다. 기기나 브라우저를 바꿔도 제한이 유지되므로 더 정확하게 중복을 막을 수 있어요.

- 이 토글을 켜려면 응답자를 식별할 수단이 필요합니다. 인증 수단이 없는 상태에서 켜면 이메일 인증이 함께 켜집니다.

- 식별 기준은 설정에 따라 달라집니다.
	- `응답자` 탭에서 이메일 인증을 사용하는 경우 → 인증된 이메일 주소
	- `응답자` 탭에서 전화번호 인증을 사용하는 경우 → 인증된 전화번호
	- `임베드` 탭에서 호스트 서명 토큰 + 회원 식별을 사용하는 경우 → 토큰에 담긴 외부 회원 ID

<Callout title="알아두세요">
`사용자 인증`을 끄면 `인증된 사용자당 1회`도 함께 꺼집니다. 인증 설정을 껐다 켠 경우에는 중복 제한이 풀려 있지 않은지 다시 확인해 주세요.
</Callout>

  </Step>
</Steps>
