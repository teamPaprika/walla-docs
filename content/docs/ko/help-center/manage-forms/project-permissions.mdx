**Enterprise 플랜** 팀에서 워크스페이스 역할 관리 또는 프로젝트 권한 관리 권한을 가진 소유자·관리자 및 허용된 역할은 개별 설문의 **설문 설정 → 프로젝트 권한** 탭에서 역할별 작업 권한과 응답 접근 범위를 설문마다 다르게 지정할 수 있습니다.

## 프로젝트 권한 설정 둘러보기

아래 인터랙티브 투어에서 **설문 설정 → 프로젝트 권한** 진입과 설정 흐름을 단계별로 눌러 확인해 보세요.

<InteractiveTour tourId="project-permissions" />

## 이 프로젝트의 역할 권한

워크스페이스 **역할 및 권한**에서 아래 7가지 프로젝트 단위 권한 중 하나 이상을 **프로젝트별 설정에 따름**으로 지정하면, 해당 역할이 **이 프로젝트의 역할 권한** 목록에 표시됩니다.

<img src="/images/guides/tours/project-permissions/step-03.png" alt="설문 설정 프로젝트 권한 탭의 이 프로젝트의 역할 권한 섹션에서 서울 리서처 역할의 프로젝트 편집·응답 다운로드 토글을 켠 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

이 화면에서 켤 수 있는 7가지 권한은 다음과 같습니다.

| 권한 이름 | 설명 |
| --- | --- |
| **프로젝트 복제** | 이 프로젝트를 복제할 수 있습니다. |
| **프로젝트 관리** | 이 프로젝트를 이동, 보관, 삭제할 수 있습니다. |
| **프로젝트 편집** | 이 프로젝트를 편집하고 태그를 지정할 수 있습니다. |
| **자동화 관리** | 이 프로젝트의 자동화를 보고, 만들고, 수정하고, 삭제할 수 있습니다. |
| **설문 발송** | 이 프로젝트에서 수신자를 등록, 수정, 삭제하고 설문을 발송할 수 있습니다. |
| **응답 삭제** | 이 프로젝트의 응답을 삭제할 수 있습니다. |
| **응답 다운로드** | 이 프로젝트의 응답을 다운로드할 수 있습니다. |

<Callout type="warn" title="알아두세요">
워크스페이스 역할 설정에서 이미 **허용(모든 프로젝트)** 또는 **허용 안 함**으로 고정한 권한은 개별 프로젝트 설정에 나타나지 않습니다. 해당 권한의 적용 범위를 프로젝트별로 바꾸려면 먼저 [워크스페이스 설정 → 역할 및 권한](/ko/docs/help-center/team-workspace/managing-workspaces)에서 **프로젝트별 설정에 따름**으로 변경해 주세요.
</Callout>

원하는 역할의 토글을 켠 뒤 **저장하기**를 누르면 변경 사항이 바로 적용됩니다.

## 응답 접근

**응답 접근** 섹션에서는 워크스페이스 역할 설정에서 **모든 응답 보기**를 **프로젝트별 설정에 따름**으로 지정한 역할이 이 설문에서 어떤 응답까지 볼 수 있는지 설정합니다.

- **허용 안 함**: 이 설문의 응답을 볼 수 없습니다. (기본 상태)
- **모든 응답**: 이 설문의 모든 응답을 볼 수 있습니다.
- **조건에 맞는 응답**: 지정한 조건 규칙을 만족하는 응답만 조회할 수 있습니다.

설문 내 응답 삭제·다운로드 권한이 있더라도 실제 삭제·다운로드 가능 범위는 여기서 허용된 응답 집합 안으로 제한됩니다.

조건 규칙 작성법, 응답 시트·통계·방문·행동 분석에서의 동작은 [응답 조회 관리](/ko/docs/help-center/security/response-access-control) 가이드에서 자세히 확인하세요.
