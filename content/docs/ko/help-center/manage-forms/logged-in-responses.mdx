## 설정 방법
<Steps>
  <Step>
    ### 설문 설정 진입
    편집 화면 우측 상단의 `⚙️` 아이콘을 클릭해 설문 설정을 엽니다.

    <img src="/images/guides/manage-forms/duplicate-response-settings.png" alt="프로젝트 편집 화면 우측 상단의 설문 설정 버튼" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>

  <Step>
    ### 응답 탭으로 이동
    좌측 탭 목록에서 `응답자`를 선택합니다.

    <img src="/images/guides/manage-forms/logged-in-response-tab.png" alt="설문 설정에서 응답자 탭이 강조된 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>

  <Step>
    ### 사용자 인증 활성화
    `인증` 섹션의 `사용자 인증`을 켭니다. 토글을 켜면 인증 수단을 고르는 선택지가 나타납니다.

    <img src="/images/guides/manage-forms/logged-in-user-authentication.png" alt="설문 설정 응답자 탭에서 사용자 인증을 활성화한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    |인증 수단|응답자가 겪는 과정|
|---|---|
|`이메일`|이메일 주소 입력 → 메일로 받은 인증 코드 입력|
|`전화번호`|전화번호 입력 → 문자로 받은 인증 코드 입력|
  </Step>

  <Step>
    ### 적용 완료
    인증을 마친 사람만 설문에 들어올 수 있습니다.
  </Step>
</Steps>

## 특정 응답자만 허용하기
<img src="/images/guides/manage-forms/logged-in-specific-respondents.png" alt="특정 이메일과 도메인만 허용하도록 설정한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
### 이메일·도메인 허용
- `특정 이메일·도메인 허용`을 켜고 입력란에 값을 넣습니다.

	- 개별 주소를 허용할 때: `user@example.com`
	- 도메인 전체를 허용할 때: `@example.com`
		- 사내 구성원 전체를 대상으로 하는 설문이라면 도메인 형식이 편리합니다.

	- 비워두면 모든 이메일을 허용합니다.
### 전화번호 허용
- `특정 전화번호 허용`을 켜고 국가번호를 포함한 형식으로 입력합니다.
- 비워두면 모든 번호를 허용합니다.

## 인증 화면 안내 문구 바꾸기
- 응답자가 보는 인증 화면에는 기본 안내 문구가 표시됩니다. 문구를 직접 작성하고 싶다면 응답자 탭 맨 위의 `인증 화면 안내`를 켜세요.
- 토글을 꺼두면 기본 안내 문구가 표시됩니다.
- 안내 문구는 이 위치에 표시됩니다.

<img src="/images/guides/manage-forms/logged-in-auth-screen-message.png" alt="설문 설정 응답자 탭에서 인증 화면 안내 문구를 활성화한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<img src="/images/guides/manage-forms/logged-in-email-verification-screen.png" alt="응답자에게 표시되는 이메일 인증 필요 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />


## 인증된 사용자당 한 번만 받기
- 인증을 켠 것만으로는 같은 사람이 여러 번 응답할 수 있습니다. 한 사람이 한 번만 응답하게 하려면 `중복 응답` 섹션의 `인증된 사용자당 1회`를 함께 켜세요.
- 인증된 이메일, 전화번호 또는 외부 회원 ID를 기준으로 한 번만 응답할 수 있게 됩니다.
- 현재 설정 상태는 `중복 응답` 섹션 상단의 요약 문장으로 언제든 확인할 수 있어요.

<img src="/images/guides/manage-forms/logged-in-once-per-user.png" alt="사용자 인증과 인증된 사용자당 1회를 함께 활성화한 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

|설정 상태|표시되는 요약 문장|
|---|---|
|아무것도 켜지 않음|같은 사람이 여러 번 응답할 수 있습니다|
|`인증된 사용자당 1회` 켜짐|인증된 이메일, 전화번호 또는 외부 회원 ID마다 한 번만 응답할 수 있습니다|

<Callout title="알아두세요">
`인증된 사용자당 1회`를 인증 수단 없이 켜면 이메일 인증이 함께 켜집니다. 반대로 `사용자 인증`을 끄면 `인증된 사용자당 1회`도 함께 꺼져요. 인증 설정을 껐다 켠 경우에는 중복 제한이 풀려 있지 않은지 다시 확인해 주세요.
</Callout>
