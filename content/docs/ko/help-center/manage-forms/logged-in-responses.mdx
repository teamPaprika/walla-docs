## 로그인하여 응답하기
<Steps>
  <Step>
    ### 설문 설정 진입
    편집 화면 우측 상단의 `⚙️` 아이콘을 클릭해 설문 설정을 엽니다.

    <img src="/images/guides/manage-forms/logged-in-settings-button.png" alt="편집 화면 우측 상단의 설문 설정 톱니바퀴 아이콘" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 응답 탭으로 이동
    좌측 탭 목록에서 `응답`을 선택합니다.

    <img src="/images/guides/manage-forms/logged-in-response-tab.png" alt="설문 설정 모달에서 응답 탭이 선택된 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 이메일 로그인 요구 활성화
    `중복 응답 방지`와`이메일 로그인 요구`를 활성화합니다.

    <img src="/images/guides/manage-forms/logged-in-toggle.png" alt="중복 응답 방지와 이메일 로그인 요구 토글이 모두 켜진 상태" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 응답자) 이메일 인증 요청
    응답자가 설문 링크에 접속하면, 응답 전에 이메일 주소를 입력하고 인증 코드를 받아야 하는 화면이 표시됩니다.

    <img src="/images/guides/manage-forms/logged-in-email-prompt.png" alt="응답자 화면에서 이메일 인증이 필요하다는 안내와 이메일 입력란이 표시된 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/manage-forms/logged-in-verification-email.png" alt="응답자에게 발송된 Walla 이메일 인증 메일에 6자리 인증 코드가 표시된 모습" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### 응답자) 인증 코드 입력
    응답자가 메일로 전송된 인증 코드를 입력하고 `인증하기`를 누르면, 본 설문 응답을 시작할 수 있어요.

    <img src="/images/guides/manage-forms/logged-in-code-input.png" alt="응답자가 받은 인증 코드를 입력하는 화면" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
