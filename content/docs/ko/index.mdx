# Walla Open API 문서

Walla Open API 문서에 오신 것을 환영합니다. 이 API를 사용하면 Walla 폼을 프로그래밍 방식으로 관리하고, 워크스페이스를 관리하며, 폼을 발송하고, 응답을 수집할 수 있습니다.

## 개요

Walla Open API는 RESTful API로, 다음과 같은 기능을 제공합니다:

- **워크스페이스 관리**: 워크스페이스 정보를 조회합니다
- **폼 관리**: 폼 데이터 및 설정에 접근하고 조회합니다
- **폼 발송**: 이메일 또는 SMS를 통해 수신자에게 폼을 배포합니다
- **응답 추적**: 폼 응답 및 제출 데이터를 모니터링하고 조회합니다

## 리소스 계층 구조

Walla API는 리소스를 계층적 구조로 구성합니다:

```
Team → Workspace → Form → Response
```

- **Team(팀)**: 최상위 조직 단위입니다. API 키는 팀 수준에서 생성되며 자동으로 팀 컨텍스트를 포함합니다.
- **Workspace(워크스페이스)**: 팀 내에서 폼과 프로젝트를 구성하는 컨테이너입니다.
- **Form(폼)**: 워크스페이스 내에서 생성된 설문 또는 폼입니다.
- **Response(응답)**: 폼에 대해 받은 개별 제출입니다.

**중요**: API 키는 팀 범위로 지정되므로 API 요청에 팀 정보를 제공할 필요가 없습니다. 팀 컨텍스트는 API 키에서 자동으로 결정됩니다.

## 기본 URL

모든 API 요청은 다음 주소로 보내야 합니다:

```
https://api.walla.my/open-api/v1
```

## 주요 기능

### 워크스페이스 관리
접근 권한이 있는 모든 워크스페이스를 조회하고 특정 워크스페이스에 대한 상세 정보를 확인할 수 있습니다.

### 폼 관리
폼에 접근하고, 폼 설정을 확인하며, 제출 수를 포함한 폼 분석 데이터를 조회할 수 있습니다.

### 폼 발송
여러 수신자에게 맞춤형 이메일 제목과 메시지로 폼을 발송할 수 있습니다. 발송 상태를 추적하고 수신자의 참여도를 모니터링합니다.

### 응답 수집
페이지네이션을 지원하여 폼 응답을 조회할 수 있습니다. 고객 키 및 제출 타임스탬프를 포함한 상세 응답 데이터에 접근할 수 있습니다.

## API 사양

- **버전**: 1.0
- **프로토콜**: HTTPS
- **데이터 형식**: JSON
- **인증**: API 키 (헤더를 통한 인증)

## 지원

문제, 질문 또는 기능 요청이 있으시면 Walla 지원팀에 문의하거나 포괄적인 API 문서를 참조하십시오.

## API 엔드포인트 개요

| 카테고리 | 엔드포인트 | 설명 |
|---------|-----------|------|
| 워크스페이스 | `GET /workspaces` | 모든 워크스페이스 조회 |
| 워크스페이스 | `GET /workspaces/{workspaceId}` | 특정 워크스페이스 조회 |
| 워크스페이스 | `GET /workspaces/{workspaceId}/forms` | 워크스페이스 내 폼 목록 조회 |
| 폼 | `GET /forms` | 모든 폼 조회 |
| 폼 | `GET /forms/{formId}` | 특정 폼 조회 |
| 필드 | `GET /field-output-schemas` | 필드 출력 스키마 조회 |
| 필드 | `GET /forms/{formId}/fields` | 폼 필드 목록 조회 |
| 필드 | `GET /forms/{formId}/fields/{fieldId}` | 특정 필드 상세 정보 조회 |
| 필드 | `GET /forms/{formId}/fields/{fieldId}/description` | 필드 설명 조회 |
| 발송 | `POST /forms/{formId}/delivery` | 폼 발송 |
| 발송 | `GET /forms/{formId}/delivery` | 발송 수신자 목록 조회 |
| 발송 | `POST /forms/{formId}/delivery/status` | 발송 상태 조회 |
| 응답 | `GET /forms/{formId}/responses` | 폼 응답 목록 조회 (페이지네이션) |
| 응답 | `GET /forms/{formId}/responses/{responseId}` | 특정 응답 조회 |
