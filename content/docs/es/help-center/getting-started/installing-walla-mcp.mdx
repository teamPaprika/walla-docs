Walla ofrece un servidor MCP (Model Context Protocol). Al conectar el MCP de Walla a ChatGPT o Claude, podrás consultar formularios y respuestas, crear formularios nuevos o construir campos personalizados mientras conversas con tu asistente de IA.

## Conecta el plugin de ChatGPT
<Steps>
  <Step>
    ### Instala el plugin de Walla
    En la página del plugin de Walla en ChatGPT, pulsa `Instalar plugin`.

    <img src="/images/guides/getting-started/chatgpt-plugin-01-install.png" alt="Botón para instalar el plugin de Walla en ChatGPT" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Inicia sesión en tu cuenta de Walla
    Elige el método que corresponda a tu cuenta: Google, SSO o correo electrónico.

    <img src="/images/guides/getting-started/chatgpt-plugin-02-sign-in.png" alt="Selección del método de inicio de sesión en Walla" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Concede los permisos
    En la pantalla de autorización, revisa los permisos solicitados por ChatGPT y pulsa `Permitir`.

    <img src="/images/guides/getting-started/chatgpt-plugin-03-authorize.png" alt="Botón Permitir en la pantalla de autorización de Walla" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Comprueba la instalación
    Cuando aparezca la confirmación, pulsa `Probar en el chat` para empezar a usar el plugin de Walla.

    <img src="/images/guides/getting-started/chatgpt-plugin-04-installed.png" alt="Confirmación de instalación del plugin de Walla" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Conecta el conector de Claude

Añade y conecta Walla desde la [página de Walla en el directorio de Claude](https://claude.ai/directory/walla-form).

<Steps>
  <Step>
    ### Abre la página de Walla en el directorio
    Abre la [página de Walla en Claude](https://claude.ai/directory/walla-form). Inicia sesión en Claude y pulsa `Conectar a Claude`.

    <img src="/images/guides/getting-started/claude-directory-01-connect.png" alt="Pulsa Conectar a Claude en la página de Walla en el directorio" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Inicia sesión en tu cuenta de Walla
    Si aparece la pantalla de inicio de sesión de Walla, accede con Google, SSO o correo electrónico, según tu cuenta. Si ya has iniciado sesión, continúa con el siguiente paso.

    <img src="/images/guides/getting-started/claude-directory-02-sign-in.png" alt="Elige Google, SSO o correo electrónico en la pantalla de acceso a Walla" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Concede los permisos
    En la pantalla de autorización, revisa los permisos solicitados por Claude y pulsa `Permitir`.

    <img src="/images/guides/getting-started/claude-directory-03-authorize.png" alt="Pulsa Permitir en la pantalla de autorización de Claude" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Comprueba la conexión
    Cuando la página de Walla en el directorio muestre `Conectado`, la conexión estará completa. Usa las herramientas de Walla en la conversación para consultar formularios o crear uno nuevo.

    <img src="/images/guides/getting-started/claude-directory-04-connected.png" alt="La página de Walla en el directorio muestra el estado Conectado" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
