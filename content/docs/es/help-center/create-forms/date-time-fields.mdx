---
title: Campos de fecha y hora
description: Puedes hacer que quien responde elija directamente una fecha o una hora en el formulario.
---

## Campo de fecha

- Permite elegir la fecha que se quiera.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Opciones configurables
  - Obligatorio
  - Enmascarado de datos
  - Borrado automático de respuestas

## Campo de hora

- Permite elegir la hora que se quiera.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Opciones configurables
  - Obligatorio
  - Enmascarado de datos
  - Borrado automático de respuestas

<Callout title="Consejo">
Los campos de fecha y hora resultan muy útiles en formularios relacionados con el tiempo: solicitudes de reserva, coordinación de horarios o inscripción a eventos.
</Callout>
