## Campo desplegable

- Es un campo para elegir una sola opción de una lista que se puede plegar y desplegar.
- Resulta útil cuando quieres aprovechar bien el espacio.
- Con el botón `Editar opciones` de abajo a la izquierda puedes añadir opciones nuevas.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Al pulsar el botón `…` (más) de abajo a la derecha puedes usar estas funciones.
  - Añadir opciones en bloque: introduce varias opciones a la vez. *(separa cada opción con un salto de línea)*
  - Definir el valor de la opción: asigna tú el valor de cada opción. (Ejemplo: si defines la primera opción como «1», en la hoja de respuestas aparecerá 1)

- Este campo permite elegir varias opciones de una lista desplegable. Aunque haya muchas opciones, puedes contraer la lista para mantener la pantalla despejada.
- Con el botón `Editar opciones` de abajo a la izquierda puedes añadir opciones nuevas.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Al pulsar el botón `…` (más) de abajo a la derecha puedes usar estas funciones.
  - Añadir opciones en bloque: introduce varias opciones a la vez. *(separa cada opción con un salto de línea)*
  - Definir el valor de la opción: asigna tú el valor de cada opción. (Ejemplo: si defines la primera opción como «1», en la hoja de respuestas aparecerá 1)

## Campo de escala lineal

- Es un campo de selección tipo escala numérica, ideal para encuestas de satisfacción o de valoración.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Puedes definir tú el valor mínimo y el máximo:
  - el mínimo puede ser 1 o 0,
  - y el máximo, de 2 a 10.

- En los extremos puedes escribir una etiqueta mínima y otra máxima para explicar con claridad el significado de cada número.
