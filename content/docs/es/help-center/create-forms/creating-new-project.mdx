## Cómo crear un proyecto

<Steps>
  <Step>
    ### Pulsa el botón Crear proyecto
    En la pantalla del espacio de trabajo, haz clic en `Crear proyecto`.
  </Step>
  <Step>
    ### Configura el proyecto
    Define el nombre del proyecto y las etiquetas.
  </Step>
  <Step>
    ### Creación completada
    Pulsa el botón `Crear proyecto` y el nuevo proyecto se añadirá al espacio de trabajo.
  </Step>
</Steps>

<Callout title="Ten en cuenta">
Puedes crear varios proyectos dentro de un mismo espacio de trabajo y gestionar distintos formularios a la vez.
</Callout>
