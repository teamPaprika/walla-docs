import { Step, Steps } from 'fumadocs-ui/components/steps';

## Crear una plantilla de equipo

<Steps>
  <Step>
    ### Ve a la biblioteca de plantillas
    Accede a la biblioteca de plantillas.
  </Step>
  <Step>
    ### Importa una plantilla
    Pulsa el botón `Importar plantilla`.
  </Step>
  <Step>
    ### Elige un proyecto
    Selecciona el proyecto que quieres usar como plantilla.
  </Step>
  <Step>
    ### Configura las opciones y guarda
    Si lo necesitas, indica si quieres importarla como copia, la orientación de la vista previa (vista estándar o agrupada) y una descripción; después pulsa `Importar` para guardarla como plantilla de equipo.
  </Step>
</Steps>

- Una vez importada, la plantilla pasa a ser un recurso compartido del equipo y todos sus miembros pueden usarla.

## Usar una plantilla de equipo

<Steps>
  <Step>
    ### Crea un proyecto nuevo
    Crea un proyecto nuevo.
  </Step>
  <Step>
    ### Selecciona Usar plantilla
    Elige `Usar plantilla`.
  </Step>
  <Step>
    ### Elige plantillas de equipo
    Selecciona las plantillas de equipo en la lista de plantillas.
  </Step>
  <Step>
    ### Elige la plantilla que quieras
    Selecciona la plantilla de equipo que prefieras y pulsa `Usar plantilla`.
  </Step>
  <Step>
    ### Listo
    Se crea un proyecto nuevo a partir de la plantilla elegida.
  </Step>
</Steps>

## Cuándo conviene usarlas

- Formularios de uso frecuente, como consultas de clientes, solicitudes de información o encuestas de satisfacción
- Formularios cuyo formato debe unificarse a nivel de empresa o de equipo
- Cuando necesitas una plantilla de referencia para que las personas nuevas creen formularios rápidamente

<Callout title="Consejo">
- Las plantillas de equipo son un recurso compartido, así que te recomendamos no guardar como plantilla proyectos innecesarios.
- Los proyectos creados a partir de una plantilla se editan de forma independiente de la plantilla original.
</Callout>
