---
title: Campos de texto corto, texto largo, número y tabla
description: Son campos de respuesta abierta que rellena quien responde. Puedes elegir uno u otro según la longitud o el formato del contenido.
---

## Campo de texto corto

- Se usa para recoger respuestas breves, de una línea aproximadamente.
- Va bien para nombres, profesiones u opiniones cortas.
- Pulsa el icono del lápiz para cambiar el texto de marcador de posición.
- Opciones configurables
  - Obligatorio
  - Longitud de la respuesta
  - Contenido obligatorio
  - Contenido prohibido
  - Expresión regular

## Campo de texto largo

- Se usa para recoger respuestas largas, de varias líneas.
- Va bien para opiniones detalladas, comentarios y respuestas descriptivas.
- Pulsa el icono del lápiz para cambiar el texto de marcador de posición.
- Opciones configurables
  - Obligatorio
  - Longitud de la respuesta
  - Contenido obligatorio
  - Contenido prohibido
  - Expresión regular

## Campo numérico

- Es un campo exclusivo para introducir números.
- Úsalo para recoger cantidades, edades, puntuaciones y otros valores numéricos.
- Pulsa el icono del lápiz para cambiar el texto de marcador de posición.
- Opciones configurables
  - Obligatorio
  - Rango numérico

<Callout type="warning" title="Advertencia">
Si recoges teléfonos con un campo numérico, los números que empiezan por «0» (010AAAABBBB) se interpretan como cifras y el 0 inicial desaparece automáticamente. Para los teléfonos usa el campo de texto corto o el campo específico de teléfono.
</Callout>

## Campo de tabla

- Es un campo que permite recoger varias respuestas abiertas a la vez en formato de tabla.
- Puedes repartir los elementos en filas y columnas, lo que resulta útil para comparar o evaluar muchos elementos al mismo tiempo.
- Opciones configurables
  - Obligatorio
