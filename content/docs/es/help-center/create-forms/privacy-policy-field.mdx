---
title: Campo de consentimiento de datos personales
description: Es el campo que se usa para obtener el consentimiento de recogida de datos personales y de cesión a terceros. Muestra de un vistazo la información legal obligatoria y recoge el consentimiento de quien responde.
---

## Campo de consentimiento de datos personales

- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Este campo incluye de forma predeterminada lo siguiente.
  - Recogida y uso de datos personales
    - Datos recogidos
    - Finalidad de la recogida y el uso
    - Periodo de conservación

  - Tratamiento de datos sensibles
    - Datos recogidos
    - Finalidad de la recogida
    - Periodo de conservación

  - Cesión de datos personales a terceros
    - Destinatario
    - Finalidad de la cesión
    - Datos cedidos
    - Periodo de conservación

- Al pulsar el botón `…` (más) de abajo a la derecha puedes usar estas funciones.
  - Añadir opciones en bloque: introduce varias opciones a la vez. *(separa cada opción con un salto de línea)*
  - Definir el valor de la opción: asigna tú el valor de cada opción. (Ejemplo: si defines la primera opción como «1», en la hoja de respuestas aparecerá 1)

## Combinarlo con la lógica

- El campo de consentimiento resulta mucho más útil combinado con la lógica.
- Por ejemplo:
  - Si eligen «No acepto» → dirígelos a un campo de descarte para no recoger la respuesta
  - Si eligen «Acepto» → continúa hacia las preguntas que recogen datos personales
Con esta configuración puedes controlar el flujo de forma natural según lo que elija cada persona.

<Callout title="Consejo">
Si usas la lógica, solo quienes elijan «Acepto» pasarán a la siguiente pregunta, y el flujo del formulario quedará mucho más ordenado.
</Callout>

<Callout type="warning" title="Advertencia">
El campo de consentimiento debe incluir siempre la información legal obligatoria y hay que adaptarlo para que coincida con la finalidad real de la recogida. Los datos personales recogidos deben destruirse una vez transcurrido el periodo de conservación indicado. ¡Prueba la función «Borrado automático de respuestas»!
</Callout>
