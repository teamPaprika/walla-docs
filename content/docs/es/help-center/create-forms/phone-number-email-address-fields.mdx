## Campo de teléfono

- Permite introducir un número de teléfono.
- Pulsa el icono de la bandera para cambiar al formato telefónico de otro país.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- El formato por defecto es el de móvil coreano (010-0000-0000).
- Opciones configurables
  - Obligatorio
  - Longitud de la respuesta
  - Contenido obligatorio o prohibido
  - Expresión regular (Regex)
  - Verificación de teléfono obligatoria
  - Enmascarado de datos
  - Borrado automático de respuestas

### Verificación de teléfono obligatoria

- Al activar «Verificación de teléfono obligatoria», solo se recogen números de teléfono que existen realmente.
- Quien responde debe verificar su número con un código SMS antes de enviar.
- Para la verificación, el número se envía a nuestro proveedor de SMS (Twilio Inc., Estados Unidos).

<Steps>
  <Step>
    #### Activa la verificación de teléfono obligatoria
  </Step>
  <Step>
    #### Al responder, se introduce el teléfono y se pulsa el botón de verificar
  </Step>
  <Step>
    #### Se envía el código de verificación
  </Step>
  <Step>
    #### Se confirma la verificación
  </Step>
</Steps>

## Campo de correo electrónico

- Permite introducir una dirección de correo electrónico.
- Debe seguir el formato `~~~@~~~.~~~`; si no coincide, no se puede enviar la respuesta.
- Con el [editor de texto](/es/docs/help-center/create-forms/editing-field-text) puedes aplicar estilos como color, tamaño y grosor de letra.
- También puedes insertar imágenes, tablas o títulos fácilmente con los [comandos de barra (/)](/es/docs/help-center/create-forms/editing-field-text).
- Pulsa el icono del lápiz para cambiar el texto de marcador de posición.
- Opciones configurables
  - Obligatorio
  - Longitud de la respuesta
  - Contenido obligatorio o prohibido
  - Expresión regular (Regex)
  - Requerir verificación de correo electrónico
  - Enmascarado de datos
  - Borrado automático de respuestas

### Verificación de correo electrónico

Activa `Requerir verificación de correo electrónico` para que quien responde verifique la dirección introducida con un código de 6 dígitos antes de enviarla como respuesta. Además de comprobar el formato del correo, esta opción permite confirmar que la persona puede acceder a ese buzón.

<Steps>
  <Step>
    #### Activa la verificación de correo electrónico

    Selecciona el campo de correo en el editor del formulario y activa `Requerir verificación de correo electrónico` en el panel de ajustes de la derecha. Publica el formulario para aplicar la configuración actualizada a quienes respondan.

    <img src="/images/guides/create-forms/email-verification-enable.png" alt="Activar la verificación de correo en los ajustes del campo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Introduce el correo y pulsa Verify

    Quien responde introduce una dirección de correo electrónico y pulsa `Verify` junto al campo.

    <img src="/images/guides/create-forms/email-verification-start.png" alt="Introducir una dirección de correo y seleccionar el botón de verificación" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Envía el código de verificación

    En la ventana de verificación, comprueba la dirección y pulsa `Send code`. Se enviará un código de verificación de 6 dígitos a la dirección introducida.

    <img src="/images/guides/create-forms/email-verification-send-code.png" alt="Seleccionar el botón para enviar el código en la ventana de verificación" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Introduce el código y confirma la verificación

    Introduce el código de 6 dígitos recibido por correo y pulsa `Verify`. Cuando la verificación se complete correctamente, aparecerá `Verified` debajo del campo de correo.

    <img src="/images/guides/create-forms/email-verification-enter-code.png" alt="Introducir el código de 6 dígitos recibido por correo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/create-forms/email-verification-complete.png" alt="Estado de verificación completada debajo del campo de correo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

- **Si cambia la dirección de correo**: es necesario verificar de nuevo la dirección modificada.
- **Si el código no es válido o ha caducado**: comprueba la dirección de correo y el código introducido. Una vez transcurrido el tiempo de espera para el reenvío, pulsa `Resend code` para recibir un código nuevo.
- **Combínalo con Obligatorio**: si necesitas recoger una dirección de correo de cada persona, activa también `Obligatorio`. Una pregunta opcional con verificación de correo puede enviarse en blanco.

<Callout type="info" title="Compruébalo en el formulario publicado">
La vista previa no envía correos de verificación. Abre el formulario publicado para probar el proceso real. Esta opción verifica la dirección introducida en un campo de correo y es independiente de la verificación de correo de los permisos de acceso al formulario.
</Callout>

## Campo de dirección

- Solo admite direcciones de Corea; tras buscar la dirección se puede añadir el detalle.
- Opciones configurables
  - Obligatorio
  - Enmascarado de datos
  - Borrado automático de respuestas

<Callout title="Consejo">
Para proteger los datos personales, te recomendamos activar el enmascarado de datos y el borrado automático de respuestas en los campos de teléfono, correo y dirección.
</Callout>
