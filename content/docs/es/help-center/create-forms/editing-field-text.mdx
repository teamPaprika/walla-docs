---
title: Editar el texto de los campos
description: Cuando quieras destacar el texto del formulario o mejorar su presentación, usa las funciones de edición para aplicar distintos estilos y formatos.
---

## Aplicar estilos de texto

- Escribe el texto y selecciónalo arrastrando para aplicarle un estilo.
- Los estilos de texto disponibles son:
  - Estilos de título
  - Estilos de cuerpo
  - Estilos especiales (cita, énfasis, etc.)
- Tipografía: puedes elegir entre 8 tipografías latinas.
- Tamaño de letra: hay 5 tamaños disponibles.
- También cuentas con varias opciones para que el texto destaque más.
  - Color de resaltado
  - Color de texto
  - Añadir enlaces
  - Insertar notas
  - Alineación del texto (izquierda, derecha, centro)

## Usar funciones adicionales con el comando barra (/)

- Al escribir «/» (barra) en el teclado puedes insertar los siguientes contenidos.
  - Títulos 1, 2 y 3
  - Listas con viñetas, listas numeradas, listas de tareas y texto plegable
  - Citas
  - Bloques de código
  - Tablas
  - Doble columna
  - Inserción de imágenes y ajuste de tamaño
  - Separadores
