title: "Verificación de dirección IP"
description: "La verificación de dirección IP restringe el acceso al proyecto a las direcciones IP o rangos de red que indiques."
---

## Activar la verificación de dirección IP
- Al activar «Verificación de dirección IP» en la página de ajustes del proyecto, solo se podrá acceder al formulario desde las IP registradas.
- Con la verificación de IP activada hay que registrar como mínimo una dirección.
## Gestionar las IP y rangos permitidos
- Puedes registrar direcciones o rangos con cualquiera de estos formatos.
  - IP individual: `192.168.1.1`
  - Rango CIDR: `192.168.1.0/24` (de 192.168.1.0 a 192.168.1.255)
  - Comodín: `192.168.*.*` (de 192.168.0.0 a 192.168.255.255)
