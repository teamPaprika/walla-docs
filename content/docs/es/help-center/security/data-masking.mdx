## Aplicar el enmascarado de datos

- Los datos sensibles se enmascaran y solo quienes tienen permiso pueden ver el valor original.
- Si activas el enmascarado y publicas el proyecto, todas las respuestas de esa pregunta quedarán enmascaradas.
- Como el enmascarado oculta los datos originales, una vez configurado no se puede deshacer.

## Consultar los datos enmascarados
- Para ver los datos enmascarados, pasa el ratón por el título de la columna en la hoja de respuestas. (Solo pueden verlos quienes tengan ese permiso.)
- Si necesitas consultarlos, según los ajustes de seguridad del administrador puede que tengas que indicar un motivo. Ese motivo queda registrado en «Registros de actividad», dentro de «Configuración del equipo».

<Callout type="warning" title="Advertencia">
- Una vez activado el enmascarado, ¡no se puede desactivar nunca!
- En las preguntas con enmascarado activado no se puede usar el límite de respuestas por opción.
- Si vas a recoger datos sensibles, lo más seguro es activar el enmascarado antes de empezar a recogerlos.
</Callout>
