## Bloquear el uso de IA externa
Al activar `Bloquear el uso de IA externa` en `Gestión del equipo` → `Seguridad`, se deshabilitan las funciones que usan IA externa —como [Crear formularios con IA](/es/docs/help-center/create-forms/creating-project-ai) y el chat de Walla AI— y se impide que los datos de respuesta del equipo se envíen a proveedores de LLM externos.

Esta configuración es independiente de `Permitir MCP (conector de IA)` en la [Configuración de seguridad del equipo](/es/docs/help-center/security/team-security-settings). Bloquear el uso de IA externa no desactiva las integraciones MCP.
