## Bloquear el uso de IA externa
Al activar la opción `Bloquear el uso de IA externa`, los datos de respuesta de este equipo dejan de enviarse a proveedores de LLM externos como OpenAI. Con esta opción activada, la función [Crear formularios con IA](/es/docs/help-center/create-forms/creating-project-ai) queda desactivada.
