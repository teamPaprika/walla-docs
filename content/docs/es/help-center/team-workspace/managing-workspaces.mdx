## Gestión de miembros (invitaciones)

- Al pulsar «Gestión de miembros» puedes invitar a miembros del equipo al espacio de trabajo.
- El plan Free no permite invitar a miembros del equipo, por lo que tampoco puede usar las invitaciones a espacios de trabajo.

## Roles y permisos

- Los roles se dividen en Admin (administrador) y Member (miembro).
- Puedes permitir o restringir las siguientes funciones para cada rol.
<Callout title="Funciones que se gestionan con permisos">
- Editar roles y permisos: crear o modificar roles y cambiar permisos
- Asignar roles: asignar un rol a un miembro
- Añadir o eliminar miembros: invitar o expulsar personas del espacio de trabajo
- Gestión de proyectos: mover, duplicar y eliminar proyectos
- Edición de proyectos: editar el contenido del proyecto
- Ver respuestas: acceder a las páginas relacionadas con las respuestas
- Eliminar respuestas: borrar las respuestas recogidas
- Descargar respuestas: exportar los datos de respuestas
- Editar opciones de enmascarado: usar las opciones de enmascarado al editar el proyecto
- Restringir acceso a datos enmascarados: controlar quién puede ver las respuestas enmascaradas
- Configurar el borrado automático: definir el periodo de borrado automático
</Callout>

## Eliminar un espacio de trabajo

  - En «Gestión del equipo → Gestión de espacios de trabajo» (arriba a la izquierda), pulsa «Eliminar espacio de trabajo».

<Callout type="warn" title="Atención">
La eliminación de un espacio de trabajo no se puede deshacer, así que te recomendamos hacer una copia de seguridad de los datos que necesites.
</Callout>

## Cambiar el propietario del espacio de trabajo

- En «Gestión del equipo → Gestión de espacios de trabajo» (arriba a la izquierda) puedes ver la lista de espacios del equipo y cambiar el propietario de cada uno.
