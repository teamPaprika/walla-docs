## Compartilhar por URL

Copie o link do formulário e cole no canal desejado, como mensagens, e-mail ou redes sociais, para enviá-lo aos participantes.

### Copiar a URL
Clique no ícone de cópia ao lado do link para copiar a URL da visualização padrão ou agrupada.

<img src="/images/guides/share-forms/share-copy-link.png" alt="Ícone de cópia em destaque na seção de links do formulário" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Abrir a URL em uma nova janela
Clique no ícone de seta para abrir o formulário em uma nova janela e conferir a tela que os participantes verão.

<img src="/images/guides/share-forms/share-open-new-tab.png" alt="Ícone de seta para abrir em nova janela em destaque na seção de links" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## Compartilhar por QR code

Transforme a URL em um QR code para facilitar o acesso em locais físicos, como cartazes, panfletos e lojas.

### Abrir o QR code
Clique no ícone de QR code para visualizá-lo e baixá-lo.

<img src="/images/guides/share-forms/share-qr-code.png" alt="Ícone de QR code em destaque na seção de links do formulário" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## Incorporar por código

Copie o código iframe para seu site ou página de destino, permitindo que os participantes preencham o formulário sem sair da página.

### Copiar o código de incorporação
Clique no ícone `<>` para exibir o código de incorporação do formulário.

<img src="/images/guides/share-forms/share-embed-code.png" alt="Ícone de incorporação em destaque na seção de links do formulário" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
