## Adicionar um item de rastreamento (campo oculto)

<Steps>
  <Step>
    ### Abra o gerenciamento de rastreamento
    Na página de compartilhamento, clique em `Gerenciar`.

    <img src="/images/guides/share-forms/tracking-01-manage.png" alt="Abrir o gerenciamento de rastreamento" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Informe o item de rastreamento
    Digite o nome de rastreamento (nome do campo oculto) e pressione Enter para criar o item.

    <img src="/images/guides/share-forms/tracking-02-input.png" alt="Entrada do item de rastreamento" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Salve
    Clique em `Salvar`.

    <img src="/images/guides/share-forms/tracking-03-save.png" alt="Salvar" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Use os campos
    Os campos ocultos cadastrados funcionam como categorias para identificar a origem do acesso.
    - ① Identificar a rede social de origem → use `SNS` como nome do campo oculto (por exemplo, Instagram ou YouTube).
    - ② Separar por grupo de clientes → use `customer` como nome do campo oculto.

    <img src="/images/guides/share-forms/tracking-04-fields.png" alt="Campos ocultos cadastrados" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
## Criar uma URL com campos ocultos

Depois de configurar os campos ocultos, adicione-os manualmente ao link (URL) do formulário.

<Steps>
  <Step>
    ### Prepare a URL base do formulário
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4
    ```
  </Step>
  <Step>
    ### Adicione o nome do campo oculto
    Adicione-o no formato `?nome_do_campo=`.
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=
    ```
  </Step>
  <Step>
    ### Informe o valor do campo
    Exemplo de acesso pelo YouTube:
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?source=youtube
    ```
  </Step>
  <Step>
    ### Compartilhe um link para cada canal
    Ao compartilhar cada link no canal correspondente, a planilha de respostas mostrará a origem do acesso, como YouTube ou Instagram.
  </Step>
</Steps>
## Usar vários campos ocultos

- Para adicionar vários campos ocultos à URL, use '&' para conectar os seguintes, em vez de '?'.
```
https://walla.my/v/QA9S0imWeo232fSbd4?source=instagram&media=video
```
→ Isso indica um acesso por anúncio em vídeo no Instagram.
<Callout type="warning" title="Atenção">
- Pressione Enter ao cadastrar um item de rastreamento para salvá-lo.
- Recomendamos usar apenas letras sem acentos (A–Z, a–z), números e sublinhado (_) nos nomes dos campos ocultos.
</Callout>
<Callout title="Dica">
Para criar muitas URLs com campos ocultos, faça uma cópia do [modelo de gerador de links no Google Sheets](https://docs.google.com/spreadsheets/d/14F7iSY6yNiEV78eceveOkPNCTHzaMK5LIEqtYE4bo_I/edit?usp=sharing).
</Callout>

## Criar condições de lógica com campos ocultos

Você pode direcionar o respondente para outra pergunta conforme o valor do campo oculto.

<Steps>
  <Step>
    ### Cadastre o campo oculto
    Cadastre o campo oculto `utm_source` e salve.
  </Step>
  <Step>
    ### Crie o link
    Adicione o valor ao link que será usado no anúncio.
    ```
    https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads
    ```
  </Step>
  <Step>
    ### Crie a condição de lógica
    Na tela de lógica, escolha `utm_source` como pergunta de referência.
    Escolha a condição `Igual a` e digite `ads` como valor de comparação.
  </Step>
  <Step>
    ### Escolha a pergunta de destino
    Escolha a pergunta para a qual irá quem chegou pelo anúncio.
  </Step>
</Steps>

- O valor do campo oculto é comparado como texto.
- Se o link não tiver valor para o campo oculto, o valor fica vazio. Nesse caso, a condição não é atendida, nem mesmo com `Diferente de`.
- Antes de publicar, você pode testar a condição na visualização do editor do projeto. Na barra de endereços do navegador, adicione `?utm_source=ads` ao final do endereço do editor e abra a visualização. Se o endereço já tiver `?`, adicione `&utm_source=ads`.
- Depois de publicar, abra o link com o valor e o link sem o valor para conferir.
- Não é possível escolher um campo oculto como destino.
- Veja os detalhes em [Criar condições com campos ocultos, em Configurar a lógica](/pt-BR/docs/help-center/create-forms/setting-up-logic#criar-condições-com-campos-ocultos).

## Excluir um campo oculto usado na lógica

Não é possível excluir um campo oculto usado em uma condição de lógica.
Se você excluir o campo e salvar, aparece `Não é possível excluir um campo oculto usado em uma condição. Altere a condição primeiro.`.
Também não é possível excluí-lo se ele for usado na lógica de um formulário já publicado.

<Steps>
  <Step>
    ### Altere a condição
    Na tela de lógica, encontre a condição que usa esse campo oculto.
    Exclua a condição ou troque a pergunta de referência.
  </Step>
  <Step>
    ### Publique novamente
    Se o formulário publicado também tinha essa condição, publique-o novamente com a lógica alterada.
  </Step>
  <Step>
    ### Exclua o campo oculto
    No gerenciamento de rastreamento, exclua o campo oculto e clique em `Salvar`.
  </Step>
</Steps>
