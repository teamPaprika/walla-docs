## Personalizar o botão Próximo →

- Na visualização agrupada, o formulário é dividido em páginas conforme os grupos do editor. O botão 'Próximo →' permite avançar para a próxima página.
- **Para ocultar esse botão**

<Steps>
  <Step>
    ### Abra a personalização de botão
    Clique em `Personalização de botão` na parte superior do editor do projeto.
  </Step>
  <Step>
    ### Ative Ocultar botão
    Na seção `Botão`, ative `Ocultar botão`.
  </Step>
</Steps>

- Para **usar outro texto** no lugar de 'Próximo →', preencha o campo 'Editar texto do botão'.

## Personalizar o botão Enviar resposta

- O texto padrão é 'Enviar resposta'.
- Para alterá-lo, clique no botão e digite diretamente o texto desejado.

<img src="/images/guides/manage-forms/submit-button-edit.png" alt="Edição do texto do botão Enviar resposta na parte inferior do editor" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<img src="/images/guides/manage-forms/submit-button-result.png" alt="Botão de envio do formulário com o texto atualizado" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

<Callout title="Observação">
Adaptar o texto dos botões à marca ou ao tom do formulário pode ajudar a aumentar a participação.
</Callout>
