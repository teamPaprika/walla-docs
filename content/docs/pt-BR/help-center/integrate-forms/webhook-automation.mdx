## Criar um webhook personalizado

Depois de criar a automação, abra a tela de edição detalhada para configurações mais avançadas.
<Steps>
  <Step>
    ### Acesse a página Conectar
    Na parte superior da edição do projeto, clique em `Conectar`.

    <img src="/images/guides/integrate/automation-page.png" alt="Página de integrações de automação" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### Adicione uma automação
    Na seção 'Minhas automações', clique em `Nova automação` para começar.

    <img src="/images/guides/integrate/automation-new-custom.png" alt="Adicionar uma automação" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### Crie a automação
    Na janela, preencha o nome e as demais informações, selecione o tipo de gatilho e clique em `Criar`.
	    - **Nome da automação**: um nome para identificar a automação.
	    - **Tipo de gatilho**: condição que inicia a automação, como envio do formulário ou desqualificação do participante. O tipo de gatilho não pode ser alterado após a criação.

    <img src="/images/guides/integrate/automation-create-custom.png" alt="Criar uma automação" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### Configure os caminhos (lógica)
    Defina filtros para enviar notificações em condições específicas, como uma resposta de múltipla escolha igual a A ou um texto curto contendo B.
	    - Clique em `+` no canto superior direito para criar vários caminhos. Se nenhum módulo de automação for conectado individualmente a cada caminho, será usado o caminho padrão, com notificações para todos os envios de respostas.
	    - Clique em `+ Adicionar condição` abaixo de cada caminho para configurar condições combinadas.

    <img src="/images/guides/integrate/automation-route-custom.png" alt="Configuração dos caminhos" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### Informe o endereço do webhook
    **Endereço do webhook**: endereço do servidor que receberá os dados.

    <img src="/images/guides/integrate/automation-webhook-url.png" alt="Endereço do webhook" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### Defina o formato de envio do webhook
	    Escolha entre o formato automático (corpo padrão do webhook) e um corpo personalizado. No automático, salve e ative para começar a usar. No personalizado, continue nas próximas etapas.
	    - **Automático (padrão)**: os dados de resposta do formulário são incluídos automaticamente no payload. Abra `Prévia` para conferir o formato exato que será enviado.
	    - **Personalizado**: defina o método da solicitação, os Headers e o Body.

    <img src="/images/guides/integrate/automation-webhook-format.png" alt="Formato de envio do webhook" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
  <Step>
    ### Configure o método e os Headers
	    - **Método da solicitação**: POST / GET / PUT etc.
	    - **Configurações de Headers**: adicione `Content-Type`, token de autenticação e outros cabeçalhos, se necessário.

    <img src="/images/guides/integrate/automation-headers.png" alt="Configuração do método da solicitação e dos Headers" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />
  </Step>
    <Step>
    ### Edite o Body
	    Personalize o texto da mensagem ou insira valores de resposta (`{{responseKey}}`) como variáveis.

    <img src="/images/guides/integrate/automation-body.png" alt="Edição do Body" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### Configure a autenticação (opcional)
    Para proteger o webhook, escolha um método de autenticação como `Bearer Token`, `Basic Auth` ou `API Key`.

    <img src="/images/guides/integrate/automation-auth.png" alt="Configuração da autenticação" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### Inclua valores de campos ocultos (opcional)
	    Nas configurações avançadas, ative `Incluir valores de campos ocultos` para enviar também os valores coletados por [Rastreamento (campos ocultos)](/pt-BR/docs/help-center/share-forms/tracking-hidden-fields). Use isso para enviar a serviços externos dados como origem do acesso ou grupo de clientes. Quando desativado, apenas as respostas sem campos ocultos são enviadas.

    <img src="/images/guides/integrate/automation-hidden-fields.png" alt="Configuração para incluir valores de campos ocultos" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
    <Step>
    ### Salve e ative
    Salve as alterações e ative a automação para que o webhook funcione.

    <img src="/images/guides/integrate/automation-save-activate.png" alt="Salvar alterações e ativar" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Reenviar um webhook (após falha no envio)

<img src="/images/guides/integrate/webhook-resend.png" alt="Reenvio de webhook" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)" }} />

- Se o envio do webhook falhar, você pode reenviá-lo.
- Confira o motivo da falha no resumo do erro.
	- Por exemplo, na automação do Gmail, 'At least one 'to' recipient is required' indica que nenhum destinatário foi informado, impedindo o envio.
	- 'Webhook failed with status: 400' indica que o servidor recebeu a solicitação, mas a rejeitou como inválida (Bad Request), por um erro no formato dos dados enviados.
### Como reenviar
- **Tentar novamente com as configurações originais**: usa as configurações salvas no momento da execução. É útil para repetir nas mesmas condições, sem alterar configurações. Use essa opção se a falha foi causada por um erro temporário no servidor.
- **Reenviar com as configurações atuais**: usa a configuração de automação salva atualmente. É útil depois de salvar alterações. Se o erro foi causado por um destinatário ausente ou por formato de dados inválido, corrija o problema e clique nessa opção.
