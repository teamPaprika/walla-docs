## Etiquetas de projetos

Adicione etiquetas aos projetos para classificá-los e gerenciá-los.

<img src="/images/guides/manage-forms/project-tags-overview.png" alt="Cartões de projetos com etiquetas coloridas organizados nas colunas Rascunho, Publicado e Encerrado" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### O que mudou em relação aos antigos emblemas de emoji

- O sistema de etiquetas substitui os emblemas de cada projeto (emoji + cor de fundo)
- Na atualização, os emblemas existentes são convertidos automaticamente em etiquetas
- Não é mais possível definir emblemas de emoji para projetos individuais

<Callout type="warning" title="Atenção">
Os nomes das etiquetas são gerados a partir do emoji. Projetos que usavam o mesmo emoji são reunidos em uma única etiqueta, mesmo com cores de fundo diferentes.
</Callout>

## Adicionar etiquetas aos projetos

### Adicionar ao criar um projeto

- É possível selecionar etiquetas durante a criação
- Crie rapidamente pelo botão Adicionar (+) no cabeçalho da coluna
  - Coluna de status: a criação só é possível na coluna Rascunho
  - Coluna de etiqueta: a etiqueta é aplicada automaticamente ao criar

<img src="/images/guides/manage-forms/tag-on-create-project.png" alt="Seletor de etiquetas aberto pelo botão + do campo Etiquetas na janela de criação de projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Adicionar depois - (1) Individualmente

Clique em `+ Adicionar etiqueta` no cartão ou na lista de projetos

<img src="/images/guides/manage-forms/tag-add-from-card.png" alt="Botão + Adicionar etiqueta destacado ao lado das etiquetas existentes no cartão do projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## Mesclar etiquetas

Você pode reunir etiquetas semelhantes em uma só.

<Steps>
  <Step>
    ### Abra o gerenciamento de etiquetas
    Abra Gerenciamento de etiquetas.

    <img src="/images/guides/manage-forms/tag-management-button.png" alt="Botão Gerenciamento de etiquetas destacado no canto superior direito do espaço de trabalho" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione as etiquetas para mesclar
    Selecione as etiquetas que deseja mesclar. (A seleção múltipla com Shift não é compatível)
  </Step>
  <Step>
    ### Clique em Mesclar
    Clique em Mesclar.

    <img src="/images/guides/manage-forms/tag-merge-button.png" alt="Etiquetas Clube de leitura e Registro de leitura selecionadas, com o botão Mesclar em Clube de leitura destacado" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Mesclagem concluída
    As etiquetas são reunidas na última etiqueta selecionada.
  </Step>
</Steps>

Exemplo: `Marketing / MKT / Equipe de marketing → Marketing`

## Filtros de projetos

### Filtrar por status

- Rascunho: ainda não foi publicado
- Publicado: recebendo respostas
- Encerrado: projeto finalizado

### Filtrar por etiquetas

- Várias etiquetas selecionadas: mostra projetos que tenham pelo menos uma delas
- Opção `Nenhuma etiqueta` selecionada: mostra apenas projetos sem etiquetas

### Combinar filtros

Ao selecionar status + etiqueta, aparecem apenas projetos que **atendem aos dois critérios**.
- Exemplo: `Publicado + Marketing` → projetos publicados com a etiqueta Marketing

## Modos de visualização

### Visualização em cartões / lista

| Cartões | Lista |
| --- | --- |
| Formato de cartões | Formato de lista |
| Informações de relance | Mais projetos na tela |
| Configuração padrão | Estrutura simples |

### Agrupar a visualização

#### Colunas (grupos)

- Por status
- Por etiqueta

#### Linhas (subgrupos)

- Sem agrupamento
- Por status
- Por etiqueta

### Critérios de ordenação

- Data de modificação
- Data de criação
- Número de respostas
  (Alternância entre ordem crescente e decrescente)

### Salvar configurações de visualização

- Salvas automaticamente por espaço de trabalho
- Mantidas após atualizar a página
- O botão Redefinir restaura os valores padrão


## Exemplos de uso

1. Gestão por equipe (criar etiquetas com nomes de equipes → filtrar os projetos de cada equipe)
1. Usar como um quadro Kanban (visualização: colunas = status → arrastar para alterar o status)
1. Organizar projetos concluídos (filtro Encerrado → seleção múltipla → mover para o arquivo)
2. Organizar etiquetas duplicadas (Gerenciamento de etiquetas → Mesclar)

## Termos principais

| Termo | Descrição |
| --- | --- |
| Etiqueta | Rótulo para classificar projetos |
| Filtro | Visualização de projetos por critérios |
| Agrupamento | Organização por categoria |
| Ação em lote | Operação em vários projetos ao mesmo tempo |
| Arquivo | Local para guardar projetos inativos |
