## Estrutura básica da tabulação cruzada

A tabulação cruzada é composta por dois elementos.

#### Variável de referência
É o campo usado como critério de comparação (por exemplo, gênero, faixa etária ou ocupação). → Define “quais grupos comparar?”.
#### Variável de análise
É o campo comparado conforme a variável de referência (por exemplo, satisfação com o preço, finalidade de uso ou intenção de recomendação). → Define “o que comparar?”.

  <Step>

    Adicione os campos que deseja comparar à área 'Variáveis de análise'.

  </Step>
</Steps>

## Como interpretar os resultados

### Exemplo
(Variável de referência: ocupação; variável de análise: satisfação com o preço)

| Ocupação | Percentual de satisfação |
| --- | --- |
| Empregados | 78% |
| Estudantes | 60% |
| Autônomos | 82% |

→ É possível observar uma satisfação relativamente menor com o preço no grupo de estudantes.

Assim, a tabulação cruzada ajuda a identificar diferenças entre grupos.

## Como usar Higher / Lower

Use os botões Higher / Lower na parte superior dos resultados

para identificar rapidamente grupos acima ou abaixo da média geral.

- Higher: destaca grupos acima da média geral
- Lower: destaca grupos abaixo da média geral

Isso ajuda a encontrar rapidamente os principais insights ao preparar relatórios.

## Observações

- Cada grupo precisa ter respostas suficientes para permitir uma comparação precisa.
- Se um grupo tiver poucas respostas, interprete os resultados com cuidado.
- A tabulação cruzada mostra diferenças; investigar suas causas exige uma análise adicional.
