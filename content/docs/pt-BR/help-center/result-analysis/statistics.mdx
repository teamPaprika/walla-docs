- Clique em `Filtro de respostas` no topo para analisar apenas respostas que atendam a critérios específicos (período, valor exato ou conteúdo de um campo etc.).
- Use `Baixar PDF de todos os campos` no topo para salvar as estatísticas de todas as perguntas em PDF.
- As estatísticas mostram os resultados de cada campo em gráficos ou tabelas.
- O formato de visualização adequado é aplicado automaticamente conforme o tipo de resposta.
  - Múltipla escolha: gráfico de pizza, barras verticais, barras horizontais e tabela
  - Resposta curta: tabela e nuvem de palavras

- Cada campo pode ser baixado como imagem PNG.
