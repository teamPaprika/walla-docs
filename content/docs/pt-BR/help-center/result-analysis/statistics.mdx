## Estatísticas

- O formato de visualização adequado é aplicado automaticamente conforme o tipo de resposta.
- Clique em `Filtrar` no topo para analisar apenas respostas que atendam a critérios específicos (período, correspondência exata ou parcial com o valor de uma pergunta etc.).
- Use `Exportar como PDF` no topo para salvar as estatísticas de todas as perguntas em PDF.
- Use a seta ao lado de `Baixar` para escolher PNG ou SVG e salvar as estatísticas de uma pergunta.
