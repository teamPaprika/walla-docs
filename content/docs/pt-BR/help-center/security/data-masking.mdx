## Mascarar dados

<img src="/images/guides/security/masking-01-toggle.png" alt="Opção de mascaramento de dados" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)"}} />

- Mascare dados sensíveis e permita que apenas usuários autorizados vejam os originais.
- Após ativar o mascaramento e publicar o projeto, todas as respostas desse campo ficam mascaradas.
- O mascaramento oculta os dados originais e, uma vez configurado, não pode ser revertido.

<img src="/images/guides/security/masking-02-confirm.png" alt="Confirmação de ativação do mascaramento" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />

## Consultar dados mascarados
- Na planilha de respostas, passe o mouse sobre o título da coluna para visualizar dados mascarados. (É necessário ter a permissão correspondente)
- Dependendo das configurações de segurança do administrador, pode ser necessário informar um motivo para remover o mascaramento. Esse motivo fica disponível em 'Configurações da equipe' → 'Logs de atividade'.

<img src="/images/guides/security/masking-03-unmask-reason.png" alt="Preenchimento do motivo para remover o mascaramento" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", border: "1px solid var(--border)"}} />

<Callout type="warning" title="Atenção">
- Depois de ativado, o mascaramento não pode ser desativado!
- Campos com mascaramento ativo não permitem configurar limites de respostas por opção.
- Se precisar coletar dados sensíveis, é mais seguro ativar o mascaramento antes de começar a coleta.
</Callout>
