## Como configurar

<img src="/images/guides/security/auto-delete-setup.png" alt="Configuração de exclusão automática de respostas" style={{ width: "100%", borderRadius: "8px", marginBottom: "12px", border: "1px solid var(--border)"}} />

1. Acesse o editor do projeto.
2. Selecione o campo que exige exclusão automática (por exemplo, um campo de dados pessoais).
3. Localize 'Exclusão automática de respostas' na parte inferior das opções e defina o período.
	- Período disponível: de 3 meses a 5 anos
4. Publique o formulário para ativar a configuração. As respostas serão excluídas automaticamente após o prazo.
## Como funciona

- Após o período selecionado, os dados de resposta desse campo são excluídos permanentemente da planilha de respostas.
- Os dados excluídos não podem ser recuperados nem consultados novamente.
<Callout type="warning" title="Atenção">
- A exclusão automática se aplica por campo. Recomendamos definir um período de retenção para campos que coletam dados pessoais.
- Os dados excluídos são considerados descartados para fins legais. Se precisar de uma cópia separada, baixe os dados antes do fim do período.
</Callout>
