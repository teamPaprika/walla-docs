## Ativar a verificação de endereço IP
- Em `Configurações da equipe` → `Segurança`, ative `Verificação de endereço IP` para permitir acesso à equipe apenas pelos IPs cadastrados.
- Com a verificação ativa, é obrigatório cadastrar pelo menos um endereço IP.
## Gerenciar endereços e intervalos de IP permitidos
- Cadastre endereços ou intervalos de IP em um dos formatos abaixo.
  - IP individual: `192.168.1.1`
  - Intervalo CIDR: `192.168.1.0/24` (192.168.1.0 ~ 192.168.1.255)
  - Curinga: `192.168.*.*` (192.168.0.0 ~ 192.168.255.255)
