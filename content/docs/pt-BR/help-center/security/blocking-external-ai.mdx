## Bloquear o uso de IA externa
Em `Configurações da equipe` → `Segurança`, ative `Bloquear uso de IA externa` para desativar os recursos que usam provedores externos de LLM. Atualmente, essa opção desativa o recurso [Criar formulários com IA](/pt-BR/docs/help-center/create-forms/creating-project-ai).

O acesso por MCP (conector de IA) é controlado separadamente pela opção `Permitir MCP (conector de IA)`. Bloquear a IA externa não desativa esse conector.
