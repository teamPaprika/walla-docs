## Campo de data

<img src="/images/guides/manage-forms/date-field-example.png" alt="Editor de formulário com um campo de data" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Permite que o usuário selecione a data desejada.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Exclusão automática de respostas

## Campo de hora

<img src="/images/guides/manage-forms/time-field-example.png" alt="Editor de formulário com um campo de hora" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Permite que o usuário selecione o horário desejado.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Exclusão automática de respostas

<Callout title="Dica">
Os campos de data e hora são úteis para formulários de reservas, agendamentos, participação em eventos e outras situações relacionadas a horários.
</Callout>
