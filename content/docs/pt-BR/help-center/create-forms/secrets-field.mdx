## Campo de informações secretas

<img src="/images/guides/manage-forms/secrets-field-example.png" alt="Campo de informações secretas com entrada de código de verificação e campo de confirmação do mesmo valor" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

No menu de campos, este tipo aparece como `Campo de segredos`. O conteúdo digitado não aparece diretamente na tela, e você pode combinar diferentes configurações para reforçar a segurança.

## Quando usar?

Recomendamos o campo de informações secretas nos seguintes casos:

- Entrada de senha ou PIN
- Entrada de código de verificação ou chave de acesso
- Verificação de usuários autorizados em formulários internos
- Coleta de informações sensíveis que não devem ser expostas

## Entrada e recursos de segurança

- Ocultação do valor digitado
  - O conteúdo digitado pelo respondente aparece como ●●●.
  - O valor real não fica exposto na tela de resposta.

- Mascaramento de dados
  - O valor também aparece mascarado nos dados de respostas coletados.
  - A proteção é mantida na tela administrativa e no compartilhamento de resultados.

- Clique no botão '… (Mais opções)' no canto inferior direito para acessar os recursos abaixo.
  - Permitir colar
    - Permite autorizar ou restringir copiar e colar.
    - Recomendamos desativar essa opção quando o usuário precisar digitar o valor manualmente.

  - Exigir confirmação
    - Permite solicitar que o mesmo valor seja digitado novamente.

- Opções disponíveis
  - Preenchimento obrigatório
  - Limite de tamanho da resposta
  - A resposta deve incluir / A resposta não pode incluir
  - Expressão regular (Regex)
  - Mascaramento de dados (padrão)
  - Excluir respostas automaticamente

<Callout type="warning" title="Atenção">
- Use o campo de informações secretas evitando coletar dados pessoais desnecessários.
- Recomendamos fornecer informações sobre o tratamento de dados pessoais conforme os requisitos legais e as políticas aplicáveis.
</Callout>
