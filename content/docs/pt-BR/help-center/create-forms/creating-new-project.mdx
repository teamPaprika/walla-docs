## Como criar um projeto

<Steps>
  <Step>
    ### Clique em Criar projeto
    Na tela do espaço de trabalho, clique no botão `Criar projeto`.

    <img src="/images/guides/manage-forms/team-template-create-project.png" alt="Botão Criar projeto no canto superior direito do espaço de trabalho" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Configure o projeto
    Defina o nome e as tags do projeto.

    <img src="/images/guides/manage-forms/new-project-name-tag.png" alt="Tela para definir o nome e as tags na janela de criação de um novo projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Conclua a criação do projeto
    Clique no botão `Criar projeto`. O novo projeto será adicionado ao espaço de trabalho.

    <img src="/images/guides/manage-forms/new-project-field-picker.png" alt="Editor com o painel de adição de campos após a criação de um novo projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout title="Observação">
Você pode criar vários projetos em um mesmo espaço de trabalho e gerenciar diferentes formulários ao mesmo tempo.
</Callout>
