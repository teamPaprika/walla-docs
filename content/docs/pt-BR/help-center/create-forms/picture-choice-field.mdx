## Escolha por imagem

<img src="/images/guides/manage-forms/picture-choice-field-example.png" alt="Campo de escolha por imagem com alternativas de design branco com azul-marinho e preto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Ajuste a altura das imagens em pixels.
- Use o [editor de texto](/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Clique no botão `…` (Mais opções) no canto inferior direito para acessar os recursos abaixo.
  - Definir valores das opções: atribua um valor a cada opção. (Exemplo: definir a primeira opção como '1' → ela aparecerá como 1 na planilha de respostas.)
  - Seleção múltipla: permite selecionar mais de uma opção.
  - `Uma linha no celular`: exibe uma imagem por linha; sem essa opção, as imagens aparecem em duas colunas em dispositivos móveis.
  - Embaralhar opções: exiba as opções em ordem aleatória para cada respondente.

- Opções disponíveis
  - Preenchimento obrigatório
  - Configuração da quantidade de seleções
  - Incluir opções
  - Excluir opções
  - Limitar respostas por opção
  - Mascaramento de dados
  - Excluir respostas automaticamente

<Callout type="warning" title="Atenção">
- Imagens muito pesadas podem aumentar o tempo de carregamento. Envie arquivos com tamanho adequado.
- Manter proporções e estilos consistentes entre as imagens ajuda a melhorar a qualidade das respostas.
</Callout>
