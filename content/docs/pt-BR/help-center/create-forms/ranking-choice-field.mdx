## Campo de classificação

<img src="/images/guides/manage-forms/ranking-choice-field-response-example.png" alt="Tela de resposta de uma pergunta para classificar de primeiro a quinto os itens que uma instituição precisa melhorar" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Permite que o respondente ordene várias opções por classificação.
- Clique em `Adicionar opção` no canto inferior esquerdo para incluir mais alternativas, ou em `Adicionar opção 'Outro'` para permitir uma resposta digitada.
- Em `Número de posições`, no canto inferior direito, defina quantas posições o respondente deve selecionar.
- Use o [editor de texto](/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.

- Clique no botão `…` (Mais opções) no canto inferior direito para acessar os recursos abaixo.
  - Adicionar opções em massa: insira várias opções de uma vez. *(Separe as opções com Enter.)*
  - Definir valores das opções: atribua um valor a cada opção. (Exemplo: definir a primeira opção como '1' → ela aparecerá como 1 na planilha de respostas.)

- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Excluir respostas automaticamente
