## Formatar o texto

<img src="/images/guides/manage-forms/text-style-toolbar.png" alt="Barra de edição de texto do campo e menu de estilos de título e corpo de texto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Depois de digitar, selecione o texto arrastando o cursor para aplicar um estilo.
- Os estilos de texto disponíveis são:
  - Estilos de título
  - Estilos de corpo de texto
  - Estilos especiais (citação, destaque etc.)
- Fonte: escolha entre 8 fontes para caracteres latinos.
- Tamanho da fonte: escolha entre 5 tamanhos.
- Há várias opções para destacar o texto:
  - Definir a cor de realce
  - Alterar a cor do texto
  - Adicionar link
  - Inserir anotação
  - Alinhar o texto (à esquerda, à direita ou ao centro)

## Usar recursos adicionais com o comando de barra

<img src="/images/guides/manage-forms/slash-command-menu.png" alt="Menu exibido ao digitar uma barra (/) no editor, com opções de títulos, listas, citações e blocos de código" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Digite '/' (barra) no teclado para inserir os seguintes conteúdos:
  - Títulos 1, 2 e 3
  - Lista com marcadores, lista numerada, lista de tarefas e texto recolhível
  - Citação
  - Bloco de código
  - Tabela (Table)
  - Duas colunas (Column)
  - Inserção e redimensionamento de imagens
  - Divisor
