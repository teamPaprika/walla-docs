## Adicionar campos

### Clique no ícone '+' na lista de campos à esquerda
Selecione o campo desejado para adicioná-lo. Se um campo já estiver selecionado, o novo campo será inserido automaticamente logo abaixo dele.

<img src="/images/guides/manage-forms/add-field-plus-icon.png" alt="Painel de adição de campos exibido ao clicar no ícone + no topo da lista de campos à esquerda" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Adicione no meio do editor
Ao passar o cursor entre dois campos, o botão `Adicionar` aparece.
Clique nele para inserir um novo campo nessa posição.

<img src="/images/guides/manage-forms/add-field-between.png" alt="Botão Adicionar exibido ao passar o cursor entre campos no editor" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Adicione dentro de um grupo de campos
Ao passar o cursor na parte inferior de um grupo de campos, o botão `Adicionar` aparece. Clique nele para adicionar uma pergunta ao grupo.

<img src="/images/guides/manage-forms/add-field-group.png" alt="Botão Adicionar exibido ao passar o cursor na parte inferior de um grupo de campos" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

## Alterar o tipo de uma pergunta existente

Você pode alterar uma pergunta já criada para outro tipo compatível. Por exemplo, pode alternar entre `Múltipla escolha` e `Caixas de seleção`, ou entre `Lista suspensa` e `Lista suspensa (seleção múltipla)`.

<img src="/images/guides/manage-forms/change-field-type.png" alt="Alterar de múltipla escolha para caixas de seleção no menu Tipo de campo à direita" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

1. No editor do formulário, selecione a pergunta cujo tipo deseja alterar.
2. Clique em `Tipo de campo` no painel de configurações à direita.
3. Escolha o tipo desejado entre os que aparecem na lista.
4. Após a alteração, confira as configurações relacionadas, como o número de seleções, a validação de respostas e a lógica, e verifique o funcionamento da pergunta na prévia. Publique o formulário para aplicar as alterações aos respondentes.

### Se o tipo desejado não aparecer

- A lista mostra apenas tipos compatíveis com a pergunta atual. Se o tipo desejado não estiver na lista, adicione uma nova pergunta desse tipo.
- Se não houver outros tipos compatíveis, o menu `Tipo de campo` ficará desativado.
- Perguntas de Classificação e Política de Privacidade não podem ser alteradas para outros tipos.

<Callout type="warning" title="Confira novamente a configuração de opção exclusiva">
Alterar o tipo da pergunta remove a configuração `Opção exclusiva` das alternativas. Voltar ao tipo original não a restaura automaticamente; configure-a novamente, se necessário.
</Callout>

## Excluir ou duplicar campos
### Exclua ou duplique diretamente no editor
Use os ícones à direita do campo para excluir ou duplicar o campo selecionado.
<img src="/images/guides/manage-forms/field-action-icons.png" alt="Ícones de configurações, duplicação e exclusão no canto superior direito do campo no editor" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

### Exclua ou duplique pela lista de campos
<Steps>
  <Step>
    ### Localize o ícone de mais opções
    Ao passar o mouse sobre um campo na lista à esquerda, o ícone `...` (Mais opções) aparece à direita dele.

    <img src="/images/guides/manage-forms/field-more-icon.png" alt="Ícone de mais opções à direita de um campo na lista à esquerda" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione Excluir ou Duplicar
    Clique no ícone e selecione `Excluir campo` ou `Duplicar campo`.

    <img src="/images/guides/manage-forms/field-more-menu.png" alt="Menu de mais opções com Duplicar campo, Salvar como modelo de campo e Excluir campo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout type="warning" title="Atenção">
Ao excluir um campo, os dados das respostas desse campo também serão excluídos. Faça uma cópia dos dados necessários antes de excluí-lo.
</Callout>
