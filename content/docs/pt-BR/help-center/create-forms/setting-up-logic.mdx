## O que é lógica?

- A lógica define "qual será a próxima pergunta conforme a resposta".
- O destino padrão define o caminho seguido quando nenhuma condição de lógica é atendida. (É um conceito diferente de 'resposta obrigatória'.)

## Adicionar lógica

<Steps>
  <Step>
    ### Acesse as configurações de lógica
    No editor do projeto, clique no botão `Lógica` para abrir a tela de configuração.

    <img src="/images/guides/create-forms/logic-button.png" alt="Botão Lógica no canto superior direito do editor do projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Entenda as condições e o destino
    A lógica é composta por duas partes: 'Condição' e 'Ir para'.

    <img src="/images/guides/create-forms/logic-condition-action.png" alt="Áreas de condição e destino da lógica" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Defina a condição
    1. **Selecione a pergunta de referência** – Escolha a pergunta cuja resposta será usada como base.
       - Em perguntas de grade, tabela, classificação e campo personalizado, escolha também um `Subitem`. Veja [Criar condições com subitens](#criar-condições-com-subitens).
       - Você também pode escolher um campo oculto como referência. Veja [Criar condições com campos ocultos](#criar-condições-com-campos-ocultos).
    2. **Selecione a condição** – Escolha o tipo de condição. As condições incluem comparações de texto/valor, opções, números e datas. Veja os detalhes em [Tipos de condição](#tipos-de-condição) abaixo.
    3. **Selecione a opção ou resposta** – Defina quais respostas acionam a condição.
       - Você pode selecionar várias respostas ao mesmo tempo.

    <img src="/images/guides/create-forms/logic-condition.png" alt="Área de condição com seleção da pergunta de referência, da condição e das opções" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Adicione várias condições
    - Clique em `+ Adicionar nova condição` para combinar condições.
    - Ao combinar condições, escolha uma das opções abaixo.
      - **AND**: a lógica é acionada apenas se ambas as condições forem atendidas.
      - **OR**: a lógica é acionada se pelo menos uma das condições for atendida.

    <img src="/images/guides/create-forms/logic-condition-multiple.png" alt="Adição de nova condição e seleção de combinação AND/OR" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Defina o destino
    - Depois de configurar as condições, selecione o campo para o qual o respondente será direcionado.
    - Com a configuração concluída, quem atender às condições irá diretamente para a pergunta definida.

    <img src="/images/guides/create-forms/logic-action.png" alt="Seleção do campo de destino na área Ir para da lógica" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Tipos de condição

### Comparação de texto ou valor

| Condição | Significado | Exemplo | Exemplo de resposta |
| ------ | -------------- | ---------------- | ----------------- |
| Igual a | O valor é exatamente igual | Se a resposta for `Seul` | Seul |
| Diferente de | O valor é diferente | Se a resposta não for `Seul` | Incheon |
| Começa com | Começa com o valor especificado | Se a resposta começar com `010` | 010-1234-5678 |
| Termina com | Termina com o valor especificado | Se a resposta terminar com `.com` | example<span>@</span>walla.com |
| Contém | Inclui o texto especificado | Se a resposta contiver `Empresa` | Empresa Paprika Data Lab |
| Não contém | Não inclui o texto especificado | Se a resposta não contiver `maçã` | Suco de uva |

### Comparação de opções
Use para verificar quais opções foram selecionadas em perguntas como múltipla escolha e caixas de seleção.

| Condição | Significado | Exemplo |
| -------- | --------------------- | ----------------------- |
| Contém todos | Todas as opções especificadas foram selecionadas | Se `A` e `B` foram selecionadas |
| Contém qualquer um | Pelo menos uma das opções especificadas foi selecionada | Se `A` ou `B` foi selecionada |
| Não contém nenhum | Nenhuma das opções especificadas foi selecionada | Se nem `A` nem `B` foram selecionadas |
| Não contém todos | Pelo menos uma das opções especificadas não foi selecionada | Se faltar pelo menos uma entre `A` e `B` |


### Comparação de números

| Condição | Significado | Exemplo |
| ----- | ------------ | ------------------------ |
| Maior que | Maior que o valor de referência, sem incluí-lo | Se a idade for maior que `19` |
| Maior ou igual a | Igual ou maior que o valor de referência | Se a idade for igual ou maior que `19` |
| Menor que | Menor que o valor de referência, sem incluí-lo | Se a pontuação for menor que `60` |
| Menor ou igual a | Igual ou menor que o valor de referência | Se a pontuação for igual ou menor que `60` |

### Comparação de datas

| Condição | Significado | Exemplo |
| -------- | ----------------------- | --------------------- |
| Anterior a | Anterior à data de referência, sem incluí-la | Se for antes de `2026-01-01` |
| Anterior ou igual a | Igual ou anterior à data de referência, incluindo-a | Se for em `2026-01-01` ou antes |
| Posterior a | Posterior à data de referência, sem incluí-la | Se for depois de `2026-01-01` |
| Posterior ou igual a | Igual ou posterior à data de referência, incluindo-a | Se for em `2026-01-01` ou depois |

## Criar condições com subitens

Algumas perguntas têm várias células em uma única resposta.
Nessas perguntas, escolha primeiro a pergunta de referência e depois, etapa por etapa, a célula que deseja comparar.

<Steps>
  <Step>
    ### Escolha a pergunta de referência
    Escolha a pergunta de referência.
    Se a pergunta tiver células internas, o seletor `Subitem` aparece abaixo dela.
  </Step>
  <Step>
    ### Escolha o subitem
    Em `Subitem`, escolha a linha, a coluna ou a propriedade que deseja comparar.
    Se aparecer outro seletor, continue escolhendo até o último.
  </Step>
  <Step>
    ### Defina a condição e o valor de comparação
    Escolha o tipo de condição e insira o valor de comparação.
    O campo do valor muda conforme o formato da última célula escolhida.
  </Step>
</Steps>

### Ordem de seleção por tipo de pergunta

| Pergunta | Ordem de seleção | Valor de comparação |
| ------------- | ------------------- | ---------------------- |
| Grade de múltipla escolha | Linha | Uma opção escolhida nessa linha |
| Grade de caixas de seleção | Linha | As opções escolhidas nessa linha (pode haver mais de uma) |
| Classificação | Posição | A opção colocada nessa posição |
| Tabela | Linha → coluna | O texto digitado nessa célula |
| Campo personalizado | Propriedade → posição do item, se necessário | Um valor no formato dessa propriedade |

- Na grade de múltipla escolha, na grade de caixas de seleção e na classificação, o valor de comparação é definido logo após escolher a linha. Não é preciso escolher a posição do item.
- Se a pergunta de classificação permitir que o respondente digite a própria opção, o valor de comparação oferece `Selecionar opções` e `Personalizado`. Em `Personalizado`, digite o valor e pressione Enter.
- Se aparecer `Esta resposta não pode ser usada em uma condição`, essa célula não pode ser usada em condições. Escolha outro subitem.

### Subitens de campos personalizados

- Se o campo tiver propriedades definidas, escolha uma em `Subitem`.
- Se a propriedade aceitar chaves próprias, aparecem os botões `Escolher propriedade` e `Digitar chave`. Para usar uma chave que não está na lista, clique em `Digitar chave` e digite-a.
- Se a resposta for uma lista, aparece o campo `Posição do item`.
  - 1 é o primeiro item e 2 é o segundo.
  - Se toda a resposta do campo personalizado for uma lista, preencha primeiro `Posição do item`.
- Você pode deixar o campo `Posição do item (opcional)` em branco.
  - Em branco, a lista inteira é comparada.
  - Com um número, apenas esse item é comparado.

### Inserir o valor de comparação

- Não é preciso digitar o valor em um formato especial (como JSON). Use apenas os seletores e campos da tela.
- **Valores com opções** – escolha uma opção da lista. Alguns campos permitem escolher várias.
- **Valores de lista digitados** – digite um valor e pressione Enter. O valor é adicionado como uma pequena etiqueta. Adicione os outros valores da mesma forma.
- **Números** – digite um número. Para comparar com 0, digite `0`. Um campo vazio não conta como 0.
- **Verdadeiro/falso** – escolha `Verdadeiro` ou `Falso`. Se nada for escolhido, o valor não conta como `Falso`. Em um campo de lista, digite `true` ou `false` e pressione Enter.

### Condições incompletas

- Se aparecer `Confira a condição e conclua os valores.` abaixo da condição, ela ainda não está concluída.
- Se sobrar texto em um campo, pressione Enter para adicioná-lo como etiqueta.
- Se o valor não estiver no formato correto, o texto fica no campo e aparece `Insira um valor do tipo esperado.`. Corrija o valor e pressione Enter de novo.
- Se `Posição do item` estiver vazia ou fora do intervalo, aparece um aviso. Corrija o número conforme o aviso.
- Nesse estado, não é possível publicar o formulário. Ao tentar publicar, aparece `Complete ou corrija a condição antes de publicar.`.

### Condições quebradas após alterar uma pergunta

- Se você excluir ou alterar linhas, colunas ou opções de uma pergunta, a condição pode mostrar `Item não encontrado` ou `Este valor não é mais uma opção. Escolha outro.`.
- Escolha outro subitem ou outro valor.
- Se uma condição assim continuar salva, não é possível publicar. Ao tentar publicar, aparece `Uma condição de valor de resposta é inválida. Verifique a pergunta, o subitem e o valor de comparação.`.

## Criar condições com campos ocultos

Você pode direcionar o respondente para outra pergunta conforme o valor do campo oculto recebido pelo link.
Primeiro, cadastre o campo oculto no rastreamento da página de compartilhamento. Veja como em [Rastreamento (campos ocultos)](/pt-BR/docs/help-center/share-forms/tracking-hidden-fields).

<Steps>
  <Step>
    ### Escolha o campo oculto
    Na lista de perguntas de referência, escolha o nome do campo oculto.
  </Step>
  <Step>
    ### Defina a condição e o valor
    Escolha uma das condições de [Comparação de texto ou valor](#comparação-de-texto-ou-valor).
    Digite o valor de comparação como texto.
  </Step>
  <Step>
    ### Escolha a pergunta de destino
    Escolha a pergunta para a qual irá quem atender à condição.
  </Step>
</Steps>

- Exemplo: campo oculto `utm_source`, `Igual a`, `ads`
  - Se o link for `https://walla.my/v/QA9S0imWeo232fSbd4?utm_source=ads`, a condição é atendida.
  - Apenas quem chegou pelo anúncio vai para a pergunta definida.
- Se o link não tiver valor para o campo oculto, o valor fica vazio. Com o valor vazio, nenhuma condição é atendida, nem mesmo `Diferente de`.
- Não é possível escolher um campo oculto como destino. Ele serve apenas como referência da condição.
- Não é possível excluir um campo oculto usado em uma condição de lógica. Veja [Excluir um campo oculto usado na lógica](/pt-BR/docs/help-center/share-forms/tracking-hidden-fields#excluir-um-campo-oculto-usado-na-lógica).

## Configurar a lógica usando nós

<Steps>
  <Step>
    ### Conheça os nós e as conexões
    Na tela de lógica, cada pergunta aparece como um nó, e as linhas entre os nós mostram o fluxo. `Destino padrão` indica o caminho seguido quando nenhuma condição é atendida, enquanto ramificações numeradas, como `Lógica #1` e `Lógica #2`, indicam caminhos que dependem das condições.

    <img src="/images/guides/create-forms/logic-node-overview.png" alt="Tela de nós da lógica com destaque para Destino padrão e conexões de Lógica #1, #2 e #3" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Configure o destino padrão
    Clique no rótulo `Destino padrão` do nó para abrir a lista `Próximo campo`. Pesquise um campo ou selecione-o na lista para definir o destino de quem não atender às condições.

    <img src="/images/guides/create-forms/logic-node-default-move.png" alt="Lista de seleção e busca de Próximo campo aberta a partir do nó Destino padrão" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Edite as condições no nó de lógica
    Clique em um rótulo de ramificação numerado, como `Lógica #1` ou `Lógica #2`, para expandir as condições. Edite a pergunta de referência, a condição de inclusão e as opções diretamente no nó, ou clique em `Adicionar nova condição`.

    <img src="/images/guides/create-forms/logic-node-condition.png" alt="Edição da pergunta de referência e das opções na área expandida do nó Lógica #3" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Clique na conexão para editar diretamente
    Depois de selecionar um campo, você também pode clicar diretamente na linha entre os nós para editar o fluxo, sem precisar clicar nos rótulos `Lógica` ou `Destino padrão`.

    <img src="/images/guides/create-forms/logic-node-line-edit.png" alt="Edição direta de um fluxo ao clicar na conexão entre nós, com o rótulo Lógica #1 destacado" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Arraste para conectar os nós
    Arraste o ponto de conexão na parte inferior de um nó até o nó de outra pergunta para ligar as duas e criar o fluxo. Ao desenhar uma nova conexão, o respondente seguirá esse caminho.

    <img src="/images/guides/create-forms/logic-node-connect.png" alt="Criação de uma conexão ao arrastar o ponto de um nó até outra pergunta" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Exemplos de uso da lógica

- #### Exemplo 1. Ramificação por consentimento para uso de dados pessoais
  - Condição: `Campo de consentimento para coleta de dados pessoais` = "Concordo"
  - Ir para: a primeira `pergunta de coleta de dados pessoais (como o campo de telefone)`
  - Para a resposta "Não concordo", configure outro caminho para o campo `Rejeitar`, sem coletar a resposta.
- #### Exemplo 2. Desqualificação por idade
  - Condição: `Pergunta de idade (múltipla escolha ou lista suspensa)`, Diferente de, "10 a 19 anos"
  - Ir para: `Campo de desqualificação`
- #### Exemplo 3. Direcionar para uma pergunta quando houver uma palavra-chave
  - Condição: `Campo de texto curto ou longo`, Contém, "maçã"
  - Ir para: `Campo de pagamento para venda de suco de maçã`

## Outras configurações e cuidados

- Se o fluxo for interrompido no meio, é provável que **haja um campo de desqualificação nessa posição ou uma regra incorreta em uma pergunta anterior**.

  <img src="/images/guides/create-forms/logic-broken-conflict.png" alt="Conflito causado por uma regra que direciona para uma opção não encontrada" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Cada pergunta dentro de um grupo também pode ter sua própria lógica. Ao direcionar para uma pergunta específica, o formulário exibirá o grupo que contém essa pergunta.
- Clique em `Redefinir` para excluir todas as regras de lógica da pergunta.
