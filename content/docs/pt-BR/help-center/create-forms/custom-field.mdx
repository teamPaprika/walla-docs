## O que é um campo personalizado?
Um campo personalizado permite criar, a partir de uma descrição em linguagem natural, formas de entrada que não estão disponíveis nos tipos padrão do Walla, como múltipla escolha, texto curto ou lista suspensa.
Nos criadores de formulários tradicionais, não é possível criar um tipo de entrada que não esteja na lista de campos. Os campos personalizados eliminam essa limitação. Basta descrever o que você precisa, como "Crie um campo para coletar assinaturas", e um campo funcional será criado com base no pedido.


## Limites por plano

Os campos personalizados estão disponíveis em todos os planos. O plano limita apenas **quantos tipos de campo personalizado a equipe pode criar**.

| Plano | Quantidade de campos personalizados que podem ser criados |
| --- | --- |
| Free | 1 |
| Pro | 5 |
| Enterprise | Ilimitada |

- O limite se aplica apenas à **criação de novos tipos**. Campos já criados podem continuar sendo adicionados aos formulários, recebendo respostas e sendo editados, independentemente do limite.
- Ao atingir o limite, apenas a criação de novos campos fica bloqueada. Confira o uso atual (por exemplo, 1/1) na aba `Campos personalizados` do editor.
- Se precisar de mais campos personalizados, [mude para um plano superior](https://docs.walla.my/pt-BR/docs/help-center/getting-started/starting-or-changing-subscription).

<Callout type="info" title="Ao mudar para um plano inferior">
Mesmo que a quantidade de campos existentes ultrapasse o limite do novo plano, eles não serão excluídos nem deixarão de funcionar. Apenas a criação de novos tipos ficará restrita.
</Callout>

    ### Use o campo personalizado
