## Campo de telefone

<img src="/images/guides/manage-forms/phone-number-field-example.png" alt="Campo de telefone com seletor de país e texto de exemplo 010-2000-0000" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Permite que o usuário informe um número de telefone.
- Clique no ícone de bandeira para alterar o formato do telefone para outro país.
- Use o [editor de texto](/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Você pode definir o país padrão no editor ou usar `Detectar automaticamente (localização do respondente)`. Na detecção automática, o país é definido pela localização do respondente ou pelo idioma do navegador; se essas informações não estiverem disponíveis, será usada a Coreia do Sul.
- Opções disponíveis
  - Preenchimento obrigatório
  - Limite de tamanho da resposta
  - A resposta deve incluir / A resposta não pode incluir
  - Expressão regular (Regex)
  - Exigir verificação de telefone
  - Mascaramento de dados
  - Excluir respostas automaticamente

### Exigir verificação de telefone

- Ative 'Exigir verificação de telefone' para coletar apenas números verificados.
- O respondente precisa verificar o telefone com um código enviado por SMS antes de enviar o formulário.
- Para realizar a verificação, o número de telefone é enviado ao provedor de SMS (Twilio Inc., Estados Unidos).

## Campo de e-mail

<img src="/images/guides/manage-forms/email-field-example.png" alt="Campo de e-mail com texto de exemplo example@email.com" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Permite que o usuário informe um endereço de e-mail.
- O endereço deve seguir o formato `~~~@~~~.~~~`. Se o formato estiver incorreto, não será possível enviar o formulário.
- Use o [editor de texto](/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Clique no ícone de lápis para editar o texto de exemplo.
- Opções disponíveis
  - Preenchimento obrigatório
  - Limite de tamanho da resposta
  - A resposta deve incluir / A resposta não pode incluir
  - Expressão regular (Regex)
  - Exigir verificação de e-mail
  - Mascaramento de dados
  - Excluir respostas automaticamente

### Verificação de e-mail

Ative `Exigir verificação de e-mail` para que o respondente verifique o endereço informado com um código de 6 dígitos antes de enviá-lo como resposta. Além de validar o formato do e-mail, essa opção permite confirmar que o respondente consegue acessar a caixa de entrada.

<Steps>
  <Step>
    #### Ative a verificação de e-mail

    Selecione o campo de e-mail no editor do formulário e ative `Exigir verificação de e-mail` no painel de configurações à direita. Publique o formulário para aplicar a configuração atualizada aos respondentes.

    <img src="/images/guides/create-forms/email-verification-enable.png" alt="Ativar a verificação de e-mail nas configurações do campo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Informe o e-mail e clique em Verify

    O respondente informa um endereço de e-mail e clica em `Verify` ao lado do campo.

    <img src="/images/guides/create-forms/email-verification-start.png" alt="Informar um endereço de e-mail e selecionar o botão de verificação" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Envie o código de verificação

    Na janela de verificação de e-mail, confira o endereço e clique em `Send code`. Um código de verificação de 6 dígitos será enviado para o endereço informado.

    <img src="/images/guides/create-forms/email-verification-send-code.png" alt="Selecionar o botão para enviar o código na janela de verificação" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    #### Informe o código e confira a conclusão da verificação

    Informe o código de 6 dígitos recebido por e-mail e clique em `Verify`. Após a verificação, a indicação `Verified` aparecerá abaixo do campo de e-mail.

    <img src="/images/guides/create-forms/email-verification-enter-code.png" alt="Informar o código de 6 dígitos recebido por e-mail" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <img src="/images/guides/create-forms/email-verification-complete.png" alt="Status de verificação concluída abaixo do campo de e-mail" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

- **Se o endereço de e-mail mudar**: o novo endereço deverá ser verificado novamente.
- **Se o código estiver incorreto ou expirado**: confira o endereço de e-mail e o código informado. Após o tempo de espera para reenvio, clique em `Resend code` para receber um novo código.
- **Use com Preenchimento obrigatório**: para coletar um endereço de e-mail de cada respondente, ative também `Preenchimento obrigatório`. Uma pergunta opcional com verificação de e-mail ainda pode ser enviada em branco.

<Callout type="info" title="Confira no formulário publicado">
A prévia não envia e-mails de verificação. Abra o formulário publicado para testar o processo real. Essa opção verifica o endereço informado no campo de e-mail e é independente da verificação de e-mail das permissões de acesso ao formulário.
</Callout>

## Campo de endereço

<img src="/images/guides/manage-forms/address-field-example.png" alt="Campo de endereço de entrega com busca de endereço" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Aceita apenas endereços da Coreia do Sul. Após buscar o endereço, o usuário pode informar o complemento.
- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Excluir respostas automaticamente

<Callout title="Dica">
Para proteger dados pessoais, recomendamos usar o mascaramento de dados e a exclusão automática de respostas nos campos de telefone, e-mail e endereço.
</Callout>
