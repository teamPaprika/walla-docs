## Criar um formulário com IA

<Steps>
  <Step>
    ### Clique em Criar projeto
    Na tela do espaço de trabalho, clique no botão `Criar projeto`.

    <img src="/images/guides/manage-forms/team-template-create-project.png" alt="Botão Criar projeto no canto superior direito do espaço de trabalho" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione Criar formulário com IA
    Selecione `Criar formulário com IA`.

    <img src="/images/guides/manage-forms/ai-create-form-select.png" alt="Opção Criar formulário com IA na janela de criação de um novo projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Digite uma instrução
    Descreva o formulário desejado em uma instrução.

    <img src="/images/guides/manage-forms/ai-prompt-input.png" alt="Tela de criação de formulário com IA para inserir uma instrução e clicar em Criar rascunho" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

    <Callout title="Exemplos básicos">
    - Crie uma pesquisa de satisfação do cliente.
    - Crie um formulário de feedback sobre a experiência de uso de um produto.
    - Crie uma pesquisa de opinião dos usuários para melhorar o serviço.
    </Callout>

    <Callout title="Exemplos com público e objetivo definidos">
    - Crie uma pesquisa de satisfação com o trabalho remoto para profissionais entre 20 e 29 anos.
    - Crie um formulário para coletar feedback de testadores beta antes do lançamento de um novo aplicativo.
    - Crie uma pesquisa de avaliação da qualidade das aulas para alunos de um curso on-line.
    </Callout>

    <Callout title="Exemplos com requisitos">
    - Crie um formulário com 5 perguntas de múltipla escolha e 2 perguntas abertas.
    - Crie um formulário simples que possa ser respondido em até 3 minutos.
    - Crie um formulário que colete a pontuação NPS e feedback detalhado.
    </Callout>
  </Step>
  <Step>
    ### Confira a prévia
    Confira a estrutura do formulário na prévia à direita. Se o resultado não for o esperado, você pode inserir outra instrução.

    <img src="/images/guides/manage-forms/ai-preview-result.png" alt="Perguntas geradas pela IA exibidas na área de prévia à direita" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Crie e edite o formulário
    Se estiver satisfeito com o resultado, clique em [Criar] para gerar o formulário. Depois, você poderá ajustá-lo livremente no editor.

    <img src="/images/guides/manage-forms/ai-form-editor.png" alt="Formulário gerado pela IA aplicado no editor" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

<Callout title="Dicas">
- Quanto mais específica for a instrução, mais preciso será o formulário gerado.
- Para gerar um formulário em outro idioma, indique o idioma desejado na solicitação.
  - Exemplo: "Crie uma pesquisa de satisfação do cliente em francês."
</Callout>
