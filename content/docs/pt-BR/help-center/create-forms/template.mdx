## Carregar um modelo

<Steps>
  <Step>
    ### Clique em Criar projeto
    Na tela do espaço de trabalho, clique no botão `Criar projeto`.

    <img src="/images/guides/manage-forms/team-template-create-project.png" alt="Botão Criar projeto no canto superior direito do espaço de trabalho" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione Usar modelo
    Selecione `Usar modelo`.

    <img src="/images/guides/manage-forms/team-template-select-template.png" alt="Opção Usar modelo na janela de criação de um novo projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione o modelo desejado
    Selecione o modelo da equipe desejado e clique em `Usar modelo`.

    <img src="/images/guides/manage-forms/template-preview-use.png" alt="Botão Usar modelo na tela de prévia do modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Conclua a criação
    Um novo projeto será criado com base no modelo selecionado.

    <img src="/images/guides/manage-forms/template-project-created.png" alt="Editor do novo projeto criado a partir do modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>
