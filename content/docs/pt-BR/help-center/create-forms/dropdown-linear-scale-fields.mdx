## Campo de lista suspensa

<img src="/images/guides/manage-forms/dropdown-field-example.png" alt="Lista suspensa aberta com busca de opções e lista de anos escolares" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Campo de seleção cuja lista de opções pode ser expandida ou recolhida.
- Útil para aproveitar melhor o espaço.
- Clique em `Editar opções` no canto inferior esquerdo para adicionar novas opções.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Clique no botão `…` (Mais opções) no canto inferior direito para acessar os recursos abaixo.
  - Adicionar opções em lote: insira várias opções de uma vez. *(Separe as opções com Enter.)*
  - Definir valores das opções: atribua um valor a cada opção. (Exemplo: definir a primeira opção como '1' → ela aparecerá como 1 na planilha de respostas.)

## Campo de escala linear

<img src="/images/guides/manage-forms/linear-scale-field-example.png" alt="Escala linear de 1 a 5 com rótulos de mínimo e máximo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Campo de seleção em uma escala numérica, ideal para pesquisas de satisfação e avaliações.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Você pode definir os valores mínimo e máximo:
  - O mínimo pode ser 1 ou 0.
  - O máximo pode ser um valor de 2 a 10.

- Adicione rótulos de mínimo e máximo nas extremidades para explicar claramente o significado dos valores.
