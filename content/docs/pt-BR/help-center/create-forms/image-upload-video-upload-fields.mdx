## Campo de captura de foto

<img src="/images/guides/manage-forms/photo-capture-field-example.png" alt="Editor de formulário com um campo de captura de foto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- O respondente pode abrir a câmera do dispositivo, tirar uma foto e enviá-la imediatamente.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Use para fotos de perfil, comprovação de presença, envio de evidências e outras finalidades.
- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Exclusão automática de respostas

## Campo de captura de vídeo

<img src="/images/guides/manage-forms/video-capture-field-example.png" alt="Editor de formulário com um campo de captura de vídeo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- O respondente pode gravar um vídeo em tempo real e enviá-lo.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Útil para respostas em formato de entrevista, avaliações de produtos e feedback em vídeo.
- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Exclusão automática de respostas
