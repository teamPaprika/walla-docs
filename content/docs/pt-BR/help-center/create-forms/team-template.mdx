## Criar um modelo da equipe

<Steps>
  <Step>
    ### Acesse a biblioteca de modelos
    Acesse a biblioteca de modelos.

    <img src="/images/guides/manage-forms/team-template-inventory.png" alt="Biblioteca da equipe > Biblioteca de modelos de formulário" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Carregue um modelo
    Clique no botão `Importar modelo`.

    <img src="/images/guides/manage-forms/team-template-load-button.png" alt="Botão Carregar modelo no canto superior direito da biblioteca de modelos" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione um projeto
    Selecione o projeto que deseja usar como modelo.

    <img src="/images/guides/manage-forms/team-template-select-project.png" alt="Lista suspensa de seleção do projeto na janela Carregar modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Configure as opções e salve
    Se necessário, defina se deseja carregar uma cópia, o modo de prévia (Visualização padrão ou Visualização agrupada) e a descrição do modelo. Clique em `Importar` para salvar como modelo da equipe.

    <img src="/images/guides/manage-forms/team-template-options-save.png" alt="Opções e botão Carregar na janela Carregar modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

- Os modelos carregados são gerenciados como recursos de toda a equipe e podem ser usados por todos os membros.

## Usar um modelo da equipe

<Steps>
  <Step>
    ### Crie um novo projeto
    Crie um novo projeto.

    <img src="/images/guides/manage-forms/team-template-create-project.png" alt="Botão Criar projeto no canto superior direito do espaço de trabalho" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione Usar modelo
    Selecione `Usar modelo`.

    <img src="/images/guides/manage-forms/team-template-select-template.png" alt="Opção Usar modelo na janela de criação de um novo projeto" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione Modelos da equipe
    Na lista de modelos, selecione os modelos da equipe.

    <img src="/images/guides/manage-forms/team-template-select-team-tab.png" alt="Aba Modelos da equipe no canto inferior esquerdo da janela Usar modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Selecione o modelo desejado
    Selecione o modelo da equipe desejado e clique em `Usar modelo`.

    <img src="/images/guides/manage-forms/team-template-preview-use.png" alt="Botão Usar modelo na tela de prévia do modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
  <Step>
    ### Conclua a criação
    Um novo projeto será criado com base no modelo selecionado.

    <img src="/images/guides/manage-forms/team-template-project-created.png" alt="Editor do novo projeto criado a partir do modelo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />
  </Step>
</Steps>

## Quando usar

- Formulários usados com frequência, como consultas de clientes, solicitações comerciais e pesquisas de satisfação
- Formulários que precisam seguir um padrão da empresa ou da equipe
- Situações em que novos membros precisam de um modelo de referência para criar formulários rapidamente

<Callout title="Dicas">
- Os modelos são recursos da equipe. Recomendamos salvar apenas projetos necessários como modelos.
- Projetos criados a partir de um modelo podem ser editados de forma independente do modelo original.
</Callout>
