## Campo de múltipla escolha

<img src="/images/guides/manage-forms/single-choice-field-example.png" alt="Campo de múltipla escolha com opções de seleção única" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- É uma pergunta de múltipla escolha em que o respondente pode selecionar apenas uma opção.
- Clique em `Adicionar opção` no canto inferior esquerdo para incluir mais opções, ou em 'Adicionar resposta livre' para permitir que o respondente digite outra resposta.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Clique no botão `…` (Mais opções) no canto inferior direito para acessar os recursos abaixo.
  - Adicionar opções em lote: insira várias opções de uma vez. *(Separe as opções com Enter.)*
  - Definir valores das opções: atribua um valor a cada opção. (Exemplo: definir a primeira opção como '1' → ela aparecerá como 1 na planilha de respostas.)
  - Embaralhar opções: exiba as opções em ordem aleatória para cada respondente.

- Opções disponíveis
  - Preenchimento obrigatório
  - Definir quantidade de seleções
  - Incluir opções
  - Excluir opções
  - Limitar respostas por opção
  - Mascaramento de dados
  - Exclusão automática de respostas

## Campo de caixas de seleção

<img src="/images/guides/manage-forms/multi-choice-field-example.png" alt="Campo de caixas de seleção com opções de palavras-chave e aviso de limite de duas seleções" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- É uma pergunta em que o respondente pode selecionar várias opções ao mesmo tempo.
- Você também pode usar os recursos `Adicionar opção` e `Adicionar resposta livre`.
- Use o [editor de texto](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#formatar-o-texto) para aplicar estilos como cor, tamanho e negrito.
- Use o [comando de barra (/)](https://docs.walla.my/pt-BR/docs/help-center/create-forms/editing-field-text#usar-recursos-adicionais-com-o-comando-de-barra) para inserir imagens, tabelas e títulos com facilidade.
- Clique no botão `…` (Mais opções) no canto inferior direito para acessar os recursos abaixo.
  - Adicionar opções em lote: insira várias opções de uma vez. *(Separe as opções com Enter.)*
  - Definir valores das opções: atribua um valor a cada opção. (Exemplo: definir a primeira opção como '1' → ela aparecerá como 1 na planilha de respostas.)
  - Embaralhar opções: exiba as opções em ordem aleatória para cada respondente.

## Opção exclusiva

- Você pode definir opções que não podem ser combinadas com outras, como 'Nenhuma das opções'.
- Ao selecionar uma opção exclusiva, todas as outras seleções da pergunta serão desmarcadas. Ao selecionar outra opção, a opção exclusiva será desmarcada.
- As regras de quantidade de seleções (mínima, máxima ou exata) não se aplicam à opção exclusiva.
- Passe o mouse sobre a opção, clique em `…` (Mais opções) e ative a opção exclusiva.
	<img src="/images/guides/manage-forms/exclusive-option-menu.png" alt="Menu de opção exclusiva aberto pelo botão de mais opções à direita de uma alternativa" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- As opções configuradas dessa forma recebem a indicação 'Opção exclusiva'.
