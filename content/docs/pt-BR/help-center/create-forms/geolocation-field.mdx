## Campo de localização

- O respondente pode clicar em `Obter localização` para compartilhar sua localização.
- Opções disponíveis
  - Preenchimento obrigatório
  - Mascaramento de dados
  - Exclusão automática de respostas

<Callout type="warning" title="Atenção">
Segundo as leis sul-coreanas de proteção de dados pessoais e de informações de localização citadas neste recurso, a coleta de localização exige o consentimento do usuário. Use a lógica e o campo de consentimento para coleta de dados pessoais para permitir que apenas quem consentiu responda ao campo de localização.
</Callout>
