## Campo de texto curto

<img src="/images/guides/manage-forms/short-text-field-example.png" alt="Campo de texto curto com uma linha para digitar a resposta" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Use para receber respostas curtas, de aproximadamente uma linha.
- Ideal para nome, profissão, comentários breves e outras respostas curtas.
- Clique no ícone de lápis para editar o texto de exemplo.
- Opções disponíveis
  - Preenchimento obrigatório
  - Limite de tamanho da resposta
  - A resposta deve incluir
  - A resposta não pode incluir
  - Expressão regular

## Campo de texto longo

<img src="/images/guides/manage-forms/long-text-field-example.png" alt="Campo de texto longo com área de várias linhas e texto de exemplo" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Use para receber respostas longas, com várias linhas.
- Ideal para opiniões detalhadas, feedback e respostas descritivas.
- Clique no ícone de lápis para editar o texto de exemplo.
- Opções disponíveis
  - Preenchimento obrigatório
  - Limite de tamanho da resposta
  - A resposta deve incluir
  - A resposta não pode incluir
  - Expressão regular

## Campo de número

<img src="/images/guides/manage-forms/number-field-example.png" alt="Campo de número para matrícula estudantil com o texto de exemplo 20XXXXXX" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Campo exclusivo para entrada de números.
- Use para coletar quantidades, idades, pontuações e outras respostas numéricas.
- Clique no ícone de lápis para editar o texto de exemplo.
- Opções disponíveis
  - Preenchimento obrigatório
  - Limite de intervalo numérico

<Callout type="warning" title="Atenção">
Se você coletar telefones em um campo de número, números que começam com '0' (como 010AAAABBBB) serão interpretados como valores numéricos e perderão o zero inicial. Para telefones, use um campo de texto curto ou o campo específico de telefone.
</Callout>

## Campo de tabela

<img src="/images/guides/manage-forms/table-field-example.png" alt="Campo de tabela com linhas e colunas para informar quantidades de bebidas em copos, garrafas, latas e cc" style={{ width: "100%", borderRadius: "8px", marginTop: "12px", marginBottom: "12px", border: "1px solid var(--border)" }} />

- Permite coletar várias respostas abertas de uma vez em formato de tabela.
- Organize os itens em linhas e colunas para comparar ou avaliar vários itens ao mesmo tempo.
- Opções disponíveis
  - Preenchimento obrigatório
